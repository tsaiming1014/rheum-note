    筆試

    1. T cell subset 與其分泌 cytokines 配對，何者錯誤？

    • Th1 → TNF-α
    • Treg → IL-21

    （原始題庫僅記錄此兩組配對，其餘選項未記錄）

    答案：Treg → IL-21

    解析：

    • Th1 → TNF-α：Th1 細胞的招牌 cytokine 是 IFN-γ，但 Th1 細胞確實也會分泌 TNF-α（與巨噬細胞活化、慢性發炎有關），所以這個配對本身不算錯誤敘述。
    • Treg → IL-21（錯）：IL-21 主要由 Tfh cell（follicular helper T cell）分泌，用來促進 germinal center 中 B cell 的存活與分化；Treg 的招牌 cytokines 是 TGF-β、IL-10（以及 IL-35），作用是抑制免疫反應、維持周邊耐受性。把 IL-21 歸在 Treg 底下混淆了 Tfh 與 Treg 兩個不同 CD4+ T cell 亞群的功能特徵。

    速記表：

    CD4+ T 亞群 招牌 cytokines 主要功能
    Th1 IFN-γ（也可分泌 TNF-α） 活化巨噬細胞，對抗胞內病原
    Th2 IL-4, IL-5, IL-13 對抗寄生蟲、過敏反應
    Th17 IL-17A/F, IL-22 對抗胞外菌、真菌；促進中性球招募
    Tfh IL-21 促進 germinal center B cell 分化、affinity maturation
    Treg TGF-β, IL-10, IL-35 免疫抑制、周邊耐受性

    2. miRNA 可抑制 mRNA translation

    （敘述題：判斷正確／錯誤）

    答案：正確

    解析：

    miRNA（microRNA）是一段約 20–22 個核苷酸的小分子非編碼 RNA，其作用機轉如下：

    • miRNA 由 pri-miRNA → pre-miRNA（經 Drosha 處理）→ 輸出到細胞質 → 經 Dicer 切割成熟 → 與 Argonaute 蛋白 等組成 RISC（RNA-Induced Silencing Complex）。
    • RISC 複合體中的 miRNA 會透過鹼基互補配對，結合到目標 mRNA 的 3' UTR 區域。
    • 依照互補程度不同，造成兩種結果：
    • 完全互補：直接切割降解該 mRNA。
    • 不完全互補（哺乳類較常見）：抑制 mRNA 的 translation（轉譯），或使其去腺苷化（deadenylation）而加速降解。

    miRNA 是重要的轉錄後基因表現調控機制，在免疫系統中也扮演角色（例如 miR-155、miR-146a 在發炎反應與自體免疫疾病中的調控功能常被拿來考）。

    3. T cell activation，何者錯誤？

    • TCR 活化後透過 calmodulin 活化 NF-κB

    （原始題庫僅記錄此一選項敘述，其餘選項未記錄）

    答案：此敘述錯誤

    正確敘述應為：TCR 活化後，鈣離子與 calmodulin 結合形成複合體，進而活化 calcineurin（一種磷酸酶），calcineurin 去磷酸化 NFAT，使其進入細胞核 —— 這條路徑活化的是 NFAT，不是 NF-κB。

    解析：

    TCR 活化後下游其實分成兩條平行路徑，分別活化 NFAT 與 NF-κB，兩者容易被考題混淆：

    路徑一（→ NFAT）： TCR/CD3 複合體活化 → ZAP-70 → PLCγ 活化 → 水解 PIP2 → 產生 IP3 → 細胞內鈣離子（Ca²⁺）上升 → Ca²⁺ 結合 calmodulin → calmodulin-Ca²⁺ 複合體活化磷酸酶 calcineurin → calcineurin 去磷酸化 NFAT → NFAT 進入細胞核，驅動 IL-2 等基因轉錄。

    路徑二（→ NF-κB）： PLCγ 水解 PIP2 同時也產生 DAG（diacylglycerol） → 活化 PKCθ → 組裝 CBM 複合體（CARMA1–BCL10–MALT1） → 活化 IKK → 磷酸化並降解 IκB → 釋放的 NF-κB 進入細胞核。

    速記重點： Calcium/calmodulin/calcineurin 這條線只走到 NFAT；NF-κB 是走 DAG/PKCθ/CBM/IKK 這條完全不同的線。這也是 calcineurin inhibitor（cyclosporine、tacrolimus） 的藥理基礎 —— 它們專一抑制 calcineurin，阻斷 NFAT 活化，而不影響 NF-κB 路徑。

    題目陷阱：把兩條路徑的分子接錯線（calmodulin 接到 NF-κB），是免疫學考題常見的混淆設計，需清楚記住「calcium 系統 → NFAT」、「DAG/PKC 系統 → NF-κB」。

    4. RA animal model 驗證新藥效果的是哪個？

    （原始題庫僅記錄題目本身，選項未記錄）

    答案：CIA（Collagen-Induced Arthritis，膠原誘導性關節炎）

    解析：

    CIA 是目前最常用於驗證 RA 新藥療效的動物模型：

    • 誘發方式：對易感基因型小鼠（如 DBA/1 品系，MHC class II 為 H-2q）以 type II collagen（軟骨主要成分）加上 complete Freund's adjuvant 免疫，誘發對自身 type II collagen 的自體免疫反應。
    • 機轉：產生 anti-type II collagen 抗體與致病性 T 細胞，攻擊關節軟骨，造成類似 RA 的多關節炎、滑膜炎、軟骨破壞與骨侵蝕。
    • 優點：病理表現（滑膜炎、pannus 形成、軟骨/骨破壞）與人類 RA 相似度高，且對多種已上市藥物（如 anti-TNF、MTX）有反應，是藥物開發階段的標準篩選模型。

    其他常見 RA 動物模型（輔助記憶用）：

    模型 誘發方式 特色
    CIA Type II collagen + adjuvant 免疫 最常用於新藥驗證，病理最接近人類 RA
    K/BxN serum transfer 轉輸 K/BxN 小鼠血清（含 anti-GPI 抗體） 快速誘發關節炎，用於研究效應期機轉
    Adjuvant-induced arthritis (AIA) Complete Freund's adjuvant 注射於大鼠 較早期模型，機轉較不具專一性
    TNF-transgenic mice 持續過度表現 human TNF-α 用於研究 TNF 在 RA 致病機轉中的角色

    5. 關節滑膜 hyaluronan 的主要分泌細胞？

    • Type A synovial lining cell
    • Type B synovial lining cell
    • Chondrocyte

    答案：Type B synovial lining cell

    解析：

    滑膜內襯層（synovial lining）主要由兩種細胞組成，功能分工明確，是常考的鑑別重點：

    細胞類型 別名 來源 主要功能
    Type A synoviocyte Macrophage-like synoviocyte 骨髓單核球系 吞噬作用、清除關節腔內廢物與碎屑、抗原呈現
    Type B synoviocyte Fibroblast-like synoviocyte (FLS) 間葉源（mesenchymal） 分泌 hyaluronan（玻尿酸）與 lubricin，維持關節液潤滑；也分泌 type IV/V/VI collagen 構成滑膜基質
    • Type B synoviocyte（FLS） 是滑膜液中 hyaluronan 的主要來源，透過細胞膜上的 HAS（hyaluronan synthase，尤其 HAS2） 合成，提供關節液黏彈性、潤滑功能。
    • 在 RA 的致病機轉中，Type B synoviocyte（FLS） 也是關鍵的效應細胞之一：受 TNF-α、IL-1β 刺激後會過度增生，並分泌 MMPs、RANKL 等，直接參與 pannus 形成與軟骨/骨破壞（呼應第 6、7 題的內容）。
    • Chondrocyte 是軟骨細胞，位於軟骨基質內，不屬於滑膜襯層細胞，主要功能是製造與維持軟骨基質（collagen type II、proteoglycan），並非 hyaluronan 的主要來源。

    6. 參與軟骨 matrix 分解的主要 cytokine？

    • IL-1
    • IL-6
    • IL-17

    答案：IL-1（IL-1β）（使用者原答 IL-6，經核對後判斷不同，詳見下方解析）

    解析：

    • IL-1β（正解）：是驅動軟骨 matrix 分解最主要的 cytokine。IL-1β 刺激 chondrocyte 與 synoviocyte 大量產生 MMPs（matrix metalloproteinases，尤其 MMP-1、MMP-3、MMP-13） 與 aggrecanases（ADAMTS-4/5），分別分解 type II collagen 與 proteoglycan（aggrecan），是軟骨基質破壞的核心驅動者；同時 IL-1β 抑制 chondrocyte 合成新的 matrix，造成分解與合成失衡。TNF-α 作用類似，兩者常並列為軟骨破壞主力 cytokine。
    • IL-6：主要角色是全身性發炎反應（急性期蛋白生成）、促進 Th17 分化、促進 osteoclastogenesis（骨侵蝕），對軟骨 matrix 的直接分解作用不如 IL-1β/TNF-α 明確，較偏向「骨」破壞而非「軟骨」matrix 直接降解。
    • IL-17：可協同 IL-1、TNF-α 增強 MMP 產生，也參與軟骨破壞，但單獨作用力較弱，通常視為輔助角色。

    速記： 軟骨破壞 → IL-1β / TNF-α（直接刺激 MMPs、aggrecanases）；骨破壞（osteoclast）→ RANKL、IL-6、IL-17。

    7. 何者可以抑制 osteoclasts 產生？

    （原始題庫記錄選項：osteoprotegerin）

    答案：Osteoprotegerin（OPG）

    整理：RANKL–RANK–OPG 軸（osteoclast 生成調控核心機轉）

    破骨細胞（osteoclast）分化由 RANKL–RANK–OPG 系統 主導：

    分子 來源 角色
    RANKL（receptor activator of NF-κB ligand） Osteoblast、活化的 T 細胞、Type B synoviocyte（FLS） 與 osteoclast 前驅細胞（單核球系）上的 RANK 結合，促進其分化、融合、活化成成熟 osteoclast
    RANK Osteoclast 前驅細胞表面受體 接收 RANKL 訊號 → 活化 NF-κB、NFATc1 → 驅動 osteoclast 分化基因表現
    OPG（osteoprotegerin） Osteoblast、fibroblast 等分泌的可溶性 decoy receptor 競爭性結合 RANKL，阻止 RANKL 與 RANK 結合 → 抑制 osteoclast 分化與活化

    機轉重點：

    • OPG 本身不是細胞膜受體，而是分泌型的誘餌受體（decoy receptor），透過「搶走 RANKL」來間接抑制骨吸收，並不直接作用在 osteoclast 前驅細胞上。
    • RANKL/OPG 比值是判斷骨吸收活性的重要指標：比值上升 → 骨破壞增加（如 RA 關節周圍骨侵蝕、停經後骨質疏鬆）；比值下降 → 骨吸收受抑制。
    • 這也是生物製劑 Denosumab 的藥理基礎：Denosumab 是抗 RANKL 單株抗體，作用機轉等同「人工版的 OPG」，直接中和 RANKL，抑制 osteoclast 生成，用於治療 osteoporosis 及 RA 相關骨侵蝕的輔助治療。
    • 促發炎 cytokines（TNF-α、IL-1β、IL-6、IL-17）會上調 osteoblast/synoviocyte 表現 RANKL，這正是 RA 慢性發炎導致骨侵蝕的機轉橋樑。

    其他選項排除：若考題另有 M-CSF、RANK、RANKL 等選項 —— M-CSF 與 RANKL 是促進 osteoclast 分化的必要因子（並非抑制），RANK 是受體本身，只有 OPG 具有抑制作用。

    8. SjS 流行病學，何者錯誤？

    • 原發性乾燥症盛行率高達 10–15%

    答案：此敘述錯誤

    解析：

    • 原發性 Sjögren's syndrome（pSjS）的真實盛行率約為 0.01–0.1%（依不同族群估計約每千人 0.1–4 人），並非 10–15%。10–15% 明顯過高，是常見混淆設計。
    • 容易被搞混的原因：乾燥症狀（dry eye/dry mouth）本身在一般族群、尤其停經後女性中相當常見，粗估可達 10–30%（單純症狀盛行率），但這不等於「符合分類標準的 pSjS 疾病」盛行率。
    • SjS 好發於中年女性，男女比約 1:9。

    延伸記憶：

    • 好發年齡：40–60 歲。
    • 續發性 Sjögren's syndrome（合併 RA、SLE 等其他 CTD）比原發性更常見。
    • 淋巴瘤風險（尤其 MALT lymphoma）較一般族群顯著增加（約 5–20 倍），高風險因子：持續性腮腺腫大、低補體（C4）、cryoglobulinemia、CD4+ lymphopenia、purpura。

    9. IIM 與 cancer 關聯性的相關描述，何者錯誤？

    • 男性 SLE 患者得到攝護腺癌的風險較高
    • （另一選項）IIM 得到 cancer 的危險因子為 old age、ILD、periungual erythema

    答案：「男性 SLE 患者得到攝護腺癌的風險較高」為錯誤選項

    解析：

    • 本題問的是 IIM 與 cancer 的關聯，但此選項討論的是 SLE 患者的攝護腺癌風險——SLE 與 IIM 是不同疾病，範疇錯置本身就是此選項錯誤的核心原因。
    • 進一步而言，目前實證上也沒有明確證據支持男性 SLE 患者攝護腺癌風險特別升高；SLE 與惡性腫瘤的關聯較常討論的是淋巴瘤（尤其 non-Hodgkin lymphoma）風險上升。

    IIM 與 cancer 關聯性重點整理：

    • IIM（尤其 dermatomyositis）合併惡性腫瘤（cancer-associated myositis, CAM）風險顯著升高，好發於診斷 IIM 前後 1–3 年內。
    • 最常見相關癌症：卵巢癌、肺癌、大腸直腸癌、鼻咽癌（尤其亞洲族群）、淋巴瘤。
    • 危險因子：old age（診斷年齡較大）、periungual erythema（甲周紅斑）、cutaneous necrosis、快速惡化的皮膚病灶、dysphagia、快速發病的肌肉症狀，以及 anti-TIF1-γ（p155/140）、anti-NXP2 陽性（目前最強的 cancer 預測抗體）。
    • ⚠️ ILD 與 cancer 風險的關係較特殊：多數文獻顯示合併 ILD 或 anti-synthetase / anti-MDA5 抗體陽性者，cancer 風險反而較低；此處若原題選項將 ILD 列為危險因子，屬於考古題記憶版本可能與主流文獻有出入之處，建議核對原題完整選項。

    10. IgG4-RD，何者錯誤？

    • 可以依賴 IgG4 level 追蹤疾病活動度與復發

    答案：此敘述錯誤

    解析：

    • 血清 IgG4 濃度與 IgG4-RD 的疾病活動度、復發風險之間的相關性並不佳，不應單獨依賴 IgG4 level 追蹤病情：
    • 部分活動性 IgG4-RD 病人 IgG4 可能正常（尤其疾病早期或侷限性病灶）。
    • 治療後 IgG4 下降幅度與臨床反應不一定平行。
    • IgG4 升高也可見於其他情況（如 atopic disease、寄生蟲感染、部分 pemphigus），特異性不足。
    • 追蹤 IgG4-RD 疾病活動度建議採綜合評估：臨床症狀、受侵犯器官的影像學變化、發炎指數，必要時輔以其他血清標記一起判讀，而非單看 IgG4 這一項數值。

    延伸記憶：

    • 好發器官：胰臟（autoimmune pancreatitis type 1）、唾液腺／淚腺（Mikulicz's disease）、後腹腔纖維化、膽管、腎臟、肺、淋巴結，常為多器官侵犯。
    • 病理特徵：storiform fibrosis（席紋狀纖維化）、obliterative phlebitis（閉塞性靜脈炎）、大量 IgG4+ plasma cell 浸潤（IgG4+/IgG+ 比值 >40%）。
    • 對 glucocorticoid 反應通常良好，復發時可考慮 Rituximab（CD20）。

    11. SLE 及抗病毒為下列哪個 cytokines？

    • IL-1
    • IL-6
    • IFN-α
    • IL-33

    答案：IFN-α

    解析：

    • Type I interferon（IFN-α/β） 是 SLE 致病機轉的核心 cytokine，同時也是機體對抗病毒感染的第一線抗病毒 cytokine：
    • 抗病毒機轉：病毒核酸（RNA/DNA）被 pDC（plasmacytoid dendritic cell）上的 TLR7/TLR9 等 PRR 辨識後，誘導大量分泌 IFN-α，進而誘導細胞內多種抗病毒蛋白（如 OAS、PKR、Mx 蛋白）表現，抑制病毒複製。
    • SLE 致病機轉：SLE 病人體內持續存在的自身核酸（來自 NETosis 釋出的 dsDNA、apoptotic cell debris 等）與抗核抗體形成 immune complex，被 pDC 上的 TLR7/9 辨識，導致 IFN-α 持續、過度分泌，形成所謂的「interferon signature」，驅動下游 B 細胞活化、自體抗體產生、慢性發炎。
    • 這也是抗 IFN 通路藥物 Anifrolumab（抗 IFNAR1，阻斷所有 type I IFN 的下游訊息） 用於治療 SLE 的機轉基礎。

    其他選項排除：

    • IL-1：主要驅動 NLRP3 inflammasome 相關的自體發炎反應（如 gout、CAPS），非 SLE 的招牌 cytokine，也非典型抗病毒 cytokine。
    • IL-6：SLE 中也會升高（與疾病活動度、狼瘡腎炎有關），但主要角色是促進 B 細胞分化、急性期反應，非抗病毒的代表 cytokine。
    • IL-33：屬於 IL-1 家族的 alarmin，主要活化 ILC2、Th2 免疫反應（過敏、纖維化相關），與抗病毒、SLE 的關聯性均不如 IFN-α 明確。

    12. COVID-19 thrombosis 可測何種抗體？

    答案：Anti-PF4（platelet factor 4）抗體

    解析：

    • Anti-PF4 抗體是自身抗體，會辨識 platelet factor 4（PF4） 與 heparin（或某些疫苗成分）形成的複合物，結合後活化血小板上的 Fcγ receptor（FcγRIIa），導致血小板過度活化、聚集，引發血小板減少合併血栓（thrombocytopenia + thrombosis）。
    • 在 COVID-19 相關情境中主要見於兩種狀況：
    • VITT（Vaccine-Induced Immune Thrombocytopenia and Thrombosis）：發生於接種腺病毒載體疫苗（如 AstraZeneca、Johnson & Johnson）後，機轉類似 HIT（heparin-induced thrombocytopenia），但通常未使用過 heparin，故稱為「HIT-like / autoimmune HIT」。特徵是不常見部位的血栓（如 cerebral venous sinus thrombosis、splanchnic vein thrombosis）合併血小板低下，anti-PF4 抗體強陽性。
    • COVID-19 感染本身：重症患者也可誘發一過性的 anti-PF4 或抗磷脂抗體（aPL）陽性，與 COVID-19 相關凝血病變有關，但通常感染痊癒後會消退，不像 VITT 那樣持續強陽性。
    • 檢測與治療關聯：anti-PF4 陽性合併臨床疑似 VITT 時，治療上避免使用 heparin（機轉類似 HIT），改用非 heparin 類抗凝劑（如 argatroban、fondaparinux、DOAC），並可考慮 IVIG 阻斷 Fc receptor 活化路徑。

    延伸鑑別：

    情境 抗體 特徵性血栓部位
    HIT（傳統肝素誘發） Anti-PF4/heparin 靜脈或動脈血栓，多為肢體
    VITT（疫苗誘發） Anti-PF4（不需 heparin 暴露） 腦靜脈竇栓塞、內臟靜脈栓塞
    COVID-19 相關凝血病變 可有 aPL、anti-PF4（多為一過性） 肺栓塞常見，也可見微血栓

    14. SLE 何種抗體有光敏感性（photosensitivity）？

    答案：Anti-Ro（SSA）（使用者原答 Anti-dsDNA，經核對後判斷不同，詳見下方解析）

    解析：

    • Anti-Ro/SSA 抗體與 SLE 的光敏感性（photosensitivity）及特定皮膚表現關係最密切：
    • 與 subacute cutaneous lupus erythematosus（SCLE） 高度相關——SCLE 的皮疹典型分佈在日曬暴露部位（臉、頸、上胸、上背、手臂伸側），對紫外線特別敏感。
    • 與 neonatal lupus（新生兒狼瘡，包含先天性心臟傳導阻滯、皮膚病灶）相關，母體 anti-Ro 抗體經胎盤傳給胎兒所致。
    • 機轉上，紫外線照射造成角質細胞凋亡（apoptosis），使原本位於細胞核內的 Ro 抗原轉位到細胞膜表面，被局部的抗 Ro 抗體結合，誘發局部發炎反應，造成光敏感性皮疹。
    • Anti-dsDNA 則主要與疾病整體活動度（尤其配合補體 C3/C4 下降）及狼瘡腎炎相關，與光敏感性並非典型/直接相關的抗體。

    SLE 抗體與臨床表現配對（延伸記憶）：

    抗體 相關臨床表現
    Anti-Ro/SSA 光敏感性、SCLE、neonatal lupus（含 congenital heart block）
    Anti-La/SSB 常與 anti-Ro 併存，neonatal lupus 風險更高
    Anti-dsDNA 疾病活動度、狼瘡腎炎
    Anti-Sm SLE 高特異性抗體（診斷用），與特定器官受侵犯無強關聯
    Anti-RNP Raynaud's phenomenon、MCTD（混合性結締組織病）
    Anti-ribosomal P Neuropsychiatric lupus（尤其 lupus psychosis）
    Antiphospholipid Ab 血栓、習慣性流產（APS 重疊）

    16. PM 病人有 ILD，與何種抗體有關？

    • Anti-synthetase
    • Anti-MDA5
    • Anti-dsDNA

    答案：Anti-synthetase

    解析：

    • Anti-synthetase antibody（最常見為 anti-Jo-1，其餘還有 PL-7、PL-12、EJ、OJ、KS 等）是與 PM/DM 合併 ILD 關聯性最經典、最強的一組抗體，構成所謂的 antisynthetase syndrome，其臨床五大特徵：
    • 肌炎（myositis）
    • ILD（常為 non-specific interstitial pneumonia, NSIP，或 organizing pneumonia）
    • 關節炎（non-erosive）
    • Raynaud's phenomenon
    • Mechanic's hand（技工手，手指外側粗糙皸裂脫皮）
    • 題目問的是 PM（polymyositis）病人的 ILD，而 antisynthetase syndrome 病人可表現為 PM 或 DM 的肌肉病理型態，因此 anti-synthetase 是與 PM 合併 ILD 關聯性最直接、最經典的答案。

    其他選項辨析：

    • Anti-MDA5：也與 ILD 高度相關（尤其 rapidly progressive ILD, RP-ILD），但典型上更常見於臨床上肌肉症狀輕微甚至無肌炎的皮肌炎（clinically amyopathic dermatomyositis, CADM），而非典型 PM，是本題重要干擾選項。
    • Anti-dsDNA：是 SLE 的特異性抗體，與 IIM（PM/DM）或 ILD 均無關。

    速記表：

    抗體 好發疾病型態 ILD 特色
    Anti-synthetase（Jo-1 等） PM/DM（antisynthetase syndrome） 慢性、NSIP/OP 型態為主
    Anti-MDA5 常表現為 CADM（皮膚病灶顯著，肌肉症狀輕微或無） Rapidly progressive ILD，預後差
    Anti-dsDNA SLE（非 IIM） 不相關
