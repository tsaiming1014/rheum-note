    1. 下列配對何者錯誤

    • A IL-17a & f 配對的 receptor
    • B IL-4/13 配對的 receptor
    • C BAFF 配對 TACI、BCMA
    • D IL-12/23 配對的 receptor

    ⚠️ 選項記錄不完整：原始題庫只記錄了「配對的類別」，沒有記錄題目實際給出的具體錯誤配對內容，無法判斷正確答案。以下整理相關機轉作為複習參考：

    • IL-17A/F receptor：IL-17A 與 IL-17F 皆透過 IL-17RA + IL-17RC 異二聚體受體傳訊。
    • IL-4/13 receptor：
    • Type I receptor（IL-4Rα + γc）→ 只有 IL-4 能結合，主要在造血細胞表現
    • Type II receptor（IL-4Rα + IL-13Rα1）→ IL-4 與 IL-13 皆可結合，在非造血細胞（如上皮細胞）表現，也是 Dupilumab（anti-IL-4Rα）能同時阻斷兩者訊息的原因
    • BAFF receptor：BAFF 可結合 三個 receptor：BAFF-R (BR3)、TACI、BCMA；APRIL 只結合 TACI、BCMA，不結合 BAFF-R，是兩者常見的鑑別考點。
    • IL-12/23 receptor：無「IL-12Rα」此正式名稱，正確為 IL-12Rβ1（IL-12 與 IL-23 共用）+ IL-12Rβ2（IL-12 專屬）；IL-23 則為 IL-12Rβ1 + IL-23R。訊息傳遞上 IL-12Rβ1 走 TYK2、IL-12Rβ2 走 JAK2，下游主要活化 STAT4。

    2. Inflammasome、caspase-1 會使細胞內前驅物產生下列何者？

    • A IL-1-alpha
    • B IL-18
    • C （未記錄）
    • D （未記錄）

    答案：B

    ⚠️ 原始題庫記錄標記答案為 A，與此處判斷不同，請自行核對。

    解析：

    • B（對） Inflammasome 活化後，caspase-1 會切割 pro-IL-1β → mature IL-1β、pro-IL-18 → mature IL-18，這是 caspase-1 最經典的兩個受質（連同 gasdermin D，切割後造成 pyroptosis）。
    • A（錯，題庫原記錄可能有誤） IL-1α 不是 caspase-1 的受質。Pro-IL-1α 本身即具有生物活性（不需要切割就能作用），主要是由 calpain（而非 caspase-1）在細胞壞死時切割釋放，屬於 alarmin 性質的 cytokine，與 inflammasome/caspase-1 路徑機轉不同，是常見的考試陷阱（IL-1α vs IL-1β 混淆）。

    速記：

    Cytokine 是否需 caspase-1 切割才有活性 主要切割酵素
    IL-1β 是 Caspase-1（inflammasome）
    IL-18 是 Caspase-1（inflammasome）
    IL-1α 否（前驅物即有活性） Calpain（壞死釋放時）

    3. 下列哪個 cytokine 不會與 JAK1, JAK2 反應

    • A IL-2
    • B IL-5
    • C TNF-alpha
    • D IL-10

    答案：C

    解析：

    • A（錯，會與 JAK1 反應） IL-2 屬於 common gamma chain (γc) family（IL-2, 4, 7, 9, 15, 21），receptor 由 IL-2Rβ（結合 JAK1）+ γc（結合 JAK3） 組成，走 JAK1-JAK3，不是 JAK2，但仍與 JAK1 有關。
    • B（錯，會與 JAK2 反應） IL-5 屬於 common beta chain (βc) family（IL-3, IL-5, GM-CSF），receptor 走 JAK2 同型二聚體（JAK2-JAK2）。
    • C（對） TNF-α 完全不透過 JAK-STAT 路徑傳訊，而是結合 TNF receptor (TNFR1/TNFR2)，經由 TRADD、TRAF、RIP1 等 adaptor 分子活化 NF-κB 與 MAPK pathway，與 JAK1、JAK2 皆無關。
    • D（錯，會與 JAK1 反應） IL-10 receptor 走 JAK1（IL-10R1）+ TYK2（IL-10R2），不是 JAK2，但仍與 JAK1 有關。

    gp130 family IL-6, IL-11 JAK1 + JAK2 + TYK2
    IL-10 family IL-10, 19, 20, 22 JAK1 + TYK2
    Type I/II IFN IFN-α/β, IFN-γ JAK1/JAK2/TYK2（依型別）
    TNF superfamily TNF-α 不走 JAK-STAT，走 TNFR → NF-κB

    5. 下列何者跟鐵離子最相關

    • A Apoptosis
    • B Necroptosis
    • C Pyroptosis
    • D Ferroptosis

    答案：D

    解析：

    • D（對） Ferroptosis 是一種鐵離子依賴的細胞死亡形式，核心機轉是細胞內鐵離子過量、觸發 Fenton reaction 產生活性氧自由基，加上 glutathione peroxidase 4 (GPX4) 功能不足（無法清除脂質過氧化物），導致細胞膜上的多元不飽和脂肪酸大量脂質過氧化 (lipid peroxidation)，最終使細胞膜崩解死亡。與鐵離子代謝、GPX4、脂質過氧化直接相關，是四種死亡機轉中唯一以鐵離子為核心驅動力的。

    四種細胞死亡機轉比較：

    機轉 觸發方式 關鍵分子 是否促發炎 風濕科相關疾病
    Apoptosis 程式性死亡（內在/外在路徑） Caspase-3, -8, -9；Bcl-2 家族 通常不促發炎（細胞膜維持完整，形成 apoptotic body 被吞噬清除） 清除自體反應性淋巴球失敗與 SLE 等自體免疫病發生相關
    Necroptosis 程式性壞死（TNFR 活化但 caspase-8 被抑制時啟動） RIPK1、RIPK3、MLKL（MLKL 造成細胞膜穿孔） 促發炎（細胞膜破裂，釋出 DAMP） 慢性發炎性疾病、IBD 相關關節炎的機轉之一
    Pyroptosis Inflammasome 活化 Caspase-1（或 caspase-4/5/11）切割 Gasdermin D，形成細胞膜孔洞 強烈促發炎（釋出成熟 IL-1β、IL-18） 痛風（MSU 結晶活化 NLRP3 inflammasome）、CAPS 等 autoinflammatory disease
    Ferroptosis 鐵依賴脂質過氧化 鐵離子、GPX4 功能不足、脂質過氧化 可促發炎（釋出 DAMP），機轉與前三者不同 近年研究與 SLE、RA 滑膜細胞死亡、器官損傷有關（仍在研究中）

    Pyroptosis 在痛風的完整路徑： MSU 結晶被 macrophage 吞噬 → 活化 NLRP3 inflammasome（NLRP3 + ASC + pro-caspase-1）→ caspase-1 活化 → 切割 pro-IL-1β → IL-1β、pro-IL-18 → IL-18，同時切割 Gasdermin D 使其 N 端片段插入細胞膜形成孔洞 → 細胞爆裂 → 大量 IL-1β、IL-18、DAMP 釋出，放大發炎反應，是急性痛風紅腫熱痛的核心機轉，也是 Anakinra、Canakinumab（anti-IL-1）在頑固性痛風可發揮療效的理論基礎。

    2. Neonatal lupus / Congenital heart block (CHB)

    • 母親帶有 anti-Ro (Ro52 和/或 Ro60)、anti-La 抗體，經胎盤傳遞至胎兒，攻擊胎兒心臟傳導系統，導致 third-degree AV block，是 neonatal lupus 最嚴重且不可逆的表現。
    • 機轉上，anti-Ro52 被認為與胎兒心臟 Cav1.2 calcium channel 及 5-HT4 receptor 有交叉反應，被視為造成 CHB 較關鍵的抗體，但 anti-Ro60、anti-La 也都與 CHB 風險相關，不是只有單一抗體。
    • 曾生過 CHB 病兒的母親，下一胎再發生的風險約 12–20%，是抗 Ro/La 陽性孕婦產檢需密切胎兒心臟監測的原因。

    3. ANA 陰性但 Ro52/Ro60 陽性的 SLE

    • 部分 SLE（尤其 subacute cutaneous lupus, SCLE）病人可以 ANA 陰性但 anti-Ro60 陽性。
    • 原因是常規 HEp-2 cell-based IFA 檢測 ANA 時，Ro60 抗原在細胞固定過程中容易流失或表現量低，導致 IFA 偵測不到，但用特異性 anti-Ro/SSA ELISA 卻可測到陽性，造成「ANA(-) 但 anti-Ro(+)」的現象（Kelly Ch055 指出這可能占「ANA 陰性 SLE」超過一半的原因）。
    • 臨床意義：懷疑 SCLE 或 Sjogren 相關疾病時，即使 ANA 陰性也應加做 anti-Ro/La，不能單靠 ANA 陰性排除診斷。

    4. Ro52 與 ILD、PAH 的關聯

    • Anti-Ro52 常與 anti-synthetase syndrome（尤其合併 anti-Jo-1） 及 systemic sclerosis 並存，並被多篇研究認為是 ILD 較嚴重、進展較快、預後較差的預測因子。
    • 在 SSc 族群，anti-Ro52/TRIM21 被 Kelly 教科書列為與 PAH 相關的抗體之一（與 anti-centromere、anti-U3 RNP、anti-Th/To、anti-Ku、anti-U1 RNP 並列）。

    9. 一位阿嬤右肩急性疼痛，去年有外傷病史，近一年右肩常痠痛、上舉困難。沒有發燒、右肩腫脹、活動受限。X 光顯示關節狹窄與退化、旋轉肌袖（rotator cuff）與二頭肌的肌腱鈣化。超音波抽 12cc 關節液：translucent with blood streaks, poor viscosity, WBC 2500/HPF, no MSU or CPPD crystal。下列診斷關節炎的步驟何者最適合？

    • A MR arthrography
    • B Arthroscopy with synovial biopsy
    • C 關節液細菌培養
    • D Alizarin red stain

    答案：A

    這題的臨床情境其實是在描述典型的 Milwaukee shoulder syndrome（BCP crystal-associated destructive arthropathy / cuff-tear arthropathy）：老年女性、慢性肩部疼痛與上舉困難（提示 rotator cuff 病灶）、X 光顯示關節退化狹窄合併肌腱鈣化（BCP/hydroxyapatite 沉積）、關節液呈血樣、poor viscosity、輕度發炎性 WBC（非化膿性）、未見 MSU 或 CPPD 結晶——這正是 BCP crystal arthropathy 的經典關節液特徵（BCP 結晶在一般偏光顯微鏡下不易看到）。

    解析：

    • A（對） 此病人核心問題是大範圍 rotator cuff tear 合併其導致的退化性關節病變（cuff tear arthropathy），MR arthrography 能提供最精確的 rotator cuff 完整性、肩關節盂唇（labrum）與關節腔結構評估，是釐清「造成此關節破壞的根本原因」最適合的下一步檢查，對後續治療決策（保守 vs 手術）也最關鍵。
    • B（錯） Arthroscopy with synovial biopsy 屬於較侵入性的檢查，通常保留給懷疑感染、腫瘤浸潤或診斷仍不明確時使用，並非此情境下的首選步驟。
    • C（錯） 關節液細菌培養用於懷疑化膿性關節炎時；此病人無發燒、WBC 僅 2500/HPF（遠低於化膿性關節炎常見的 >50,000/μL），臨床上不支持感染，優先度低。
    • D（錯，但為重要鑑別知識點） Alizarin red S stain 是用來偵測 BCP（basic calcium phosphate/hydroxyapatite）結晶的特殊染色，因為 BCP 結晶太小、在一般偏光顯微鏡下無法像 MSU（negative birefringent）、CPPD（weakly positive birefringent）一樣被辨識，需要靠 Alizarin red 染色間接證實。這個病人的關節液型態（bloody, poor viscosity, no MSU/CPPD）高度懷疑 BCP crystal 沉積，Alizarin red 可以確認診斷（Milwaukee shoulder），但題目問的是「診斷關節炎（即找出破壞根源）最適合的步驟」，MR arthrography 對於評估合併的大範圍 rotator cuff tear 及後續治療規劃更為關鍵，故仍以 A 為優先。

    11. 下列眼睛併發症和藥物史的關係，何者錯誤？

    • A Hydroxychloroquine 可能會造成 retinal maculopathy
    • B Adalimumab 可能會造成 uveitis
    • C Dupilumab 可能會造成 conjunctivitis

    答案：B（此為錯誤敘述）

    解析：

    • A（正確敘述） Hydroxychloroquine (HCQ) 長期使用具有劑量與療程相關的視網膜毒性，典型為 bull's eye maculopathy（雙眼對稱的環狀視網膜色素上皮病變），是 HCQ 病人需定期眼科篩檢（baseline + 每年）的原因。
    • B（錯誤敘述，本題答案） Adalimumab（anti-TNF 單株抗體）不是造成 uveitis 的藥物，反而是治療 uveitis 的藥物之一（尤其用於 Behçet's disease、JIA-associated uveitis、難治性葡萄膜炎）。臨床上真正與誘發或惡化 uveitis 相關的 anti-TNF 藥物是 Etanercept（TNF receptor fusion protein，非單株抗體），機轉推測與其藥物結構（非單株抗體、半衰期短、無法有效中和膜結合型 TNF）有關，因此 Etanercept 在有葡萄膜炎病史或高風險（如 axSpA 合併 uveitis）病人中通常不列為優先選擇，而是選 Infliximab、Adalimumab。

    • D（正確敘述） Cevimeline（muscarinic agonist，用於治療 Sjogren's 相關口乾）具擬副交感神經作用，會造成瞳孔收縮，在隅角閉鎖型青光眼（narrow/angle-closure glaucoma）病人可能誘發或惡化眼壓上升，臨床使用前須詢問青光眼病史並小心評估。

    • A（最不相關，本題答案） 帶狀皰疹（Herpes zoster） 典型表現是單側、沿著皮節（dermatomal）分布的群聚水泡，通常侷限在單一皮節範圍，不會表現為雙下肢大範圍、對稱性的水泡，與此臨床圖像不符，鑑別診斷幫助最小。

    A. HCQ 對 pSS 關節痛（arthralgia）有無統計顯著改善效果

    • 最重要證據來自 JOQUER trial（Gottenberg et al., Ann Rheum Dis 2014）——法國多中心 RCT，將 pSS 病人隨機分派使用 HCQ 或 placebo 24 週。

    MTX（Methotrexate）與腎功能的關係，主要是雙向的：

    1. 腎功能不好 → MTX 清除下降 → 全身性毒性風險增加（最重要的方向）

    • MTX 主要經腎臟排除（約 80–90% 以原型藥物經腎絲球過濾 + 腎小管主動分泌排出）。
    • 腎功能不全時，MTX 清除率下降、血中濃度累積，大幅增加骨髓抑制、口腔黏膜炎、肝毒性、甚至致命性 pancytopenia 或 MTX 相關肺炎的風險。
    eGFR (mL/min) 建議
    ≥60 一般劑量
    30–59 建議減量，密切監測
    <30 通常避免使用（多數指引與教科書列為禁忌）
    • NSAID 交互作用：NSAID 會競爭性抑制腎小管對 MTX 的主動分泌，在腎功能已經不佳的病人合併使用 NSAID，會進一步降低 MTX 清除、放大毒性風險，是臨床上常見的用藥陷阱（RA 病人常同時使用 NSAID 止痛）。

    2. MTX 本身也可能造成腎毒性（風濕科低劑量使用時較少見）

    • 主要發生在腫瘤科高劑量 MTX（HDMTX）：MTX 及代謝物在酸性尿液中溶解度低，易在腎小管內結晶沉澱，造成急性腎損傷，需搭配大量水化 + 尿液鹼化 + leucovorin rescue。
    • 風濕科常用低劑量每週一次 MTX（7.5–25 mg/week）直接造成腎毒性較少見，臨床上更重要的是腎功能不佳導致藥物排除下降、進而引發全身性毒性。

    考試重點：MTX 主要經腎排除，腎功能不全時應減量或避免使用；並非 MTX 本身特別容易傷腎，而是腎功能差會讓 MTX 累積中毒。

    24. 關於 Conventional DMARD（含 calcineurin inhibitor）的藥物機轉，何者錯誤？

    ⚠️ 原始題庫記錄考點誤植為「CYP3A4、Ketoconazole 是否會造成 AZA 代謝改變」，經確認 AZA 代謝（xanthine oxidase、TPMT、HGPRT）與 CYP3A4 無關，實際應為 Cyclosporine/Tacrolimus 與 CYP3A4 的交互作用（已依 Kelly's Textbook Ch062 Immunosuppressive Drugs 修正）。

    Cyclosporine、Voclosporin、Tacrolimus 皆為 calcineurin inhibitor，其藥物處置（disposition）高度依賴 CYP3A（腸道與肝臟）以及 P-glycoprotein (Pgp)。

    • Ketoconazole（azole 類抗黴菌藥，強效 CYP3A4 抑制劑）會抑制 CYP3A4 對 cyclosporine/tacrolimus 的代謝，導致藥物血中濃度上升，增加毒性風險（尤其腎毒性）。
    • 依照藥理學原則：抑制代謝酵素 → 藥物清除下降、血中濃度上升 → 應該「減量」，而不是「增加劑量」。若選項敘述「Ketoconazole 會使 cyclosporine/tacrolimus 代謝改變，需要增加劑量」，方向是錯的——正確處置應是減量並密切監測藥物濃度、腎功能。

    Cyclosporine 藥物交互作用速記（Kelly Table 62.5）：

    類別 藥物 對 Cyclosporine 濃度的影響
    Macrolide 類抗生素 Erythromycin, clarithromycin（Azithromycin 例外，影響較小） ↑ 濃度（CYP3A4 抑制）
    Azole 類抗黴菌藥 Ketoconazole, fluconazole, itraconazole ↑ 濃度（CYP3A4 抑制）
    鈣離子通道阻斷劑 Diltiazem, verapamil, amlodipine ↑ 濃度
    其他 Amiodarone, danazol, allopurinol, colchicine ↑ 濃度
    肝酵素誘導劑 Rifampicin, phenytoin, phenobarbitone, nafcillin, St. John's wort ↓ 濃度

    臨床要點： Ketoconazole 與 cyclosporine/tacrolimus 併用時血中濃度可能大幅上升，需要減少劑量並密切監測藥物濃度與腎功能，而非增加劑量；此交互作用機轉臨床上有時甚至被刻意利用（低劑量 ketoconazole 併用降低 cyclosporine 用量、減少藥費），但需嚴格監測。

    • B 臨床常有皮膚潰瘍（cutaneous ulcerations）與掌面紅斑（palmar erythema）的症狀

    • B DECT
    • C MRI
    • D 常規 X-ray

    答案：D（不建議用常規 X-ray 診斷）

    • B Febuxostat 與 warfarin 有交互作用，容易造成 warfarin 過量
    • C Pegloticase 為 recombinant uricase，需留意病人有無 G6PD deficiency

    84. 下列何者跟在 Osteocyte 的缺乏和 AS 的增骨新生有關？

    • A MMP
    • B BMP
    • C Sclerostin
    • D Cathepsin K

    答案：C

    解析：

    • C（對） Sclerostin 是由 osteocyte 分泌的蛋白，正常抑制 Wnt/β-catenin 訊息傳遞（結合 LRP5/6，阻斷 osteoblast 的骨形成活性）。AS 病理機轉中，附著點炎發炎處的 osteocyte 因發炎而凋亡/功能喪失，導致局部 sclerostin 濃度下降，局部 Wnt 訊息失控活化，促進過度骨形成（syndesmophyte、ankylosis）——這解釋了 AS 病人「全身性骨質疏鬆」與「局部新生骨贅」可同時並存的弔詭現象（AS paradox）。
    • A（錯） MMP 主要參與組織基質分解重塑，與此機轉無直接關聯。
    • B（錯） BMP 雖能促進骨形成，但是直接的成骨誘導因子，並非因「osteocyte 缺乏」而調控釋放，機轉路徑不同。
    • D（錯） Cathepsin K 由蝕骨細胞分泌，功能是分解膠原蛋白、促進骨吸收，方向相反。

    • D Selective estrogen receptor modulator

    • B（會產生 ONJ 風險，但相對少見） Sclerostin inhibitor（Romosozumab）仍有 ONJ 風險的藥物標示警語，只是發生率相對較低。
    • D（對，本題答案） SERM（如 Raloxifene）的抗骨吸收作用機轉遠比前三者溫和，目前並無顯著的 ONJ 風險關聯報告，是這四類藥物中最不會造成 ONJ 的選擇。

    骨鬆藥物 ONJ 風險速記：

    藥物類別 ONJ 風險
    Bisphosphonate 高（尤其高劑量 IV）
    RANKL inhibitor (Denosumab) 高，與 bisphosphonate 相近
    Sclerostin inhibitor (Romosozumab) 有，但相對少見
    SERM (Raloxifene) 極低/無顯著關聯

    94. 初診來了一位上肢關節炎患者，過去病史有尿路結石和 hyperparathyroidism，下列何者正確？

    • A 與 hyperparathyroidism 相關的關節炎，較常為小關節炎
    • B 與 hyperparathyroidism 相關的關節炎，不會引起 joint erosion
    • C 與 hyperparathyroidism 相關的關節炎，PIP 為常見部位
    • D 與 hyperparathyroidism 相關的關節炎，ESR 常會上升，故不易與 RA 區分

    答案：C

    解析：

    Hyperparathyroidism 相關關節病變的經典影像學特徵，是手指中節指骨橈側緣的骨膜下骨質吸收（subperiosteal resorption at the radial aspect of the middle phalanges），好發位置正好落在 PIP（近端指間關節）附近區域，是內科/影像學教科書上非常經典的徵象。

    • C（對，本題答案） PTH 過多 → 持續刺激蝕骨細胞活性 → 骨膜下骨質吸收，最典型好發部位是第二、三指的中節指骨橈側緣（PIP 關節周圍）。
    • B（錯） Subperiosteal resorption 本質上就是一種侵蝕性（erosive）骨質變化，hyperparathyroidism 確實可以造成關節周圍骨質侵蝕。
    • A（錯） Hyperparathyroidism 相關的關節病變（含續發性 CPPD 沉積）大關節（膝、腕、肩）也很常見，並非侷限於小關節。
    • D（錯） ESR 上升並非 hyperparathyroidism 關節病變的特徵性描述重點。

    Hyperparathyroidism 骨關節病變速記：

    特徵 內容
    經典影像學徵象 Subperiosteal resorption（骨膜下骨質吸收）
    好發部位 手指中節指骨橈側緣（PIP 關節周圍），也可見於遠端鎖骨、薦髂關節
    是否會侵蝕 會，屬於侵蝕性骨質變化
    關節分布 大小關節皆可能受累，非侷限小關節
    常見續發現象 可誘發 CPPD 沉積

    95. 下列何種藥物跟 hyperuricemia 較無關？

    • A 下肢水腫使用 furosemide
    • B 有中風風險使用 aspirin 預防
    • C 肺結核病人使用標準 isoniazid、ethambutol、rifampin、pyrazinamide 治療
    • D SLE 使用低劑量 hydroxychloroquine 治療

    答案：D（Hydroxychloroquine 與 hyperuricemia 較無關）

    解析：

    • A（有關） Furosemide（loop diuretic）是造成藥物性高尿酸血症的經典藥物——容積收縮加上競爭性抑制近端腎小管尿酸排泄。
    • B（有關） 低劑量 Aspirin 弔詭地會降低尿酸排除、造成高尿酸血症（與高劑量 aspirin 相反，高劑量反而有 uricosuric 效果）。
    • C（有關） 標準 TB 四合一治療中，Ethambutol 與 Pyrazinamide 都是已知會降低腎臟尿酸排除的藥物。
    • D（對，本題答案） Hydroxychloroquine 並非造成高尿酸血症的相關藥物，無明確證據顯示 HCQ 會影響尿酸代謝或排除。

    造成藥物性高尿酸血症速記：

    藥物 機轉
    Furosemide（及其他 thiazide、loop diuretics） 容積收縮 + 競爭性抑制腎小管尿酸排除
    低劑量 Aspirin 抑制尿酸排除（劑量依賴性，高劑量則相反）
    Ethambutol、Pyrazinamide 降低腎臟尿酸排除
    Cyclosporine、Tacrolimus 影響腎功能，間接造成高尿酸血症
    Hydroxychloroquine 無明確關聯

    96. 有關 catastrophic APS，下列何者正確？

    • A 突然有三個以上器官出血，必須用止血劑
    • B 血管造影為最適當診斷方式
    • C 除抗凝血劑之外，還必須使用類固醇、IVIG 或更強的免疫抑制劑
    • D 血中高濃度 fibrin split products 成為有用的疾病診斷標誌

    答案：C

    解析：

    CAPS 的病理本質是短時間內（通常 <1 週）發生 ≥3 個以上器官的微小血管廣泛性血栓形成，並非出血性疾病。

    • A（錯） CAPS 的病理本質是血栓形成，不是出血，若使用止血劑（促凝血）反而會加重病情。
    • B（錯） CAPS 診斷主要依賴臨床診斷準則（短時間多器官侵犯 + 病理切片證實小血管血栓 + 血清學證實 aPL 陽性），血管攝影並非最適當的診斷工具。
    • C（對，本題答案） CAPS 標準治療是「三合一療法」：抗凝血劑 + 高劑量類固醇 + 血漿置換或 IVIG，難治型病人可再加上 rituximab、cyclophosphamide。
    • D（錯） Fibrin split products/D-dimer 升高是非特異性發現，不具 CAPS 特異性診斷價值。

    Catastrophic APS 速記：

    特徵 內容
    病理本質 廣泛微小血管血栓（非出血）
    診斷 臨床準則（短時間多器官侵犯）+ 病理 + 血清學，非單靠影像
    標準治療 抗凝血劑 + 類固醇 + 血漿置換/IVIG（三合一），難治型加 rituximab/cyclophosphamide
    Fibrin split products 非特異性，非診斷標誌

    97. 關於 pregnancy in SLE，下列鑑別診斷 lupus nephritis and preeclampsia 何者有誤？

    • A 血中尿酸較容易於 preeclampsia 增加
    • B 尿中 cellular/granular cast 較易於 lupus nephritis 中發現
    • C Preeclampsia 最好發於 third trimester
    • D 血中補體數值可能有利於鑑別兩者

    ⚠️ 原始題庫記錄答案為 D，但查證後判斷 A、B、C、D 四個選項皆為教科書支持的正確敘述，找不到 Kelly's Textbook 直接反駁 D 的內容。以下先記錄雙方判斷，供日後對照原始題目確認。

    原始題庫記錄答案：D

    98. 65 歲男性，右膝痛、跛行兩週，有腫脹，X 光顯示 OA，BMI 29，下列處置何者有誤？

    • A Quadriceps isokinetic exercise
    • B 減重
    • C Aquatic exercise in a partial nonloading position
    • D Cycling in a nonloading position

    答案：A（此為不適合的處置）

    解析：

    這位病人是急性發作（兩週）、有腫脹（提示關節積液/發炎中）的 OA，處置原則應先減少關節負荷、緩解發炎，再進階到高強度肌力訓練：

    • A（錯，本題答案） Quadriceps isokinetic exercise（等速肌力訓練）屬於高強度、高阻力的肌力訓練模式，通常建議用於病情穩定、無急性腫脹發炎的 OA 病人。在關節仍處於急性腫脹發炎階段時，貿然進行可能加重關節發炎與疼痛。
    • B（對，適合） 減重對 OA（尤其超重病人）是實證等級最強的非藥物治療介入之一。
    • C（對，適合） Aquatic exercise 利用水的浮力大幅降低關節負荷，特別適合急性疼痛/腫脹期的病人。
    • D（對，適合） Cycling in a nonloading position 同樣是低衝擊、不需負重的有氧運動方式，即使症狀較明顯的階段也適合進行。

    OA 運動治療階段性原則速記：

    階段 適合的運動型態
    急性疼痛/腫脹期 非負重運動（水中運動、非負重騎車）
    病情穩定期 漸進式肌力訓練（含等速肌力訓練），搭配持續減重

    99. 下列 RA 敘述何者錯誤？

    • A 足部疼痛會影響步態及行走距離
    • B 客製化手部 splint 可減輕關節疼痛、改善抓握能力
    • C 客製化足部矯具可減輕疼痛及足底壓力
    • D 客製化足部矯具有充份實證可改善步態及行走距離

    解析：

    • D（錯，本題答案） 客製化足部矯具在減輕疼痛與足底壓力上有相對清楚的實證支持，但對於是否能改善步態與行走距離，目前證據強度並不充分。
