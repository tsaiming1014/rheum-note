    Obinutuzumab in SLE 兩大 Phase 3 試驗：REGENCY (LN) 與 ALLEGORY (非腎臟SLE)

    REGENCY：Furie RA, Rovin BH, Garg JP, et al. N Engl J Med. 2025;392:1471-83. DOI: 10.1056/NEJMoa2410965. NCT04221477.

    ALLEGORY：Furie RA, Dall'Era M, Vital EM, et al. N Engl J Med. 2026 (Epub March 6, 2026). DOI: 10.1056/NEJMoa2516150. NCT04963296.

    兩試驗皆由F. Hoffmann–La Roche贊助；REGENCY收案active class III/IV(±V) LN病人，ALLEGORY收案active SLE但排除proliferative/membranous LN病人——兩者互補，共同建立obinutuzumab於SLE全疾病光譜（腎臟+肺腎外）的療效證據。

    藥物背景（兩試驗共通）

    Obinutuzumab 為 glycoengineered type II anti-CD20單株抗體，已核准用於CLL、FL，及（REGENCY後）active LN。

    Type I vs Type II anti-CD20機轉差異：

    Type I（如rituximab） Type II（obinutuzumab）
    主要效應機轉 Complement-dependent cytotoxicity (CDC) + antibody-dependent cell-mediated cytotoxicity (ADCC) 幾乎無CDC，主要走ADCC、antibody-dependent cellular phagocytosis (ADCP)、更強的直接細胞死亡
    結合模式 多抗體同時接上CD20，造成antigen modulation（下調/內化），降低效果 Antigen modulation少，FcγRIIIa結合增強
    B cell depletion效果 較差；且早期rituximab於SLE/LN試驗未證實臨床效益 較佳；非人靈長類與人類研究皆顯示可深度清除組織內（非僅周邊血）B細胞

    早期rituximab於SLE（EXPLORER trial）與LN（LUNAR trial）的RCT皆未達到主要終點顯著差異，但post hoc分析顯示B細胞清除深度與臨床反應相關——此為obinutuzumab（更強效清除）的立論基礎。CD19-CAR T細胞療法在難治型SLE觀察到的深度B細胞清除與remission，也支持此機轉假說。

    兩試驗設計比較

    REGENCY（LN） ALLEGORY（非腎臟SLE）
    試驗性質 Phase 3、randomized、double-blind、placebo-controlled，15國 Phase 3、randomized、double-blind、placebo-controlled，14國
    收案期間 2020/7–2023/3 2021/7–2024/9
    隨機分派人數 271人（obi 135、placebo 136） 303人（obi 151、placebo 152）
    主要收案條件 過去6個月內腎切片證實active Class III/IV(±V) LN；UPC≥1；ANA陽性 SLEDAI-2K≥8；≥1個BILAG domain A或≥2個domain B；PGA≥1.0；ANA或anti-dsDNA或anti-Smith陽性+低補體
    主要排除條件 eGFR<30或ESKD；活動性感染；9個月內用過anti-CD20；2個月內用過CYC/CNI Screening前6個月內proliferative/membranous LN；UPCR>3.5；9個月內用過anti-CD20且B細胞<25/μL；重度活動性CNS SLE
    給藥時程 1000mg：Day1、Wk2、24、26、52（±Wk50額外劑量，探索性） 1000mg：Day1、Wk2、24、26（無Wk52劑量）
    Premedication 未特別詳述 IV MP 80mg + acetaminophen 650–1000mg + diphenhydramine 50mg
    隨機分層因子 地理區域、種族（黑人vs其他） Screening SLEDAI-2K（<12/≥12）、baseline prednisone（<10/≥10mg/day）
    背景標準治療 MMF（自Day1起）+ prednisone（Wk12目標≤7.5mg/day，Wk24目標≤5mg/day） 病人原有穩定治療（抗瘧藥/非GC免疫抑制劑/GC至少一種）；Wk40前>5mg/day且病情穩定/改善者須嘗試減量至≤5mg/day
    Primary endpoint Week 76 Complete Renal Response (CRR)：UPC<0.5 + eGFR≥85% baseline + 無intercurrent event Week 52 SRI-4 response：SLEDAI-2K↓≥4分 + BILAG/PGA無惡化 + 無intercurrent event
    Baseline疾病嚴重度 Median SLEDAI-2K 10–12 Mean SLEDAI-2K約13（略高）
    族群多元性 Hispanic/Latino 57.6%、Black 14.8%、Asian 5.9% Hispanic/Latino約50%、Black約15%

    臨床意義

    • 兩試驗共同建立obinutuzumab作為SLE（含腎臟與肺腎外表現）B細胞標靶治療的角色，機轉上互補印證「更深度B細胞清除→更佳臨床反應」的假說
    • REGENCY已正式改變LN治療guideline：2025 EULAR LN guideline建議4已納入MPAA+obinutuzumab為初始治療選項之一（詳見 SLE_Lupus_Nephritis_治療.md）；ACR LN guideline定稿時間early於REGENCY發表，僅列入Discussion，未正式收錄
    • ALLEGORY尚未反映在任一2025年版guideline中（發表時間晚於ACR SLE guideline與EULAR SLE guideline定稿），是下一版guideline更新最可能新增的證據
    • REGENCY重複腎切片顯示腎臟組織內B細胞近乎歸零，支持obinutuzumab「組織層級深度清除」機轉；ALLEGORY未收集組織切片，此點僅能類推

    共同限制與討論重點

    • 兩試驗皆排除重度活動性中樞神經系統SLE病人（REGENCY另排除eGFR<30/ESKD；ALLEGORY另排除proliferative/membranous LN），限制結果外推性
    • 追蹤時間皆有限（REGENCY 76週、ALLEGORY 52週），長期療效與安全性（尤其是否能延緩ESKD、降低長期flare率）仍待更長期資料
    • 兩試驗皆由藥廠（Roche）設計並贊助，惟聲明sponsor未限制發表結果
    • REGENCY次要終點中，eGFR變化量、Wk50整體腎臟反應、FACIT-F疲勞分數皆未達統計顯著（僅CRR相關的兩項顯著）；ALLEGORY的DORIS/LLDAS則屬未校正type I error的次要分析，不可取代正式假設檢定
    • REGENCY收案期橫跨COVID-19疫情初期，可能放大部分安全性數據的組間差距，解讀時須納入時空背景考量
