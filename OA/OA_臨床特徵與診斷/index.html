    OA 臨床特徵與診斷

    依據：Kelly's Textbook of Rheumatology Ch101 "Clinical Features of Osteoarthritis"

    流行病學

    • 全球影響 >3 億人，是造成失能的主要原因之一（WHO：OA造成的失能年數甚至超過心臟病與肺結核）
    • OA 可用病理學、影像學、臨床三種方式定義，三者盛行率不完全一致——多數影像學OA無明顯症狀（尤其手部：Framingham研究中影像學手OA盛行率女性44%、男性38%，但有症狀者僅16%和8%）
    • 終生風險（至85歲）：膝 45%、髖 25%、手 40%
    • 脊椎小面關節OA極常見（>65歲社區族群中頸椎57%、腰椎89%經CT確認）

    種族差異

    • 黑人 vs 白人：膝OA（影像學與症狀性）黑人皆較高；髖OA黑人盛行率整體較低，但一旦有病灶症狀性比例相近；手OA黑人盛行率較低
    • 華人女性膝OA盛行率高於白人女性（男性則相近）；華人整體髖OA、手OA盛行率低於白人

    原發性 vs 續發性 OA

    隨著更多局部（如 femoroacetabular impingement、malalignment）與系統性風險因子被發現，原發性/續發性的區分界線已逐漸模糊。

    續發性OA常見病因：

    類別 疾病
    代謝性 CPPD、apatite deposition disease、肢端肥大症（acromegaly）、ochronosis、hemochromatosis、Wilson's disease、副甲狀腺機能亢進、Ehlers-Danlos 症候群、Gaucher's disease、糖尿病
    機械／局部因素 Slipped capital femoral epiphysis、epiphyseal dysplasia、Legg-Calvé-Perthes disease、先天性髖脫臼、femoroacetabular impingement、肢長不等、關節過動症候群、缺血性壞死
    創傷性 關節創傷（如ACL斷裂）、關節內骨折、先前關節手術（半月板切除、ACL重建）、Charcot joint
    發炎性 RA或其他發炎性關節病變、痛風、感染性關節炎病史

    OA 分類標準（重要考點）

    1986/1991 ACR Classification Criteria（依關節位置各異，敏感度/特異度）：

    手部（僅臨床標準，敏感度92%、特異度98%） 1. 過去一個月大多數時間有手部疼痛、痠痛或僵硬 2. 10個特定關節中，≥2個有硬組織腫大 3. MCP腫脹關節<3個 4. ≥2個DIP關節有硬組織腫大 5. 10個特定關節中，≥2個變形

    診斷需符合 1+2+3，並符合 4或5

    膝關節：臨床標準（敏感度91%、特異度86%） 1. 過去一個月大多數時間有膝痛 2. 主動關節活動時有捻髮音（crepitus） 3. 晨僵≤30分鐘 4. 理學檢查有骨性腫大 5. 年齡≥38歲

    診斷需符合 1+2+4，或 1+2+3+5，或 1+4+5

    膝關節：臨床+影像學標準 1. 過去一個月大多數時間有膝痛 2. 關節邊緣有骨贅 3. 滑液性狀符合OA 4. 年齡≥40歲 5. 晨僵≤30分鐘 6. 主動關節活動時有捻髮音

    診斷需符合 1+2，或 1+3+5+6，或 1+4+5+6

    髖關節：臨床+影像學標準（敏感度91%、特異度89%） 1. 過去一個月大多數時間有髖痛 2. ESR≤20mm/hr 3. 影像學股骨和/或髖臼骨贅 4. 影像學髖關節間隙狹窄

    診斷需符合 1+2+3，或 1+2+4，或 1+3+4

    補充：EULAR 與 NICE 也各自提出分類標準，三者中 NICE 標準對膝OA敏感度最高；ACR標準因高特異度，主要用於區分OA與發炎性關節病變，較不適合區分早期OA與健康人

    OA 表現型（Phenotypes）

    • 手部OA已知有三種主要表現型，各自可能有不同遺傳性與管理策略：
    • Interphalangeal（nodal）disease
    • Carpometacarpal disease
    • Erosive OA

    各關節之臨床特徵

    一般表現：活動後疼痛加劇、晨僵<30分鐘（明顯短於發炎性關節炎）、活動後的「gelling」現象、骨性腫大、捻髮音、關節活動度下降；症狀嚴重度可能與結構損傷程度不成比例（受憂鬱、睡眠障礙、中樞敏感化影響）

    膝關節：走路、由坐到站、上下樓梯時疼痛/受限；「giving out」不穩定感；locking（可能因meniscus病灶或游離體，McMurray test可誘發）；varus malalignment（varus thrust是膝OA惡化的risk factor）；股四頭肌無力是早期可介入的膝OA進展risk factor（尤其女性）；髕股關節OA常被忽略但可能比脛股關節OA更常見

    髖關節：鼠蹊部疼痛（較specific），也可能表現為大腿、臀部、下背、甚至同側膝痛；髖內旋受限常是早期徵象（病人常因穿襪子、綁鞋帶、剪腳趾甲困難察覺）；年輕病人鼠蹊痛合併坐姿加重、屈曲內收內旋受限需考慮 femoroacetabular impingement

    手部：Heberden's nodes（DIP）、Bouchard's nodes（PIP）；erosive OA（好發年長女性，反覆發炎/腫痛，是否為獨立疾病實體尚有爭議）；第一CMC關節受累特別影響功能與握力；MCP關節顯著受累需考慮發炎性/結晶性關節病變或hemochromatosis等續發原因

    脊椎：小面關節OA極常見；DISH（脊椎韌帶/entheses廣泛骨化，≥4個脊椎節段，形似流動蠟燭）常無症狀；Radiculopathy依節段表現不同： - L4：小腿內側感覺變化、膝伸直無力、髖內收無力、膝反射可能減弱 - L5：垂足（foot drop）、小腿前外側及足背感覺症狀 - S1：足底屈曲無力、膝屈曲無力、髖伸直無力、踝反射減弱 - Cauda equina syndrome（醫療急症）：常見於L4-L5中央椎間盤突出，造成大小便功能障礙、鞍狀麻木、下肢無力

    肩關節：症狀常源自 AC/SC 關節而非盂肱關節本身；rotator cuff病變可誘發盂肱關節OA；Milwaukee shoulder syndrome（罕見破壞性關節病變，60%雙側，50%合併膝關節受累，關節液可見大量紅血球及BCP結晶）

    其他關節：第一MTP OA（合併hallux valgus）；足踝OA可能被低估；肘關節OA罕見（多與創傷、震動傷害或痛風/假痛風有關）；顳顎關節OA表現與其他關節類似（疼痛、彈響、鎖住、活動度下降）

    多關節型 OA（Polyarticular/Generalized OA）

    • 目前無統一定義；早年 Kellgren-Moore 描述以 Heberden's nodes + CMC關節為主，依序涉及脊椎、膝、髖、足
    • 臨床重點：單一關節有OA的病人，很可能其他部位也有病灶，應評估整體OA負擔對病人功能狀態的影響，而非只關注單一關節

    診斷檢查

    抽血檢查

    • 一般不需要抽血或影像學確診典型OA
    • MCP關節顯著受累時，需考慮評估甲狀腺功能低下與 hemochromatosis

    關節液分析

    • OA關節液通常正常或輕度發炎：WBC ≤ 2000 cells/mm³，外觀清澈至微黃
    • 可同時發現CPP結晶；BCP/hydroxyapatite結晶則需特殊染色（如Alizarin Red）才能於一般檢查中發現

    影像學

    傳統X光：關節間隙狹窄、骨贅、subchondral bone硬化與囊腫

    Kellgren-Lawrence (KL) 分級（研究最常用，考試重點）：

    • KL 0：無骨贅、無關節間隙狹窄
    • KL 1：疑似骨贅（不足以確診）
    • KL 2：確定骨贅、無關節間隙狹窄——一般認為KL≥2即符合OA診斷
    • KL 3：確定關節間隙狹窄+骨贅
    • KL 4：關節間隙完全消失，嚴重subchondral硬化

    KL系統限制：文獻定義不一致、發展於1950年代適用性受質疑、關節間隙狹窄也可能反映meniscus病變而非單純軟骨流失

    OARSI grading system：將骨贅與關節間隙狹窄分開個別評分，依關節腔室各自給分

    MRI：可同時評估軟骨、meniscus、韌帶/肌腱、滑膜、積液、骨髓，是唯一能一次評估「全關節」的影像工具（但關節鏡仍是評估關節組織的黃金標準）；常見半定量評分系統：WORMS（最經典）、KOSS、BLOKS、MOAKS

    超音波：低成本、無輻射、可即時評估發炎（滑膜炎、積液）與骨贅，適合導引注射；限制是無法穿透骨皮質評估bone marrow lesion

    CT：評估骨皮質與軟組織鈣化的最佳工具，是評估小面關節OA的主要影像方式；dual-energy CT可鑑別結晶種類

    核醫：骨骼掃描可評估全身OA負擔；PET可偵測滑膜炎、bone marrow lesion等代謝活性增加區域，與疼痛相關

    預後評估工具

    • WOMAC（Western Ontario and McMaster Universities Arthritis Index）：最廣泛使用的OA專用下肢疼痛/功能量表，含疼痛、僵硬、功能三個子量表
    • 關節專一性量表：HOOS（髖）、KOOS（膝）；手部專用：AUSCAN、FIHOA
    • Performance-based測試（OARSI建議核心測試）：30秒坐站測試、40公尺快走測試、爬梯測試
    • OMERACT-OARSI responder criteria：定義治療反應的複合式評估標準

    死亡率

    • OA（尤其是有症狀的疼痛性膝OA）與死亡率上升相關，主要與心血管及腸胃道死因有關
    • 關鍵發現：死亡率上升主要與「疼痛」相關，而非單純影像學OA變化本身——大型世代研究顯示，有症狀的膝OA病人死亡時間縮短35–37%，且此關聯與影像學嚴重度無關
