    腎移植前評估 — 故事版：林小姐的換腎之路

    用一位 LN 合併 ESKD 病人的虛構案例，串起腎移植前的完整評估流程。觀念細節見 移植免疫學 — HLA 命名、Mismatch 計算與移植前評估；ACR／EULAR 移植建議比較見 SLE_Lupus_Nephritis_治療。

    序章：病人登場

    林小姐 38 歲，20 歲時診斷 SLE。28 歲出現 LN class IV，用過 cyclophosphamide 和 MMF，腎功能還是慢慢變差，一年前開始血液透析。

    她有兩個小孩（G2P2），第二胎產後大出血，輸過 4 單位紅血球。幾年前因下肢 DVT 驗出 lupus anticoagulant 陽性，目前用 warfarin。

    她想換腎，有兩位家人願意捐：先生和妹妹。

    你是她的移植評估醫師，要怎麼一步一步評估？

    第一章：她適合移植嗎？時機對嗎？

    你先問： 移植優於透析嗎？現在是時候了嗎？

    • 對 ESKD 的 LN 病人，移植的存活與生活品質都優於透析（ACR 強烈建議）。
    • 理想上應該更早評估：eGFR 降到 20 左右就可以轉介、列入等待名單，接近 15 時可考慮 preemptive 移植（10 年腎存活較好）。林小姐已經在透析，現在開始也不算晚。
    • SLE 活性：透析後 SLE 常會「燒完」。她近一年沒有關節炎、皮疹或血球低下，只是 anti-dsDNA 還有點高、C3 偏低。
    • EULAR：要求腎外疾病 clinically inactive ≥6 個月，她符合。
    • ACR：不要求特定月數，沒有其他主要器官侵犯即可。
    • 血清學不需要完全正常，所以 anti-dsDNA 偏高不影響移植。

    結論： 可以移植，開始全面評估。

    第二章：她的身體撐得住手術與免疫抑制嗎？（一般醫療評估）

    心血管

    SLE 會造成加速性動脈粥狀硬化，加上透析、長期類固醇，她的心血管風險比同齡女性高很多。

    • 心電圖、心臟超音波（也順便看有沒有 pulmonary hypertension、valvular disease，例如 Libman-Sacks）。
    • 因為有多項危險因子，安排 stress test（dobutamine stress echo 或 myocardial perfusion scan）。
    • 腹部、骨盆 CT：看 iliac artery 鈣化程度，因為移植腎動脈要接在 iliac artery 上，嚴重鈣化會讓外科醫師接不上。

    癌症篩檢

    移植後免疫抑制會增加癌症風險，活動性癌症是禁忌，所以移植前要先排除。

    • 子宮頸抹片 + HPV：SLE 病人（尤其用過 cyclophosphamide）子宮頸病變風險較高。
    • 乳房攝影（依年齡）。
    • 用過 cyclophosphamide → 有血尿時要做尿液細胞學／膀胱鏡，排除 bladder cancer。
    • 依年齡與風險做大腸癌篩檢。

    感染評估

    檢查 她的結果 意義
    CMV IgG 陽性（R+） 移植後依捐者狀態決定 prophylaxis 或 preemptive 策略
    EBV IgG 陽性 PTLD 風險較低，belatacept 可以用
    HBV（HBsAg、anti-HBc、anti-HBs） HBsAg−、anti-HBc+、anti-HBs+ 過去感染。移植後要監測 HBV DNA 或給予預防性 antiviral（尤其用 rituximab、ATG 時）
    HCV、HIV、syphilis 陰性
    TB（IGRA） 陽性 Latent TB → 移植前開始治療（例如 isoniazid 9 個月，或 rifampin-based 療程；rifampin 會和 tacrolimus 交互作用，最好移植前完成）
    VZV IgG 陽性 有免疫力

    疫苗： 補上 HBV 加強、肺炎鏈球菌、流感疫苗。活性疫苗必須在移植至少 4 週前打完。 她 VZV 已有抗體，不需要活性疫苗；recombinant zoster vaccine（Shingrix） 是非活性疫苗，也一起打。

    其他器官與系統

    • 牙科：處理蛀牙、牙周病（免疫抑制後會成為感染源）。
    • 泌尿科：透析後尿量少，評估膀胱功能，必要時做 VCUG。
    • 腸胃道：有沒有 peptic ulcer、diverticulitis 病史。
    • 骨質疏鬆：長期類固醇 → DXA。
    • 體重／frailty：BMI 過高會增加手術併發症。

    心理社會評估

    • 服藥順從性：這是移植腎存活的關鍵，順從性差 → de novo DSA → AMR → graft loss。她 SLE 治療多年都規律回診，順從性好。
    • 家庭支持、經濟狀況、交通。

    第三章：她的 SLE 會帶來哪些特殊問題？

    抗磷脂抗體

    她有 LA 陽性 + DVT 病史，符合 APS。

    • 移植腎動脈或靜脈血栓、thrombotic microangiopathy、graft loss 的風險上升。
    • 補驗完整的 aPL 三項（LA、aCL、anti-β2GPI）：triple positive 風險最高。
    • 擬定圍手術期抗凝計畫：術前停 warfarin，改用 heparin bridging，術後儘早恢復抗凝。

    LN 會在新腎復發嗎？

    • 臨床復發率約 10%，多為輕度 mesangial 病灶，很少造成 graft loss。Protocol biopsy 的組織學復發率更高（30–50%）。
    • 這不是移植的禁忌，但移植後要追蹤尿蛋白、補體、anti-dsDNA。

    第四章：關鍵轉折：免疫學評估

    這是最重要的一章。

    Step 1：ABO 血型

    血型
    林小姐 O
    先生 A（subtype 檢驗為 A1）
    妹妹 O
    • 先生 A → 林小姐 O：ABO-incompatible。她體內的 anti-A 會攻擊移植腎內皮 → hyperacute rejection。
    • 如果先生是 A2，內皮 A 抗原表現量低，anti-A titer 低時還有機會；但他是 A1。
    • 也可以做 ABOi 移植：測 anti-A isoagglutinin titer，用 rituximab + plasmapheresis 降到目標值。不過先往下看。
    • 妹妹 O → 林小姐 O：ABO 相容 ✓
    • Rh 不用配。

    Step 2：HLA typing

    三人都做 DNA-based 分型（NGS）：

    HLA-A HLA-B HLA-DR
    林小姐 A2, A11 B46, B60 DR9, DR15
    先生 A24, A33 B58, B13 DR3, DR12
    妹妹 A2, A33 B46, B58 DR9, DR3

    Mismatch 計算（數「捐者有、受者沒有」的抗原）：

    • 先生 → 林小姐：A24、A33、B58、B13、DR3、DR12 → 6 mismatch（2-2-2）。
    • 妹妹 → 林小姐：A33、B58、DR3 → 3 mismatch（1-1-1），因為她們是 haploidentical，共享 A2-B46-DR9 這條 haplotype。

    Step 3：Single antigen bead（找出她有哪些 anti-HLA 抗體）

    報告出來：

    抗體針對 MFI
    anti-B58 12,000
    anti-DR3 8,500
    anti-A24 6,000
    anti-B13 4,000

    想一想：為什麼她有這些抗體？

    👉 兩次懷孕。胎兒帶有爸爸的 HLA（A24、B58、B13、DR3…），胎兒細胞進入母體循環，讓她被致敏。輸血 4 單位也有貢獻。

    這些抗原被定為她的 unacceptable antigens，算出 cPRA = 85% → highly sensitized。也就是說，捐者族群中有 85% 的人帶有她不能接受的 HLA。

    對先生來說： anti-A24、anti-B58、anti-B13、anti-DR3 全部都是 DSA，再加上 ABO 不合。先生不能直接捐給她。

    對妹妹來說： 妹妹的 A33、B58、DR3 中，B58 和 DR3 也是 DSA！

    Step 4：怎麼辦？

    妹妹和先生都帶 B58、DR3，這兩個在台灣族群並不少見，所以她被先生致敏的抗體，也會打到妹妹。可以考慮的選項：

    選項 說明
    A. Paired kidney exchange（交換捐贈） 把她和先生（或妹妹）配對，與另一對不相容的配對交換，找一位沒有她 unacceptable antigens 的捐者。對 highly sensitized 病人是首選
    B. 屍腎等待名單 cPRA 85% 會延長等待時間（cPRA ≥98% 在分配上才有最高優先）
    C. Desensitization 後接受妹妹的腎 IVIG + plasmapheresis + rituximab（必要時加 imlifidase），把 DSA 降到 crossmatch 陰性。但 AMR 風險較高

    故事走 A 路線：透過交換配對，找到一位血型 O、HLA 沒有 B58、DR3、A24、B13 的非親屬捐者 陳先生。Virtual crossmatch：她的抗體不打陳先生的任何 HLA → 預期 crossmatch 陰性。

    Step 5：Crossmatch（最後一關）

    實際用林小姐的血清加上陳先生的淋巴球：

    檢查 結果
    T cell CDC crossmatch 陰性 ✓
    T cell flow crossmatch 陰性 ✓
    B cell flow crossmatch 陽性 ❗

    SAB 明明找不到針對陳先生的 DSA，為什麼 B cell crossmatch 陽性？三個可能：

    1. 她有 SLE → 常有 lymphocytotoxic autoantibody。
    2. 最近有沒有用過 rituximab？沒有。
    3. IgM 抗體干擾？

    於是：

    • Autologous crossmatch（她的血清加她自己的淋巴球）→ 陽性 → 證實是 autoantibody。
    • 血清加 DTT（去除 IgM）、捐者細胞用 pronase 處理 → B cell crossmatch 轉陰。

    結論： 這是 SLE autoantibody 造成的假陽性，不是 DSA，可以移植 ✓

    教訓：SLE 病人 crossmatch 陽性時，一定要做 autologous crossmatch，不然可能誤判而放棄一顆好腎。

    Step 6：其他免疫學補充

    • Non-HLA 抗體（anti-AT1R）：中心可選擇性檢驗，作為日後沒有 DSA 卻發生 AMR 時的參考。
    • 保存這次的 baseline DSA 譜：移植後監測 de novo DSA 時要拿來比較。

    第五章：別忘了捐者也要評估

    交換配對中的陳先生（以及原本想捐的妹妹）都要接受活體捐贈者評估：

    項目 目的
    腎功能（measured GFR）、尿蛋白、尿液鏡檢 捐一顆腎後剩下的腎要夠用
    CT angiography 看腎動脈、靜脈的解剖（決定取左腎或右腎）
    血壓、血糖、BMI 高血壓、糖尿病、肥胖會增加捐者日後 CKD 風險
    感染（CMV、EBV、HBV、HCV、HIV、syphilis、TB） 避免把感染傳給受者
    癌症篩檢 避免把癌症傳給受者
    心理社會評估、獨立捐者權益代言人（independent donor advocate） 確認是自願、沒有被強迫或金錢交易

    特別提醒： 如果最後用的是妹妹的腎，因為 SLE 有家族聚集性，要篩檢妹妹本身有沒有 SLE 或 LN：ANA、尿液分析、尿蛋白、補體。不能把一顆可能發病的腎移給病人，也要保護妹妹自己。

    CMV 配對： 陳先生 CMV IgG 陽性（D+），林小姐也是 R+ → D+/R+，屬於中度風險。如果是 D+/R−，則風險最高，一定要給 valganciclovir prophylaxis。

    第六章：手術前最後確認

    移植前幾天：

    • [ ] 重做 final crossmatch（用最新的血清），確認仍然陰性
    • [ ] 再次確認沒有新的感染、SLE 沒有發作
    • [ ] LTBI 治療已在進行，並已調整好藥物交互作用
    • [ ] Warfarin 已轉換成 heparin bridging
    • [ ] Induction 選擇：她是 highly sensitized，有 AMR 風險 → 選 rabbit ATG（depleting），而不是 basiliximab
    • [ ] Maintenance：tacrolimus + MMF + steroid（MMF 對 LN 復發也有保護）
    • [ ] CMV（D+/R+）、PJP 預防計畫
    • [ ] 移植後 DSA 監測時程（例如 1、3、6、12 個月）

    手術順利，新腎在手術台上就開始產尿了。

    尾聲：一張表看完整個評估流程

    階段 評估項目 林小姐的故事
    1. 適應症與時機 ESKD、eGFR <20 可轉介、preemptive；SLE 活性 腎外 SLE 已靜止 >6 個月
    2. 一般醫療 心血管（含 iliac 鈣化）、癌症、牙科、泌尿、骨質、frailty SLE 加速動脈硬化 → stress test；用過 CYC → 子宮頸、膀胱
    3. 感染與疫苗 CMV、EBV、HBV、HCV、HIV、syphilis、TB、VZV；活性疫苗移植前 ≥4 週 IGRA 陽性 → 治療 LTBI；anti-HBc+ → 監測
    4. 心理社會 順從性、支持系統 規律回診
    5. 原發病相關 aPL／APS、復發風險 LA+ → 抗凝計畫；LN 復發約 10%
    6. ABO 血型、A2 subtype、isoagglutinin titer 先生 A1 → ABOi
    7. HLA typing 受者與捐者，A-B-DR mismatch 妹妹 haplo 3 MM、先生 6 MM
    8. SAB → cPRA 找 unacceptable antigens、算 cPRA、判斷 DSA 懷孕致敏 → 抗先生 HLA；cPRA 85%
    9. 解決不相容 Paired exchange、等屍腎、desensitization 交換配對
    10. Crossmatch CDC、flow、virtual；auto-XM B cell FXM 假陽性 → SLE autoantibody
    11. 捐者評估 腎功能、解剖、感染、癌症、心理；親屬捐者篩 SLE 妹妹要篩 ANA、尿液
    12. 術前定案 Final XM、induction 選擇、預防性用藥、baseline DSA Sensitized → ATG

    一句話記住： 先確認「能不能移植」（時機、身體狀況、感染、癌症），再確認「跟誰移植」（ABO → HLA → DSA → crossmatch）。對 SLE 病人，還要多想三件事：aPL、復發、autoantibody 造成的 crossmatch 假陽性。
