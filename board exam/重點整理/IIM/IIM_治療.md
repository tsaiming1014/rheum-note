# IIM 治療總整理

> 資料來源：Kelly's Textbook of Rheumatology, Ch.86 "Inflammatory Diseases of Muscle and Other Myopathies"。分類標準、MSA/MAA 抗體詳見 [IIM_分類標準.md](IIM_分類標準.md)；診斷檢查詳見 [IIM_診斷工具.md](IIM_診斷工具.md)；活性與療效評估量表詳見 [IIM_疾病活性與療效評估.md](IIM_疾病活性與療效評估.md)。

## 一、治療原則總覽

- IIM（不含 IBM）治療 = **藥物治療 + 運動**的合併策略；目前藥物證據多來自病例系列與少數對照試驗（老一輩藥物如 MTX、AZA 為主），**最佳治療方案仍不明確**
- 治療目標依臨床表現分流：**肌無力/皮疹為主** vs **ILD 為主**，兩者治療流程不同（見第三節附圖）
- 病人衛教（疾病本質、長期管理）是治療的重要一環，最好由風濕科團隊與病友支持團體共同提供

## 二、藥物治療

### 1. 第一線：Glucocorticoid（GC）

| 項目 | 內容 |
|---|---|
| 起始劑量 | Prednisone（或等效劑量）**0.75–1 mg/kg/day**，使用 4–8 週 |
| 減量 | 之後緩慢減量至低劑量（5–10 mg），耗時約 6 個月 |
| 目標 | 12 個月內嘗試減量至停用 prednisone |

**多數專家建議 GC 一開始就合併另一種免疫抑制劑**，目的：

- 降低 GC 副作用
- 增強免疫抑制效果

### 2. Steroid-sparing agents（合併/第二線藥物）

| 藥物 | 重點 |
|---|---|
| **Azathioprine（AZA）** | 2 mg/kg/day；雙盲安慰劑對照試驗延伸期顯示，AZA+GC 相較單用 prednisone，1 年與 3 年後功能較佳、所需 prednisone 劑量較低 |
| **Methotrexate（MTX）** | 劑量與 RA 相似，可達每週 25 mg（甚至更高劑量的報告）；**肺部侵犯（ILD）不必然是 MTX 禁忌** |
| **MTX + AZA 併用** | 前瞻隨機開放交叉研究顯示，對難治型肌炎的兩種積極療法合併使用有效 |
| **Mycophenolate mofetil（MMF）** | 個案報告/系列顯示可作為對 GC、MTX、AZA 反應不佳者的第二線；**對難治型 DM 皮疹與 ILD 使用漸增** |
| **Cyclosporine A / Tacrolimus** | 多篇報告顯示有益，是另一潛在替代藥物，**尤其適用於合併 ILD 者** |

### 3. 難治型／重症治療選擇

| 藥物 | 適應情境 |
|---|---|
| **Cyclophosphamide** | 合併 ILD 時可能有價值 |
| **Rituximab（anti-CD20）** | 傳統口服免疫抑制劑無效時愈趨常用；RIM 試驗（大型多中心 RCT，PM/DM/JDM 難治型）**未達主要終點**，但事後分析顯示 **anti-Jo-1 或 anti-Mi-2 陽性者反應較佳**；多篇病例系列支持用於 ILD（尤其 anti-synthetase syndrome） |
| **IVIG** | 安慰劑對照 RCT 證實對 DM 有效，**已獲美國 FDA 核准用於治療反應不佳的 DM**；也可用於癌症相關肌炎、吞嚥困難、ILD，或合併感染／懷孕時的輔助治療；對 **anti-HMGCR 陽性壞死性肌病**也有效；限制：費用高、需長期反覆輸注、耐受性問題、效果可能只是暫時性 |
| **IV methylprednisolone 脈衝治療** | 用於嚴重、快速惡化、可能危及生命，以及中重度 ILD 患者 |
| **TNF 抑制劑** | **不建議用於肌炎**——結果不一致，甚至有病例顯示 anti-TNF 後疾病惡化；Infliximab 試驗（PM/DM/IBM）僅 30% 改善，其餘惡化或出現副作用；Etanercept 前導試驗顯示 DM 皮疹惡化 |

### 4. IBM 特殊考量

- **IBM 對 GC 通常無反應**；偶有病例報告「穩定」數月，但可能只是反映疾病自然病程
- **長期使用 GC 可能反而讓 IBM 臨床惡化**（雖然 CK 與切片中 T 細胞數目可能改善），並增加肌肉中類澱粉蛋白（amyloid）纖維數目
- 小型研究顯示 IVIG、MTX、抗 T 淋巴球球蛋白（anti-T lymphocyte globulin）或 MMF 可能有部分效益；開放性試驗顯示 **MTX 單用**病人比 **MTX + 抗 T 淋巴球球蛋白** 併用組惡化更明顯
- **Anabolic steroids／Oxandrolone**：對肌力可能有部分效益（尚待大型研究證實），多數專家認為合理使用情境為：合併 GC 短期使用於切片有發炎浸潤者，或合併其他結締組織病時與更積極的免疫抑制治療（MTX、AZA）併用

## 三、治療流程圖（Fig 86.14）

### A. 肌無力／皮疹為主之治療流程

![IIM treatment](../images/IIM%20treatment.png)

- **輕中度**肌無力/皮疹：口服 GC 誘導 → 維持期加 GC-sparing 藥物（MTX、AZA 或 MMF）並減量 GC 目標 12 個月內減至 ≤5 mg → 若改善則持續減量至最低有效劑量；若未改善則升階至 IVIG、rituximab、MMF、tacrolimus/cyclosporine 或合併治療
- **重度**肌無力/皮疹：IV GC（脈衝或 0.75–1 mg/kg/day）+ Mycophenolate 或 tacrolimus（DM 可加 IVIG 或 rituximab）誘導 → 維持期緩慢減量 GC 並持續免疫抑制劑 → 未改善則換藥/合併用藥，可加 **JAK 抑制劑或 abatacept**，仍無效則進入臨床試驗

### B. 合併 ILD 為主之治療流程

![IIM-ILD treatment](../images/IIM-ILD%20treatment.png)

- **輕中度 ILD**：口服或 IV GC 誘導 → 維持期加 GC-sparing 藥物（Mycophenolate、AZA 或 calcineurin inhibitor）→ 未改善則升階至 rituximab、MMF、tacrolimus/cyclosporine、IVIG 或合併治療；**若為進行性纖維化，可考慮加上抗纖維化藥物（antifibrotics）**
- **重度／RP-ILD（rapidly progressive ILD）**：IV methylprednisolone 脈衝 + rituximab ± cyclophosphamide 誘導 → 維持期緩慢減量 GC，持續 mycophenolate/tacrolimus/cyclosporine/rituximab → 未改善則換藥或加藥（JAK 抑制劑、abatacept、IVIG，可考慮 plasma exchange、抗纖維化藥物）→ 仍無效則進入臨床試驗，或評估 ECMO 過渡至肺移植

> 縮寫：GC，glucocorticoid；ILD，interstitial lung disease；IVIG，intravenous immunoglobulin；JAK，Janus kinase；MSA，myositis specific antibody；RP-ILD，rapidly progressive ILD。

## 四、Glucocorticoid 相關注意事項

- **骨質疏鬆預防**：建議補充 vitamin D + calcium，臨床需要時加 bisphosphonate
- **類固醇肌病（steroid myopathy）**：無特異性檢測方法；在疾病無活動性證據下的肌無力應懷疑此可能，處理方式為謹慎減量 GC 並評估臨床反應
- **低血鉀**：GC 可能造成低血鉀，若未矯正可導致肌無力，**容易被誤判為疾病活動中的肌炎**
- 治療（含 GC 減量）應由臨床結果導向：以肌耐力/肌力與器官特異性表現（皮疹、ILD）作為主要監測指標

## 五、非藥物治療：運動

- 免疫抑制治療下約 **75% 病人改善**，但即使肌肉發炎已消退，仍少有人恢復正常肌肉功能
- 舊觀念曾建議肌炎病人避免運動（擔心肌肉損傷/發炎加劇），**近期文獻證實合併運動與免疫抑制治療是安全的**，且對肌力與功能有明確效益
- 慢性發炎導致骨骼肌流失的機制：低活動量、GC 負面效應、循環中細胞激素；即使肌肉發炎已消退，PM/DM 病人在疾病晚期仍可能有肌無力
- 運動已證實在疾病早期與晚期都能安全改善肌肉表現與生活品質；新證據顯示運動甚至可能**降低肌肉與全身性發炎**
- 與健康族群相似，運動效益為短期性，**需規律持續進行**才能維持
- 小型研究：個人化次最大運動計畫（personalized submaximal exercise）可改善免疫抑制中肌炎病人的肌肉功能，且不增加發炎；切片顯示肌力改善與 **type I（慢縮肌）纖維比例增加**及發炎/纖維化減少有關
- **運動處方原則**：應個別化並由物理治療師督導，避免過度使用肌肉；應結合有氧與阻力訓練；病人狀況許可即應盡早開始
- 現行建議：**運動為免疫抑制治療的合併治療（combination therapy）**，非僅輔助角色

## 六、療效評估（簡要）

治療反應監測與減量依據，核心工具為 **IMACS core set measures**（醫師/病人整體活性 VAS、MMT-8 肌力、HAQ 功能、肌肉酵素、MDAAT 肌肉外活性）及 **2016 ACR-EULAR myositis response criteria (Total Improvement Score)**，詳細量表定義與計分方式見 [IIM_疾病活性與療效評估.md](IIM_疾病活性與療效評估.md)。

- 肌肉酵素（CK、LDH、AST、ALT、Aldolase）中，**CK 最常用**，但應以基準時「最異常」的酵素（相對其正常上限）作為追蹤依據
- **DM、IBM 的肌肉酵素可能與疾病活性相關性差**
- AST/ALT 上升可能混淆「肌肉活動性疾病」與「治療藥物之肝毒性」，可用 GGT、ALP、bilirubin，特別是 **glutamate dehydrogenase** 作為肝臟特異性指標區分
- 心肌受累首選標記為 **Troponin I**（非 Troponin T，因骨骼肌再生時 Troponin T 可能偽陽性）
