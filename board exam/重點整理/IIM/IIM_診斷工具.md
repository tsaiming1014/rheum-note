# IIM 診斷

> 抽血、肌電圖、影像（MRI/CT/超音波）、肌肉切片、肺功能檢查在 IIM 診斷中的角色與判讀重點。分類標準與 MSA/MAA 抗體詳見 [IIM_分類標準.md](IIM_分類標準.md)，活性評估量表詳見 [IIM_疾病活性與療效評估.md](IIM_疾病活性與療效評估.md)。

## 一、診斷架構總覽

目前**沒有前瞻驗證的診斷標準**（2017 EULAR/ACR 是分類標準，非診斷標準），臨床上採取多面向組合判斷：

臨床評估（病史+理學檢查）→ 抽血（CK+其他酵素+MSA/MAA）→ EMG → 肌肉 MRI → 肌肉切片（視情況）→ 肺部 HRCT + PFT（篩檢 ILD）

**核心原則**：沒有任何單一檢查對 IIM 具高度特異性，所有結果都必須放回臨床脈絡解讀。

---

## 二、理學檢查重點

- 大多數病人以**肌無力或疲勞**表現，但 IIM 是全身性結締組織病，需完整理學檢查（皮膚、指甲摺、頭皮、關節、心肺）
- 須區分「肌力（strength）」與「肌肉疲勞（fatigue）」：徒手肌力測試（MMT，MRC scale）測力量；重複動作測試（如 FI-2/FI-3）測耐力，較敏感
- 典型 IIM：**對稱性近端 > 遠端**無力；**頸屈肌明顯弱於頸伸肌**（2017 EULAR/ACR 計分項目之一）
- **IBM 例外**：可近端＋遠端合併，且可**不對稱**；特色為**指屈肌（finger flexors）與膝伸肌（knee extensors）**明顯無力，常伴不成比例之肌肉萎縮（股四頭肌、前臂屈肌）

## 三、抽血檢查（Biochemical Tests）

### 1. 肌酸激酶（CK）— 第一線檢查

| 重點 | 說明 |
|---|---|
| 敏感度 | 初診時約 **80–90%** 成人肌炎病人 CK 上升 |
| 亞型差異 | **IMNM 最高**；**DM 常常正常**（尤其早期／輕症）；**IBM 通常較 PM/DM 低** |
| 與活性關係 | CK 上升與整體疾病活性相關，但**與肌力／功能不一定相關**；CK 可能在無臨床惡化下上升，或在無改善下正常化 |
| 特異性 | 不特異 — 甲狀腺低下、肌肉失用、藥物性肌病、橫紋肌溶解、肌肉失養症都會升高 |
| 陷阱 | **CK 正常不能排除 IIM**，尤其是 DM 或 IBM；DM 因有典型皮疹，即使 CK 正常也較易診斷，PM 若 CK 正常則診斷困難許多 |

### 2. 其他肌肉酵素

Aldolase、AST（SGOT）、ALT（SGPT）、LDH — 當 CK 正常但臨床仍懷疑活動性肌炎時，加驗這些酵素可提高診斷率；缺點是也會被肝臟疾病干擾，需先確認酵素來源是肌肉而非肝臟。

### 3. Myoglobin

反映肌肉細胞膜完整性的敏感指標，非酵素性免疫學檢測；但有**日夜節律變異**，且不像 CK 普及，臨床較少常規使用。

### 4. 心肌 Troponin I（非 Troponin T）

**偵測心肌受累最敏感/特異的血清標記**。注意：肌炎病人骨骼肌再生時可能出現 Troponin T 偽陽性，故心肌受累評估應優先用 **Troponin I**。

### 5. 自體抗體（MSA/MAA）

詳細抗體—表型對照表見 [IIM_分類標準.md](IIM_分類標準.md) 第六節。此處僅提醒：**anti-Jo-1** 是目前唯一被納入 2017 EULAR/ACR 分類標準計分的抗體；其他 MSA/MAA 需標準化檢測方法（多為 line blot 或 immunoprecipitation）以降低偽陽性/偽陰性。

## 四、肌電圖（EMG）

**特性**：對肌肉病變**敏感但不具特異性**（無法區分 IIM 與其他肌病）。

**典型肌炎變化**：

- **異常電活性（irritability）**：insertional activity 增加、positive sharp waves、fibrillation potentials（DM/PM 為疾病活動度的合理指標）
- **肌病性運動單位電位（myopathic MUP）**：時程短、振幅低（short duration, low amplitude）、多相波增加（increased polyphasia）
- **募集增加（increased recruitment）**：因單一運動單位可徵召肌纖維減少，需提早募集更多單位才能達到相同力量
- 病程晚期：肌纖維喪失 → 募集反而**減少**

**臨床角色**：

1. IIM 發炎常呈 patchy 分布，EMG 可協助**定位該切哪一條肌肉做切片**
2. **EMG 針刺本身會造成局部組織偽影**，干擾切片病理判讀 → 建議 **EMG 做一側、切片取對側同名肌肉**（IBM 雖然常不對稱，仍可用此原則，前提是對側肌肉也有無力）
3. 也可協助鑑別神經性疾病（如 ALS 的 fibrillation/fasciculation potentials、重症肌無力的 decremental response）

**病人實際範例**：

| | Case 1：Myositis（CK↑） | Case 2：Hypomyopathy（CK 正常） |
|---|---|---|
| 取樣部位 | 右側 Deltoid、Biceps、Rectus femoris（對稱性近端無力） | 右側 Biceps、Rectus femoris、TA |
| Spontaneous activity | **有**：Deltoid、Rectus femoris 出現 fibrillation、positive sharp waves | **無**：三條肌肉皆未記錄到自發性電活性 |
| MUAP 型態 | 短時程、低振幅、多相波（典型肌病性型態） | 小振幅、多相波，但呈**長時程（long duration）**——與典型急性肌病之短時程不同 |
| Recruitment | Deltoid 呈現**募集減少**（reduced；報告特別註明此為值得留意的例外表現） | 三條肌肉皆呈現**早期募集**（early recruitment，典型肌病性表現） |
| 判讀結論 | Myopathic change **合併活動性發炎證據**（因有 spontaneous activity） | Myopathic change，但**無**活動性發炎證據（無 spontaneous activity） |

**重點整理**：

- IIM 肌電圖**最具特徵性**的兩項發現：**Early recruitment**（提早募集）與 **Spontaneous activity**（fibrillation、positive sharp waves）；後者才是判讀「有活動性發炎證據（evidence of active inflammation）」的關鍵
- **CK 正常**的 hypomyopathic／amyopathic IIM，肌肉受侵犯程度輕，EMG 常缺乏 spontaneous activity，**甚至可完全正常**——EMG 正常**不能排除** IIM，尤其在 amyopathic DM 病人
- 募集型態並非固定不變：多數呈早期募集，但當肌纖維大量喪失（病程久、損傷重）時也可能轉為募集**減少**，此時判讀須留意與神經性疾病的鑑別

## 五、影像檢查

### 1. 肌肉 MRI — 首選影像工具

- 三種常用影像（超音波、CT、MRI）中，**MRI 是評估軟組織肌肉異常的首選**，可同時顯示發炎（STIR 序列高訊號）、脂肪浸潤、鈣化，並定位到特定肌群
- **臨床用途**：
  - 導引肌肉切片取樣部位
  - 區分「活動性發炎（disease activity）」vs「不可逆損傷（damage）」
  - 部分亞型（DM、IBM、IMNM）有較具特色的 MRI 表現，可輔助診斷
  - 有潛力作為治療反應的縱向追蹤工具，但**其對變化的敏感度尚未確立**，臨床試驗尚未廣泛採用

### 2. 超音波

可偵測異常血管化，配合 color Doppler 監測血流速率；但在 IIM 診斷或治療監測上的實用性**尚未確立**。

### 3. CT

- **偵測軟組織鈣化（如 JDM 的 calcinosis）的首選影像**，但**無法偵測肌肉發炎變化**
- 可做橫斷面定量評估深層肌肉的萎縮與脂肪取代（超音波不易觸及的部位）

### 4. 肺部 HRCT（Chest High-Resolution CT）

- **偵測 ILD 的重要工具**，因肌炎併發 ILD 盛行率高，**診斷時即應考慮做基礎 HRCT**（即使無呼吸道症狀）
- **一般胸部 X 光敏感度不足**，不能取代 HRCT
- **例外**：IBM 病人 ILD 罕見，可考慮不列為常規
- 也用於追蹤免疫抑制治療效果

## 六、肺功能檢查（PFT）

- 典型呈現**侷限性通氣障礙（restrictive pattern）**：
  - ↓ TLC（total lung capacity）、↓ FRC（functional residual capacity）、↓ RV（residual volume）、↓ FEV1、↓ FVC
  - **FEV1/FVC 比值正常或偏高**（與阻塞性疾病相反）
  - **DLCO（一氧化碳擴散能力）下降**
- 用途：客觀評估呼吸道受累嚴重度、搭配影像追蹤治療反應

## 七、肌肉切片（Muscle Biopsy）— 診斷關鍵工具

### 取樣原則

- 選擇**中度無力**的肌肉做切片（太弱 → 可能已纖維化，資訊量低；正常肌力 → 可能尚未受累）
- 若同時安排 EMG，**建議切片取對側同名肌肉**，避免 EMG 針道造成的組織學偽影干擾判讀

### 共同組織學特徵（所有 IIM 亞型皆可見）

肌纖維壞死、再生、退化、纖維直徑變異增加、結締組織增生、發炎浸潤。

### 各亞型特異病理特徵

| 亞型 | 特異病理表現 |
|---|---|
| **DM** | **Perifascicular atrophy（束周萎縮）**— 診斷 hallmark，但屬**晚期表現**，早期切片可能看不到；微血管喪失/型態改變、微血管壞死合併補體膜攻擊複合體（MAC）沉積於血管壁、偶見肌梗塞；發炎浸潤以**血管周圍分布**為主，CD4+ T 細胞與巨噬細胞為主，偶見 B 細胞；早期 MHC class I 呈 patchy、以束周區域染色為主 |
| **ASyS（anti-synthetase syndrome）** | 部分血管病變特徵與 DM 重疊，但**束周區域肌纖維壞死合併肌束膜（perimysial）碎裂**是與 DM 不同之處；**束周 MHC class II 上調**被認為對 ASyS 更專一 |
| **PM** | 巨噬細胞＋活化 CD4+/CD8+ T 細胞浸潤，肌纖維瀰漫性 MHC class I 表現；特徵性表現為**肌內膜（endomysial）單核細胞侵入非壞死肌纖維（invasion of nonnecrotic fibers）** |
| **IBM** | 病理近似 PM（含 endomysial 侵入），另加：**Rimmed vacuoles（鑲邊空泡）**、細胞質/細胞核內含物、**類澱粉沉積（amyloid deposits）**；COX 陰性纖維增加（非 IBM 特異）；**電子顯微鏡**下可見 **15–21 nm 細胞質/細胞核內管狀絲狀體（tubulofilaments）**，此為 DM/PM 所沒有的特徵 |
| **IMNM** | 以**肌纖維壞死為主**，發炎細胞浸潤**稀少或缺席**；MHC class I 上調；**肌膜 C5b-9 補體沉積**（詳見分類標準.md） |

![IIM 各亞型肌肉病理比較](../images/IIM%20comparison.png)

**重要陷阱**：部分病人切片同時找不到 rimmed vacuoles 與 tubulofilamentous inclusions（IBM 兩項特徵性表現），此時診斷需仰賴典型臨床特徵；**對免疫抑制治療無反應**可進一步支持 IBM 診斷（而非誤判為治療反應不佳的 PM）。

## 八、鑑別診斷／Mimics（重要考點）

IIM 的鑑別診斷範圍廣，需系統性排除，以下依類別整理，含各病鍵鑑別特徵：

### 肌肉失養症（Dystrophic Myopathies）

| 疾病 | 關鍵鑑別特徵 |
|---|---|
| **Dysferlinopathy**（LGMD2B / Miyoshi myopathy） | Dysferlin 基因突變；LGMD2B 表現為漸進性近端無力（先股四頭肌）；Miyoshi 型為遠端無力（腓腸肌/比目魚肌，先影響墊腳尖）；發病於青少年後期至 20 多歲；CK 明顯上升，切片可見發炎浸潤（易誤判為 PM），**對類固醇無反應**是重要鑑別線索 |
| **Facioscapulohumeral muscular dystrophy (FSHD)** | 4q35 D4Z4 repeat 部分缺失；始於臉部與肩胛帶無力，漸進至骨盆帶與四肢；CK 正常或輕度上升；EMG 呈典型肌病性變化；切片可見 perivascular/endomysial/perimysial 發炎（易與肌炎混淆） |
| **Becker's dystrophy** | Dystrophin 基因突變（X 性聯隱性）；肢帶型無力合併心肌病；CK 明顯升高 |
| **Proximal myotonic myopathy (type 2 myotonic dystrophy)** | ZNF9 基因 intron 1 CCTG repeat 擴增；體染色體顯性；肌強直（myotonia）常輕微需靠 EMG 偵測；近端無力為主；常見平滑肌/心肌/橫膈受累，第一度房室傳導阻滯與猝死需注意 |
| **Sarcoglycanopathy（LGMD2C–2F）** | Sarcoglycan（α/β/γ/δ）基因突變；兒童期起病（6–8 歲），骨盆帶無力（搖擺步態）為先，合併擴張性心肌病；CK 明顯升高 |

### 代謝性肌病（Metabolic Myopathies）

| 疾病 | 關鍵鑑別特徵 |
|---|---|
| **Acid maltase deficiency (Pompe disease)** | Acid α-glucosidase 基因突變；有嬰兒/兒童/成人型；成人型於 20 多歲表現，酷似 PM 或肢帶型失養症，合併呼吸肌受累；CK/AST/LDH 皆升高，EMG 呈肌病性變化 |
| **McArdle's disease** | Myophosphorylase 基因突變；**運動不耐**（early fatigue, myalgia, 休息可緩解）為特徵；前臂缺血運動試驗顯示**靜脈乳酸幾乎不上升**；CK 變異大；切片可見肌纖維周邊肝醣沉積 |
| **Mitochondrial myopathies** | 粒線體 DNA 或多種核基因突變；病程差異極大；無力型態常為 facioscapulohumeral 分布，合併眼外肌／眼輪匝肌受累；反覆肌紅蛋白尿；切片需**特殊粒線體染色**（succinate dehydrogenase、COX、Gomori trichrome）方可診斷 |

### 內分泌性肌病（Endocrine Myopathies）

| 疾病 | 關鍵鑑別特徵 |
|---|---|
| **Cushing's syndrome / 類固醇肌病** | 內生或外源性糖皮質素過高；近端無力（下肢重於上肢），起病隱匿；**血清肌肉酵素通常正常**（與 IIM 重要鑑別點）；切片見第二型肌纖維空泡化與肝醣堆積；減量或停用類固醇後可逆 |
| **Hyper/Hypothyroid myopathy** | 近端無力＋肌肉消瘦；甲亢時肌肉酵素常正常或偏低，**甲低時則會升高**；EMG 變化不一（短時程、多相波增加），fibrillation 少見 |

### 感染性肌病（Infectious Myopathies）

| 疾病 | 關鍵鑑別特徵 |
|---|---|
| **HIV myopathy** | 亞急性近端對稱無力，酷似 IIM；EMG 可見自發性活動（fibrillation、positive sharp waves） |
| **HTLV-1 myopathy** | 好發於日本、牙買加等地；可合併 tropical spastic paraparesis；CK 升高；病理可同時見 PM 樣（壞死）與 IBM 樣（空泡、類澱粉、絲狀體）變化 |
| **寄生蟲性肌病（Parasitic）** | 弓漿蟲、錐蟲、肉孢子蟲、囊蟲、旋毛蟲等；臨床可酷似 PM/DM；切片可見病原體本身（如 toxoplasma cysts）合併肌束膜/肌內膜發炎；需合併切片與血清學診斷 |

### 藥物性肌病（Drug-Induced Myopathies）

| 藥物 | 關鍵鑑別特徵 |
|---|---|
| **Zidovudine（AZT）** | 近端無力合併血清**乳酸**上升；切片見 ragged red fibers 與粒線體異常（藥物毒性造成的粒線體病變）；**停藥可改善** |
| **Statin** | 可表現為壞死性肌病（necrotizing myopathy）；急性/亞急性疼痛性近端肌病；CK 明顯升高；需與 **anti-HMGCR IMNM** 鑑別（後者即使停藥仍持續進展，需免疫抑制治療） |
| **Corticosteroid** | 近端＋遠端無力；切片見第二型肌纖維萎縮與空泡化；CK 上升 |
| **Penicillamine、Interferon-α、Procainamide** | 可誘發真正的發炎性肌病（近端無力合併疼痛、皮膚變化）；切片可見發炎與壞死；CK 上升 |

### 神經肌肉疾病（Neuromuscular Disorders，非肌病本身但常需鑑別）

| 疾病 | 關鍵鑑別特徵 |
|---|---|
| **運動神經元疾病（如 ALS）** | 上/下運動神經元合併徵象；不對稱無力伴去神經萎縮；EMG 見 fibrillation/fasciculation；CK 輕度上升；**IBM 是最常與 ALS 混淆的肌病**，需靠切片鑑別 |
| **脊髓性肌肉萎縮症（SMA，晚發型）** | 對稱性無力萎縮、腱反射減弱；EMG 與切片皆呈神經性變化（fiber type grouping 提示再神經支配）；CK 正常或輕度上升 |
| **重症肌無力（Myasthenia Gravis）** | 異常疲勞性無力，重複/持續用力後加重；常合併眼外肌受累；EMG 呈**遞減反應（decremental response）**；多數病人 anti-acetylcholine receptor 抗體陽性 |

## 九、實務記憶串接

- **CK 正常不代表沒有 IIM** — 尤其 DM、IBM，此時要靠皮疹（DM）或典型臨床型態（IBM）
- **EMG 敏感不特異，主要功能是導引切片部位** — 記得做對側
- **MRI 是肌肉影像首選；CT 是鈣化首選；HRCT 是 ILD 篩檢必備**（IBM 除外）
- **切片是鑑別 DM／PM／IBM／IMNM 最終依據**，各有特徵：DM 束周萎縮＋補體血管病變、PM/IBM 肌內膜 T 細胞侵入非壞死纖維、IBM 多一個 rimmed vacuoles＋絲狀體、IMNM 壞死為主但發炎稀少＋補體沉積肌膜
- **Troponin I（非 T）評估心肌受累**
