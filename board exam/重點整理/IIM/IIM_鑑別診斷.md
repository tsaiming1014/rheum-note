# IIM 鑑別診斷（Mimics）

> 整理自 Kelly's Textbook of Rheumatology, Ch.86 — Inflammatory Diseases of Muscle and Other Myopathies, Differential Diagnosis/Mimics（Table 86.8）

IIM（PM/DM/IBM/necrotizing myositis）的鑑別診斷之所以重要，是因為各類 mimics 的臨床關聯與對治療的反應都不同。Kelly 將容易與 IIM 混淆的疾病分成五大類：Dystrophic myopathies、Neuromuscular disorders、Metabolic myopathies、Endocrine myopathies、Infectious myopathies，另外單獨列出 Drug-Induced Myopathies。

| 分類 | 疾病 | 好發／起病 | CK | 關鍵鑑別特徵 |
|---|---|---|---|---|
| **Dystrophic myopathies** | Dysferlinopathy (LGMD2B / Miyoshi) | 青少年晚期～20 出頭 | 明顯升高 | LGMD2B：骨盆股骨型無力起始；Miyoshi：遠端腓腸肌無力（墊腳尖困難）；急性起病易誤認 PM |
| | Facioscapulohumeral MD | 隱襲起病 | 升高（隨年齡/性別變異） | 臉部肌肉先受累 → 肩胛固定肌無力；EMG 肌病變化，可有發炎浸潤 |
| | Dystrophinopathy (Duchenne/Becker) | X-linked，兒童/青少年 | 顯著升高 | Becker 較輕型：肌痛、運動不耐、輕度 limb-girdle 無力 + quadriceps myopathy |
| **Neuromuscular disorders** | ALS (motor neuron disease) | 成人 | 僅輕度升高 | 上 + 下運動神經元徵象；EMG 見 fibrillation/fasciculation；IBM 最易與其混淆，需切片鑑別 |
| | SMA (late-onset型) | 各年齡 | Juvenile 型輕度升高，其他型多正常 | 漸進無力 + 萎縮 + 深部腱反射減弱；EMG 為 neurogenic pattern；切片見 fiber type grouping（reinnervation 證據）；**不會有代謝異常（如低血糖、乳酸血症）** |
| | Myasthenia Gravis | 各年齡 | 正常 | 運動誘發疲勞無力 + 外眼肌受累 + AChR 抗體 (+)；EMG decremental response |
| **Metabolic myopathies** | Acid Maltase Deficiency (Pompe, GSD II) | Infantile/childhood/adult 三型 | CK/AST/LDH 都升高 | 近端無力為主；infantile 型合併心衰竭死亡；EMG 肌病變化 |
| | McArdle's disease (GSD V) | 各年齡 | 變異大 | 運動不耐 + 運動後肌痛僵硬；forearm ischemic exercise test 乳酸「幾乎不上升」 |
| | Mitochondrial myopathies | 嬰兒到成人皆可 | 可升高 | **血中乳酸升高**（Key Diagnostic Feature）+ 近端無力（含眼外肌）+ 運動不耐 + 反覆 myoglobinuria；切片 ragged red fibers / SDH、COX、Gomori trichrome 異常染色 |
| **Endocrine myopathies** | Cushing's syndrome / 類固醇肌病 | 隱襲起病 | 正常 | 近端無力（下肢 > 上肢）；切片見 type II fiber 空泡化 + glycogen 堆積；降類固醇可逆 |
| | 甲狀腺機能異常 | 各年齡 | Hyperthyroid 正常/偏低；Hypothyroid 升高 | 近端無力 + 運動不耐 + 呼吸肌無力可能需呼吸支持 |
| **Infectious myopathies** | HIV myopathy | 亞急性 | 可升高 | 對稱近端無力，臨床/EMG 都與 IIM 極相似，需病毒學檢測鑑別 |
| **Drug-induced myopathies** | Statin myopathy（含 anti-HMGCR 壞死性肌病） | 用藥後 | 升高 | 急性/亞急性疼痛性近端肌病；停藥後改善；若持續惡化需考慮 statin 誘發的自體免疫壞死性肌病 |

## 考題應用：近端無力 + CK 升高 + 低血糖 + 乳酸血症

Kelly 這章唯一明確把「血中乳酸升高」列為 Key Diagnostic Feature 的類別是 **mitochondrial myopathy**，可據此排除 SMA（SMA 屬於單純神經退化性疾病，不會產生代謝異常）。

低血糖這個線索書中未特別著墨，屬於代謝/兒科教科書中 GSD 相關章節（如 GSD I von Gierke、GSD III Cori disease）的重點，可視為額外佐證方向：往「代謝性肌肉病」大類思考，而非 IIM 本身或 SMA。
