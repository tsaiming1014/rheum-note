# DAS28 理學檢查詳解：28 個關節怎麼摸

> 補充筆記，與 [RA_disease_activity_measures_T2T.md](RA_disease_activity_measures_T2T.md) 的簡表對照閱讀。本篇著重**實際觸診動作細節**。

---

## 一、總覽：為什麼是這 28 個關節

DAS28（及 SDAI、CDAI 共用）評估以下 28 個關節的 **TJC（tender joint count）** 與 **SJC（swollen joint count）**：

| 部位 | 關節 | 側 | 數量 |
|---|---|---|---|
| 肩 Shoulder | glenohumeral | 雙側 | 2 |
| 肘 Elbow | 肱橈/肱尺關節 | 雙側 | 2 |
| 腕 Wrist | 整個腕部視為 1 個關節（不細分腕骨） | 雙側 | 2 |
| 掌指 MCP | 1–5 指 | 雙側 | 10 |
| 近端指間 PIP | 1–5 指 | 雙側 | 10 |
| 膝 Knee | 股脛關節 | 雙側 | 2 |
| **總計** | | | **28** |

**明確不含**：DIP、髖（hip）、踝（ankle）、MTP（蹠趾）、第一 CMC（拇指基底）。

這點很重要——臨床上 RA 病人常合併足部 MTP 侵犯甚至比手部更早出現症狀，但 DAS28 不計入，所以疾病活性可能被低估；若懷疑足部有活動性滑膜炎，仍應觸診記錄，只是不納入 DAS28 計分。

---

## 二、檢查前的基本原則

1. **雙側同時比較**：兩手/兩腳自然放在檢查桌上，同一姿勢下左右比較大小、輪廓、溫度差異，不對稱腫脹比單側更容易辨識。
2. **光線與角度**：從側面（tangential lighting）看關節輪廓更容易發現輕微腫脹，正面光容易忽略。
3. **順序**：建議固定順序（例如由近端到遠端：肩→肘→腕→MCP→PIP→膝），避免漏檢，也方便病人適應檢查節奏。
4. **力道一致**：觸診力道約以**指腹按壓至甲床變白**為參考力道（約 4 kg/cm²），太輕測不出 tenderness，太重會誘發假陽性疼痛。
5. **同時問診**：邊觸診邊觀察病人表情/退縮反應，比單純口頭「會不會痛」更客觀。

## 三、Tender 與 Swollen 的定義區分

這是最容易混淆、也是計分準確度的關鍵：

- **Tender（壓痛）**：觸診/擠壓當下病人表現疼痛或不自主退縮。與是否腫脹**無關**——單純滑膜炎的痛覺敏感，或關節周圍軟組織痛都可能造成 tender，須盡量鎖定「關節本身」而非肌腱、韌帶附著處。
- **Swollen（腫脹）**：觸診到 **synovial thickening 或 effusion**——手感為 boggy（軟綿、有彈性）、fluctuant（波動感）或關節周圍正常骨性輪廓消失。**單純骨性肥大（如 OA 的 Heberden/Bouchard nodes）不算 swollen**，這是與 OA 鑑別的關鍵。

**臨床陷阱**：
- 病人焦慮或有 fibromyalgia 共病時，全身觸診閾值下降，TJC 會被高估，但 SJC 不受影響——這也是 DAS28/CDAI 在此類病人身上會偏高估疾病活性的原因。
- 陳舊性關節變形（骨性增生）摸起來也是「腫大」，但質地偏硬、無 fluctuant 感，須與活動性滑膜炎區分。

## 四、各關節詳細觸診手法

### 1. Shoulder（肩，glenohumeral joint）

- **姿勢**：病人手臂自然下垂放鬆，或請病人以對側手扶住患側手肘，放鬆三角肌。
- **手法**：檢查者站在病人前方或後方，以拇指觸診 **anterior joint line**（喙突外側、肱骨頭前方的凹陷），也可觸診 **subacromial/subdeltoid 區域**。
- **難點**：盂肱關節位置深，被三角肌、肩峰覆蓋，滑膜腫脹很難直接摸到，臨床上常需**合併主動/被動活動度受限、外展時疼痛弧（painful arc）**來輔助判斷，單純觸診陰性不能排除。
- **鑑別**：肩部疼痛常見合併 rotator cuff tendinopathy、subacromial bursitis，觸診時盡量分辨壓痛點是在關節線還是肩峰下外側（後者較屬肌腱/滑囊病灶）。

### 2. Elbow（肘）

- **姿勢**：肘關節微彎約 70°，前臂放鬆置於檢查桌或病人大腿上。
- **手法**：以拇指或食指沿 **外側溝（lateral groove，橈骨頭與肱骨小頭之間）** 及 **後側溝（posterior groove，鷹嘴突兩側的凹陷）** 觸診。
- **判讀**：正常時這些凹陷清楚可觸；有 effusion/滑膜增生時凹陷消失，摸起來呈 boggy 或有波動感；同時可能合併伸直角度受限（elbow extension lag，RA 肘關節常見早期徵象）。
- **鑑別**：鷹嘴突後方若為局限性、可推動的腫塊，較可能是 olecranon bursitis 而非關節本身病變。

### 3. Wrist（腕）

- **姿勢**：手腕輕度屈曲放在檢查桌上，或病人雙手互握、腕背朝上。
- **手法**：雙側拇指沿 **dorsal radiocarpal joint line**（橈骨遠端與腕骨交界處的橫向凹溝）觸診，同時可延伸到 DRUJ（遠端橈尺關節）及 midcarpal 區域——但**DAS28 只算整個腕部為 1 個關節**，不需分別計分。
- **判讀**：正常時可摸到清楚的骨性輪廓與凹陷；滑膜炎時整個背側呈飽滿、boggy，凹陷消失，有時可見背側靜脈擴張（因腫脹推擠）。
- **鑑別**：腕背側侷限性、光滑可移動的囊腫多為 ganglion cyst，非瀰漫性滑膜炎；De Quervain's tenosynovitis 壓痛點在橈骨莖突而非關節線本身（Finkelstein test 可鑑別）。

### 4. MCP（掌指關節，1–5 指）

- **姿勢**：病人手掌自然放鬆置於桌上，或握拳放鬆。
- **篩檢手法**：先做 **MCP squeeze test**——檢查者以拇指與食指從兩側橫向擠壓第 2–5 掌骨（跨越所有 MCP），若誘發疼痛，代表其中至少一個 MCP 有問題，再逐一觸診確認是哪一指。
- **個別觸診**：拇指置於關節背側兩側，食指從掌側頂住支撐，以拇指在關節線兩側輕壓觸診，感受滑膜腫脹（關節兩側正常凹陷消失、飽脹感）。
- **判讀重點**：RA 好發 2、3 指 MCP，早期可能只有壓痛無明顯腫脹，需仔細比較雙側對稱關節。

### 5. PIP（近端指間關節，1–5 指）

- **姿勢**：手指自然伸直放鬆。
- **手法**：以拇指與食指從兩側（內外側）夾按觸診關節，而非從背側按壓（背側較難分辨滑膜腫脹與皮下組織）。
- **判讀**：RA 典型呈現 **fusiform（紡錘狀）腫脹**——關節兩側均勻膨出，摸起來 soft/boggy；與 OA 的 Bouchard's nodes（骨性、硬、常合併 Heberden's nodes 於 DIP）需鑑別，後者不算 swollen。
- **注意**：拇指的 PIP 相當於其 IP 關節，仍計入拇指這一格。

### 6. Knee（膝）

- **姿勢**：病人平躺，膝關節伸直放鬆，或坐姿膝屈曲 90°。
- **視診**：先觀察 **suprapatellar pouch**（髕骨上方）是否膨出、兩側是否對稱。
- **少量積液**：用 **bulge sign（浮動測試）**——先用手掌由內下方往上推擠液體集中到外上方 suprapatellar pouch，再從外上方向內下方推回，觀察內側凹陷處是否出現鼓起波動，適合偵測少量積液。
- **中大量積液**：用 **patellar tap / ballottement**——一手固定 suprapatellar pouch 向下推擠液體集中至髕骨下方，另一手食指快速下壓髕骨中央，若感覺髕骨浮動、碰觸股骨後有回彈感即為陽性。
- **關節線觸診**：膝屈曲時沿內外側 joint line 觸診壓痛，同時評估是否合併 popliteal (Baker's) cyst（膕窩腫塊，需與 DVT 鑑別）。

## 五、常見鑑別陷阱總結

| 情境 | 容易誤判為 swollen/tender 但其實不是（或反之） |
|---|---|
| OA 骨性增生（Heberden/Bouchard nodes） | 硬、骨性、無 fluctuant → **不算 swollen** |
| Fibromyalgia 共病 | 全身觸痛閾值低 → TJC 假性升高，SJC 不受影響 |
| Ganglion cyst（腕背、指間） | 局限性、可推動的囊性腫塊，非瀰漫性滑膜炎 |
| Tenosynovitis（如 De Quervain's） | 壓痛點在肌腱路徑而非關節線 |
| Olecranon/prepatellar bursitis | 局限於滑囊區域，非整個關節腫脹 |
| 陳舊性關節變形（無活動性發炎） | 關節輪廓改變但無 boggy/fluctuant 感 → 不計 swollen（可能仍 tender） |

## 六、記錄與計分提醒

- 記錄時建議用**人形關節圖（mannequin diagram）**逐一標記 tender（通常標 T 或藍色）與 swollen（標 S 或紅色），比純數字更利於下次追蹤比較。
- DAS28 只需要 28 關節的 TJC/SJC **總數**代入公式，不需個別關節分數；但完整記錄每個關節的 T/S 狀態，有助於判斷疾病分布模式（對稱性 polyarthritis 是否維持）及後續治療反應追蹤。
- 若懷疑足部（MTP）或其他非 DAS28 關節有活動性滑膜炎，仍應觸診並記錄在病歷中，只是不納入 DAS28 分數計算——避免因為「DAS28 remission」但足部仍有活動性關節炎而誤判病人已達標。
