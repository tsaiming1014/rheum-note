## 2022

### 3. RA 的鑑別診斷

**PMR vs EORA（Early-Onset RA）vs OA**

| 特點 | PMR | EORA | OA |
|------|-----|------|----|
| 年齡 | >50 | >60 | 中老年 |
| 主要部位 | 肩、骨盆帶 | 手腕、MCP | DIP、膝、髖 |
| 晨間僵硬 | 明顯 | 明顯 | 短暫 |
| RF/CCP | 陰性 | 可陽性 | 陰性 |
| ESR/CRP | 明顯升高 | 升高 | 輕度升高或正常 |
| 類固醇反應 | 極佳 | 良好 | 一般 |

> 此為 2022 年唯一涉及 LVV 相關疾病（PMR）的考題，以鑑別診斷表格形式出現，非獨立 PMR 案例站。

## 2023

### AAV / Vasculitis 站（林世昌）

- **GCA/TAK 在年齡分佈、種族分佈、影響血管、臨床表現及治療上有何區分？**

這是歷年題庫中唯一一題明確要求完整比較 GCA 與 TAK 的考題，完整答案已整理於 [GCA_TAK_口試比較.md](GCA_TAK_口試比較.md)，摘要速記表如下：

| 項目 | GCA | TAK |
|---|---|---|
| 年齡 | >50歲（尖峰70-80） | <40歲 |
| 種族 | 北歐/白人 | 亞洲人 |
| 性別比(女:男) | 2-4:1 | 8-9:1 |
| 主要侵犯血管 | 主動脈弓顱外分支（顳動脈） | 主動脈及其主要分支 |
| 特徵性表現 | Jaw claudication、視力喪失、合併PMR | Pulseless、上肢跛行、血壓不對稱、腎血管性高血壓 |
| 診斷工具 | Temporal artery biopsy / US | CTA/MRA |
| 核准生物製劑 | Tocilizumab | 證據較弱，常用TNFi/Tocilizumab（off-label） |

同站另有蔡文展考官考 2012 Chapel Hill Vasculitides 分類、2022 ACR/EULAR GPA/MPA/EGPA classification criteria，屬 AAV 範疇，不重複列於此篇。

## 2025

### 第三關：GPA 以及 Giant Cell Arteritis（吳詹永嬌主任）

**情境**：老人家有頭痛、視力模糊，你要排哪些檢查、抽哪些血？懷疑什麼？為什麼？

**考官要求**：

1. 把 GCA 的分類標準分數背出來
2. 每一個檢查的 limitation 都要答（例如 temporal artery biopsy 不一定抓得到 lesion）
3. 治療有哪些選擇，什麼時候用生物製劑

**完整答案整理**（綜合 [LVV_分類標準與臨床特徵.md](LVV_分類標準與臨床特徵.md)、[LVV_GCA_TAK_治療.md](LVV_GCA_TAK_治療.md)）：

**1. 病史/理學檢查重點**

- 頭痛特徵：新發、持續性、顳部為主
- Jaw/tongue claudication（咀嚼/講話跛行）
- Scalp tenderness（頭皮壓痛，梳頭時明顯）
- 視力症狀：單眼 vs 雙眼、是否已完全喪失、有無 amaurosis fugax 病史
- 合併 PMR 症狀：肩帶/骨盆帶疼痛與晨僵
- 顳動脈觸診：脈搏減弱/消失、壓痛、cord-like 硬結
- 全身症狀：發燒、體重減輕、疲倦

**2. 應排檢查與抽血**

- 抽血：ESR、CRP、CBC（常見正球性貧血、血小板升高）、ALP（約 30% 升高）
- 影像：顳動脈超音波（首選第一線非侵入性檢查，找 halo sign）
- 確診：顳動脈切片（TAB，黃金標準）
- 若懷疑合併大血管侵犯：CTA/MRA 或 FDG-PET/CT（評估主動脈及其分支）

**3. 2022 ACR/EULAR GCA 分類標準（需背出分數）**

絕對先決條件：年齡 ≥50 歲 + 已確認 LVV（影像或病理）並排除模擬病

| 項目 | 分數 |
|------|------|
| 晨間僵硬（肩/頸部） | +2 |
| 新發持續性顳部頭痛 | +2 |
| 頭皮壓痛 | +2 |
| 下巴或舌頭跛行 | +2 |
| 顳動脈理學異常（脈搏消失/減弱、壓痛、cord-like） | +2 |
| 突發視力喪失（單眼） | +3 |
| 顳動脈切片陽性 或 顳動脈超音波暈圈徵 | +5 |
| 雙側腋動脈侵犯（影像） | +2 |
| FDG-PET 下行胸主動脈+腹主動脈異常攝取 | +2 |
| ESR ≥50 mm/hr 或 CRP ≥10 mg/L | +3 |

**≥6 分符合分類。**

**4. 各檢查的 limitation（考官要求逐項答）**

- **ESR/CRP**：非特異性，感染、惡性腫瘤也會升高；大血管型 GCA 發炎指數可能偏低甚至正常，不能單靠 lab 排除
- **顳動脈超音波**：操作者依賴度高；已使用類固醇數天後 halo sign 可能快速消失，需儘早檢查
- **顳動脈切片（TAB）**：病灶為 **skip lesion**（節段性侵犯），單側切片可能取樣落在正常段而偽陰性；為侵入性檢查；建議在類固醇開始後 **2 週內**取樣，且切片長度需 ≥1–2 cm 以降低偽陰性率
- **FDG-PET/CT**：對顱內小血管（顳動脈本身）解析度不足，主要用於評估大血管侵犯；類固醇使用後 FDG 攝取會迅速下降，影響判讀；有輻射劑量、費用高
- **CTA/MRA**：CTA 有輻射劑量；MRA 若腎功能不佳需考慮顯影劑（gadolinium）風險；兩者皆無法取得組織診斷

**5. 治療與生物製劑使用時機**

- **視力威脅（threatened vision loss / acute visual loss）**：立即給予 **IV methylprednisolone 1000 mg/day × 3 天**，不可等切片結果延誤治療，再接續 oral prednisone 60 mg/day
- 無視力威脅：**Oral prednisone 40–60 mg/day**，每日給藥
- **生物製劑（Tocilizumab, IL-6R inhibitor）使用時機**：
  - **新診斷 GCA**：建議 GC + tocilizumab 合併治療優於單用 GC（降低 relapse、達成 steroid-sparing 效果，FDA 2017 核准）
  - **復發合併 cranial ischemia**：加 tocilizumab 優於加 MTX
  - 使用 tocilizumab 期間 CRP 不可靠（IL-6 被抑制，約 92% exacerbation 時 markers 正常），仍需監測 aortitis 進展（影像追蹤）
  - 禁忌：diverticulitis、活動性肝炎
  - TNF inhibitors 對 GCA **無效**
  - Large-vessel GCA：加用 non-GC IS（tocilizumab 或 MTX）

## 考試速記重點（跨年度重複考點）

- **GCA temporal artery halo sign（超音波暈圈徵）**：2020（影像九宮格）、2025（GCA 案例站）皆考，為 GCA 影像判讀最核心考點。
- **PMR 鑑別診斷**（vs EORA、OA）：2022 考，以表格形式出題，唯一一次獨立 PMR 考題。
- **GCA vs TAK 全面比較**（年齡、種族、性別、侵犯血管、臨床表現、治療）：2023 考，答案詳見 [GCA_TAK_口試比較.md](GCA_TAK_口試比較.md)。
- **2022 ACR/EULAR GCA 分類標準逐項配分**：2025 考官明確要求「背出分數」，為近年考試難度提升的代表題型；建議同時準備 [LVV_分類標準與臨床特徵.md](LVV_分類標準與臨床特徵.md) 中的 TAK、PMR 分類標準以防延伸提問。
- **各項 GCA 檢查的 limitation**（TAB skip lesion、超音波 operator-dependent、PET 對顱內血管解析度不足、ESR/CRP 非特異性）：2025 明確要求逐項答，屬於「不只要會做檢查，還要知道檢查的極限」的進階考法。
- **Tocilizumab 在 GCA 的角色與使用時機**（新診斷合併使用優於單用 GC；復發合併 cranial ischemia 時優先於 MTX）：2025 考，需與 [LVV_GCA_TAK_治療.md](LVV_GCA_TAK_治療.md) 中 TAK 的 tocilizumab 角色（TAK 不建議優先使用）做對比，避免混淆。
- **近年趨勢**：2019–2022 年 LVV 出題比重低（多僅零星帶到），2023 起明顯轉為要求深入比較與分類標準記憶，2025 更進一步要求檢查 limitation 與生物製劑使用時機的臨床決策，顯示口試難度逐年提升。
