# Granuloma 形成機轉與跨疾病比較

## 一、Granuloma 的一般形成機轉

Granuloma 是巨噬細胞為了圍堵無法清除的抗原（感染原、免疫複合體、外來物質）所形成的組織學結構。

![Granuloma formation](../images/Granuloma%20formation.png)

形成過程：

```
Macrophage 呈現抗原 → 活化 CD4+ Th1 cells
        ↓
Th1 cells 分泌 IFN-γ → 進一步活化 macrophage
        ↓
Macrophage 轉變為 epithelioid cells + Langhans giant cells
        ↓
外圍被 lymphocytes + fibroblasts 包圍形成一道牆
```

---

## 二、組織學重點

| 名詞 | 說明 |
|--|--|
| Epithelioid histiocytes | 活化的巨噬細胞，粉紅色細胞質，形似上皮細胞 |
| Langhans giant cells | 多個巨噬細胞融合而成的多核巨細胞，細胞核排列在周邊呈馬蹄形 |
| Central necrosis | 只出現在 caseating granuloma |

### Caseating vs Non-caseating

| | Caseating（乾酪樣壞死） | Non-caseating（無壞死） |
|--|--|--|
| 中心構造 | Necrotic（壞死） | Solid，無壞死 |
| 代表疾病 | TB、fungal infection | Sarcoidosis、Crohn's disease、GPA、beryllium exposure |

## 三、會形成 Granuloma 的疾病總整理

| 分類 | 疾病 | 備註 |
|--|--|--|
| Granulomatous vasculitis | **GPA** | PR3-ANCA + T cell 軸驅動，necrotizing granuloma；機轉詳見 [AAV_三大疾病完整比較](../Vasculitis/AAV/AAV_三大疾病完整比較.md) |
| Granulomatous vasculitis | **EGPA** | 嗜酸球性肉芽腫，Th2/IL-5 軸驅動 |
| Granulomatous vasculitis | **GCA** | 大血管，血管壁可見 giant cell |
| Granulomatous vasculitis | **Takayasu arteritis** | 大血管，granulomatous inflammation |
| 非血管炎的 systemic granulomatous disease | **Sarcoidosis** | Non-caseating granuloma 的原型代表 |
| 消化道相關 | **Crohn's disease** | Non-caseating granuloma；為 IBD-associated arthritis 的原發疾病 |
| Autoinflammatory | **Blau syndrome / EOS**（early-onset sarcoidosis） | NOD2 突變，表現為 arthritis + uveitis + dermatitis |
| 結締組織病的局部變形 | **RA rheumatoid nodule** | Palisading granuloma：中心 fibrinoid necrosis，外圍 palisading histiocytes |
| 感染性 | TB、fungal infection（如 histoplasmosis） | Caseating granuloma 為主 |
| 職業／環境暴露 | Berylliosis、Silicosis | Non-caseating granuloma |

## 四、易混淆的鑑別診斷 Pearls

> ⚠️ **IgG4-RD 通常「沒有」granuloma**
> IgG4-RD 的病理特徵是 dense lymphoplasmacytic infiltrate + storiform fibrosis + obliterative phlebitis。切片若看到 granuloma，反而要重新考慮 sarcoidosis 或 GPA，而不是 IgG4-RD——這是鑑別診斷上的重要陷阱。

> ⚠️ **MPA 沒有 granuloma**
> MPO-ANCA 平常藏在顆粒裡，不需要 priming 就外露的性質不像 PR3，T cell 較少被持續刺激，所以 MPA 只有純粹的 vasculitis，沒有 granulomatous inflammation，這是 MPA 與 GPA 在機轉與病理上的關鍵差異。

> ⚠️ **PAN（polyarteritis nodosa）也沒有 granuloma**
> PAN 是 medium-vessel vasculitis，病理為 fibrinoid necrosis，不具 granulomatous 成分，可與 GPA/EGPA 這類 granulomatous vasculitis 區別。
