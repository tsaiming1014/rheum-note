# Herpes Zoster（帶狀疱疹）於風濕免疫疾病病人之整理

> 帶狀疱疹（herpes zoster, HZ, shingles）是 varicella zoster virus（VZV）沿感覺神經節（dorsal root ganglia／cranial nerve ganglia）再活化所致。風濕免疫疾病病人因疾病本身及免疫抑制治療，HZ 風險較一般人高，是應試重點之一。

---

## 一、為什麼風濕病人 HZ 風險較高

- VZV 的長期潛伏控制主要仰賴**細胞免疫（cell-mediated immunity, CD8+ T cell）**，體液免疫（抗體）角色較次要
- 疾病本身：**SLE、發炎性肌肉病變（inflammatory myositis）**病人 HZ 風險即高於一般人（不論是否用藥）
- 藥物：凡是會削弱細胞免疫、T 細胞功能，或干擾抗病毒天然免疫路徑（type I interferon）的藥物，皆會進一步提高風險

---

## 二、各類藥物之 HZ 風險整理

| 藥物類別 | 代表藥物 | HZ 風險 | 機轉／備註 |
|---|---|---|---|
| **JAK inhibitors**（class-wide） | Tofacitinib、Baricitinib、Upadacitinib、Filgotinib、Peficitinib | **目前風濕科藥物中風險最高的一類**，明顯高於 csDMARD 及大多數 bDMARD | 阻斷 JAK-STAT 訊息傳遞，抑制 IFN-γ 等細胞激素訊號，削弱抗病毒細胞免疫（機轉見 [JAK-STAT 訊息傳遞機轉](../Immunology/JAK-STAT_訊息傳遞機轉.md)）；危險因子：**10mg 劑量、併用類固醇、高齡、亞裔**；HZ 發生率不隨用藥時間增加而上升 |
| ↳ Tofacitinib | | HZ 3.6/100 pt-yrs | 10mg 劑量因 SIE 較高，未獲 FDA/EMA 核准用於 RA（僅核准 UC） |
| ↳ Baricitinib | | HZ 3.0/100 pt-yrs | |
| ↳ Upadacitinib | | HZ 3.7/100 pt-yrs（15mg） | 頭對頭試驗中 HZ、CPK 上升皆高於 adalimumab |
| ↳ Filgotinib | | HZ **相對較低**（0.6–1.1/100 pt-yrs） | 台灣、歐盟仍核准用於 PsA（美國未過核准） |
| **Anifrolumab**（anti-IFNAR1） | Saphnelo | **明顯增加**（SLE 生物製劑中最突出者） | 阻斷**全部 type I interferon** 訊號，而 type I IFN 是對抗 herpesvirus 的重要先天免疫路徑；風險方向與 Belimumab 相反（Belimumab 風險不突出） |
| **TNF inhibitors** | Adalimumab、Etanercept 等 | 較 csDMARD 略增，但**遠低於 JAKi** | |
| **Rituximab**（anti-CD20） | | 相關研究較少，一般感染風險增加 | B 細胞去除，體液免疫受影響為主；對疫苗體液反應的影響需考慮 |
| **Azathioprine** | | 感染率約 2.5/100 pt-yrs（含 HZ、CMV） | 較 alkylating agent（如 cyclophosphamide）感染風險低 |
| **Glucocorticoid** | | 為多項研究中**重要的共同危險因子**（與 JAKi、TNFi 併用時風險加乘） | |

**臨床提醒（口試常考）**：不考慮藥物因素，**SLE、發炎性肌肉病變**病人本身 HZ 風險即較高；考慮藥物因素則以 **JAK inhibitor** 與 **Anifrolumab（anti-IFNAR1）** 最需留意。

## 三、疫苗比較：Shingrix（RZV）vs. Zostavax（ZVL）

| | **Shingrix**（RZV, recombinant zoster vaccine） | **Zostavax**（ZVL, live zoster vaccine） |
|---|---|---|
| 疫苗類型 | **重組蛋白疫苗**（glycoprotein E + AS01B 佐劑），**非活性** | **活性減毒疫苗** |
| 免疫抑制病人可否使用 | **可以**，不論用藥狀況皆可安全接種 | **禁忌**（免疫抑制病人不建議；僅特定情況下高風險族群可個別化考慮） |
| 效力 | ZOE-50 試驗於一般族群效力約 **97%**；AIIRD 族群次分析效力達 **90.5%**，未增加疾病復發 | 效力較低，且免疫力隨時間下降較快 |
| 保護持續時間 | 可達 **10 年以上**（機轉：AS01B 佐劑誘發強效且持久的 CD4+ T 細胞與體液免疫反應） | 較短 |
| 目前上市狀況 | 現行標準疫苗 | **已自美國市場下市**，部分地區仍可取得 |
| 與免疫抑制劑併用 | Tofacitinib RCT 中，接種後體液免疫反應與安慰劑組相近；TNFi 使用者接種後體液及細胞免疫反應反而**增加 30%**；JAKi 使用者體液免疫反應相對保留，但**細胞免疫反應減弱**，併用 MTX 時更明顯 | 需於使用 bDMARD/tsDMARD **前 4 週**接種，治療中不可接種 |
| 接種後疾病復發風險 | 觀察性研究顯示疾病復發（flare）發生率 ≤7%，多為輕度，好發於**類固醇使用中、疾病活性較高**者，一般不需調整免疫抑制治療 | — |

**考題重點（免專筆試曾考）**：Zostavax 與 Shingrix 的差異在於**引發的免疫機轉不同**——Zostavax 為活性減毒病毒直接引發免疫反應（但強度與持久性有限）；Shingrix 則是**重組蛋白抗原 + AS01B 佐劑**設計，能誘發更強、更持久（可達十年以上）的 CD4+ T 細胞反應，這也是 Shingrix 效果能維持較久的關鍵原因。

## 四、疫苗接種建議（ACR / EULAR）

- **核心原則**：診斷時即應評估並規劃疫苗接種（[風濕病人疫苗接種建議](2022_ACR_疫苗接種指引_台灣對照版.md)），不論疾病活性，儘早接種
- **ACR 建議**：18 歲以上、使用免疫抑制治療的病人，只要當地可取得 RZV（Shingrix），皆建議接種
- **EULAR 建議**：在無法取得 RZV 的情況下，ZVL（Zostavax）可於**高風險免疫抑制病人**個別化考慮使用
- **JAK inhibitor 使用者**：建議**用藥前**先完成 HZ 疫苗接種（因 JAKi 為目前風濕科藥物中 HZ 風險最高者）
- 若因故仍需使用 ZVL（活性疫苗），須於啟動 bDMARD/tsDMARD **前 4 週**接種，且**治療期間不可接種**
- Shingrix 為非活性疫苗，**不論用藥狀況皆可安全接種**，不需因此停藥或延後治療

## 五、臨床表現與鑑別診斷

- 典型表現：**單側、沿單一皮節（dermatomal）分布**的群聚水泡，常合併皮節分布之神經痛（可先於皮疹出現）
- **鑑別診斷（口試常考情境：老年人雙下肢大量水泡）**：

| 病因 | 關鍵病史 | 典型特徵 |
|---|---|---|
| Herpes zoster | 免疫低下、皮節分布疼痛前驅症狀 | **單側**、沿皮節分布，**不會**表現為雙側大範圍水泡 |
| Bullous pemphigoid | DPP4 inhibitor、allopurinol 等藥物史 | 緊繃的張力性水泡（tense bullae），常伴搔癢 |
| Vibrio vulnificus 感染 | 海鮮傷口、泡海水史、肝硬化 | 出血性水泡，進展快、易併發敗血症 |

- 特殊型態需留意：**多皮節（multidermatomal）HZ** 可見於 JAK inhibitor 使用者，提示免疫功能明顯低下，需視為機會性感染
- 侵犯眼部分支（herpes zoster ophthalmicus）需立即眼科會診，避免角膜併發症

## 六、治療重點

- **抗病毒藥物**：valacyclovir、famciclovir 或 acyclovir，理想於皮疹出現 **72 小時內**開始，可縮短病程、降低 post-herpetic neuralgia（PHN）風險；依腎功能調整劑量
- **Post-herpetic neuralgia（PHN）**：好發於高齡、疼痛程度重者；治療選擇包含 gabapentin、pregabalin、三環抗憂鬱劑、局部 lidocaine patch
- **免疫抑制藥物是否暫停**：無明確證據要求常規停藥，臨床上可依感染嚴重度、是否有瀰漫性/多皮節/內臟侵犯個別化決定是否暫時調整治療
- 眼部侵犯、瀰漫性（disseminated）或多皮節 HZ 應視為較嚴重感染，積極治療並考慮會診感染科

---

## 七、考題重點速記

- Zostavax（活性減毒）已下市，被 Shingrix（重組蛋白，非活性）取代；**Shingrix 效果持久（10年+）的關鍵是 AS01B 佐劑誘發強效且持久的 CD4+ T 細胞反應**
- 不考慮藥物，**SLE、發炎性肌肉病變**本身即 HZ 高風險疾病；考慮藥物則 **JAK inhibitor、Anifrolumab（anti-IFNAR1）** 風險最突出
- **Anifrolumab 的 HZ 風險高於 Belimumab**（機轉方向：阻斷 type I IFN → 削弱抗病毒先天免疫），這是常考的「方向題」陷阱
- JAK inhibitor 危險因子：**10mg 高劑量、併用類固醇、高齡、亞裔**；**Filgotinib 的 HZ 風險在同類藥物中相對較低**
- 老年人雙下肢「大範圍、對稱性」水泡 → **不是** HZ 的典型表現（HZ 是單側、沿皮節分布）
