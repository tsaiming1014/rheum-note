# 各風濕免疫疾病之眼睛表現總整理（Kelly Ch44）

> 相關筆記：[風專筆試題庫 第19題](../考試準備/風專歷屆考題/風專筆試.md)（不同疾病配對的眼睛表現；SLE 的皮膚表現）

## 一、總表：疾病 vs. 最具代表性眼睛表現

| 疾病 | 眼睛表現 | 詳細描述 |
|---|---|---|
| **Rheumatoid arthritis** | Scleritis | 通常**病程晚期**才出現，幾乎不會是 RA 的首發表現；多發生在**長病程、RF/ACPA 陽性**病人，常合併 nodule、vasculitis、pleuropericarditis；預後差、**存活率降低**；嚴重時可致 **corneal melt / 穿孔**（peripheral ulcerative keratitis） |
| | Sicca (KCS) | RA 最常見的眼睛表現；本質是 **2° Sjögren's syndrome**；症狀輕微，局部治療即可 |
| | Episcleritis | 無痛性紅眼，血管在 limbus 處止住（可用 2.5% phenylephrine 使血管收縮做鑑別）；**不影響視力**，通常自限 |
| **SLE** | Sicca | 同樣多為 **2° Sjögren's** |
| | Cotton-wool spots | 視網膜微梗塞，反映 retinal microvasculopathy，可作為疾病活性指標之一 |
| **Sjögren's syndrome (primary)** | Sicca (KCS) | 疾病**核心/定義性**表現，非續發性 |
| **Spondyloarthritis（尤其 AS）** | **Acute anterior uveitis (AAU)** | 北美/歐洲**最常見**與 uveitis 相關的風濕病；AS 病人終生約 **40%** 會發生；特徵為 **unilateral、recurrent、sudden onset、<3個月自行緩解、眼壓偏低**（可與 HSV 引起的 uveitis 鑑別——HSV 眼壓會升高）；可能出現 hypopyon；復發可換到對側眼，但**同時雙側少見**；約 50% AAU 病人 HLA-B27(+)，其中約 80% 有 associated spondyloarthropathy（常未被診斷出來） |
| **ANCA-associated vasculitis (AAV)** | Scleritis | 可以是 **granulomatosis with polyangiitis 的首發表現**；常合併 limited disease（肺腎未受侵犯）；建議所有原因不明 scleritis 病人都應檢驗 ANCA |
| | Orbital inflammation | AAV 是**最常侵犯眼眶**的風濕病；發炎可非常疼痛、可致失明；對治療常較頑固 |
| **Giant cell arteritis (GCA)** | **Anterior ischemic optic neuropathy (AION)** | GCA **最令人畏懼的併發症**；因 posterior ciliary artery 發炎缺血造成突發性視力喪失（arteritic AION，與較常見的 nonarteritic AION 因小血管動脈硬化不同，後者病人視神經盤較小）；也可侵犯 central retinal artery 造成失明，眼底可見 **cherry-red spot**；顳動脈切片陽性率約 80% |
| **Systemic sclerosis (SSc)** | Sicca | 同樣多為 2° Sjögren's |
| **Behçet's disease** | Uveitis + retinal vasculitis | Uveitis 常是**驅動全身免疫治療的關鍵表現**；多為 **bilateral、recurrent**，且不像 AS **發作間無法完全緩解**；視網膜**動脈**特別容易被侵犯；未治療視力預後**很差、可致失明**；infliximab 對此特別有效（日本已核准此適應症） |
| **Relapsing polychondritis** | Scleritis、Episcleritis、Uveitis | 幾乎眼睛任何結構（episclera、sclera、uveal tract）都可能受侵犯，眼部發炎相當常見 |
| **Dermatomyositis** | Heliotrope eyelids | 本質為**皮膚**表現（眼皮紫紅色皮疹合併水腫），而非眼球內發炎 |
| **Sarcoidosis** | Granulomatous uveitis | 北美地區與 uveitis 相關**第二常見**全身性疾病（部分地區甚至超過 SpA）；可侵犯眼睛幾乎所有構造（orbit、lacrimal gland、anterior uvea、vitreous、choroid、retina、optic nerve）；特徵性 **keratic precipitates**（角膜內皮上白色沉積物，稱 granulomatous，但組織學不一定真有 granuloma）；約 **30% 特發性 uveitis 病人其實是未被發現的 sarcoidosis**；眼睛症狀常是 sarcoidosis **最初表現**，與肺部症狀一樣常見 |
| **JIA**（ANA+、pauciarticular、好發 2–8 歲女童）| Chronic anterior uveitis | **insidious onset**，幾乎不痛不紅，常在學校視力篩檢才發現；多為 **bilateral、持續性**；特徵性併發症：**band keratopathy**（鈣沉積於角膜）、posterior synechiae（虹膜與水晶體沾黏）、glaucoma |
| **Blau syndrome**（NOD2/CARD15 突變，體染色體顯性）| Uveitis + arthritis + dermatitis | 兒童期發病之三聯症；granulomatous（與 sarcoidosis 組織學相似），但**不侵犯肺部**（與早發型 sarcoidosis 的鑑別點） |
| **NOMID/CINCA** | Papilledema + uveitis | 自體發炎症候群，眼睛表現較 Blau syndrome 變異度大 |
| **Cogan's syndrome** | Interstitial keratitis + sensorineural hearing loss | 典型定義即此組合；廣義定義可包含 uveitis 或 scleritis |
| **Kawasaki's disease** | Anterior uveitis + conjunctivitis | 兩者常同時出現（與 AS 不同——AS 較少合併 conjunctivitis，即使 conjunctivitis 是 reactive arthritis 典型三聯症之一） |
| **IBD-associated arthritis / PsA** | Uveitis | IBD 約 5%、PsA 約 7% 發生率；部分病人為 unilateral/acute（類似 AS 型），部分為 **bilateral、chronic、posterior**；約半數 HLA-B27(+) |
| **IgG4-related disease (IgG4-RD)** | Orbital pseudotumor（IgG4-related orbital disease）| IgG4-RD **好發侵犯部位之一**：淚腺（dacryoadenitis，常雙側）、眼外肌（**orbital myositis**，可致永久眼外肌功能障礙）、眼眶軟組織形成 inflammatory pseudotumor / mass-like lesion；影像上易與 lymphoma、其他眼眶惡性腫瘤混淆，需病理（IgG4+ plasma cell、storiform fibrosis）鑑別；與 Kelly Ch44 提到的「orbital pseudotumor（非特異性眼眶發炎，排除性診斷）」在此疾病脈絡下常見的病因之一 |
| **Multiple sclerosis** | Optic neuritis | 免疫疾病中**最常侵犯視神經**者；突發單眼疼痛、afferent pupillary defect、色覺喪失、視野缺損；非風濕科主要治療範疇 |
| **NMO (anti-aquaporin-4)** | Optic neuritis + transverse myelitis | 脊髓侵犯需**≥3個脊椎體長度**才符合典型；治療包括抗 C5、抗 IL-6R、B cell depletion |

## 二、重要鑑別要點（考試常考）

**HLA-B27 uveitis vs. HSV uveitis**

| | HLA-B27 associated | HSV |
|---|---|---|
| 側別 | Unilateral，可換邊復發 | 常也是 unilateral 復發 |
| 眼壓 | **降低** | **升高** |
| 病程 | <3個月，完全緩解 | 較慢性 |

**Conjunctivitis in AS vs. Reactive arthritis**：conjunctivitis 是 reactive arthritis 古典三聯症（arthritis + urethritis + conjunctivitis）之一，但在 AS 本身**少見**——即使兩者 uveitis 表現本身無法區分。

**Scleritis vs. Episcleritis**（Kelly Table 44.4）

| | Episcleritis | Scleritis |
|---|---|---|
| 疼痛 | 輕微不適（scratchy） | **疼痛明顯** |
| 與全身疾病相關性 | 少見 | **約 40% 有全身性疾病**（最常見：limited AAV、RA） |
| 血管反應（2.5% phenylephrine）| 完全收縮 | 不完全收縮 |
| 併發症 | 無（無 glaucoma/uveitis）| 可致 glaucoma、uveitis、optic nerve edema、corneal melt |

## 三、藥物相關眼毒性

- **Hydroxychloroquine (HCQ) retinopathy**：OCT 時代下發現盛行率約 7.5%，詳見既有筆記 [HCQ-retinopathy.md](HCQ-retinopathy.md)
- 可誘發 uveitis 的藥物：rifabutin、IV bisphosphonates、moxifloxacin、TNF inhibitors、ipilimumab

## 四、速記口訣

**「僵葡（AS-uveitis）、肉鞏（AAV-scleritis）、顳缺（GCA-AION）、貝葡血（Behçet-uveitis+retinal vasculitis）、肉眶（AAV-orbit）、少年慢葡（JIA-chronic uveitis）」**

| 疾病 | 一句話記憶 |
|---|---|
| AS | 前葡萄膜炎，單眼、突發、<3個月緩解、眼壓低 |
| AAV | 鞏膜炎（可為首發）+ 眼眶炎（最會侵犯眼眶的風濕病）|
| GCA | AION 是最怕的併發症（失明）|
| Behçet | 葡萄膜炎驅動治療決策 + 視網膜動脈炎 |
| Sarcoidosis | 第二常見 uveitis 病因，全眼構造都可侵犯 |
| JIA | 無痛無紅的慢性前葡萄膜炎，band keratopathy |
| RA | Scleritis 晚期出現、預後差；Sicca 最常見但輕微 |
| IgG4-RD | 雙側淚腺腫大（dacryoadenitis）+ orbital myositis/pseudotumor，需與 lymphoma 鑑別 |
