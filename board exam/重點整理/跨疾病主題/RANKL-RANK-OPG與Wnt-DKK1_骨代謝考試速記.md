# RANKL-RANK-OPG 與 Wnt/DKK1/Sclerostin — 骨代謝考試速記

兩大調控軸決定骨骼「吸收」與「生成」的平衡，也是理解 RA 侵蝕不修復、AS/PsA 侵蝕合併骨贅形成的核心機轉。

## 1. 總覽：兩條軸線

| 軸線 | 管什麼 | 促進端 | 抑制端 |
|---|---|---|---|
| **RANKL–RANK–OPG** | Osteoclast 生成（骨吸收） | RANKL + RANK | **OPG**（decoy receptor） |
| **Wnt/β-catenin** | Osteoblast 分化（骨生成） | Wnt + frizzled/LRP5-6 | **Sclerostin**、**DKK1**、SFRP1 |

## 2. RANKL–RANK–OPG 軸（蝕骨）

| 分子 | 來源 | 角色 |
|---|---|---|
| RANKL | Osteocyte（生理主要來源）、preosteoblast、stromal cell；活化 T/B 細胞 | 結合破骨前驅細胞的 RANK，驅動分化成熟 |
| RANK | 破骨前驅細胞（myeloid 系）表面受體 | 接收 RANKL 訊號 |
| OPG | Osteoblast、stromal cell 分泌 | 可溶性誘餌受體，搶走 RANKL，阻止其結合 RANK |

**重點**：

- 破骨分化另需 **M-CSF**（osteoblast/MSC 產生）作為必要共同訊號，缺一不可
- **RANKL:OPG 比值**＝骨吸收活性指標，比值↑ → 骨破壞增加
- **RANKL-KO 小鼠 → osteopetrosis**（無法產生破骨細胞）
- **Denosumab**＝anti-RANKL 單株抗體＝「人工版 OPG」

## 3. Wnt/DKK1/Sclerostin 軸（造骨）

Wnt 結合 osteoblast 前驅細胞的 frizzled + LRP5/6 受體 → β-catenin 活化入核 → 誘導成骨分化基因表現。

| 抑制物 | 來源 | 機轉 |
|---|---|---|
| **Sclerostin** | Osteocyte | 結合 LRP5/6，阻斷 Wnt 訊號 |
| **DKK1**（Dickkopf-1） | 多種細胞（受 TNF 誘導上調） | 結合 LRP5/6，阻斷 Wnt-frizzled complex 形成 |
| SFRP1 | Osteoblast | 直接結合 Wnt 本身 |

**治療應用**：**Romosozumab**＝anti-sclerostin 單株抗體，促進骨生成，用於骨質疏鬆。

## 4. 考試核心比較：RA（侵蝕不修復）vs. AS/PsA（侵蝕＋骨贅並存）

| | RA | AS / PsA（seronegative） |
|---|---|---|
| 早期表現 | 侵蝕（erosion） | 侵蝕（erosion）——早期兩者類似 |
| 晚期表現 | 持續侵蝕，**不會**新骨修復 | 出現 **osteoproliferation**（syndesmophyte、enthesophyte、骨贅） |
| RANKL:OPG | 明顯上升（synovial fibroblast、活化 T/B 細胞是主要 RANKL 來源） | 早期同樣上升，驅動侵蝕 |
| DKK1 | **上升**（TNF 誘導）→ 持續阻斷 Wnt → 無法修復侵蝕 | 功能性 DKK1 **較低者**反而保護，不易形成 syndesmophyte（Heiland et al. 2012, *Arthritis Rheum*）→ 意即 DKK1 相對不足時 Wnt 較不受抑制，promotes 新骨形成 |
| IL-17A 角色 | 主要促破骨（誘導 RANKL、RANK 表現） | **雙重角色**：一方面誘導 RANKL 促破骨，另一方面經 JAK2、γδT 細胞促進 osteoblast 分化（促骨形成）——被認為是連結發炎與新骨形成的關鍵 cytokine |
| 治療對骨的影響 | JAK 抑制劑降低 DKK1、活化 Wnt → 可誘導侵蝕修復 | Anti-TNF 理論上降低 DKK1、應「釋放」Wnt 驅動的骨形成，但**臨床觀察相反**——anti-TNF 實際上減緩 ankylosis 進展，推測是因為在骨形成路徑活化前就先壓制了早期發炎（此為考試常見的認知陷阱，機轉尚未完全釐清） |

## 5. 記憶要點

- **OPG = 誘餌受體**，搶走 RANKL → 抑制蝕骨；**Denosumab = 人工 OPG**
- **Sclerostin / DKK1 = 阻斷 Wnt** → 抑制造骨；**Romosozumab = anti-sclerostin** → 促進造骨
- **Osteocyte 是 master regulator**：同時分泌 RANKL（促蝕骨）與 sclerostin（抑制造骨）
- **RA**：RANKL↑ + DKK1↑ → 只蝕骨、不修復
- **AS/PsA**：RANKL↑（早期侵蝕）＋ Wnt/BMP 路徑後期活化（IL-17A 雙重角色）→ 侵蝕與骨贅並存
