# Migratory Oral Ulcer（反覆/游走性口腔潰瘍）鑑別診斷與檢查方向

## 風濕科常見造成反覆/游走性口腔潰瘍的疾病

| 疾病 | 口腔潰瘍特徵 | 建議檢查 |
|---|---|---|
| **Behçet's disease** | **反覆發作（一年至少 3 次）**、疼痛性、邊緣清楚、多發性 aphthous-like ulcer，常合併 genital ulcer、眼葡萄膜炎、皮膚病灶 | **Pathergy test**、**HLA-B51**、生殖器/眼科檢查、ESR/CRP |
| **SLE** | 通常**無痛**，好發於**硬顎（hard palate）**或鼻中膈，也可有頰黏膜潰瘍 | ANA、dsDNA、補體 (C3/C4)、CBC（血球減少）、尿液分析 |
| **Reactive arthritis** | 通常**無痛**，表淺、邊緣不規則 | 近期腸胃/泌尿道感染史詢問、HLA-B27、關節症狀評估 |
| **IBD-associated arthritis（IBD-A）** | 可有 aphthous ulcer，與腸道疾病活性相關 | 糞便鈣衛蛋白 (fecal calprotectin)、大腸鏡、CRP |
| **MAGIC syndrome**（Behçet's + relapsing polychondritis overlap） | 口腔/生殖器潰瘍 + 軟骨炎（耳、鼻） | 綜合 Behçet's 與 relapsing polychondritis 之檢查 |
| **PFAPA**（多見於兒童） | 週期性發燒伴隨 aphthous ulcer、咽炎、頸部淋巴結炎 | 病史型態（週期性）為主要診斷依據，需排除其他病因 |

## 需同時排除的非風濕科病因

| 病因 | 特徵 | 建議檢查 |
|---|---|---|
| **HSV 感染** | 群聚小水泡潰瘍，疼痛明顯 | 病毒培養/PCR、Tzanck smear |
| **營養缺乏**（鐵、維生素 B12、葉酸、鋅） | 反覆性 aphthous ulcer | CBC、鐵蛋白、B12、葉酸 |
| **HIV 感染** | 反覆頑固性口腔潰瘍 | HIV 篩檢 |
| **Celiac disease** | 反覆口腔潰瘍伴腸胃道症狀 | Anti-tTG IgA |
| **血液惡性腫瘤（如白血病）** | 潰瘍合併其他血球異常 | CBC with differential，必要時骨髓穿刺 |
| **口腔癌/惡性病灶** | 單一、持續不癒合、邊緣硬化的潰瘍（非典型「游走性」表現） | **切片病理檢查**（若潰瘍持續 >2–3 週未癒合須考慮） |

## 整體檢查思路（由簡入繁）

1. **病史詢問**：潰瘍發作頻率、疼痛與否、部位（硬顎提示 SLE，其他部位較不具特異性）、伴隨症狀（生殖器潰瘍、眼睛紅痛、關節炎、皮疹、發燒模式、腸胃症狀）
2. **基礎檢查**：CBC、ESR/CRP、營養指標（鐵、B12、葉酸）
3. **自體免疫指標**：ANA、dsDNA、補體（懷疑 SLE）；HLA-B51（懷疑 Behçet's）；HLA-B27（懷疑脊椎關節病變）
4. **感染篩檢**：HSV、HIV，必要時梅毒血清
5. **若潰瘍持續不癒合或型態不典型**：安排**切片**排除惡性病灶
