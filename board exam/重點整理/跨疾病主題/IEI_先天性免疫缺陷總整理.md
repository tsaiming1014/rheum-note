# IEI — 先天性免疫缺陷（Inborn Errors of Immunity）總整理

> 來源：Kim VHD, Upton JEM, Derfalvi B, Hildebrand KJ, McCusker C. *Inborn errors of immunity (primary immunodeficiencies).* Allergy Asthma Clin Immunol 2024;20(Suppl 3):76.（Practical Guide for Allergy and Immunology in Canada 2024）

---

## 一、定義與流行病學

- **PID（Primary immunodeficiency）現多稱為 IEI**：免疫系統**發育和/或功能**缺陷所造成的一大群異質性疾病。
- 目前已有**近 700 種**疾病找到致病基因，且持續增加。
- 多數為 **germline gene variant**；但也有後天的 **「phenocopies of IEI」**：
  - **Neutralizing anti-IFN-γ autoantibody** → 見於 **>95% 的 disseminated NTM infection** 病人
  - **Anti-type I IFN autoantibody** → 與致命性 **SARS-CoV-2** 重症相關
- 評估 IEI 時，必須先排除 **secondary immunodeficiency**：病毒/細菌感染、營養不良、Ig 流失、惡性腫瘤、免疫抑制藥物。

**盛行率**

| 疾病 | 盛行率 |
|---|---|
| IEI 整體（不含 selective IgA deficiency 與 MBL deficiency） | 約 **1/1200** 活產（美國） |
| Selective IgA deficiency | 約 **1/300 – 1/500** |
| MBL deficiency | 白人 **5–7%**（臨床意義有爭議） |

- **Antibody deficiency 最常見**：約占所有 IEI 診斷的 **50%**
- **Complement deficiency**：約占 **4%**

## 二、分類

依主要受影響的免疫成分分為：

1. **Adaptive immunity 異常**：combined（CID/SCID）、antibody deficiency
2. **Innate immunity 異常**：phagocyte、complement、MSMD
3. **Immune dysregulation**：以 autoimmunity、hyperinflammation 為主，而非感染風險
4. **Primary atopic disorders（PAD）**：以 allergy/atopy 為主要表現的單基因疾病

> 觀念：B cell 產生抗體需要完整的 T cell 功能，因此**大多數 T cell defect 同時合併 antibody deficiency** → 稱為 **combined immunodeficiency（CID）**。

| | Selective immunoglobulin A deficiency（sIgAD） | B cell **無法 class switch/分化為分泌 IgA 的 plasma cell**；多數無明確基因，與 HLA 單倍型、TACI variant 相關；**部分可進展為 CVID** | 多數無症狀；反覆感染、autoimmunity（SLE、celiac disease）；輸血可能出現 **anti-IgA 過敏反應** |
| | Specific antibody deficiency（SAD） | 總 Ig 與 IgG subclass 正常，但**對 polysaccharide antigen（T-independent）反應差**；2 歲以下本來就反應不佳，故 **>2 歲才能診斷** | 反覆 sinopulmonary infection |
| | Immunoglobulin G subclass deficiency | 某 IgG subclass 偏低，以 **IgG2（對 polysaccharide 反應）** 較有臨床意義；單獨存在時臨床意義有爭議 | 反覆 sinopulmonary infection |
| **Phagocyte defects** | Chronic granulomatous disease（CGD） | **NADPH oxidase** 缺陷（最常見 **CYBB/gp91phox，X-linked**，約 65–70%；其次 NCF1/p47phox，AR）→ 無法產生 superoxide/ROS → 殺不死 **catalase-positive organism**（*S. aureus*、*Burkholderia*、*Serratia*、*Nocardia*、*Aspergillus*）；發炎無法消退 → granuloma；**DHR test 異常** | 嚴重感染；**abscess 合併 granuloma 形成**；colitis（類 Crohn disease） |
| | Leukocyte adhesion deficiency（LAD） | **LAD-I：ITGB2（CD18，β2 integrin）** 缺陷 → neutrophil 無法穩定黏附血管內皮與穿出血管 → **血中 neutrophil 極高但感染處無膿**；LAD-II：selectin ligand（sialyl-Lewis X）fucosylation 缺陷；LAD-III：kindlin-3 缺陷（integrin 無法活化，合併出血傾向） | 反覆嚴重細菌感染（**無膿**）；傷口癒合差；**臍帶延遲脫落**；牙周病 |
| **Complement defects** | Early classical pathway deficiency（C1q、C1r、C2、C4） | **Apoptotic cell 與 immune complex 清除障礙（waste disposal hypothesis）** → 核抗原持續暴露、打破 tolerance；**SLE 風險：C1q > C4 > C2**；C2 deficiency 是最常見的 complement deficiency | **SLE-like syndrome**；rheumatoid disease；多種 autoimmune disease；encapsulated bacteria 感染 |
| | Terminal pathway deficiency（C5–C9） | 無法形成 **membrane attack complex（MAC，C5b-9）** → 無法溶解細胞壁薄的 **Neisseria**（同 eculizumab/anti-C5 之風險） | **Neisseria 感染**（反覆 meningococcal disease）；SLE-like syndrome |
| | C3 與 regulatory component deficiency（factor H、factor I、properdin） | **C3 是 opsonization 核心** → encapsulated bacteria 無法被吞噬；**factor H/I** 缺乏 → alternative pathway 失控 → C3 被消耗而下降，並與 **aHUS、C3 glomerulopathy** 相關；**properdin** deficiency（X-linked）→ Neisseria 易感 | 反覆 encapsulated bacteria 感染 |
| **Mendelian susceptibility to mycobacterial disease（MSMD）** | Interleukin-12 / interferon-γ（IL-12/IFN-γ）axis deficiency | Macrophage 分泌 IL-12 → T/NK cell 產生 IFN-γ → 活化 macrophage 殺死胞內菌；此軸缺陷（**IL12RB1** 最常見，另有 IFNGR1/2、STAT1 LOF、IL12B 等）→ **胞內病原**無法清除 | **Atypical mycobacteria（NTM、BCG）與 Salmonella 感染** |
| **Disorders of immune dysregulation** | Hemophagocytic lymphohistiocytosis（HLH） | Familial HLH：**cytotoxic granule 路徑**缺陷（**PRF1/perforin**、UNC13D、STX11、STXBP2）→ CTL/NK 無法殺死受感染細胞與 APC → 持續活化 → **cytokine storm**（IFN-γ、IL-18、IL-6、TNF）→ macrophage 活化吞噬血球；風濕科後天型：sJIA/AOSD 的 **MAS** | 發燒；脾腫大；cytopenia；皮疹；ferritin 極高 |
| | Autoimmune lymphoproliferative syndrome（ALPS） | **FAS（TNFRSF6）** 最常見（另有 FASLG、CASP10）→ **Fas 介導的 activated lymphocyte apoptosis 缺陷** → 淋巴球堆積；特徵 **double-negative T cell（TCRαβ⁺CD4⁻CD8⁻）增加**、vitamin B12/IL-10/sFASL 升高；lymphoma 風險增加 | 脾腫大；淋巴結腫大；autoimmune cytopenia |
| | Immune dysregulation, polyendocrinopathy, enteropathy, X-linked syndrome（IPEX） | **FOXP3** 突變 → **Treg 缺乏/失能** → 失去 **peripheral tolerance**；治療可用 rapamycin（mTOR inhibitor）、HSCT | Autoimmune enteritis（嬰兒期頑固腹瀉）；**early-onset type 1 diabetes**；thyroiditis；cytopenia；eczema |
| | Autoimmune polyendocrinopathy–candidiasis–ectodermal dystrophy（APECED，又稱 APS-1） | **AIRE** 突變（AR）→ thymus medullary epithelial cell 無法表現 tissue-restricted self-antigen → **negative selection 失敗（central tolerance 缺陷）** → 器官特異性 autoimmunity；另產生 **anti-IL-17F / anti-IL-22 autoantibody** → chronic mucocutaneous candidiasis；**典型三聯症：CMC + hypoparathyroidism + Addison disease** | Parathyroid、adrenal 等內分泌器官 autoimmunity；**candidiasis**；牙釉質發育不全 |
| | Cytotoxic T-lymphocyte-associated protein 4（CTLA4）haploinsufficiency | AD；Treg 上的 **CTLA4 透過 trans-endocytosis 移除 APC 上的 CD80/CD86**，限制 CD28 共刺激 → CTLA4 量不足 → Treg 抑制失敗、T cell 過度活化；**LRBA deficiency** 表現類似（LRBA 保護 CTLA4 免於 lysosome 分解）；可用 **abatacept（CTLA4-Ig）** targeted therapy | Lymphoproliferation；autoimmune cytopenia；**hypogammaglobulinemia**；反覆感染；其他 autoimmunity（enteropathy、ILD） |
| **Primary atopic disorders（PAD）** | CARD11-associated atopy with dominant interference of NF-κB signaling（CADINS） | **CARD11 dominant-negative** 突變；CARD11 與 BCL10、MALT1 組成 **CBM complex**，傳遞 TCR/BCR → **NF-κB、mTORC1** 訊號 → 訊號受損造成 **Th2 偏移**、嚴重 atopy（對比：CARD11 GOF → **BENTA**，B cell 過度增生） | 嚴重 atopic dermatitis；eosinophilia；皮膚病毒感染；呼吸道感染 |
| | Dedicator of cytokinesis 8（DOCK8）deficiency | AR（**autosomal recessive hyper-IgE syndrome**）；DOCK8 為 Cdc42 的 GEF，調控 actin cytoskeleton → T cell、DC 通過緻密組織（皮膚）時細胞破裂死亡（**cytothripsis**）→ 皮膚病毒感染（HPV、HSV、molluscum）、T cell 耗竭、Th2 偏移；IgE 高、eosinophilia；**squamous cell carcinoma** 風險；治療以 HSCT 為主 | 嚴重 atopic dermatitis；**嚴重食物過敏**；**皮膚病毒感染**；autoimmunity |
| | Mucosa-associated lymphoid tissue lymphoma translocation protein 1（MALT1）deficiency | AR LOF；MALT1 為 **CBM complex** 成員 → TCR/BCR 下游 **NF-κB 活化受損**、Treg 缺陷 → **合併免疫缺陷 + atopy** | 嚴重皮膚炎；IgE 升高；生長不良；反覆皮膚、呼吸道、腸胃道感染 |

## 三、各類疾病臨床表現

### 1. Combined immunodeficiency（CID / SCID）

- 可有 **lymphopenia**、neutropenia。
- **SCID**：缺乏 T cell 和/或 T cell 功能 → 分為 **T⁻B⁺** 與 **T⁻B⁻**；**NK cell 數量**也有助判斷基因型。
- ⚠️ **T cell 數量正常不能排除 T cell defect** → 臨床像免疫缺陷時要進一步做 T cell 功能檢查。
- CID 常合併：thrombocytopenia、**DNA repair defect → 惡性腫瘤**、症候群特徵（先天異常、智能發展遲緩、聽損、身材矮小、ectodermal dysplasia）、臉部異型。
- **SCID 表現**：**1 歲內**出現慢性腹瀉、failure to thrive、反覆 opportunistic infection（*Candida albicans* thrush、**PJP**、**CMV**）、皮疹。
  - **SCID 是小兒急症**，常因感染死亡；**HSCT 可根治**。
- **較輕的 CID**（不一定早期致死）：Wiskott-Aldrich syndrome、DiGeorge syndrome、ataxia-telangiectasia → 兒童期較晚出現反覆感染，**autoimmunity 與 immune dysregulation 常見**。
- **Hyper-IgE syndrome**：皮膚、骨骼、肺的 **staphylococcal infection** + 骨骼異常 + 高 IgE。
  - 致病基因：**STAT3** 突變 → 影響 phagocyte 辨識 *S. aureus*，以及骨骼重塑相關的 osteoclast 功能。

### 2. Antibody deficiency（最常見，約 50%）

- 易感 **encapsulated bacteria**（尤其 ***S. pneumoniae***、***H. influenzae***）呼吸道感染。
- **6 個月大後**才發病（母體經胎盤傳來的 IgG 消退後）→ 反覆、常嚴重的 otitis media、sinusitis、pneumonia。
- 常見合併：腹瀉、疲倦、**autoimmunity（尤其 autoimmune cytopenia）**、聽力受損、慢性肺病（**granuloma、bronchiectasis**）。
- 血清 Ig 可降低或測不到，但**也可能正常甚至升高而功能異常**。
- **>50% 在成年後才被診斷**，從發病到確診常有長時間延誤。
- 已有 >50 種找到致病基因。

**三大 antibody deficiency 比較**

| | XLA（Bruton） | CVID | Selective IgA deficiency |
|---|---|---|---|
| 基因 | **BTK** | 異質性 | — |
| 性別 | 男性（X-linked） | 男女相同 | — |
| 發病 | **2 歲內** | 較晚（常 **>10 歲**） | — |
| 血清 Ig | IgG、IgA、IgM 全部明顯下降 | **IgG 明顯下降** + IgA 和/或 IgM 低 | IgA 極低或測不到，**IgG、IgM 正常** |
| B cell | **循環 B cell 明顯減少** | — | — |
| 疫苗反應 | — | **差或無反應** | 部分有 specific antibody 缺陷 |
| 特徵 | 反覆 sinopulmonary infection；**沒有淋巴結與扁桃腺** | 反覆 sinopulmonary infection、**autoimmune 與 granulomatous disease**、腸胃道合併症、**lymphoma、gastric carcinoma**、bronchiectasis（主要罹病與死亡原因） | **多數無症狀**；有症狀者約 1/3 反覆感染、約 1/3 有器官特異性或全身性 autoimmunity |

- XLA 是**第一個被描述、也是第一個被做基因研究的免疫缺陷疾病**。

### 3. Innate immunodeficiency

- **任何年齡**都可能發病，常見少見或難以根除的感染。
- **Phagocyte disorder**：皮膚、呼吸道、內臟的嚴重**化膿性細菌與黴菌感染**，以及指甲、牙齦問題與口周疼痛潰瘍。
- **CGD**：特別易感 **catalase-positive bacteria** 與黴菌。
- **Complement deficiency（約 4%）**：表現為 **lupus-like 全身性自體免疫疾病**，或反覆嚴重 encapsulated organism 感染。

### 4. Immune dysregulation

- Lymphocyte 可能存在但功能異常 → 過度自體反應。
- 主要表現：autoimmune cytopenia、lymphoproliferation、enteropathy、allergy、systemic autoimmunity、inflammation；**仍可能感染**。
- 代表疾病：**HLH、ALPS、IPEX、APECED、CTLA4 haploinsufficiency**。
- **Tolerance 機轉**：
  - **Central tolerance**（thymus）：強烈自體反應的 T cell 被清除（negative selection），或分化為 **Treg**。
  - **Peripheral tolerance**：表現 **FoxP3** 的 Treg 抑制 T cell 反應。
  - Checkpoint 出問題 → autoimmunity、allergy、inflammation、lymphoproliferation、惡性腫瘤。

### 5. Primary atopic disorders（PAD）

- 單基因疾病，**penetrance 與 expressivity 不一**。
- 相關機轉：cytokine signaling 異常、皮膚屏障破壞、mast cell 功能異常、TCR/BCR signaling 受損、tolerance 失敗。
- 過敏表現通常嚴重難控（如嚴重 atopic dermatitis），可合併感染、autoimmunity、惡性腫瘤。
- 很多 PAD 合併**身材矮小、生長不良、結締組織異常**。

## 四、診斷

### 診斷延遲（2023 IDF 美國全國病人調查）

- 多數病人**成年後**才被診斷（**平均 49.5 歲**）。
- 從開始感染到確診**平均約 25 年**。
- 確診並治療後，感染比例明顯下降。

### 新生兒篩檢：TREC assay

- **TREC（T-cell receptor excision circle）**：TCR 基因重組時被剪下的環狀 DNA → 可定量新生兒 T cell 生成量。
- 可篩出**多數（但非全部）SCID**；**不能篩其他 IEI**。
- 在嚴重感染發生前做 HSCT，預後大幅改善。

### Jeffrey Modell Foundation 10 warning signs（Table 2）

| 兒童 | 成人 |
|---|---|
| 1 年內 **≥4 次**新的中耳炎 | 1 年內 **≥2 次**新的中耳炎 |
| 1 年內 **≥2 次**嚴重鼻竇炎 | 1 年內 **≥2 次**新的鼻竇炎（排除過敏） |
| 用抗生素 **≥2 個月**效果不佳 | **每年 1 次肺炎、持續 >1 年** |
| 1 年內 **≥2 次**肺炎 | **慢性腹瀉合併體重減輕** |
| 嬰兒體重不增或生長不良 | **反覆病毒感染**（感冒、herpes、疣、condyloma） |
| 反覆深部皮膚或器官膿瘍 | 反覆需要 IV 抗生素才能控制感染 |
| 持續口腔 thrush 或皮膚黴菌感染 | 反覆深部皮膚或內臟膿瘍 |
| 需要 IV 抗生素才能控制感染 | 持續 thrush 或皮膚等處黴菌感染 |
| **≥2 次**深部感染（含 septicemia） | **正常人不致病的類結核菌感染** |
| IEI 家族史 | IEI 家族史 |

- 符合任一項 → 立即轉介 clinical immunologist。
- 其他警訊：嚴重 atopy、autoimmunity、cytopenia 等**過度發炎反應**。

### 檢查流程

1. **CBC + blood smear**：lymphopenia（**明顯 lymphopenia 可能是 T cell 缺陷的第一個線索**）、異常 lymphocyte 或 phagocyte。
2. **Flow cytometry（lymphocyte subsets）**：計數 B、T、NK cell；**多數 SCID 與許多 CID 會異常**；進一步可做 lymphocyte proliferation assay、TCR diversity、adhesion receptor。
3. **Antibody deficiency**：
   - 先驗 **IgG、IgA、IgM**（**IgD 對診斷 IEI 沒有幫助**）。
   - 部分病人 Ig 正常或只輕度降低 → **最佳確診方式是測疫苗反應**：打 **protein antigen（tetanus toxoid）** 與 **polysaccharide antigen（pneumococcus）**，比較接種前後 specific IgG 效價（判讀可參考 AAAAI 共識文件）。
4. **Innate disorder**：
   - Neutrophil function assay：**DHR（dihydrorhodamine）test** → **neutrophil oxidase 功能異常 → 通常是 CGD**。
   - Cytokine stimulation assay。
   - **Complement studies**（濃度和/或功能）→ 需在有經驗的認證實驗室進行。
5. **Genetic testing**：NGS gene panel、whole exome sequencing，已常規用於複雜或嚴重個案。
   - 例：CVID 表現型病人中有 **25% 可找到基因缺陷**（原文提到約 70 種可辨識的基因缺陷）→ 可據以做 targeted therapy。

## 五、治療（Table 3）

**原則**

- **不需等到基因診斷才開始治療**：依臨床與實驗室表現開始，延誤可能造成永久器官損傷或死亡。
- 基因診斷可指引 targeted therapy：small-molecule inhibitor、biologics、immune modulator、gene therapy、HSCT。
- 疫苗策略要個別調整：有些禁用、有些需追加劑量、有些需配合治療時程。

| | Supportive | Definitive |
|---|---|---|
| **CID/SCID** | Ig replacement（IV/SC）、**PJP prophylaxis**、抗菌與抗黴菌預防、積極治療現有感染、住院感染防護、**停打所有活疫苗**、SCID 依母親 CMV 狀態可能需停止哺乳 | **多數 SCID 做 HSCT**；部分 SCID 可 gene therapy |
| **Antibody deficiency** | Ig replacement（IV/SC）、抗生素預防、視病因抗黴菌預防、**監測聽力與肺功能** | Gene therapy（未來可能） |
| **Innate disorder** | 抗菌與抗黴菌預防；CGD 有時考慮 **IFN-γ**；有時需 Ig replacement | **部分（如 CGD、LAD）做 HSCT**；gene therapy |
| **Immune dysregulation** | 免疫抑制／調節治療 autoimmune/inflammatory 表現、抗黴菌預防、監測 autoimmune/inflammatory/惡性腫瘤合併症、有時需 Ig replacement 或 **small molecule inhibitor** | 部分做 HSCT |
| **PAD** | 免疫抑制／調節、有時需 Ig replacement | 部分做 HSCT |

### 1. SCID / CID

- **抗生素預防**沒有標準方案（缺乏 RCT），常用 **amoxicillin、TMP-SMX、azithromycin**；SCID 要開始 **PJP prophylaxis**。
- **避免暴露**：減少接觸他人；**母親 CMV 陽性時避免哺乳**；血品需**照射過且 CMV 陰性**。
- **疫苗**：
  - **活疫苗禁用**（MMR、varicella、**BCG**、rotavirus、OPV）→ 可能造成致命的播散性感染。
  - 不活化疫苗可照常規施打，但保護力可能不足。
  - 家人疫苗要打齊，但家人應**避免 OPV、smallpox、live attenuated influenza vaccine**（有傳染給病人的風險）。
- **HSCT 盡快做**：HLA-identical sibling 長期存活與免疫重建最佳；matched unrelated、haploidentical、cord blood 的結果也持續進步。
- **Gene therapy**：ADA-SCID、**SCID-X1**、Wiskott-Aldrich syndrome、CGD 已有成功案例，但仍主要在研究階段。
- **ADA deficiency**：可用 recombinant ADA **每週肌肉注射**做 enzyme replacement therapy。

### 2. Antibody deficiency：Ig replacement 為主要治療

- **IV 與 SC 效果相當**，沒有證據顯示哪個產品較好 → 考慮病人偏好（SC 可在家自行施打）。
- **Hyaluronidase-facilitated SCIG（fSCIG）**：可打較大量、間隔較長。
- ⚠️ **不建議肌肉注射 Ig**（效果不如 IV/SC）。
- CVID、XLA 病人大多對疫苗沒有明顯反應 → 打非活疫苗可能無效但無害；**正在接受 Ig replacement 者不應打活病毒疫苗**（Ig 會干擾反應）。

**Ig 起始劑量**

| 劑型 | 劑量 | 頻率 |
|---|---|---|
| **IVIG** | **400–600 mg/kg** | 每 **3–4 週** |
| **SCIG** | **100–150 mg/kg** | 每週 **1–2 次** |
| **fSCIG** | **300–800 mg/kg** | 每 **3–4 週** |

- **副作用**：頭痛、潮紅、畏寒、肌肉痛、喘鳴、心搏過速、下背痛、噁心、低血壓 → 可預先給退燒藥、抗組織胺、類固醇；反覆反應時換產品或給藥途徑。
- **監測**：定期測 IgG trough（IVIG）或 steady-state（SCIG）濃度；**trough 偏低與慢性肺病惡化相關**（即使無症狀）→ 肺功能變差或感染反覆時加量。
- **抗生素預防**：涵蓋 *S. pneumoniae*、*H. influenzae*；**azithromycin prophylaxis 可減少呼吸道急性惡化與抗生素使用**。
- 定期追蹤**聽力與肺功能**；注意惡性腫瘤與 autoimmunity。
- 目前沒有可常規建議的根治療法，gene therapy 仍在研究中。

### 3. Innate disorder

- **Phagocyte disorder**：以抗菌與抗黴菌預防為主。
  - **IFN-γ 作為常規預防有爭議**：支持它的研究大多是在常規使用抗黴菌預防之前做的。
  - **HSCT 可根治 CGD**。
- **Complement deficiency**：**沒有根治療法** → 抗生素預防與疫苗。
  - 易感 *N. meningitidis* → 考慮 **multivalent meningococcal vaccine**。
  - 易感 encapsulated organism 者 → 也考慮 pneumococcal、Hib 疫苗。

### 4. Immune dysregulation

- 需要免疫抑制或調節治療，但會增加感染風險 → 多專科合作。
- 依致病機轉選擇治療：例如 **IPEX**（Treg 功能受損）→ **rapamycin（mTOR inhibitor）** 可改善 Treg 功能與 autoimmunity，讓病人穩定到可以做 HSCT。

## 六、預後

- 預後依病因而異；自 1970 年代以來大幅改善，原因包括：更好的辨識與診斷、感染控制、早期使用抗微生物藥物、HSCT 技術進步、加護醫療進步。
- **群體免疫**可保護高風險病人。
- 未來期待基因研究與 gene therapy 等根治療法的進展。

---

## 七、Take-home messages

1. IEI 比過去以為的常見：約 **1/1200** 活產。
2. 多數以感染表現，但**過度發炎與 autoimmunity 也很常見**。
3. 任何年齡出現以下情況都要懷疑 IEI：反覆、嚴重或少見的感染；抗生素效果差；failure to thrive；持續 thrush 或皮膚膿瘍；IEI 家族史；**多重過敏與 atopy**。
4. 需要 clinical immunologist 確診；基因檢測已常規使用。
5. **SCID 不矯正就會致死** → 盡快 HSCT；**TREC** 新生兒篩檢能篩出部分 SCID，但篩不出其他 IEI。
6. **Ig replacement 是 antibody deficiency 的主要治療**，也是 SCID/CID 的重要支持治療。
7. 許多 IEI 需要抗菌與抗黴菌預防，並調整疫苗時程。

## 八、補充：風濕科考試連結（非原文內容）

| 考點 | 重點 |
|---|---|
| **Early complement（C1q > C4 > C2）deficiency** | SLE 最強的單基因風險因子之一；**C1q deficiency 的 SLE 外顯率最高**；**C2 deficiency 是最常見的 complement deficiency**，但 SLE 外顯率較低 |
| **Late complement（C5–C9）deficiency** | 反覆 **Neisseria** 感染；與使用 **eculizumab** 的病人一樣需打 meningococcal vaccine |
| **CVID 與風濕病** | 常見 autoimmune cytopenia（ITP、AIHA）、**GLILD**（granulomatous-lymphocytic ILD）、類 sarcoidosis granuloma、關節炎 |
| **Selective IgA deficiency** | 與 SLE、RA、JIA、celiac disease 相關；**輸血可能出現 anti-IgA 過敏反應**；打 IVIG 需注意 |
| **Phenocopy：anti-IFN-γ autoantibody** | 東南亞與台灣成人**播散性 NTM** 的重要原因（原文：>95% 的 disseminated NTM 病人陽性） |
| **CTLA4 haploinsufficiency** | 可用 **abatacept**（CTLA4-Ig）targeted therapy，是基因診斷指引治療的範例 |
| **APECED（AIRE）** | Anti-IL-17/IL-22 autoantibody → chronic mucocutaneous candidiasis |
| **Secondary hypogammaglobulinemia** | 用過 rituximab 後出現低 IgG，需與 CVID 鑑別（追溯用藥前 Ig 濃度與疫苗反應） |
