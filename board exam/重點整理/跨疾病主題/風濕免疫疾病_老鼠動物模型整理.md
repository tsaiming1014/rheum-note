# 風濕免疫疾病老鼠動物模型整理（考試用）

> 資料來源：Kelly's Textbook of Rheumatology（RA/SLE 致病機轉、axSpA、PsA、SSc 致病機轉、IIM、Sjögren、Vasculitis 各章）

## RA

| 模型 | 重點 |
|---|---|
| Collagen-induced arthritis (CIA) | 以 type II collagen 免疫小鼠誘發關節炎，最常用的 RA 動物模型，常作為藥物篩選平台 |
| K/BxN mouse | 自發性關節炎，機轉為抗 GPI (glucose-6-phosphate isomerase) 抗體；血清轉移模型（K/BxN serum transfer）需 alternative complement pathway、FcR、mast cell，**不需 T/B cell**；IL-1（非 TNF）是此模型關鍵細胞激素，IL-1 KO 幾乎完全保護 |
| TNF transgenic mice | TNF over-expression → 嚴重破壞性滑膜炎，支持 TNF 在 RA 致病角色 |
| SCID mouse + human synovium/cartilage 移植 | 證實 RA FLS 具侵襲性表型，可經淋巴/血流跨部位遷移（不需免疫細胞參與） |
| ZAP-70 突變小鼠（SKG mice） | TCR signaling 缺陷 → 胸腺選擇異常，自體反應 T 細胞逃脫，產生 RF/anti-dsDNA 及破壞性關節炎；雌激素可改善疾病 |
| Cadherin-11 KO mice | 滑膜 intimal lining 幾乎消失，證實其為滑膜結構關鍵分子 |

## SLE

| 模型 | 重點 |
|---|---|
| **NZB/NZW F1 mice** | 最經典自發性狼瘡模型；female 病情較重（雌激素相關），常考 |
| MRL/lpr (Fas 缺陷) mice | TLR9 deficiency 使疾病惡化 → 提示 TLR9 活化可能有保護作用（與 TLR7 promote 疾病相反） |
| TREX1 KO mice | TREX1 缺失 → type I IFN (IFNβ) 上升，模擬 SLE IFN signature |
| Lupus-prone mice (B6.Sle1 等) | EBV LMP1（CD40 mimic）促進 B 細胞失調、加速自體免疫 |
| Humanized mouse model | 支持雌激素 + X 染色體劑量在 pDC 產生 type I IFN（TLR7 活化）中的角色 |

## AS / axSpA

| 模型 | 重點 |
|---|---|
| **HLA-B27 transgenic rat**（⚠️非小鼠，是大鼠） | 每細胞表現 40–50 套 HLA-B27（人類最多2套）；疾病不依賴 CD8+ T 細胞，挑戰傳統 class I 抗原呈現理論；是 AS 最重要的動物模型 |
| SKG mice（ZAP-70 point mutation） | 多器官發炎，模擬人類 SpA（enthesitis、axial/peripheral arthritis、psoriasis、IBD-like ileitis）；**germ-free 環境下不發病**，需腸道菌叢誘發，為 IL-23/IL-17 axis 驅動 |

Kelly 並無提及 AS 專屬的自發性「小鼠」模型；主要仰賴上述 B27-transgenic rat 及 SKG mice。

## PsA

| 模型 | 重點 |
|---|---|
| SKG mice | 同上，SpA-like 疾病（含 psoriasis、enthesitis、axial/peripheral arthritis） |
| DBA/1 mice（老年雄性同籠飼養） | 自發性 dactylitis、periostitis、ankylosing enthesitis，好發於指端/甲床，類似 PsA 表現 |
| TNF transgenic mice (Tg197) | 廣泛骨質破壞，類似 PsA erosive disease；DC-STAMP 剔除可減少骨吸收與發炎 |
| JunB/c-Jun 表皮專一剔除小鼠 | 100% penetrance 出現皮膚+關節疾病，高度模擬人類 psoriasis/PsA |
| SCID mouse model of psoriasis | 藥物開發工具 |

## SSc（Kelly 描述最完整，分四大類）

| 分類 | 模型 | 重點 |
|---|---|---|
| 自發性 | **Tsk1/+ (tight skin) mice** | fibrillin-1 基因內重複突變；homozygous 胚胎致死，heterozygous 有皮下增生但**真皮變化不明顯**（與人類 SSc 不同，是常考的「模型限制」） |
| 誘發性 | **Bleomycin-induced** | 皮膚/肺纖維化，**最常用的 SSc 誘發模型** |
| 誘發性 | Angiotensin II-induced | 皮膚/肺纖維化 |
| 移植 | HLA-mismatched bone marrow transplant | Chronic sclerodermatous GVHD-like 變化 |
| 基因工程 | Fra-2 transgenic mice | 少數具 SSc-like **血管病變**的模型（多數模型缺乏微血管病變，此為考點） |
| 基因工程 | CTGF / PDGFRα / Wnt10b overexpression；caveolin-1、uPAR、Fli-1 KO | 各自誘發皮膚/多器官纖維化 |

⚠️ 常考重點：大多數 SSc 小鼠模型**缺乏血管病變**（發炎驅動模型反而血管新生增加），這是與人類疾病最大差異之一。

## IIM

| 模型 | 重點 |
|---|---|
| **MHC class I over-expression transgenic mice**（骨骼肌專一性） | 出現類似人類肌炎的臨床/生化/組織學/免疫學特徵；自限性、女性較重、常伴 MSA；肌無力可先於單核球浸潤出現，支持 **ER stress/UPR 機轉**（非單純免疫細胞毒殺） |
| Trypanosoma cruzi 感染 CBA/J mice | 感染相關肌炎模型 |

## Sjögren's Syndrome（Kelly 有整理表格，內容豐富）

| 分類 | 模型 | 重點 |
|---|---|---|
| 自發性 | (NZB×NZW) F1 mice | 進行性局部涎腺炎 |
| 誘發性 | Carbonic anhydrase 免疫 PL/J mice | 涎腺淋巴球浸潤 + 抗 carbonic anhydrase 抗體 |
| 誘發性 | Ro peptide 免疫 BALB/c mice | 涎腺淋巴球浸潤 |
| 基因剔除/轉殖 | LTα KO mice | **不**出現腺體疾病 → 證實 LTβR signaling 參與致病 |
| 基因剔除/轉殖 | IL-14α transgenic mice | 類 Sjögren 表現型，老年後常伴大 B 細胞淋巴瘤 |
| 基因剔除/轉殖 | **NOD (non-obese diabetic) mice** | **最常用模型**；抗 M3 muscarinic receptor 抗體被動轉移可致腺體功能低下；阻斷 LTβR signaling 可改善腺體分泌功能 |

## Vasculitis

| 疾病 | 模型 | 重點 |
|---|---|---|
| GCA | **GCA-SCID mouse**（顳動脈植入 SCID mice） | 證實 GCA 為血管壁內 adaptive immune response；血中 LPS 可經 TLR 活化動脈 DC；清除 DC 大幅減少血管炎 |
| Takayasu | Herpesvirus 感染小鼠 | 病毒感染大動脈中膜平滑肌細胞（media 為 immune-privileged site） |
| AAV | **抗-MPO 抗體轉移模型**（Mpo−/− mice 免疫產生抗體→轉移至正常小鼠） | **最經典、最具致病性直接證據的血管炎模型**；誘發 pauci-immune GN，需嗜中性球 + C5a/C5aR |
| AAV | 人源化免疫系統小鼠 + 人類 anti-PR3 抗體 | 支持 anti-PR3 致病性（單純小鼠模型較難單獨誘發） |
| Behçet's | HSV 誘發 BD-like mouse model | 皮膚/腸胃病灶可測得 HSV DNA，支持病毒為可能誘因 |
| PAN | — | Kelly 未提及專屬動物模型，**無** |
| 免疫複合體小血管炎 (IgA vasculitis 等) | — | Kelly 未提及專屬小鼠模型，**無** |
