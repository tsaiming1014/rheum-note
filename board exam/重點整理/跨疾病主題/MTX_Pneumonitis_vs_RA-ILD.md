# MTX-Pneumonitis

## 一、兩個不同的概念：不要混淆

MTX 與肺部相關的兩種不良反應，機轉、時序、處置完全不同，考試與臨床上常被混為一談：

| | MTX-associated (hypersensitivity) pneumonitis | 慢性 RA/CTD-ILD 進展 |
|---|---|---|
| 機轉 | Idiosyncratic hypersensitivity reaction | 疾病本身的肺部侵犯（如 UIP、NSIP pattern） |
| 時序 | 通常早期發生（治療第一年內），acute/subacute | 慢性、隨疾病活性起伏 |
| 與劑量關係 | 非劑量依賴 | 不適用 |
| MTX 對其影響 | MTX 直接誘發 | 證據顯示 MTX **不會**加速，甚至可能有保護效果 |

## 二、MTX 與慢性 RA-ILD 進展的關係

近年證據顛覆舊觀念（舊觀念：MTX 會誘發或惡化 RA-ILD）：

- 多筆觀察性研究顯示 MTX **不會**增加 RA-ILD 發生風險，部分研究甚至顯示 MTX 使用與**較低的 RA-ILD incidence** 相關
- 推測機轉：MTX 透過控制 RA 系統性發炎活性，達到 disease-modifying 效果，間接降低肺部侵犯風險
- 證據等級：以觀察性研究為主，非 RCT

## 三、指引怎麼說：2023 ACR/CHEST Guideline for Treatment of ILD in SARDs

- **Conditionally recommend AGAINST** 把 MTX 當作 SARD-ILD 的**第一線「治療肺病」藥物**（因為缺乏證據證明它對 ILD 本身有療效，不是因為它有害）
- **不等於**「RA-ILD 病人要開始治療關節時要避免用 MTX」——這是常見誤解。若目的是治療**關節**症狀，MTX 仍是可選藥物之一
- 已在使用 MTX 且**穩定**（關節控制良好、肺部穩定）者：2021 ACR RA treatment guideline conditionally recommend **繼續使用** MTX 治療關節症狀，除非懷疑 pneumonitis
- Preexisting ILD 是否為 MTX pneumonitis 的風險因子：證據不一致，部分研究提出但**未被其他研究重複驗證**，屬爭議項目

## 四、臨床應用摘要

> MTX 對 RA 疾病活性的控制，可能透過降低系統性發炎而對 RA-ILD 長期進展有中性甚至保護效果；已穩定使用 MTX 者若無 pneumonitis 疑慮，可因關節控制需求繼續使用。但 MTX 仍存在獨立於此機轉之外的 idiosyncratic hypersensitivity pneumonitis 風險（非劑量依賴、好發於治療早期），這與慢性 ILD 進展是兩回事。

## 五、MTX Pneumonitis 的治療策略

**1. 先排除感染（診斷排除法，此步不可跳過）**

病人本身免疫抑制中，臨床/影像表現與感染性肺炎高度重疊，開類固醇前須排除：

- PJP（immunosuppressed 病人常規要考慮）
- 一般細菌、非典型病原、黴菌、病毒
- 血液/痰液培養陰性，才較有信心歸因於 MTX

**2. 立即停用 MTX（治療基石）**

- 確診/高度懷疑後立即停藥，是最核心的處置
- 多數病人停藥後幾天內臨床即改善，但**影像學異常可能要拖數週才消退**

**3. 類固醇（因機轉是 hypersensitivity reaction，對類固醇反應通常良好）**

- 劑量：常用 prednisone 1 mg/kg（或等效劑量），重症可先 IV（methylprednisolone/hydrocortisone），改善後轉口服
- 之後依臨床反應緩慢 taper，無固定療程天數，個別化調整
- 輕症（單純停藥就明顯改善者）不一定需要類固醇，中重度或症狀持續才加上

**4. 重症/對類固醇反應不佳者**

- 少數 case report 會加上其他免疫抑制劑（如 cyclophosphamide），但**非標準一線做法**，證據等級低

**5. Leucovorin（folinic acid）的角色——常見誤解澄清**

- Leucovorin rescue 適應症是 **MTX 過量／全身性抗葉酸毒性**（骨髓抑制、黏膜炎、肝毒性），機轉是直接補充 reduced folate 拮抗 MTX 的細胞毒性
- MTX pneumonitis 是 **hypersensitivity 機轉**，不是抗葉酸細胞毒性造成，故 leucovorin **對治療 pneumonitis 本身沒有明確角色**，文獻無一致建議
- 不要把兩種不同的 MTX 毒性（全身性抗葉酸毒性 vs. 肺部過敏反應）混為一談而誤用 leucovorin

**6. Rechallenge（之後還能不能再用 MTX）**

- 個案報告結果不一（有復發案例，也有可耐受案例），但臨床上普遍**避免再次使用 MTX**，通常視為相對永久禁忌

**7. 預後**

- 多數恢復良好，但**死亡率可達 17.6%**，發病時間點在用藥後**第一個月內**者死亡率較高，非良性反應

### 治療步驟摘要表

| 步驟 | 處置 |
|---|---|
| 1. 排除感染 | 血液/痰培養、PJP 等病原檢測 |
| 2. 停藥 | 立即且永久停用 MTX |
| 3. 類固醇 | Prednisone ~1 mg/kg（或 IV），依反應 taper |
| 4. 重症 | 考慮加其他免疫抑制劑（證據弱） |
| 5. Leucovorin | 無明確角色（機轉不同於全身性 MTX 毒性） |
| 6. Rechallenge | 一般避免 |
