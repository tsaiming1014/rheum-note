# 關節液外觀描述與鑑別診斷

## 一、關節液外觀三大描述面向（記憶口訣：CVC）

關節液外觀描述須從三個獨立面向分別評估，合併起來才是完整的外觀報告，可用 **CVC**（**C**olor, **V**iscosity, **C**larity）記憶：

| 面向 | 描述重點 | 常用英文術語 |
|---|---|---|
| **C — Color（顏色）** | 液體本身顏色深淺 | colorless, straw-colored/pale yellow, yellow, xanthochromic, green, milky/chalky white, serosanguinous, sanguinous/frankly bloody |
| **V — Viscosity（黏稠度）** | Hyaluronic acid 是否被破壞，以 string sign 測試 | high viscosity (string sign positive, 可拉絲 >5cm), low viscosity (string sign negative) |
| **C — Clarity（透明度）** | 光線穿透程度，反映細胞/結晶密度 | transparent/clear, translucent, cloudy/turbid, opaque, purulent |

各術語的病理意義：

- **Serosanguinous**：血清與血液混合的淡血色，代表輕度出血或部分創傷性抽吸。
- **Sanguinous / frankly bloody**：全血樣鮮紅色，代表真正的 hemarthrosis 或明顯創傷性抽吸。
- **Xanthochromic**：黃變，因舊出血分解產物（bilirubin）造成，提示陳舊性出血。
- **String sign**：正常關節液因 hyaluronic acid 完整，滴落時可拉成長絲；發炎性關節液因 hyaluronidase 破壞黏稠度而呈水滴狀滴落（string sign negative）。

## 二、依外觀分類的關節液類型與臨床意義

| 分類 | 外觀（Color＋Viscosity＋Clarity） | 代表疾病 | WBC (/μL) | PMN % |
|---|---|---|---|---|
| Normal | Colorless–pale yellow, high viscosity, transparent | 正常關節液 | <200 | <25% |
| Noninflammatory | Straw-colored–yellow, high viscosity, transparent–translucent | OA、外傷 | <2,000 | <25% |
| Inflammatory | Yellow, low viscosity, cloudy/turbid | Gout、Pseudogout、RA、SpA | 2,000–50,000 | 常 >50% |
| Septic | Yellow-green, variable viscosity, opaque/purulent | Septic arthritis | >50,000 | >90% |
| Hemorrhagic | Serosanguinous–frankly bloody, viscosity 常無法判讀, opaque | 外傷、凝血異常、腫瘤、PVNS、澱粉樣關節病 | 依病因而定 | 依病因而定 |

**核心觀念**：外觀分類只是初步印象，確定診斷仍須靠偏光顯微鏡找結晶——血性關節液不代表沒有痛風，混濁黃色關節液也不代表沒有感染共存。

## 三、案例分析

### Case 1：60 歲，長期洗腎，有痛風病史，膝關節抽吸為血性液體

**外觀描述（CVC）**：Color — sanguinous（frankly bloody）；Viscosity — not assessable due to gross blood；Clarity — opaque。

**Hemarthrosis 鑑別診斷（一般）**：

- 外傷 / traumatic tap
- 凝血功能異常（服用抗凝劑、血友病）
- **PVNS（pigmented villonodular synovitis）**
- 關節內腫瘤
- Charcot joint（neuropathic arthropathy）
- Scurvy

**PVNS 補充說明**：

| 項目 | 內容 |
|---|---|
| 別名 | Tenosynovial giant cell tumor, diffuse type (D-TGCT) |
| 本質 | 良性但局部侵襲性的滑膜增生性病變（非真正腫瘤） |
| 分型 | Localized（nodular，較局限）vs. Diffuse（廣泛侵犯整個滑膜，較易復發） |
| 好發族群 | 年輕至中年成人（20–50 歲），無明顯性別差異 |
| 好發關節 | 膝關節最常見（約 80%），其次為髖、踝、肩 |
| 典型表現 | 慢性、單一關節反覆腫脹合併反覆血性關節積液（recurrent hemorrhagic effusion），常無明顯外傷史 |
| 影像學（MRI 關鍵特徵） | 因滑膜內 hemosiderin 沉積，T1 與 T2 皆呈低訊號，在 gradient echo/susceptibility-weighted 序列會有明顯 blooming artifact——此為 PVNS 特異性影像表現 |
| 病理組織學 | Hemosiderin-laden macrophages、多核巨細胞（multinucleated giant cells）、滑膜絨毛結節狀增生 |
| 治療 | 手術滑膜切除（synovectomy，可關節鏡或開放式）；diffuse type 復發率高，可能需合併放射線治療或標靶藥物（CSF1R inhibitor，如 pexidartinib） |

**洗腎病人特別需考慮的病因**：

| 洗腎相關病因 | 機轉 |
|---|---|
| 透析用 Heparin 抗凝 | 血液透析時全身肝素化，增加關節內出血傾向 |
| 尿毒症血小板功能障礙（uremic platelet dysfunction） | 血小板數目正常但功能異常（黏附/聚集障礙），無外傷也易出血 |
| 透析相關類澱粉沉積症（Dialysis-related amyloidosis, β2-microglobulin amyloid） | 長期洗腎（通常 >5–10 年）病人，β2-microglobulin 無法被一般透析膜清除而沉積在滑膜、肌腱，造成 destructive arthropathy，好發於肩、腕、膝，可呈現血性積液 |
| 腎性骨併發症（renal osteodystrophy）續發關節破壞 | 可合併病理性關節出血 |
| 同時發生的痛風急性發作 | 洗腎病人痛風盛行率高（腎功能不佳、尿酸排除下降），血性外觀不代表痛風診斷被排除 |

**應送檢項目**：

1. Cell count（血性液體判讀較困難，需留意 RBC 稀釋效應對 WBC 計算的干擾）
2. 偏光顯微鏡找 MSU 結晶——即使血性，仍應離心後找結晶，不可因肉眼見血放棄
3. Gram stain + culture（洗腎病人血管通路感染風險高，敗血性關節炎機率不低，務必排除）
4. 懷疑凝血異常時：PT/PTT、platelet count/function
5. 懷疑 PVNS 時：安排 MRI 評估滑膜 hemosiderin 沉積表現
6. 懷疑澱粉樣關節病時：病史（洗腎年數）、影像學骨侵蝕表現，必要時滑膜切片染 Congo red

### Case 2：35 歲，痛風病史，膝關節抽吸為黃色液體

**外觀描述（CVC）**：Color — yellow；Viscosity — low（string sign negative）；Clarity — cloudy/turbid。

**鑑別診斷**：

- Acute gout flare
- Pseudogout（CPPD）
- 其他發炎性關節炎（反應性關節炎等）
- 必須排除：septic arthritis（結晶性關節炎與感染可共存，不可因見到結晶就排除感染）

**應送檢項目**：

1. Cell count with differential
2. 偏光顯微鏡找結晶：MSU 結晶為 needle-shaped、negatively birefringent（平行偏光軸時呈亮黃色）
3. Gram stain + culture（即使懷疑痛風也要送）

## 四、兩病人的關聯性（考題核心）

1. **同一疾病，不同外觀表現**：兩人皆為痛風，但外觀差異主要來自 Case 1 病人的共病（洗腎相關凝血/血小板功能異常、可能的 β2-microglobulin 類澱粉沉積症、或需鑑別的 PVNS）疊加造成，而非痛風本身典型表現改變。
2. **教學重點**：關節液外觀不能作為排除或確立結晶性關節炎的唯一依據——無論外觀是 yellow 或 sanguinous，都必須做偏光顯微鏡找結晶。
3. **洗腎病人是特殊族群**：尿酸代謝異常（好發痛風）＋凝血/血小板功能異常（好發血性關節液）＋β2-microglobulin 類澱粉沉積（好發破壞性/血性關節病變）三者可能同時存在，是此類病人關節症狀鑑別診斷時須一併考慮的框架；PVNS 則是慢性反覆血性關節積液的另一個重要鑑別診斷，需與上述病因區分。
4. **共通原則**：無論外觀如何，都必須送 Gram stain/culture 排除敗血性關節炎，因為結晶性關節炎與感染可以同時發生，且洗腎病人本身感染風險較高。
