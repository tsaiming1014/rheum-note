# Gout 臨床表現與風險因子（Kelly Ch.97）

## 一、流行病學

**盛行率與趨勢：**

Gout 是最常見的發炎性關節炎，全球盛行率呈持續上升趨勢，與人口老化、肥胖盛行率增加、代謝症候群普及、飲食型態改變（高普林飲食、含糖飲料）有關。台灣的盛行率是全球數一數二高的地區之一，與遺傳因子（尤其 **ABCG2** 基因變異在漢人/亞裔族群中盛行率較高）及飲食習慣（海鮮、飲酒）都有關。

**性別與年齡分布：**

- 男性明顯多於女性，男女比約 **3-4:1**
- 機轉：雌激素具有促進尿酸排除（uricosuric）的作用，停經前女性因雌激素保護，痛風發生率明顯較低
- 男性好發年齡：**30-50 歲**；女性好發年齡明顯較晚，多在**停經後（60 歲以後）**
- 若**年輕女性（停經前）出現痛風**，臨床上要提高警覺，考慮是否有次發性原因（如腎功能不全、利尿劑使用、遺傳性尿酸代謝異常等）

**核心觀念：**

高尿酸血症是必要但非充分條件——**大多數高尿酸血症的人終其一生不會發生痛風**。共病症（高血壓、CKD、心血管疾病、糖尿病、代謝症候群）皆與 gout 有密切雙向關聯。

**重點速記：**

| 面向 | 重點 |
|---|---|
| 性別 | 男 >> 女（3-4:1），雌激素保護停經前女性 |
| 好發年齡 | 男性 30-50 歲；女性停經後（60+） |
| 種族 | 太平洋島民、Māori、台灣原住民/漢人族群盛行率高（與 ABCG2 相關） |
| 飲酒 | 啤酒、烈酒風險最高，紅酒相對較低 |
| 遺傳 | SLC2A9、ABCG2、SLC22A12（尿酸轉運蛋白基因） |

## 二、疾病分期概念

Gout 是 **MSU 晶體沉積的慢性疾病**，分幾個階段：

1. **無症狀高尿酸血症** → 晶體沉積但無症狀
2. **急性發作（Gout Flare）**
3. **間歇期（Intercritical period）**：完全無症狀，但晶體仍存在
4. **慢性痛風石性痛風（Tophaceous gout）/ 慢性痛風關節炎**

---

## 三、急性發作（Gout Flare）

**典型特徵**：

- 急性單關節炎為主（也可 oligo/polyarticular）
- **好發部位**：第一 MTP（podagra）最常見，其次 midfoot、ankle、knee
- 疼痛在 **24 小時內達到最高峰**
- 自然病程 **1-2 週**緩解
- 典型發作特徵（SUGAR study 最有鑑別力）：
  - Male sex
  - Dietary trigger
  - First MTP 受侵犯（當次或過去）
  - 臨床可見痛風石
  - 關節紅腫（erythema）
  - 關節極度壓痛
  - ≥ 2 次急性發作且在 2 週內完全緩解
  - 行走困難

- 嚴重發作可有發燒等全身症狀
- 緩解期皮膚可能脫屑
- 若無治療，發作越來越頻繁，侵犯範圍擴大至上肢（olecranon bursa、腕、手指小關節）

**誘發因素**：

- 高 SUA、急性疾病/手術、利尿劑、高普林飲食/酒精、脫水、關節外傷
- 開始 ULT 初期（晶體釋放）
- 高溫、極端濕度
- 低劑量 aspirin、住院

---

## 四、痛風石（Tophi）

**定義（G-CAN）**：MSU 晶體 + 宿主組織反應形成的有序結構

**外觀**：透明皮膚下白堊色或漿液性皮下結節，常有表面血管增生

**好發部位**：第一 MTP、耳廓（helix）、olecranon bursa、Achilles 肌腱、手指腹、腕

**非典型部位**：頭頸部、眼、耳鼻喉、心臟、乳房、腸道、脊椎、神經（壓迫性神經病變，如 carpal tunnel）

**臨床意義**：

- 通常**不痛**，但急性發炎時會痛
- 造成關節變形、活動受限
- **骨內痛風石 → 骨侵蝕（erosion）**
- 破潰 → 繼發感染風險
- Chronic gouty arthritis（持續性滑膜炎）

**高風險族群**：年老、女性、利尿劑使用者、CKD → 早期即出現痛風石

---

## 五、特殊臨床情境

- **Eruptive tophaceous gout**：腎移植患者、老年人合併 CKD + 利尿劑 → 快速進展
- **MSU + CPPD 共存**：同一關節可同時找到兩種晶體
- **Gout + RA**：難以區分 flare 來源，需仔細鑑別
- **Gout + OA**：痛風好發於 OA 已受損關節（尤其 DIP、第一 MTP）
- **Gout + PsA**：乾癬病人有高 SUA，第三趾痛風石 + 甲癬可擬似 sausage digit

## 七、Factors Associated With Developing Gout（Table 97.3）

> 核心概念：**大多數風險因子都是透過升高 SUA 來增加 gout 風險**（性別、年齡、種族、遺傳基因、飲酒詳見「一、流行病學」）

### 飲食（升 SUA 機轉）

**核心原則**：避免富含普林食物（見下表），急性痛風發作期應避免第三組食物。

| 食物類別 | 第一組｜低普林（可每天適度攝取） | 第二組｜中等普林 | 第三組｜高普林（急性期避免） |
|---|---|---|---|
| 奶類及其製品 | 各種乳類及乳製品 | | |
| 肉及蛋類 | 蛋類（雞蛋、鴨蛋、鵝蛋）、豬血 | 牛肉、羊肉、鴨肉、雞肉、豬皮、瘦豬肉 | 內臟類 |
| 魚類及其製品 | 海參、海蜇皮 | 旗魚、黑鯧魚、草魚、鯉魚、紅鱠、紅甘、秋刀魚、鱔魚、鰻魚、烏賊、螃蟹、蜆仔、鮑魚、鯊魚 | 馬加、白鯧、鰱魚、虱目魚、吳郭魚、四破、白帶魚、烏魚、草蝦、小管、小魚干、沙丁魚、扁魚干、蚌蛤、蛤蜊、干貝、海鰻、牡蠣 |
| 全穀雜糧類 | 除第二、三組以外的各種全穀雜糧類 | 綠豆、紅豆、花豆、栗子、蓮子、皇帝豆、豌豆 | 胚芽米 |
| 豆類及其製品 | 豆腐、豆干、豆漿 | 味噌、黑豆、毛豆 | 黃豆、發芽豆類 |
| 蔬菜類 | 除第二、三組以外的各種蔬菜類 | 各式菇類（洋菇、鮑魚菇等）、海藻、海帶 | 嫩芽蔬菜（蘆筍頭、豆苗）、發芽蔬菜（綠豆芽、黃豆芽、苜蓿芽）、紫菜、乾香菇 |
| 水果類 | 適度攝取各種水果類 | | |
| 油脂類 | 各類植物油、瓜子（不建議動物油） | 花生、腰果、杏仁果 | |
| 其他 | 枸杞 | | 濃肉湯（汁）、牛肉汁、雞精、酵母粉、各種酒類 |

**其他升 SUA 飲食因子**：

| 飲食因子 | 說明 |
|---|---|
| **含糖飲料（sugar-sweetened beverages）** | 高果糖攝取促進普林代謝、升高 SUA |
| 酒精 | 促進尿酸生成並抑制腎排除；啤酒 > 烈酒 > 紅酒（紅酒風險相對低） |

**保護性飲食因子（降低 SUA / 降低 gout 風險）：**

- **低脂乳製品（low-fat dairy）**
- **咖啡（coffee）**
- **維生素 C（vitamin C）**
- **DASH 飲食**（強調蔬果、低脂乳製品，減少飽和脂肪/總脂肪/膽固醇）：可降低 SUA，並與較低的 incident gout 風險相關

**重要臨床概念（Kelly 特別強調）：**

- 上述飲食因子對「一般族群」SUA 的影響幅度其實都偏小
- 對於**已確診 gout 且正在接受 ULT 治療的病人**，證據顯示飲食調整幾乎**無法**額外顯著降低 SUA 或改善臨床結果（多項 RCT 與 2021 Cochrane review 均未證實飲食補充品有效）
- 因此國際指引（ACR/EULAR）將飲食/生活型態調整定位為**藥物治療的輔助（adjunct）**，而非替代方案
- 2020 ACR guideline 建議：限制酒精、普林攝取、高果糖玉米糖漿，並於過重/肥胖者建議減重
- 例外：severe obesity 病人接受 **bariatric surgery** 可能對 SUA 有較明確效益
