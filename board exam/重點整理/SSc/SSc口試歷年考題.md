## 風濕專科（風專）口試

SSc 在風專口試中固定為一個獨立考站，常與 IIM 合併同站（見「風專歷屆考題/風專口試關卡.md」第七關：IIM, SSc），幾乎每年必考，且主考官固定為**黃文男醫師**。

### 2019（口試 9：Inflammatory Myositis and Systemic Sclerosis）

**黃文男醫師**（情境：硬皮症 + 走路會喘）

1. ANA 判讀（fine speckled + nucleolar）→ **Anti-Scl70（anti-topoisomerase I）**
2. 甲摺鏡判讀（見 2020 口試第 9 站）
3. 肺功能 + DLCO 嚴重程度判讀（restrictive + decreased DLCO）
4. HRCT 判讀（**NSIP**，為何不是 UIP）：
   - NSIP：ground glass opacity 為主，subpleural sparing，lower lobe predominance
   - UIP：honeycombing、traction bronchiectasis、lower lobe predominance、peripleural
5. 後續如何治療（MMF 首選、CYC、RTX）

**蔡醫師**

- 硬皮症是否跟癌症相關？哪個硬皮症抗體出現要考慮惡性腫瘤？
  - **Anti-RNA Pol III**（與癌症時間相關，close temporal correlation）
  - Anti-Scl-70、Anti-U1-RNP（也有相關，但較弱）
- **CA15-3 與 ILD 的關係**：CA15-3 與 KL-6（Krebs von den Lungen-6）在 CTD-ILD 中相關；CA15-3 在 IPF 中表現最好（R = 0.83 with KL-6）

（同站另有蔡嘉哲醫師針對 IIM 部分的提問，屬 IIM 主題，詳見 [IIM口試歷年考題.md](../IIM/IIM口試歷年考題.md)。）

**其他考站提及 SSc（非獨立考站，作為 DDx / 延伸提問出現）**

- 口試 6（Hand & Feet，陳信華醫師）：**Prayer's test** 可評估的鑑別診斷？→ **SSc（硬皮症）** 造成 Stiff hand（皮膚硬化限制關節活動），對照 DM 造成的 Diabetic stiff hand syndrome
- 口試 14（Sonography, MRI, and CT，陳瑋昇醫師）：除了關節炎，哪些時候會考慮做超音波？（肌腱病變、乾燥症腮腺、**SSc 血管評估**）

### 2020（口試 9：SSc）

**黃文男主任**（情境題：Raynaud's + puffy finger + DOE）

1. **ANA 判讀**：**AC-29（topo-1 like）** → 與 anti-Scl70 相關 → diffuse SSc + ILD 高風險
2. **接下來要做哪些檢查**：NFC（Nailfold Capillaroscopy）、PFT（肺功能）、Echo（心臟超音波，評估 PAH）、Lab（抗體、CBC、腎功能）
3. **NFC 判讀**：Early to active SSc pattern
   - Early：少量巨大 capillary + 少量出血
   - Active：較多巨大 capillary、出血、部分 avascular area
   - Late：大量 avascular area、neoangiogenesis
4. **PFT 判讀**：Restrictive lung + reduced diffusion capacity（DLco 降低）
5. **Chest CT**：**NSIP pattern**（ground glass opacity 為主）
6. **Tx for ILD and RP**：
   - ILD：MMF（首選）或 CYC；RTX（refractory）
   - RP：CCB（nifedipine）→ PDE5i（sildenafil）→ iloprost IV

**另一位老師**

- 說出所有 SSc 相關自體免疫抗體的特色、發生頻率、相關表現：

| 抗體 | 頻率 | 臨床關聯 |
|------|------|---------|
| Anti-Scl70（anti-topoisomerase I） | 15–40% | Diffuse SSc + **ILD** |
| Anti-Centromere（ACA） | 20–40% | Limited SSc + **PAH**，CREST |
| Anti-RNA Pol III | 10–25% | Diffuse SSc + **Renal crisis**；Cancer（乳癌） |
| Anti-Th/To | <5% | Limited SSc + ILD + PAH |
| Anti-U3-RNP（fibrillarin） | <5% | Diffuse SSc + **PAH**；African American |
| Anti-U1-RNP | 5–10% | **Overlap（MCTD）** |
| Anti-PM/Scl | <5% | **Overlap（SSc + myositis）** |
| Anti-Ku | <5% | Overlap |

> RNA Pol III 特別注意：SSc 發病與 cancer 診斷時間接近（close temporal correlation）→ 需積極排癌（尤其乳癌）

### 2022（第 10 站：SSc，翁孟玉）

- 看病人手部 X-ray 判讀（**指尖骨頭吸收 + 小指硬指 → SSc**）
- 看手部照片，詢問 impression
- SSc 診斷標準、分類
- 要做什麼檢查、抽血看什麼 auto Ab：

| 抗體 | 臨床表現 |
|------|---------|
| Anti-Scl70（anti-topoisomerase I） | Diffuse cutaneous SSc + ILD |
| Anti-Centromere（ACA） | Limited cutaneous SSc + PAH |
| Anti-RNA Pol III | Diffuse cutaneous SSc + renal crisis |
| Anti-Th/To | Limited cutaneous SSc + ILD/PAH |
| Anti-U3-RNP | Diffuse cutaneous SSc + PAH（African American 多） |
| Anti-U1-RNP | Overlap（MCTD） |

### 2024（第七站 Part 1：黃文男、陳宏安）

情境帶入到 ANA 判讀（AC-29），對應到什麼抗體（Anti-Scl-70），可能的診斷（Systemic sclerosis），要安排什麼檢查（capillary microscope、肺功能、HRCT、heart sono），甲褶鏡/HRCT/肺功能檢查的判讀，該如何治療（尤其針對 ILD），anti-fibrotic agents 的使用時機跟健保條件。

### 2025（第七關：IIM, SSc，黃文男）

情境題：男性有 puffy、RP、SOB，然後給檢驗報告，跟一張 ANA 請你判斷（就是 AC-29），接著給 X 光、甲摺鏡的照片（microhemorrhage、giant capillary，是 active scleroderma pattern）、肺功能檢查（restrictive pattern，DLCO 顯著下降），叫你判讀所有報告，講接下來要做的所有治療。

## 考試速記重點（跨年度重複考點）

- **固定情境題模板（2019、2020、2023、2024、2025 連續出現，主考官固定黃文男醫師）**：中年病人主訴 Raynaud's phenomenon + puffy finger + 走路會喘（DOE/SOB）→ **ANA 判讀（AC-29 → anti-Scl70）** → **甲摺鏡（NFC）判讀**（early/active/late pattern，giant capillary、microhemorrhage）→ **PFT 判讀**（restrictive + ↓DLCO）→ **HRCT 判讀**（NSIP pattern，需能與 UIP 區分）→ **治療**（ILD：MMF 首選/CYC/RTX；RP：CCB→PDE5i→iloprost IV；2024 起加考 anti-fibrotic agents 使用時機與健保條件）。此為**最高頻**考點，務必能一路從問診 → 判讀 → 治療完整講述。
- **SSc 相關自體抗體與臨床表現對應表**（Anti-Scl70/ACA/RNA Pol III/Th-To/U3-RNP/U1-RNP/PM-Scl/Ku）——2020、2022 反覆整表考，須熟記 subtype（diffuse vs limited）、盛行率、器官關聯（ILD、PAH、renal crisis、cancer、overlap），詳見 [SSc_自體抗體與臨床表現型.md](SSc_自體抗體與臨床表現型.md)。
- **癌症相關抗體**：**Anti-RNA Pol III** 與 SSc 發病時間相近的惡性腫瘤（尤其乳癌）有 close temporal correlation，需積極排癌——2019、2020 皆考，詳見 [SSc_癌症相關性.md](SSc_癌症相關性.md)。
- **手部診察與影像**：指尖骨頭吸收（fingertip bone resorption）+ 皮膚硬化辨識 SSc 的手——2019（Prayer's test 鑑別 SSc vs DM stiff hand）、2022（手部 X-ray 加分題）皆考。
- **SSc 常與 IIM 併同一考站**（風專歷屆考題固定「第七關：IIM, SSc」）——需同時準備 ANA 判讀（AC-29 = Anti-Scl-70）、甲摺鏡、HRCT/肺功能判讀、anti-fibrotic agents 使用時機與健保條件，另需準備 IIM 側的 MSA/MAA 抗體表，詳見 [IIM口試歷年考題.md](../IIM/IIM口試歷年考題.md)。
- **超音波九宮格會考 SSc 皮膚評估**（2020，張棋楨主任）——需知道皮膚增厚在超音波下的評估方式。
- **免專口試迄今未單獨考 SSc**（2019–2025），但免專筆試常考，複習時仍需涵蓋 GI involvement、renal crisis、與 SLE 的 overlap 及 HSCT 適應症等筆試考點。
