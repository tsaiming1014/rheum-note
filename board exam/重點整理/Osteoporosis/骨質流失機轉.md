# Osteoporosis — Cortical vs Trabecular Bone Loss

## Cortical bone（皮質骨）流失機轉

隨年齡增長，皮質骨的流失主要來自 **endosteal surface（骨內膜面，即髓腔側/內側）的骨吸收（resorption）**加速；同時 **periosteal surface（骨外膜面，即外側）**反而有代償性的**骨質新生（apposition）**，使骨頭外徑略微增加。淨效果是：**內側（endosteal）流失 > 外側（periosteal）流失**，導致皮質骨變薄、髓腔擴大，但整體骨頭外徑不變或略增。

## Trabecular bone（海綿骨）流失機轉

海綿骨的 **turnover rate（代謝週轉率）遠高於皮質骨（約 8 倍）**，因此在骨質疏鬆早期（尤其**停經後骨鬆，Type I osteoporosis**）流失速度最快、也最先出現變化，機轉上主要是**水平連結性 trabeculae（horizontal/connecting trabeculae）優先流失**，導致骨小樑之間失去連結、結構強度大幅下降（即使骨密度數值下降不多，骨折風險已顯著上升）。

## 速記：兩型骨質疏鬆症比較

| | Type I（停經後骨鬆） | Type II（老年性骨鬆） |
|---|---|---|
| 主要受影響骨骼 | Trabecular bone（海綿骨，如脊椎） | Cortical + trabecular（皮質骨為主，如髖部） |
| 好發骨折部位 | 脊椎壓迫性骨折 | 髖部骨折 |
| 機轉 | 雌激素缺乏 → 蝕骨作用增加，水平 trabeculae 優先流失 | 老化 → endosteal resorption > periosteal apposition，皮質變薄 |

## 提醒

2023 風專筆試考古題原記錄「Cortical bone loss 外側 > 內側」的敘述，依上述機轉方向可能相反（應為內側流失為主），信心不高，此爭議點未列入正文，僅供對照參考（見 [2023風專筆試解答](../考試準備/風專歷屆考題/2023風專筆試解答.md)）。
