# MCAS（Mast Cell Activation Syndrome）

*Middleton's Allergy 9th ed., Ch74／Ch75／Ch76；補充 Valent 共識（2012、2019）與 AAAAI 2019 Work Group Report*

> 相關筆記：[Mastocytosis](Mastocytosis_Middleton_Ch74.md)、[Anaphylaxis](Anaphylaxis_Middleton_Ch75.md)
>
> 標示【補充】者為 Middleton 以外的內容。

## 一、MCAS 是什麼

- 一群**反覆、發作性**的症候群，原因是 mast cell 一次釋放大量 mediator，同時侵犯多個器官系統
- **Mast cell 數量正常或接近正常**，問題在於太容易被活化
- 跟 mastocytosis 不同：MCAS 是**臨床診斷**，mastocytosis 是**病理和分子診斷**
- Middleton Ch75 的描述：MCAS 病人最常以 **flushing 和腹瀉**來表現，不一定有 anaphylaxis
- 以前被診斷為 idiopathic anaphylaxis 的病人中，最多 **40%** 其實是 MCAS 或 SM（Middleton Ch75）

## 二、診斷：三項都要符合

| 要件 | 內容 |
|---|---|
| ① 臨床症狀 | **發作性**、**同時侵犯 ≥2 個器官系統**的典型 mast cell mediator 症狀 |
| ② 實驗室證據 | 發作時有效的 mast cell mediator **高於個人基礎值** |
| ③ 治療反應 | 用針對 mast cell mediator 或 mast cell 活化的藥物後，症狀**明顯改善** |

## 三、什麼叫「多系統」？

指**同一次發作中，同時出現 ≥2 個器官系統**的症狀。

| 器官系統 | 典型症狀 |
|---|---|
| **皮膚** | Flushing、urticaria、angioedema、pruritus |
| **心血管** | **低血壓**、presyncope／syncope、心搏過速 |
| **呼吸道** | Wheezing、喉頭水腫或喉嚨緊縮感、鼻癢、鼻塞 |
| **腸胃道** | 噁心、嘔吐、腹瀉、腹部絞痛 |
| **眼** | 結膜充血、結膜癢 |

**判讀重點**【補充】：

- **要同時發生，才算多系統**。例如今天 flushing、下週腹瀉，這不算多系統發作。
- **單一器官的症狀不算**。只有 flushing，或只有慢性腹瀉，都不符合要件。
- 發作型態通常**類似 anaphylaxis**，嚴重時就是 anaphylaxis。
- **慢性、持續性、非特異性**的症狀不算，例如疲倦、腦霧、慢性疼痛、纖維肌痛樣症狀、各種「不耐」。Middleton 明確寫目前沒有證據支持這類症狀是 mast cell 造成的。

## 四、實驗室證據怎麼取得

**Serum tryptase（首選）**

- Middleton Ch75：tryptase 在發作後 **1–2 小時達高峰**，至少維持 3 小時。所以要在發作後 **1–4 小時內**抽血。
- **Baseline tryptase**：在症狀完全緩解 **≥24–48 小時後**另外抽一次。
- **20% + 2 公式**【補充，Valent 共識】：
  - **發作時 tryptase > 1.2 × baseline + 2 ng/mL**，就算有意義的上升
  - 例：baseline 5 → 發作時要 >8 ng/mL 才算
- 單看絕對值 >11.4 ng/mL 不夠，**一定要跟個人基礎值比較**。

**抽不到發作時的 tryptase 時，可以改用尿液 mediator**【補充】

在發作期間或發作後收集尿液（24 小時尿或發作後的 spot urine）：

| 尿液 mediator | 代表的 mediator |
|---|---|
| N-methylhistamine | Histamine |
| 11β-PGF2α（2,3-dinor-11β-PGF2α） | PGD2 |
| LTE4 | Cysteinyl leukotriene |

- 這些指標的特異性比 tryptase 低，但可以作為輔助證據。
- 測到哪一種 mediator 升高，也有助於選藥。例如 LTE4 高就用 LTRA，PGD2 代謝物高就考慮 aspirin。

## 五、MCAS 分類

| 類型 | 機轉 | 舉例 | 處理方向 |
|---|---|---|---|
| **Primary（clonal）** | 有克隆性 mast cell（KIT D816V 及/或 CD25⁺） | **Mastocytosis**、**MMAS** | 症狀治療；必要時交給血液科做 cytoreduction |
| **Secondary** | Mast cell 正常，但被外在因素強烈活化 | IgE 介導的食物、蜂毒、藥物過敏；物理性 urticaria；其他發炎或腫瘤疾病 | 找出並避開誘因、AIT、治療原發病 |
| **Idiopathic** | 沒有克隆性，也找不到誘因 | 包括大部分 idiopathic anaphylaxis | 症狀治療 |

**MMAS（monoclonal MCAS）**：

- 有克隆性標記（KIT D816V 或 CD25⁺），但**還不符合 SM 的完整 WHO 標準**
- 典型是**蜂螫後 anaphylaxis 或 idiopathic anaphylaxis、沒有皮膚病灶、tryptase <20 ng/mL** 的病人
- 有人改稱 monoclonal mast cells of uncertain significance，因為可能會進展成 SM
- 每年追蹤：理學檢查（器官腫大、淋巴結）、tryptase、CBC with differential

## 六、診斷流程

1. **確認症狀符合要件①**：發作性、同時 ≥2 個系統。
2. **取得客觀證據**：發作時抽 tryptase，之後補抽 baseline，套用 20% + 2 公式。抽不到的話，改收集尿液 mediator。
3. **排除其他會造成類似症狀的疾病**（Middleton Box 75.6）：
   - Carcinoid（5-HIAA）、pheochromocytoma（metanephrines）、medullary thyroid carcinoma
   - Scombroid 中毒、HAE、vasovagal、panic attack、vocal cord dysfunction、capillary leak syndrome
4. **分類**：
   - **找 secondary 誘因**：IgE 過敏原、藥物、物理刺激
   - **評估克隆性**，有以下任一情況要往 primary 查：
     - Baseline tryptase >20 ng/mL，或用 HαT 校正後仍偏高
     - 有 MPCM 皮膚病灶
     - 不明原因骨質疏鬆、肝脾腫大、血球異常
     - 蜂螫後 anaphylaxis 以**低血壓或昏厥**為主、**沒有 urticaria 或 angioedema**
   - **REMA score**【補充】：男性、沒有 urticaria 或 angioedema、有 presyncope 或 syncope、tryptase 偏高，都會提高克隆性的可能。分數高就驗周邊血 KIT D816V（高敏感度 PCR），必要時做骨髓切片。
5. **Baseline tryptase 偏高但不像克隆性**：驗 TPSAB1 copy number，排除 **hereditary α-tryptasemia（HαT）**。
6. **治療試驗**：確認症狀對抗 mediator 藥物有反應，也就是要件③。

## 七、治療

**原則**：

- 三種 MCAS 都以**症狀控制**和**預防 anaphylaxis** 為主
- Secondary 型要處理誘因
- Primary 型如果症狀頑固，要跟血液科合作

### (1) 避開誘發因子

| 類別 | 常見誘因 |
|---|---|
| 物理 | 高溫或突然的溫度變化、摩擦、壓力、劇烈運動 |
| 飲食 | 酒精、辛辣食物、熱飲 |
| 藥物 | **NSAIDs**（部分病人）、**opioids**（morphine、codeine 會直接活化 mast cell）、vancomycin、iodinated 顯影劑、部分肌肉鬆弛劑 |
| 其他 | 蟲螫、感染、情緒壓力 |

### (2) 階梯式藥物治療

| 階梯 | 藥物 | 重點 |
|---|---|---|
| **Step 1** | **H1 blocker**（非鎮靜型，例如 cetirizine、fexofenadine、loratadine） | 改善 pruritus、urticaria、flushing、心搏過速；控制不佳時可比照慢性 urticaria 加到 2–4 倍劑量【補充】。也可以白天用非鎮靜型、睡前用鎮靜型（Middleton Ch74） |
| **Step 2** | **加 H2 blocker**（famotidine） | 改善腹痛、胃酸過多、腹瀉，也能幫助 flushing 和低血壓 |
| **Step 3** | **Cromolyn sodium（口服）** | 穩定 mast cell，**對 GI 症狀最有效**（Middleton Ch74）；成人常用 200 mg QID，飯前服用【補充】。幾乎不會被吸收，所以全身副作用少 |
| | **Leukotriene modifier**（montelukast、zileuton） | 適合尿液 LTE4 高、有 wheezing，或用 H1/H2 後 flushing 和骨痛仍沒改善的病人 |
| | **Aspirin**【補充】 | 適合尿液 PGD2 代謝物高、flushing 很嚴重的病人；**要在監測下逐步加量**，因為本身也可能誘發發作；NSAID 過敏者不能用 |
| | Ketotifen | H1 blocker 兼具 mast cell 穩定作用；Middleton 認為比 hydroxyzine 的優勢有限 |
| **Step 4** | **Omalizumab（anti-IgE）**【補充】 | 可降低 idiopathic 和克隆性病人的 anaphylaxis 發作頻率，也用於保護蜂毒 VIT 期間不發生嚴重反應（Middleton Ch76 有引用 MMAS 病例） |
| | **短期口服類固醇** | 頑固或嚴重發作時短期使用，不建議長期 |
| **克隆性頑固病例** | 轉介血液科：**KIT inhibitor**【補充：avapritinib 已核准用於 ISM】、cytoreduction | 只用於 primary MCAS 或 mastocytosis |

### (3) Anaphylaxis 預防

- **隨身攜帶 2 支 epinephrine autoinjector**，並教病人或家屬使用
- 給書面 anaphylaxis action plan，配戴 medical alert 識別
- 反覆發作低血壓的人，可預防性使用 H1 ± H2 blocker（Middleton Ch74）

### (4) 特殊情境

- **手術、麻醉、顯影劑檢查前**【補充】：
  - 預防用藥：H1 + H2 blocker，±類固醇
  - 麻醉科要事先知道病人有這個病
  - 避免已知的 mast cell 活化藥物，例如 morphine 改用 fentanyl
  - 注意體溫和摩擦
- **蜂毒過敏合併克隆性 mast cell 疾病**【補充】：
  - 屬於嚴重 anaphylaxis 的高風險族群
  - 建議 **VIT 終身持續**，不要在 3–5 年後停
  - 可用 omalizumab 輔助
- **Secondary 型**：處理誘因，包括避開過敏原、AIT、治療原發疾病

## 八、跟 mastocytosis 的差別

詳見 [Mastocytosis](Mastocytosis_Middleton_Ch74.md) 筆記。

| | **Mastocytosis** | **MCAS** |
|---|---|---|
| 本質 | **克隆性腫瘤**，mast cell 數量增加並浸潤器官 | **功能性症候群**，mast cell 太容易被活化，數量不一定增加 |
| 診斷依據 | 病理與分子：骨髓、KIT D816V、CD25、tryptase（WHO criteria） | 臨床三要件 |
| Baseline tryptase | 常 >20 ng/mL，持續偏高 | 通常正常，重點在**發作時比基礎值上升** |
| 症狀型態 | 持續性（皮膚病灶、器官腫大、骨質疏鬆）＋發作性 | **以發作性為主**，發作間期大致正常 |
| 器官浸潤 | 可能有（B/C findings） | 沒有 |
| 治療 | 症狀治療；advanced SM 要 cytoreduction | 症狀治療並處理誘因 |
| 兩者關係 | Mastocytosis 合併反覆發作 = **primary MCAS** | 只有 primary 型與克隆性 mast cell 有關 |

光譜可以這樣想：

**Secondary／idiopathic MCAS（非克隆性）→ MMAS（有克隆、未達 SM）→ ISM → SSM → advanced SM**

## 九、不符合 MCAS 嚴格標準的病人

- 常見主訴：疲倦、對環境／食物／藥物「不耐」、記憶力差、憂鬱
- 沒有發作時 mediator 上升的客觀證據，**就不應該診斷 MCAS**，因為 MCAS 很容易被過度診斷
- 要考慮 **hereditary α-tryptasemia**：
  - TPSAB1 copy number 增加，造成 baseline tryptase 偏高，通常 >8 ng/mL【補充】
  - 會有 flushing、pruritus、dysautonomia、functional GI 症狀、慢性疼痛、joint hypermobility
  - HαT 本身不等於 MCAS，但會增加嚴重 anaphylaxis 的風險【補充】
