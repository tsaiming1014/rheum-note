# Contact System 生理作用與 ACEi／ARB 對 Bradykinin 的影響

> 相關筆記：[HAE 致病機轉／診斷](HAE_致病機轉診斷治療.md)、[HAE 治療](HAE_治療.md)

## 一、Contact system 的組成

Contact system 又稱 **plasma kallikrein–kinin system (KKS)**，由三個血漿蛋白組成：

| 成分 | 角色 |
|---|---|
| **Factor XII (FXII, Hageman factor)** | 起始的 zymogen，接觸到帶負電的表面後自我活化成 FXIIa |
| **Prekallikrein (PK)** | 被 FXIIa 切成 **plasma kallikrein (PKa)** |
| **High-molecular-weight kininogen (HK/HMWK)** | 輔因子，也是 bradykinin 的前驅物 |

- **活化表面**：體外是玻璃、kaolin；體內是 polyphosphate（血小板釋放）、NETs 的 DNA/RNA、misfolded protein、collagen、mast cell 釋放的 heparin、細菌表面。
- **正回饋放大**：FXII → FXIIa → PK → PKa，PKa 再回頭活化更多 FXII。
- PKa 切割 HK 後釋出 **bradykinin (BK)**。

## 二、Bradykinin 的受體與代謝

- **B2 receptor**：持續表現（constitutive），完整的 BK 作用在這裡。**HAE 的症狀主要經由 B2R 產生**。
- **B1 receptor**：發炎時才誘導表現。配體是 des-Arg⁹-BK，由 carboxypeptidase N 切出來。
- **降解酵素**：**ACE (kininase II)** 是主要的降解酵素，另外還有 aminopeptidase P (APP)、DPP-4、neprilysin (NEP)。

## 三、Contact system 的生理作用

| 作用 | 機轉 |
|---|---|
| **血管擴張、降血壓** | B2R → 內皮細胞釋放 NO 與 PGI₂ |
| **增加血管通透性** | 內皮細胞間的 VE-cadherin 連接鬆開 → 血漿滲出 → **水腫**，這是 HAE 的核心機轉 |
| **發炎與疼痛** | BK 刺激感覺神經 → 疼痛；也會促進 PG 生成 |
| **內在凝血途徑（intrinsic coagulation）** | FXIIa 活化 FXI。體外是 **aPTT** 的基礎，但體內對止血不重要：**FXII 缺乏不會出血**，只會讓 aPTT 延長。它在病理性血栓中有角色，因此是抗凝新藥的標的 |
| **纖溶（fibrinolysis）** | PKa 活化 pro-urokinase 與 plasminogen；BK 刺激內皮細胞釋放 tPA |
| **補體交互作用** | FXIIa 可活化 C1；kallikrein 可切割 C5；plasmin 可切割 C3/C5 |
| **RAAS** | Kallikrein 可把 prorenin 活化成 renin |
| **先天免疫** | HK 的 domain 5 可衍生出抗菌胜肽 |

## 四、C1-INH：Contact system 的剎車

**C1-inhibitor（SERPING1 基因）** 是一種 serpin，抑制的目標包括：

- **FXIIa**：體內 FXIIa 的抑制作用 >90% 來自 C1-INH
- **Plasma kallikrein (PKa)**：主要抑制者之一
- C1r、C1s（classical pathway）
- MASP-1/2（lectin pathway）
- Plasmin（次要）

C1-INH 雖然在命名上屬於補體，但它最重要的生理功能其實是**剎住 contact system**。

### HAE 的病生理

C1-INH 不足（type 1 是量少，type 2 是功能異常）會造成以下連鎖反應：

1. FXIIa 與 PKa 失去控制
2. HK 被大量切割，BK 過量
3. B2R 被活化，血管通透性上升
4. 出現**非組織胺性 angioedema**

這解釋了幾個臨床特點：

- **Antihistamine、steroid、epinephrine 無效**，因為它不是 mast cell 介導的。
- **沒有蕁麻疹（urticaria）、沒有搔癢**。
- **C4 低下是篩檢指標**：C1s 失控後持續消耗 C4 與 C2。
- **誘發因子**：外傷、拔牙、手術、感染、壓力、estrogen（OCP、懷孕）、ACEi。Estrogen 會增加 FXII 與 PK 的表現。

### C1-INH 正常的 HAE（HAE-nC1-INH）

同樣以 contact system 或 BK 為主軸，相關基因包括 **F12**（FXII gain-of-function，例如 Thr309Lys，與 estrogen 高度相關）、**PLG**、**KNG1**、**ANGPT1**、**MYOF**、**HS3ST6**。

### 治療標的（沿著 contact system 一路阻斷）

| 標的 | 藥物 | 用途 |
|---|---|---|
| 補回 C1-INH | pdC1-INH（Berinert、Cinryze、Haegarda）、rhC1-INH（Ruconest） | 急性發作／預防 |
| **FXIIa** | **Garadacimab**（anti-FXIIa mAb） | 長期預防 |
| **Plasma kallikrein** | **Lanadelumab**（mAb）、**Berotralstat**（口服）、Ecallantide | 預防；Ecallantide 用於急性發作 |
| | **Sebetralstat**（口服） | 急性發作（on-demand） |
| PK mRNA | **Donidalorsen**（antisense oligonucleotide） | 預防 |
| **B2 receptor** | **Icatibant** | 急性發作 |
| 其他 | Danazol（增加 C1-INH 合成）、Tranexamic acid | 舊式預防，現在較少用 |

## 五、ACEi 對 BK 的影響：直接讓 BK 堆積

**ACE 就是 kininase II**，它有兩個身分：

- 把 Ang I 轉成 Ang II
- 降解 BK：BK(1–9) → BK(1–7) → BK(1–5)，產物不具活性

ACEi 一出手就同時壓低 Ang II、拉高 BK。

| 機轉 | 結果 |
|---|---|
| 抑制 BK 降解 | BK 半衰期延長，**B2R 活化增加** |
| 降解路徑改道 | BK 改由 carboxypeptidase N 切成 **des-Arg⁹-BK**，作用在 **B1R** |
| ACE–B2R 交互作用 | ACEi 可使 B2R 再敏感化，訊息傳遞增強 |
| Substance P 堆積 | ACE 也會降解 substance P 與其他 tachykinin |

### 臨床後果

**1. 好的一面**

BK 經 B2R 釋放 NO 與 PGI₂，帶來血管擴張、降壓與心腎保護，是 ACEi 療效的一部分。

**2. 乾咳（約 5–35%）**

由 BK、substance P、PG 刺激呼吸道感覺神經造成，與劑量關係不明顯。停藥後 1–4 週緩解。

**3. ACEi angioedema（約 0.1–0.7%）**

- **機轉**：BK 介導，屬於**非組織胺性**，與 HAE 相同的終端路徑。
- **好發部位**：臉、唇、舌、上呼吸道，也可以只表現為**腸道 angioedema**（腹痛）。
- **沒有蕁麻疹**，antihistamine、steroid、epinephrine 效果差。
- **C4 與 C1-INH 正常**，可以藉此和 HAE、AAE 區分。
- **時間點**：多在用藥初期，但**可在服藥數年後才首次發作**，這是常考陷阱。

**危險因子**

| 因子 | 原因 |
|---|---|
| **黑人**（風險約 3–5 倍） | APP 等 BK 降解酵素活性較低 |
| 女性、吸菸、年齡增加 | |
| 曾有特發性 angioedema 病史 | |
| **併用 DPP-4 inhibitor**（gliptins） | DPP-4 降解 substance P 與 des-Arg⁹-BK |
| **併用 neprilysin inhibitor**（sacubitril） | NEP 也降解 BK |
| **器官移植、mTOR inhibitor**（sirolimus、everolimus）、免疫抑制劑 | 降低 DPP-4 表現 |
| 使用 **tPA**（中風溶栓） | plasmin 會活化 contact system |
| **APP 基因（XPNPEP2）多型性**造成活性低下 | |
| （反例）**糖尿病病人風險較低** | |

**處置**

- 停用 ACEi，**無論已服用多久都要停**，並終身避免整類 ACEi。消腫可能延遲數週；若繼續服用，5 年內再發作的風險 >50%。
- 先處理呼吸道。
- Icatibant 和 C1-INH 的 RCT 結果不一致，不是標準治療；FFP 有零星報告。

## 六、ARB 對 BK 的影響：不直接影響降解，但有間接效應

ARB 阻斷的是 **AT1R**，**不抑制 ACE**，所以 BK 的主要降解路徑完好。

**間接增加 BK 的機轉**

1. AT1R 被阻斷後，負回饋解除，**Ang II 濃度上升**。
2. 多出來的 Ang II 轉而刺激**未被阻斷的 AT2R**。
3. AT2R 活化後會增加 kinin 生成，再帶動 NO 與 cGMP 上升。

所以 ARB 對 BK 仍有輕度、間接的提升作用。

| | ACEi | ARB |
|---|---|---|
| 對 BK 的影響 | **直接**抑制降解，BK 明顯上升 | **間接**、輕度上升（經 AT2R） |
| 乾咳 | 常見 | **與 placebo 相近**，ACEi 咳嗽病人的標準替代藥 |
| Angioedema 發生率 | 約 0.3%（研究間 0.1–0.7%） | 約 0.1%，接近 placebo |
| 曾發生 ACEi angioedema，換成 ARB 後復發 | — | 確定病例約 **2–3%**，含可能病例最高約 **10%** |

**實務原則**

- ACEi angioedema 後可改用 ARB，建議停用 ACEi 後**等 6 週**再開始，並告知病人風險、密切觀察。
- 若適應症允許，CCB、利尿劑等非 RAAS 藥物最安全。

## 七、其他會影響 BK 的 RAAS 相關藥物

| 藥物 | BK 相關風險 |
|---|---|
| **Sacubitril/valsartan（ARNI）** | Neprilysin 被抑制，BK 上升。**曾有 ACEi angioedema 者禁用**；與 ACEi 切換須間隔 **36 小時** |
| Omapatrilat（ACE + NEP 雙重抑制） | Angioedema 太多，**未上市**，是「BK 雙路徑都被阻斷」的經典教訓 |
| Aliskiren（renin inhibitor） | 也有 angioedema 報告，機轉不完全清楚 |

## 八、HAE vs ACEi angioedema

| | HAE（C1-INH 缺乏） | ACEi angioedema |
|---|---|---|
| BK 異常的原因 | **生成過多**（C1-INH 剎車失靈） | **清除不足**（ACE 被抑制） |
| 終端路徑 | BK → B2R → 血管通透性上升 | 相同 |
| C4 | **低** | 正常 |
| C1-INH 抗原／功能 | 低（type 1）或功能低（type 2） | 正常 |
| 家族史 | 常有（AD） | 無 |
| 藥物禁忌 | **禁用 ACEi**（雙重打擊）、避免 estrogen；ARB 非絕對禁忌但要謹慎 | 終身避免 ACEi |

## 速記

- **FXII → PKa → HK → BK → B2R → 漏水**
- **C1-INH 是 FXIIa 與 PKa 的剎車**：剎車壞了就是 HAE。
- **ACE = kininase II**：ACEi 讓 BK 拆不掉，咳嗽與 angioedema 都是 BK 造成的。
- **ARB 不碰 ACE**：BK 只有經 AT2R 的間接、輕微上升。咳嗽約等於 placebo，ACEi angioedema 後換 ARB 的復發率約 2–10%。
- **ACEi angioedema 的 C4 與 C1-INH 都正常**，可以和 HAE 區分。
- **FXII 缺乏只會延長 aPTT，不會出血。**
