# Asthma 分型（Phenotypes & Endotypes）

來源：Middleton's Allergy 9th ed., Ch51、Ch47、Ch56

相關筆記：[Asthma 致病機轉](Asthma_致病機轉.md)、[Type 2 inflammation 共同機轉與比較](../Type2_inflammation_共同機轉與比較.md)

---

## 一、先搞懂兩個名詞

- **Phenotype**：看得到的特徵，例如臨床表現、誘發因子、發炎細胞。
- **Endotype**：由特定致病機轉定義的亞型。目前公認的只有兩個：**AERD** 和 **ABPA**。

同一位病人可以同時屬於多個分型，例如「早發、allergic、eosinophilic」。

---

## 二、教科書的五大分類軸（Box 51.1）

| 分類軸 | 類型 |
|---|---|
| 發炎型態 | Eosinophilic／neutrophilic／mixed／paucigranulocytic |
| 臨床特徵 | 嚴重度、易惡化、治療抗性、早發或晚發、老年 |
| 肺功能 | 固定性阻塞、劇烈波動、過度充氣 |
| 誘發因子 | 過敏原、NSAID、職業、荷爾蒙、運動、吸菸 |
| 共病 | 鼻竇炎與鼻息肉、肥胖、OSA、GERD、VCD、COPD、精神疾病 |

最常被報告的五個 phenotype：**early-onset allergic、late-onset eosinophilic、exercise-induced、obesity-related、neutrophilic**。

---

## 三、五個主要 phenotype 一表看懂

| Phenotype | 典型病人 | 機轉 | 治療重點 |
|---|---|---|---|
| **Early-onset allergic** | 兒童期發病，合併 AR、AD，過敏原檢測陽性 | Th2 → IgE → mast cell | ICS 有效；omalizumab |
| **Late-onset eosinophilic** | 成人發病，過敏原檢測陰性，常合併**鼻息肉** | **ILC2**（不靠 IgE） | 常需 OCS；anti-IL-5 效果好 |
| **Exercise-induced（EIB）** | 運動後 5–15 分鐘喘，1 小時內緩解；運動員、游泳選手 | 呼吸道乾燥形成高滲透壓 → mast cell 釋放 PGD2、CysLTs | 運動前使用 SABA 或 ICS-formoterol |
| **Obesity-related** | 晚發，女性，eos 少 | T2-low，加上機械性因素 | 對 ICS 反應差；**減重 5–10%** 就有效 |
| **Neutrophilic** | 嚴重 asthma、吸菸者、病毒誘發的惡化 | NLRP3 → IL-1β；Th17 | 對 ICS 反應差 |

## 四、特殊類型

### AERD（aspirin-exacerbated respiratory disease）

- **Samter triad**：asthma ＋ 鼻息肉 ＋ NSAID 不耐受。
- 機轉：抑制 COX-1 → PGE2 減少 → CysLT 過度產生。

### Occupational asthma

| | Sensitizer-induced | Irritant-induced（RADS） |
|---|---|---|
| 潛伏期 | **有** | **沒有**（單次大量暴露） |
| 例子 | 麵粉、latex、**isocyanate** | 氯氣、氨氣 |
| 治療 | **完全避開**，越早越好 | — |

- 另有 **work-exacerbated asthma**：原本就有 asthma，被工作環境誘發惡化，但不是由工作引起。

### Cough-variant asthma

- 只有慢性乾咳。
- 和 **eosinophilic bronchitis** 的差別：**CVA 有 AHR，eosinophilic bronchitis 沒有**。

### T2-high vs T2-low

| | T2-high | T2-low |
|---|---|---|
| 指標 | 血中 eos、FeNO、IgE 上升 | 上述指標都低 |
| ICS 反應 | 好 | 差 |
| 生物製劑 | 多種可選 | 選擇少（tezepelumab） |

---

## 五、速記

- **公認的兩個 endotype**：AERD、ABPA。
- **早發型** = allergic、IgE；**晚發型** = ILC2、鼻息肉。
- **對 ICS 反應差的三種**：肥胖型、neutrophilic、吸菸者。
- **職業性 asthma**：有潛伏期 → 致敏型；沒有潛伏期 → RADS。
- **CVA 和 eosinophilic bronchitis**：看有沒有 AHR。
