# 過敏原免疫治療（AIT）：SCIT / SLIT / OIT 完整比較

> 對應題庫：2026免疫講習班第29題

## 1. 核心概念：AIT 想做什麼？

過敏原免疫治療（Allergen Immunotherapy, AIT）是目前唯一能**改變過敏疾病自然病程**（而非只是症狀控制）的治療方式，原理是**逐步、重複給予患者過敏的過敏原**，誘導免疫系統從Th2主導的過敏反應，逐漸轉向**Treg/調節性反應**（誘導IL-10、TGF-β分泌，誘導blocking antibody如IgG4），達到臨床耐受。

三種主要途徑：**SCIT（皮下注射）、SLIT（舌下）、OIT（口服）**，給藥途徑不同，機轉、適應症、副作用profile也不同。

## 2. 三種途徑詳細比較

| | **SCIT**（Subcutaneous Immunotherapy） | **SLIT**（Sublingual Immunotherapy，含tablet/drops） | **OIT**（Oral Immunotherapy） |
|---|---|---|---|
| 給藥途徑 | 皮下注射 | 舌下（錠劑或滴劑） | 口服吞食 |
| 給藥地點 | **診所**（需醫護監測） | **可每日自行在家給藥** | 每日在家自行口服 |
| Up-dosing（劑量調升）階段 | **需要**，通常數週至數月 | 通常不需（起始劑量固定，SLIT tablet多為固定劑量） | **需要**，劑量緩慢遞增，過程需醫療監測 |
| 維持期給藥頻率 | 每4-8週一次 | 每日 | 每日 |
| 主要適應症 | 吸入性過敏原（塵蟎、花粉、黴菌、動物皮屑）、蜂毒 | 塵蟎、牧草/樹木花粉相關過敏性鼻炎/氣喘 | 食物過敏（花生等） |
| 已核准代表產品 | 多種吸入性過敏原萃取物 | 塵蟎SLIT tablet、牧草花粉SLIT tablet | **Palforzia**（花生OIT，FDA核准） |
| 建議療程長度 | 3-5年 | **約3年** | 需持續治療以維持耐受性 |
| 全身性副作用（systemic AE） | 中等，注射後30分鐘內需觀察 | **低**（局部口腔搔癢/腫脹較常見） | **相對較高**（腸胃道症狀、全身性反應風險較高） |
| 治療目標 | Desensitization → 部分可達長期耐受 | Desensitization → 部分可達長期耐受 | 多數為desensitization，停藥後耐受性可能消退 |

## 3. 機轉：誘導免疫耐受性的共同路徑

不論哪種途徑，AIT的免疫調節機轉大致遵循類似順序：

1. **早期（數小時-數天）**：肥大細胞/嗜鹼性球去敏感化（減少脫顆粒反應）
2. **中期（數週-數月）**：誘導**過敏原特異性Treg細胞**擴增，分泌IL-10、TGF-β，抑制Th2反應
3. **抗體轉換**：誘發**IgG4（blocking antibody）**上升，與IgE競爭結合過敏原，阻斷IgE介導的肥大細胞活化
4. **長期**：過敏原特異性Th2細胞減少、IgE逐漸下降，部分病人可達停藥後仍持續的**長期耐受性（sustained unresponsiveness）**

## 4. 各途徑的安全性考量

- **SCIT**：注射部位局部反應常見；全身性過敏反應（含過敏性休克）雖不常見但可能發生，因此**注射後須在診所觀察至少30分鐘**，是三者中對醫療監測要求最高的途徑。
- **SLIT**：安全性相對最佳，多數副作用為**局部口腔搔癢、輕微腫脹**，全身性嚴重反應罕見，因此可**在家自行給藥**，不需每次回診。
- **OIT**：因直接讓病人攝入原本會過敏的食物，**全身性副作用（含過敏性休克）風險相對三者中最高**，尤其在劑量調升期，因此起始與調升階段通常需在醫療院所進行，是三種AIT中安全性風險最需要密切監測的一種。

## 5. 速記

- **SCIT** = 診所注射、需up-dosing、全身性副作用中等
- **SLIT** = **可在家每日自行給藥**、副作用最輕微、療程約3年
- **OIT** = 口服、需up-dosing、**全身性副作用風險相對最高**
- 三者共同機轉：誘導Treg／IL-10／IgG4 blocking antibody，抑制Th2/IgE路徑
