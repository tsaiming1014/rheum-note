# Atopic Dermatitis (AD)：臨床特徵、診斷與治療整理

> 致病機轉部分請見 [AD_致病機轉.md](AD_致病機轉.md)，本篇不重複整理。

## 一、流行病學與自然病程

- 兒童最常見的慢性皮膚病，美國學童 lifetime prevalence 最高可達 18%，但各年齡層都可能發生。
- **90% 於 5 歲前發病**；成人新發型 AD（無兒童期濕疹/氣喘/過敏性鼻炎病史者）需優先排除其他疾病。
- 自然病程數據（重點記憶）：
  - 追蹤至 11–13 歲：僅 18% 完全消失，65% 轉輕微。
  - 2 歲前診斷者，20 年後仍有 AD 者達 72%。
  - 芬蘭青少年中重度 AD 追蹤至成人：77–91% 持續或頻繁復發，僅 6% 仍為重症。
  - 德國 Multicenter Allergy Study（出生世代）：2 歲內發病之 AD，3 歲時 43.2% 完全緩解、38.3% 間歇發作、18.7% 每年都有症狀；**嚴重度與 atopic sensitization 是預後的主要決定因子**。

## 二、診斷標準：Hanifin-Rajka Criteria

AD **沒有病理特異性皮疹或實驗室標記**，診斷純靠臨床（Box 33.1）。

**Major features（需符合）**

- Pruritus
- 嬰幼兒：臉部與四肢伸側侵犯；較大兒童/成人：屈側 lichenification
- 慢性或反覆發作病程
- 個人或家族過敏病史

**Minor features**

- Xerosis、皮膚感染
- 手足非特異性皮膚炎
- Ichthyosis、掌紋增多（palmar hyperlinearity）、毛孔角化症（keratosis pilaris）
- Pityriasis alba、乳頭濕疹
- White dermatographism、delayed blanch response
- 前囊下白內障（anterior subcapsular cataract）
- 血清 IgE 上升、immediate-type skin test 陽性

（SCORAD、EASI 主要用於臨床試驗嚴重度評分，非診斷工具）

## 三、依年齡的臨床分布

| 年齡層 | 好發部位 |
|---|---|
| 嬰兒期 | 臉、頭皮、四肢**伸側**；尿布區通常倖免（若侵犯合併 Candida 感染，會侵犯鼠蹊摺；AD 本身則侵犯 infragluteal 但可倖免鼠蹊摺——與 candida diaper rash 鑑別重點） |
| 較大兒童/成人 | 四肢**屈側** lichenification 為主 |

Copenhagen Prospective Study：3 歲時對 AD 預測力最高的臨床表現是「手臂與關節部位侵犯」。

**Clinical phenotype 差異**：Asian AD 患者 Th17 axis 較歐美白人明顯，組織學可見類似 psoriasis 的 parakeratosis，暗示東西方 AD 存在不同 endophenotype（機轉細節見致病機轉筆記）。

## 四、鑑別診斷（Table 33.1）—— 考試常考的「類 AD 疾病」

| 分類 | 疾病 | 鑑別重點 |
|---|---|---|
| 先天性 | **Netherton syndrome** | SPINK5 突變，ichthyosis + hair shaft abnormality + atopy |
| 慢性皮膚病 | Seborrheic dermatitis、Contact dermatitis、Nummular eczema、Lichen simplex chronicus | 分布與病史 |
| 感染/寄生蟲 | Scabies、HIV-associated dermatitis | Scabies：生殖器/腋下分布、linear burrow、可找到 mite/ova/scybala |
| 惡性 | Cutaneous T cell lymphoma（mycosis fungoides/Sézary） | 成人無兒童濕疹病史的新發皮膚炎，建議三處切片找 Sézary cell |
| **免疫缺陷**（考試熱點） | **IPEX**（FOXP3 突變，X-linked，Treg 發育缺陷）：dermatitis + enteropathy + type 1 DM + thyroiditis + hemolytic anemia + thrombocytopenia | |
| | **Wiskott-Aldrich syndrome**：X-linked，濕疹 + thrombocytopenia + humoral/cellular immunity 異常 + 反覆細菌感染 | |
| | **Hyper-IgE syndrome (STAT3, AD 遺傳)**：反覆深部細菌感染（cold abscess）+ 肺炎，coarse facies | |
| | **DOCK8 缺損（AR-HIES 主因）**：濕疹 + 反覆病毒性皮膚感染，**無** coarse facies，常合併 food allergy | |
| 代謝性 | Zinc deficiency、Vit B6/niacin deficiency、Multiple carboxylase deficiency、PKU | |
| 增生性疾病 | Letterer-Siwe disease | |

## 五、併發症（Complicating Features）

**眼部**

- Atopic keratoconjunctivitis：一定雙側，癢/灼熱/流淚/黏液分泌物，合併眼瞼皮膚炎與慢性 blepharitis，可致角膜疤痕影響視力。
- **Keratoconus**：因長期揉眼所致的角膜圓錐狀變形。
- **前囊下白內障**：可於青少年/成年早期出現。

**手部濕疹**：AD 病史使刺激性接觸暴露的手部濕疹風險至少加倍，職業性濕熱工作者風險更高。

**感染**

- 病毒：HSV（→ **eczema herpeticum, EH**）、molluscum contagiosum、HPV；EH 患者特徵：疾病較重（BSA、eosinophil、IgE、TARC、CTACK 較高）、較常合併 S. aureus/molluscum 共感染、較常有氣喘與食物/吸入性過敏；**FLG 突變者發生 EH 的 odds ratio > 10**。
- 細菌：S. aureus colonization 極普遍，MRSA 已成重要病原。
- 真菌：Malassezia sympodialis 與**頭頸部分布**AD 相關；superficial dermatophytosis 可誘發急性惡化。

**心理社會層面**：焦慮/憂鬱盛行率高，搔抓常為壓力反應；睡眠障礙普遍且顯著影響生活品質；German cohort 顯示即使濕疹已緩解，10 歲時情緒行為問題風險仍較高。

## 六、過敏原的角色（臨床相關性）

**食物**

- 約 33% 嬰幼兒 AD 對食物過敏原有臨床相關反應（雙盲安慰劑對照食物激發試驗證實）。
- 牛奶、蛋、花生、黃豆、小麥、魚 佔兒童食物誘發惡化原因的 ~90%。
- Specific IgE cutoff（ImmunoCAP，>95% 機率有臨床反應）：**egg 7 kUA/L**（≤2 歲：2）、**milk 15**（≤2 歲：5）、**peanut 14**、**fish 20**。但這些數值僅預測「是否會反應」，不代表反應嚴重度。
- 大範圍 elimination diet 幾乎不需要——即使多重過敏原檢測陽性，激發試驗證實臨床有意義者通常 ≤3 種食物。
- **NIAID Expert Panel**：重度濕疹嬰兒建議 **4–6 個月大**及早引入花生食品以降低花生過敏風險；引入前應先做 peanut-specific IgE 或 skin prick test 評估；輕中度濕疹嬰兒建議約 6 個月大引入。

**吸入性過敏原**

- 塵蟎經**支氣管激發**可誘發皮膚病灶（有氣喘病史者），顯示呼吸道路徑也可能誘發/惡化 AD。
- Atopy patch test 可測到接觸性誘發但仍屬研究性工具。
- 環境控制（防蟎寢具套、高溫洗滌、移除臥室地毯、降低濕度）對塵蟎 IgE 陽性患者可改善病情；值得注意：**未致敏患者用防蟎套也有幫助**，暗示這類措施也減少其他過敏原/刺激物/病原暴露。

## 七、治療（Management）—— 本章重點

![2023 AAAI AD treatment algorithm 2](../../images/2023%20AAAI%20AD%202.png)

### 治療流程總覽（Fig 33.6）

1. 確認診斷符合 Hanifin-Rajka criteria、排除鑑別診斷。
2. 基礎治療：辨識並移除誘發因子（刺激物、確認的過敏原）、衛教、保濕。
3. 依嚴重度加上外用抗發炎藥物（corticosteroid → calcineurin inhibitor → PDE4 inhibitor）、感染控制、止癢。
4. 若治療失敗/重度：轉介專科，考慮 wet wrap、dupilumab、光療、全身性免疫抑制劑、住院。
5. 治療成功後：定期追蹤、考慮 proactive maintenance therapy。

### (一) 保濕與皮膚照護

- AD 患者 ceramide 減少→保水力下降、TEWL 增加；**先泡澡/沐浴（溫水非涼水，約 10 分鐘）→立即塗抹 occlusive 鎖水**是重建屏障的核心方法。
- 稀釋漂白水浴（bleach bath）：近期統合分析顯示**並未優於單純清水浴**，但對於需頻繁抗生素治療感染併發症的患者仍可能有幫助。
- Petrolatum：可上調 antimicrobial peptide 及屏障分化基因表現、增加角質層厚度、減少 T cell 浸潤。
- 保濕劑選擇：ointment 封閉性最佳、防止水分蒸發，但濕熱環境下 cream 可能耐受性更好。

### (二) 外用類固醇（Topical corticosteroids）—— 一線藥物

依效價分 7 組（1 = 超強效 → 7 = 弱效），常考代表藥物：

| Group | 藥物範例 |
|---|---|
| 1（超強） | Clobetasol propionate 0.05%、Betamethasone dipropionate 0.05% |
| 2–3 | Mometasone furoate 0.1% ointment、Fluocinonide 0.05%、Desoximetasone 0.25% |
| 4–5（中效） | Triamcinolone acetonide 0.1%、Fluocinolone acetonide 0.025%、Betamethasone valerate 0.1% |
| 6–7（弱效） | Desonide、Alclometasone dipropionate、Hydrocortisone 1–2.5% |

- 原則：先用**能控制病灶的最低效價**藥物；顏面／間擦部位僅用低效價。
- **Fingertip unit (FTU)**：食指掌側末節長度的藥膏量。1 FTU 可覆蓋手掌/鼠蹊，2 FTU 臉/腳，3 FTU 手臂，6 FTU 腿，14 FTU 軀幹——成人全身約需 30g。
- 兒童年齡限制範例：fluticasone 0.05% cream ≥3 個月、fluticasone lotion ≥12 個月、mometasone ≥2 歲。
- 副作用：皮膚萎縮/telangiectasia/瘀斑/色素脫失/痤瘡/皮紋/續發感染；顏面、眼瞼、間擦部位最敏感；**perioral dermatitis**、**"steroid addiction"**（成年女性顏面長期使用後灼熱感，須完全停用才改善）。
- **Proactive（maintenance）therapy**：病灶控制後，於曾侵犯但外觀正常部位**每週 2 次**外用類固醇維持，可減少復發與整體用藥量（優於單純 reactive 治療）。
- 外用類固醇也可**降低 S. aureus colonization**（非僅抗發炎效果）。
- 全身性類固醇（口服 prednisone）**應避免**用於這種慢性復發疾病——停藥後常有顯著反彈惡化；若不得已短期使用，減量期間須加強外用照護以防 rebound。

### (三) 外用 Calcineurin Inhibitors（TCI）

- **Tacrolimus ointment**：0.03%（≥2 歲，中重度）、0.1%（成人，中重度）；**Pimecrolimus cream 1%**（≥2 歲，輕中度）。
- 不會造成皮膚萎縮，適合臉部與間擦部位；常見副作用為短暫灼熱感。
- FDA **boxed warning**（長期安全性資料不足，非確立因果關係）：建議作為**第二線、間歇性**治療，**不建議用於 <2 歲**。大型病例對照研究（n=293,253）**未發現**淋巴瘤風險增加。
- Tacrolimus proactive therapy 於歐洲核准可用至 12 個月（≥2 歲）。

### (四) 外用 PDE4 inhibitor

- **Crisaborole**：抑制 PDE4 減少發炎細胞激素釋放，已核准用於 **≥2 歲**輕中度 AD。

### (五) 焦油製劑、Wet Wrap Therapy

- Tar：抗發炎效果不如類固醇，可用於合併治療減少強效類固醇需求；頭皮可用 tar shampoo；急性發炎期避免使用（會刺激）。
- **Wet wrap therapy**：濕敷+外用類固醇可增加穿透、降低搔抓創傷、促進屏障修復；適合急性惡化或頑固病灶短期使用，過度使用可能造成浸潤/毛囊炎；**TCI 不可用於 occlusive dressing 下**。

### (六) 感染控制（Antiinfective Therapy）

- 續發性 S. aureus 感染：口服半合成 penicillin 或第一/二代 cephalosporin 7–10 天（紅黴素抗藥性常見，較不建議 macrolide）；停藥後常快速再度移生，**不建議長期預防性抗生素**（易致 MRSA）。
- 局部：Mupirocin 外用 3 次/天 × 7–10 天；鼻腔 mupirocin 2 次/天 × 5 天可減少鼻腔帶菌。
- **Eczema herpeticum**（disseminated）：需**全身性 acyclovir**；反覆發作可用預防性口服 acyclovir。
- Dermatophyte/Malassezia：外用（少數口服）抗黴菌藥物。

### (七) 止癢（Antipruritic）

- 組織胺可能非主要致癢介質（microdialysis 研究顯示 histamine 以外的介質才是主因）；中樞性 opioid receptor antagonist 對止癢有效，支持神經傳導路徑角色。
- Doxepin（TCA，兼具 H1/H2 拮抗）睡前 10–50mg 可用於頑固夜間搔癢。
- 第二代抗組織胺對 AD 本身癢感**證據不支持**，但對合併蕁麻疹/過敏誘因者可能有幫助；**外用抗組織胺/局部麻醉藥應避免**（致敏風險）。
- 頑固合併疼痛者可考慮 gabapentin（off-label）。
- Nemolizumab（anti-IL-31RA）第二期試驗顯示止癢效果；**dupilumab** 亦顯著減少搔癢；JAK inhibitor 對頑固慢性搔癢有效。

### (八) 難治型 AD 的進階治療

**住院**：erythrodermic 或病情看似 toxic 之患者，或對一線治療無效之重度瀰漫性 AD；脫離環境過敏原/壓力源合併加強衛教常有顯著改善。

**Dupilumab**（anti-IL-4Rα，同時阻斷 IL-4/IL-13 訊號）——章節重點：

- Phase 3 試驗（中重度成人 AD，topical 治療控制不佳）：IGA 0/1 達標率 dupilumab 每週注射 ~37%、隔週注射 ~38%，安慰劑僅 ~10%（P<0.001）；EASI-75 亦顯著優於安慰劑。
- 同時改善搔癢、焦慮/憂鬱症狀與生活品質。
- 副作用：注射部位反應、**結膜炎**較常見（多為自限性）。
- 核准劑量：600mg 負荷劑量 SC，之後 300mg SC 每 2 週一次（成人 ≥18 歲，中重度，外用治療不足或不適用者）；**青少年**依體重給藥（<60kg：400mg 負荷 + 200mg q2w；≥60kg：成人劑量）。

**光照治療**

- Narrowband UVB 最常用，其次 broadband UVB、UVA1；短期副作用：紅斑、疼痛、癢、色素沉著；長期：皮膚老化、皮膚癌風險。
- 開放性試驗：每週 3 次 narrowband UVB 治療 12 週，所有患者 SCORAD 下降 ≥50%；同時抑制 Th2/Th22/Th1 pathway、使表皮增生正常化、**降低皮膚上產毒 S. aureus 量**。
- **PUVA**（oral methoxypsoralen + UVA）用於重度患者，長期皮膚癌風險使其較少用於兒童。

**全身性免疫抑制劑**

- 美國僅**全身性類固醇**正式核准用於 AD，但治療指引**不建議連續或慢性間歇使用**。
- 統合分析（34 RCT，12 種全身治療）：**Cyclosporine A 是唯一可被推薦作為短期第一線全身治療**的藥物。
- 其他：methotrexate、mycophenolate mofetil、azathioprine（劑量監測需個別化）。

**過敏原減敏治療（Allergen immunotherapy）**：小型研究顯示對**合併吸入性過敏原致敏**之 AD 患者可能有效（劑量依賴），但 **Cochrane review 結論證據不一致**，尚無法確立角色。

### (九) 實驗性/未證實療法

- **IVIG**：理論上可中和 staphylococcal toxin、降低 IL-4，但對照研究少且結果不一致，兒童反應優於成人；效果隨時間遞減。
- **Omalizumab**：case series 結果不一，安慰劑對照試驗（n=20）未顯示顯著效果；系統性回顧結論證據不足，但仍可能對特定重度頑固病患有效。
- **重組人類 IFN-γ**：可抑制 IgE 合成與 Th2 功能，長期使用（≥22 個月）安全且有效，改善與嗜酸性球數下降相關。
- **益生菌（Probiotics）**：整體證據混雜——部分統合分析顯示對**預防**（而非治療）兒童 AD 有小幅效益；Cochrane review 認為對治療濕疹**無效**且有小風險。
- **Rituximab**（anti-CD20）：小型開放性試驗顯示重度 AD 有臨床改善（伴組織學上 spongiosis/acanthosis 改善），但另一研究僅短暫改善後惡化，證據有限。
- 其他未證實療法：抗黴菌藥、中藥、必需脂肪酸、白三烯受體拮抗劑。

### (十) 預防

- 出生後早期規律使用保濕劑（尤其 ceramide-dominant emollient）之先導研究顯示有降低 AD 發生率之趨勢，但仍需更大型研究確認。
