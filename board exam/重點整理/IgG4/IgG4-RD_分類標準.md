# IgG4-RD 分類標準（2019 ACR/EULAR Classification Criteria）

> 出處：Kelly's Textbook of Rheumatology, Ch126「IgG4-Related Disease」

## 概述

2019年 ACR/EULAR 制定的 IgG4-RD 分類標準，2020年正式發表，sensitivity 86%，specificity 99%。分類共分三步驟：entry criteria → exclusion criteria → weighted inclusion criteria。

## 第一步：Entry Criteria（入選條件）

病灶須侵犯以下 11 個典型器官中至少一個：

胰臟（pancreas）、膽管（bile ducts）、眼眶（orbits）、淚腺（lacrimal glands）、大唾液腺（major salivary glands）、肺（lungs）、腎臟（kidneys）、主動脈（aorta）、後腹腔（retroperitoneum）、硬腦膜（pachymeninges）、甲狀腺（Riedel's thyroiditis）。

## 第二步：Exclusion Criteria（排除條件，共32項）

任一項存在即排除 IgG4-RD 分類。

**Clinical**

- Fever
- 對 glucocorticoid 無客觀反應

**Serologic**

- 無法解釋的 leukopenia 與 thrombocytopenia
- Peripheral eosinophilia
- ANCA 陽性（anti-PR3 或 anti-MPO）
- SS-A(Ro) 或 SS-B(La) 抗體陽性
- dsDNA、RNP、或 Sm 抗體陽性
- 其他疾病特異性自體抗體
- Cryoglobulinemia

**Radiologic**

- 尚未充分評估、疑似惡性腫瘤或感染的影像發現
- 影像快速惡化
- 符合 Erdheim–Chester disease 的長骨異常
- Splenomegaly

**Pathologic**

- 疑似惡性腫瘤但未充分評估的細胞浸潤
- 符合 inflammatory myofibroblastic tumor 的標記
- 明顯 neutrophilic inflammation
- Necrotizing vasculitis
- 明顯壞死
- 以肉芽腫性發炎（granulomatous inflammation）為主
- 符合 macrophage/histiocytic disorder 的病理特徵

**已知診斷者直接排除**

- Multicentric Castleman's disease
- Crohn's disease 或 ulcerative colitis（若只有 pancreatobiliary disease 侵犯）
- Hashimoto's thyroiditis（若甲狀腺是唯一被侵犯的器官）

## 第三步：Weighted Inclusion Criteria（八大加權納入項目）

| Domain | 項目 | 權重 |
|---|---|---|
| **Histopathology** | Uninformative biopsy | 0 |
| | Dense lymphoplasmacytic infiltrate | 4 |
| | + obliterative phlebitis | 6 |
| | + storiform fibrosis（合併或不合併 obliterative phlebitis） | 13 |
| **Immunostaining** | IgG4+ plasma cells/hpf × IgG4:IgG ratio 交叉評分（見下表） | 0–16 |
| **Serum IgG4** | 正常或未檢測 | 0 |
| | >正常值但 <2× ULN | 4 |
| | 2–5× ULN | 6 |
| | ≥5× ULN | 11 |
| **雙側腺體侵犯**（lacrimal, parotid, sublingual, submandibular） | 無腺體侵犯 | 0 |
| | 一組腺體 | 6 |
| | 兩組以上腺體 | 14 |
| **Chest / thoracic aorta** | 未檢測或無 | 0 |
| | Peribronchovascular 及 septal thickening | 4 |
| | Paravertebral band-like soft tissue | 10 |
| **Pancreas / biliary tree** | 未檢測或無 | 0 |
| | 胰臟瀰漫腫大（lobulation消失） | 8 |
| | 瀰漫腫大 + capsule-like rim（delayed enhancement） | 11 |
| | 上述任一 + biliary tree 侵犯 | 19 |
| **Kidney** | 未檢測或無 | 0 |
| | Hypocomplementemia | 6 |
| | Renal pelvis thickening/soft tissue | 8 |
| | 雙側腎皮質低密度區 | 10 |
| **Retroperitoneum / aorta** | 未檢測或無 | 0 |
| | 腹主動脈壁瀰漫增厚 | 4 |
| | Infrarenal aorta/iliac arteries 周圍環狀或前外側軟組織 | 8 |

**Immunostaining 加權表**：以 IgG4+ plasma cells/hpf（0–9、10–50、≥50）交叉 IgG4:IgG ratio（indeterminate、0–40%、41–70%、≥70%）計分，範圍 0–16分，最高分為 IgG4+ ≥50/hpf 且 ratio ≥70%。

## 判定標準

**符合 entry criteria** + **無任一 exclusion criteria** + **inclusion criteria 總分 ≥20分** → 可分類為 IgG4-RD。

## 診斷相關補充重點

- 病理上沒有單一「診斷性」發現——即使有 dense lymphoplasmacytic infiltrate 加 plasma cells 也不足以單獨支持診斷；需結合臨床病理綜合判斷。
- IgG4+/IgG+ plasma cell ratio >40% 曾被提出作為跨器官的診斷 criterion，但單獨數值不具特異性。
- 血清 IgG4 濃度升高不等於診斷：很高比例經病理確診的 IgG4-RD 病人血清 IgG4 是正常的（過度倚賴血清 IgG4 診斷會導致嚴重的 underdiagnosis）；反之，血清 IgG4 顯著升高者中，仍有相當比例最終診斷並非 IgG4-RD。
