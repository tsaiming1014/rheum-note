# PRES（Posterior Reversible Encephalopathy Syndrome）與 SLE

> 參考：Kelly's Textbook of Rheumatology Ch081；PubMed/PMC 文獻（見文末）

---

## 是什麼？

**PRES（後部可逆性腦病變症候群）**是一個**臨床－影像學症候群（clinical-radiologic syndrome）**，特徵為：

- 頭痛（headache）
- 意識程度下降（decreased consciousness）
- 視覺變化（visual changes，甚至皮質性失明）
- 癲癇發作（seizures）

影像學上對應**後大腦區域白質水腫（posterior cerebral white-matter edema）**。

- 1996 年首次以 15 例病例系列描述，其中 2 例為 SLE 患者
- 是 **CNS lupus（NPSLE）的重要 mimic**，也可能是 NPSLE 的表現之一 —— 兩者關係至今仍有爭議：當 PRES 發生在活動性 SLE 中，不清楚是 CNS lupus 本身的表現，還是免疫抑制治療／腎臟病／高血壓等共病造成的併發症

---

## 流行病學

- PRES 在 SLE 病人中盛行率約 **0.7–1.4%**
- 主要誘發因子：**lupus nephritis、腎功能不全、高疾病活性（high SLEDAI）、高血壓**

---

## 危險因子

| 因子 | 說明 |
|------|------|
| **高血壓** | 傳統上被認為是最重要因子，但一篇 SLE 病例系列中僅 30% 有嚴重高血壓（>170/110），明顯低於一般文獻報導的 95% |
| **Lupus nephritis／腎功能不全** | 最常見的誘發共病 |
| **免疫抑制治療** | 尤其 cyclophosphamide、高劑量類固醇 |
| **高疾病活性** | 高 SLEDAI |
| **anti-SSA 抗體陽性** | |
| **低補體血症、低白蛋白血症** | |
| 其他非 SLE 特異因子 | 子癲前症／子癲症（eclampsia）、實質器官移植後、其他自體免疫病 |

> 由於 SLE-PRES 病人嚴重高血壓比例明顯低於一般 PRES，提示 **SLE 本身的細胞毒性／發炎機轉可能是獨立致病因素**，不完全依賴血壓。

---

## 病理機轉

PRES 的核心是**內皮功能異常導致腦部血管源性水腫（vasogenic edema）**，三個主要假說：

1. **腦血管收縮 → 缺血／梗塞假說**
2. **腦血流自動調節失敗（failure of cerebral autoregulation）假說** —— 血壓急遽升高超過自動調節上限，造成過度灌流與血腦屏障破壞
3. **內皮細胞直接損傷假說** —— 毒性物質（如免疫抑制劑、子癲症毒素）直接傷害內皮，破壞血腦屏障

**在 SLE 中的特殊機轉（immune activation hypothesis）：**

- 異常內皮細胞活化、功能障礙與白血球黏附／追蹤（leukocyte trafficking）造成腦部灌流不足
- 高疾病活性時，促發炎細胞激素上升，刺激腦血管內皮細胞產生一氧化氮（NO），進一步破壞血腦屏障
- 多達 **50% 的 PRES 病人有自體免疫相關異常**，支持「免疫活化」本身即為致病機轉之一，而非單純續發於高血壓

---

## 影像學特徵

**MRI 優於 CT**，典型表現：

| 序列 | 發現 |
|------|------|
| **T2 / FLAIR** | 後循環供應區域（枕葉、頂葉為主，也可波及顳葉）**瀰漫性白質高信號** |
| **DWI（擴散加權）** | 訊號**不受限或低訊號**，代表**血管源性水腫**（vasogenic edema）而非細胞毒性水腫（可藉此與缺血性中風做鑑別）|

- 枕葉受累比例最高（文獻中可達 100%），頂葉次之（約 80%）
- 少數病例**初期 MRI 可正常**，數週後才出現異常 → 臨床高度懷疑時不可因初次 MRI 陰性而排除診斷
- 典型分布為後循環（頂枕葉），但也有非典型分布（額葉、小腦、脊髓等）的報告

---

## 鑑別診斷（重點：與 NPSLE 區分）

PRES 與神經精神狼瘡（NPSLE）臨床表現可高度重疊（頭痛、意識改變、癲癇），但**鑑別診斷至關重要**，因為兩者治療方向不同：

| | PRES | NPSLE（其他型態） |
|---|------|------|
| 影像學分布 | **後循環優勢**白質水腫，血管源性 | 分布較不固定，可有梗塞、脫髓鞘等多樣表現 |
| 臨床－影像一致性 | 通常**一致**（影像異常對應臨床症狀）| 可能出現**臨床－影像不一致**（症狀重但影像正常，或反之）|
| 治療方向 | **降血壓 + 支持性治療**為主，移除誘因；免疫抑制僅針對「同時活動的 SLE」，非針對 PRES 本身 | 視病因（發炎性 vs 血栓性）決定是否需要免疫抑制或抗凝 |

也需與 **CNS vasculitis**、**缺血性腦中風（尤其 APS 相關）**做鑑別，MRI + 臨床病程 + 血清學（aPL、anti-dsDNA、補體）是主要工具。

---

## 治療

**PRES 本身多可完全恢復**，治療原則：

1. **控制血壓**（急性期最重要）
2. **移除或減量誘發藥物**（如 cyclophosphamide 等免疫抑制劑，若懷疑為誘因）
3. **癲癇發作時給予 antiepileptics**
4. **若同時有活動性 SLE**：治療原發病（如 methylprednisolone pulse ± IVIG，續以口服 prednisolone ± cyclophosphamide／其他免疫抑制劑）—— 但這是針對「共病的 SLE 活動」，並非 PRES 本身需要免疫抑制

> 一篇病例系列中，8/10 病人接受 methylprednisolone pulse + IVIG 治療後**完全臨床與影像學恢復**；延誤診斷則可能導致永久神經後遺症甚至死亡。

---

## 預後

- **及早辨識、及早處理 → 預後佳**，多數病人完全恢復（臨床與影像都可逆）
- 延遲診斷或延遲治療 → 可能演變為不可逆神經損傷，甚至死亡
- 是少數「早期診斷即可逆轉預後」的 NPSLE 相關表現，臨床上務必列入 SLE 合併癲癇／意識改變／視覺症狀的鑑別診斷第一線

---

## 一句話總結

> **PRES = SLE 神經精神症狀的重要 mimic／可能表現；核心是後循環血管源性水腫，MRI（T2/FLAIR 高信號 + DWI 不受限）是診斷關鍵，治療以控制血壓、移除誘因、控制原發 SLE 活動為主，及早診斷則預後佳、可完全恢復。**
