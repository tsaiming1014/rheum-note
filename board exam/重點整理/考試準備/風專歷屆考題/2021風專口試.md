### Vasculitis

**考官**

- 給 CHCC 2012 圖片，按照血管分類每種分別有哪些？

- 加分題：什麼病以**靜脈炎**為主？（**Panniculitis**，如 EN）

**ANCA vasculitis 深入考題：**
- Hx、PE、biopsy、diagnosis
- Renal biopsy 會看到什麼 IF 圖？（選 **pauci immune**，其他有 LN class IV、LN class V、Anti-GBM）
- Nasal biopsy 可能看到什麼？（**Granuloma**）
- 比較 GPA/MPA/EGPA 差別（prevalence、antibody、organ involvement）

| 特點 | GPA | MPA | EGPA |
|------|-----|-----|------|
| 抗體 | cANCA（PR3）60–90% | pANCA（MPO）50–60% | pANCA（MPO）30–40% |
| 腎臟 | 常見 | 常見 | 較少 |
| 心臟 | 少見 | 少見 | 最常見（15–25%） |
| 周邊神經 | 少見 | 中等 | 最常見（50–80%） |
| 上呼吸道 | 最常見 | 少見 | 有（副鼻竇炎） |
| Granuloma | ✓ | ✗ | ✓（eosinophilic） |
| 氣喘/嗜酸性球 | ✗ | ✗ | **✓（必要條件）** |

- 治療：（見 2022 口試第 5 站）
- **Avacopan** 機轉：**C5a receptor antagonist**（補體 C5a 在 AAV 腎炎中促進中性球活化）

- 比較 HES 和 EGPA 的差別：
  - HES：eosinophil > 1500/μL，無血管炎，器官受損由 eosinophil 直接浸潤
  - EGPA：血管炎 + 哮喘 + 嗜酸性球增多
- EGPA 臨床分型（vasculitis vs eosinophilic phase）的意義

### APS

**陳政宏醫師**
- APS 診斷標準（Sapporo/Sydney 2006 criteria）：
  - 臨床：血栓或pregnancy morbidity
  - 實驗室：LA、aCL（IgG/IgM）、anti-β2-GP1（IgG/IgM）各兩次，間隔 ≥12 週
- 治療（包括 non-criteria obstetric APS）：

| 情境 | 治療 |
|------|------|
| aPL 陽性，無血栓 | HCQ ± low-dose aspirin |
| 只有 pregnancy loss | Low-dose aspirin + LMWH |
| Venous thrombosis | Warfarin（INR 2–3） |
| Arterial thrombosis | Warfarin（INR 2–3 或更高） |
| CAPS | Anticoagulation + 高劑量 steroid + IVIG/plasma exchange |

- DOAC 用在 APS 的 comment：
  > **不建議**在 triple positive（LA+aCL+anti-β2-GP1）的 APS 使用 DOAC（TRAPS trial：rivaroxaban 動脈血栓風險較高）
- 加分題：計算 APS 疾病活動度的量表 → **GAPSS（Global Anti-Phospholipid Syndrome Score）**

### Gout

（情境題）
- **35 歲女生 UA 高反覆關節痛，被診斷為 gouty arthritis，從 epidemiology、clinical、lab 的角度說明診斷有何不合理之處**：
  - Epidemiology：痛風在 35 歲**女性**罕見（停經前女性 estrogen 有保護作用）
  - Clinical：需確認典型痛風表現（第一 MTP、急性劇痛）
  - Lab：需排除繼發性高尿酸原因

- **ACR/EULAR 2015 Gout criteria** 特色（location、course、character、recurrence）
- **ACR Gout 2020 guideline，針對 ULT strong recommendation**：
  - Indication（tophi、≥2 flares/year、CKD ≥ stage 3）
  - Allopurinol as first-line ULT
  - Allopurinol 起始低劑量（50–100 mg/day），緩慢上調
  - Concomitant NSAID/colchicine for flare prophylaxis

### Image

**張棋楨醫師**
- 超音波圖片判讀：
  - **Baker cyst** → 解釋是 from OA、CPPD 或 RA
  - 最後 show 腳踝痛的病人 sono（**rupture cyst** 痛到腳踝，被急診當 DVT）

**盧俊吉醫師**
- AS **Modified New York Criteria**：
  - 臨床：下背痛 ≥3 個月、腰椎活動限制（矢狀面/冠狀面）、胸廓擴張受限
  - 影像：SI joint bilateral grade ≥2 或 unilateral grade 3–4
- AS 的 MRI 標準（BME，怎麼認定）：
  - STIR 或 T1 Gd+ 見 SI joint 骨髓水腫（BME）≥2 個 lesion 在 2 個連續切片 或 ≥3 個 lesion 在 1 個切片
- AS spine X-ray 判讀：
  - **Shiny corner**（Romanus lesion）：椎體前緣發炎後脂肪沉積
  - **Andersson lesion**：脊椎 pseudoarthrosis
  - **Romanus lesion**：椎體前緣侵蝕
- Andersson lesion 的 DD：**Schmorl's node**（椎間盤突入椎體終板）
- 想要用影像工具（sono、MRI）做什麼研究？
