### SLE / APS

2. 為何診斷是 APS？簡述 **2023 Criteria**，此版與 Revised Sapporo 相比有何不同？

**APS 治療（依情境）**

| 情境 | 治療 |
|------|------|
| aPL 陽性，無血栓 | Hydroxychloroquine ± low-dose aspirin |
| 只有 pregnancy loss | Low-dose aspirin + LMWH（obstetric APS） |
| First venous embolism | Warfarin（INR 2-3） |
| First artery thrombosis | Warfarin（INR 2-3）或 higher INR（2.5-3.5） |
| Catastrophic APS | Anticoagulation + high-dose steroids + IVIG/plasmapheresis |
