# 風專口試 圖片判讀題彙整（2019–2025）

> 彙整自歷年 [風專口試](.) 筆記中所有「有給圖片/影像判讀」的題目，依**影像類型**分類，方便針對第八關（Image）與其他站的圖判讀技能複習。原始題目脈絡請參照各年度 `{年份}風專口試.md`。

## 一、X 光（Plain film）

**Chondrocalcinosis / CPPD**

- [2019 口試3-陳俊宏] 膝蓋 X-ray → **Chondrocalcinosis** → CPPD
- [2019 口試3-陳俊宏] 肩膀 X-ray（鈣化）+ 超音波（tendon calcification）→ CPPD、BCP（Basic Calcium Phosphate）、calcified tendinitis
- [2022 口試9-曾瑞成] 給一張 Chondrocalcinosis 的 knee X-ray → 診斷：CPPD

**Gout**

- [2024 第六站-李惠婷] 給 typical tophaceous gout X-ray，問 X 光 finding（如 punched-out erosions）
- [2024 第八站-張棋楨] Overhanging edge – "hook" sign、punched-out lytic bone lesions → **Gout**

**OA / Erosive OA**

- [2019 口試13-陳相成] OA X-ray 判讀
- [2019 口試13-吳詹永嬌] X-ray 判讀：Syndesmophyte、Spondylolisthesis、Compression fracture → **DISH + OA**
- [2020 口試12-陳相成] 兩張 X-ray：OA vs PsA 閱片加 DD（分布、骨刺型態、侵蝕、對稱性比較）
- [2020 口試12-陳相成] 兩雙手：OA vs PsA，著重 PsA 指甲變化（pitting、onycholysis）
- [2022 口試11-陳相成] 判讀手部 X-ray（OA 相關 DD）
- [2022 口試8-盧俊吉] Erosive OA（手指 DIP 侵蝕性 OA）圖片判讀
- [2024 第八站-張棋楨] DIP lesions、joint space narrowing → **Erosive OA**
- [2025 第八關-張棋楨] 給手部的 X-ray，區分 RA、gout、OA 不同之處

**SSc（硬皮症）手部**

- [2022 口試9-曾瑞成] 加分：hand X-ray → 硬皮症的手（finger tip bone resorption）
- [2022 口試10-翁孟玉] 看病人手部 X-ray 判讀（指尖骨頭吸收 + 小指硬指 → SSc）
- [2025 第四關-陳德源] 手部 X-ray + 雙手外觀照片，看起來有某種 deformity（SLE 新診斷 + 長期關節痛晨僵情境）

**AS / axial SpA**

- [2019 口試14-張棋楨] SpA X-ray（syndesmophyte、SI joint）
- [2021 口試-盧俊吉] AS spine X-ray 判讀：**Shiny corner（Romanus lesion）**、**Andersson lesion**（脊椎 pseudoarthrosis，DD：Schmorl's node）
- [2022 口試8-盧俊吉] Andersson lesion、Schmorl's nodes 圖片判讀
- [2024 第八站-張棋楨] SpA X-ray 判讀（與 MRI 併考，見下方 MRI）
- [2025 第八關-張棋楨] 3 個 L-spine plain film，區分 degenerative change、axial SpA、DISH

**RA / 綜合手部**

- [2020 口試8-陳緯昇] RA X-ray 判讀
- [2020 口試3] Hand X-ray 有哪些 view（PA、Lateral、Oblique、Ballcatcher's/Nørgaard view）
- [2025 第八關-李克仁] 手腕 ultrasound/CXR 分析 finding → 答案 CPPD

## 二、超音波（Ultrasound / Sono）

**九宮格綜合判讀**

- [2020 口試8-張棋楨] 超音波九宮格：Peritendinous inflammation→PsA；MTP1 double contour sign+滑膜高回音點→Gout；踝背側 tenosynovitis；Achilles enthesitis；肩峰下滑液囊積液；腮腺（乾燥症）；皮膚（硬皮症）；血管炎（GCA temporal artery halo sign）
- [2024 第八站-李克仁] 超音波九宮格，其中一張是小朋友 suprapatellar recess，femur region 不連續結構 → **Growth plates**

**Baker cyst**

- [2021 口試-Image站-張棋楨] Baker cyst 超音波判讀（可源自 OA、CPPD、RA）；腳踝痛病人的 sono → **ruptured cyst**（曾被急診當 DVT）
- [2025 第八關-李克仁] Baker's cyst ultrasound finding，如何區分有無破掉

**Synovitis grading**

- [2022 口試8-張棋楨] Synovial echo GS/PD grading
- [2025 第八關-李克仁] RA 的 ultrasound grading，給幾張圖分析 GS/PD 各是多少

**Gout / CPPD 超音波**

- [2023 Image站-李克仁] 痛風石超音波 finding；多張超音波圖判讀
- [2024 第八站-李克仁] Chronic tophaceous gouty arthritis 超音波 findings；膝蓋的 CPPD 圖片判讀
- [2025 第八關-李克仁] CPPD 手腕超音波

**PsA / AS 相關**

- [2024 第八站-李克仁] RA 的 wrist echo findings；AS 的 heel 超音波 findings；PsA 的 Dactylitis 圖片判讀

## 三、MRI

- [2019 口試14-張棋楨] SpA MRI（BME、fat metaplasia、SI joint 炎症）
- [2021 口試-盧俊吉] AS 的 MRI 標準：STIR 或 T1 Gd+ 見 SI joint 骨髓水腫（BME）判讀（≥2 lesion/2 連續切片，或 ≥3 lesion/1 切片）
- [2023 Image站-張棋楨] SpA MRI STIR/T1 判讀（SI joint MRI + T-L spine MRI）；加分題：單側 SI joint 附近軟組織 T1 signal increase 的鑑別診斷
- [2024 第八站-張棋楨] SpA X-ray、MRI STIR/T1 判讀（考官用箭頭指出病灶）；單側 SI joint 附近軟組織 STIR signal increase，有 BME、capsulitis lesion，bone marrow 與 periosteum alignment 怪異 → 需列入 infection、trauma DDx；看一系列 MRI（T1+T2 STIR）套用詞彙（Bone marrow edema、Synovitis、Capsulitis、Enthesitis / Fat metaplasia、Erosion、Sclerosis、Backfill、Ankylosis）
- [2025 第八關-張棋楨] SI joint 的 MRI 看 T1/T2 image，區分哪些是 axial SpA、哪些要考慮 infection/malignancy

## 觀察重點（複習方向）

1. **ANA AC-29 → Anti-Scl-70 → SSc** 幾乎每年都考（2019、2023、2024、2025），且常與甲摺鏡、HRCT/PFT 併題成一整組「SSc 全套影像判讀」站。
2. **X-ray 判讀三大常客**：Chondrocalcinosis/CPPD、Gout（punched-out lesion/overhanging edge）、OA vs PsA/RA 鑑別。
3. **超音波九宮格**（張棋楨、李克仁）幾乎每年固定出現，涵蓋 PsA dactylitis、tenosynovitis、enthesitis、Baker cyst、GCA halo sign、synovitis GS/PD grading。
4. **臨床照片近年（2024–2025）比例增加**，且常結合「平板/iPad」情境給圖、要求現場輸入判讀（2025 特別明顯）。
