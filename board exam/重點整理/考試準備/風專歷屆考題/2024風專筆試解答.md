### 1. 下列配對何者錯誤
- A IL-17a & f 配對的 receptor
- B IL-4/13 配對的 receptor
- C BAFF 配對 TACI、BCMA
- D IL-12/23 配對的 receptor

**⚠️ 選項記錄不完整**：原始題庫只記錄了「配對的類別」，沒有記錄題目實際給出的具體錯誤配對內容，無法判斷正確答案。以下整理相關機轉作為複習參考：

- **IL-17A/F receptor**：IL-17A 與 IL-17F 皆透過 **IL-17RA + IL-17RC** 異二聚體受體傳訊。
- **IL-4/13 receptor**：
  - **Type I receptor**（IL-4Rα + γc）→ 只有 **IL-4** 能結合，主要在造血細胞表現
  - **Type II receptor**（IL-4Rα + IL-13Rα1）→ **IL-4 與 IL-13 皆可結合**，在非造血細胞（如上皮細胞）表現，也是 Dupilumab（anti-IL-4Rα）能同時阻斷兩者訊息的原因
- **BAFF receptor**：BAFF 可結合 **三個** receptor：**BAFF-R (BR3)、TACI、BCMA**；**APRIL 只結合 TACI、BCMA，不結合 BAFF-R**，是兩者常見的鑑別考點。
- **IL-12/23 receptor**：無「IL-12Rα」此正式名稱，正確為 **IL-12Rβ1（IL-12 與 IL-23 共用）+ IL-12Rβ2（IL-12 專屬）**；IL-23 則為 **IL-12Rβ1 + IL-23R**。訊息傳遞上 **IL-12Rβ1 走 TYK2、IL-12Rβ2 走 JAK2**，下游主要活化 **STAT4**。

### 2. Inflammasome、caspase-1 會使細胞內前驅物產生下列何者？
- A IL-1-alpha
- B IL-18
- C （未記錄）
- D （未記錄）

**答案：B**

> ⚠️ 原始題庫記錄標記答案為 A，與此處判斷不同，請自行核對。

**解析：**

- **B（對）** Inflammasome 活化後，**caspase-1** 會切割 **pro-IL-1β → mature IL-1β**、**pro-IL-18 → mature IL-18**，這是 caspase-1 最經典的兩個受質（連同 gasdermin D，切割後造成 pyroptosis）。
- **A（錯，題庫原記錄可能有誤）** **IL-1α 不是 caspase-1 的受質**。Pro-IL-1α 本身即具有生物活性（不需要切割就能作用），主要是由 **calpain**（而非 caspase-1）在細胞壞死時切割釋放，屬於 alarmin 性質的 cytokine，與 inflammasome/caspase-1 路徑機轉不同，是常見的考試陷阱（IL-1α vs IL-1β 混淆）。

**速記：**

| Cytokine | 是否需 caspase-1 切割才有活性 | 主要切割酵素 |
|---|---|---|
| IL-1β | 是 | Caspase-1（inflammasome） |
| IL-18 | 是 | Caspase-1（inflammasome） |
| IL-1α | 否（前驅物即有活性） | Calpain（壞死釋放時） |

### 3. 下列哪個 cytokine 不會與 JAK1, JAK2 反應
- A IL-2
- B IL-5
- C TNF-alpha
- D IL-10

**答案：C**

**解析：**

- **A（錯，會與 JAK1 反應）** IL-2 屬於 **common gamma chain (γc) family**（IL-2, 4, 7, 9, 15, 21），receptor 由 **IL-2Rβ（結合 JAK1）+ γc（結合 JAK3）** 組成，走 **JAK1-JAK3**，不是 JAK2，但仍與 JAK1 有關。
- **B（錯，會與 JAK2 反應）** IL-5 屬於 **common beta chain (βc) family**（IL-3, IL-5, GM-CSF），receptor 走 **JAK2 同型二聚體（JAK2-JAK2）**。
- **C（對）** **TNF-α** 完全不透過 JAK-STAT 路徑傳訊，而是結合 **TNF receptor (TNFR1/TNFR2)**，經由 **TRADD、TRAF、RIP1** 等 adaptor 分子活化 **NF-κB** 與 **MAPK** pathway，與 JAK1、JAK2 皆無關。
- **D（錯，會與 JAK1 反應）** IL-10 receptor 走 **JAK1（IL-10R1）+ TYK2（IL-10R2）**，不是 JAK2，但仍與 JAK1 有關。

**速記表：**

| Cytokine family | 代表成員 | JAK 組合 |
|---|---|---|
| Common γ chain (γc) | IL-2, 4, 7, 9, 15, 21 | JAK1 + JAK3 |
| Common β chain (βc) | IL-3, IL-5, GM-CSF | JAK2 + JAK2 |
| gp130 family | IL-6, IL-11 | JAK1 + JAK2 + TYK2 |
| IL-10 family | IL-10, 19, 20, 22 | JAK1 + TYK2 |
| Type I/II IFN | IFN-α/β, IFN-γ | JAK1/JAK2/TYK2（依型別） |
| TNF superfamily | TNF-α | 不走 JAK-STAT，走 TNFR → NF-κB |

### 5. 下列何者跟鐵離子最相關
- A Apoptosis
- B Necroptosis
- C Pyroptosis
- D Ferroptosis

**答案：D**

**解析：**

- **D（對）** **Ferroptosis** 是一種**鐵離子依賴**的細胞死亡形式，核心機轉是細胞內鐵離子過量、觸發 **Fenton reaction** 產生活性氧自由基，加上 **glutathione peroxidase 4 (GPX4)** 功能不足（無法清除脂質過氧化物），導致細胞膜上的多元不飽和脂肪酸大量**脂質過氧化 (lipid peroxidation)**，最終使細胞膜崩解死亡。與鐵離子代謝、GPX4、脂質過氧化直接相關，是四種死亡機轉中唯一以鐵離子為核心驅動力的。

**四種細胞死亡機轉比較：**

| 機轉 | 觸發方式 | 關鍵分子 | 是否促發炎 | 風濕科相關疾病 |
|---|---|---|---|---|
| Apoptosis | 程式性死亡（內在/外在路徑） | Caspase-3, -8, -9；Bcl-2 家族 | 通常**不**促發炎（細胞膜維持完整，形成 apoptotic body 被吞噬清除） | 清除自體反應性淋巴球失敗與 SLE 等自體免疫病發生相關 |
| Necroptosis | 程式性壞死（TNFR 活化但 caspase-8 被抑制時啟動） | RIPK1、RIPK3、MLKL（MLKL 造成細胞膜穿孔） | **促發炎**（細胞膜破裂，釋出 DAMP） | 慢性發炎性疾病、IBD 相關關節炎的機轉之一 |
| Pyroptosis | Inflammasome 活化 | Caspase-1（或 caspase-4/5/11）切割 Gasdermin D，形成細胞膜孔洞 | **強烈促發炎**（釋出成熟 IL-1β、IL-18） | 痛風（MSU 結晶活化 NLRP3 inflammasome）、CAPS 等 autoinflammatory disease |
| Ferroptosis | 鐵依賴脂質過氧化 | 鐵離子、GPX4 功能不足、脂質過氧化 | 可促發炎（釋出 DAMP），機轉與前三者不同 | 近年研究與 SLE、RA 滑膜細胞死亡、器官損傷有關（仍在研究中） |

**Pyroptosis 在痛風的完整路徑：** MSU 結晶被 macrophage 吞噬 → 活化 NLRP3 inflammasome（NLRP3 + ASC + pro-caspase-1）→ caspase-1 活化 → 切割 pro-IL-1β → IL-1β、pro-IL-18 → IL-18，同時切割 Gasdermin D 使其 N 端片段插入細胞膜形成孔洞 → 細胞爆裂 → 大量 IL-1β、IL-18、DAMP 釋出，放大發炎反應，是急性痛風紅腫熱痛的核心機轉，也是 Anakinra、Canakinumab（anti-IL-1）在頑固性痛風可發揮療效的理論基礎。

### 7. 50 歲男性，反覆鼻竇炎、中耳炎，最近血痰、腎功能惡化，兩足下垂及感覺異常。除了 ANA，下列何者有助於鑑別診斷？
- A （未記錄）
- B Procalcitonin
- C ANCA
- D dsDNA

**答案：C**

**解析：**

- **C（對）** 除了排除 SLE（ANA），這個病人的臨床表現組合——**上呼吸道（鼻竇炎、中耳炎）+ 下呼吸道/腎臟（血痰、腎功能惡化，pulmonary-renal syndrome）+ 周邊神經（雙足下垂、感覺異常 = mononeuritis multiplex）**——是典型 **ANCA-associated vasculitis (AAV)** 的三大器官侵犯模式，**ANCA（含 PR3-ANCA/c-ANCA、MPO-ANCA/p-ANCA）**是這類疾病最關鍵的鑑別診斷檢查。
- **B（錯）** Procalcitonin 主要用於區分細菌感染 vs 非感染性發炎，跟這個以血管炎表現為主的臨床圖像鑑別價值有限。
- **D（錯）** dsDNA 是 SLE 的特異性抗體，這個病人臨床表現（鼻竇炎、中耳炎、肺出血、周邊神經侵犯）較不符合 SLE 典型表現，優先度低於 ANCA。

**AAV 三型鑑別速記：**

| | GPA | MPA | EGPA |
|---|---|---|---|
| ANCA 型別 | c-ANCA/PR3 為主 | p-ANCA/MPO 為主 | p-ANCA/MPO（約半數陽性） |
| 上呼吸道侵犯 | **典型**（鼻竇炎、中耳炎、鞍鼻） | 少見 | 可有（鼻息肉、慢性鼻竇炎） |
| 氣喘/嗜酸性球增高 | 無 | 無 | **必要條件** |
| 肉芽腫 | 有（granulomatous） | 無 | 有 |
| 肺侵犯 | 結節、空洞病灶、肺出血 | 肺出血、ILD | 遊走性肺浸潤、氣喘 |
| Mononeuritis multiplex | 中等 | 中等 | **最常見** |

### 8. SSA/Ro52 & Ro60 相關整理

**⚠️ 選項記錄不完整（僅記錄關鍵字，非完整敘述句），無法判斷「何者錯誤」，以下整理相關考點作為參考：**

**1. Ro52 與 Ro60 是兩個不同的抗原**

| | Ro60 (SSA1/TROVE2) | Ro52 (TRIM21) |
|---|---|---|
| 分子功能 | 結合 RNA（hY RNA、pre-5S rRNA），參與 RNA quality control | E3 ubiquitin ligase，胞內抗體受體，參與先天免疫調控 |
| 好發疾病 | SLE、SjD（原發性修格連氏症候群） | SjD、IIM（肌炎）、SSc、SLE，常與其他抗體並存（如 anti-Jo-1） |
| 單獨陽性意義 | 較具疾病特異性 | 常為 non-specific co-positive marker，單獨陽性臨床意義較弱 |

**1-1. 盛行率數據（引用 Kelly's Textbook of Rheumatology）**

| 疾病 | Anti-Ro/SS-A 盛行率 | 備註 |
|---|---|---|
| SLE | ~40%（Table 55.3） | |
| 原發性 SjD | 40–95%（Table 55.6，範圍寬因各實驗室檢測方式異質性大） | 與 NLS、CHB 相關 |
| SSc | anti-Ro52 約 35.6%（Ch085 Scleroderma） | 未特別與特定臨床表現相關，但 anti-Ro52/TRIM21 被列為與 PAH 相關的 SSc 抗體之一 |
| IIM | 未給明確百分比，列為 myositis-associated antibody (MAA) | 常與 anti-synthetase syndrome 並存 |

原文（Kelly Ch055）："The prevalence of anti-Ro52 versus anti-Ro60 appear similar in SLE and SjS but appear to differ in other autoimmune diseases (e.g., with **anti-Ro52 more prevalent than anti-Ro60 in IIM, SSc, and MCTD**). In general, anti-Ro52 antibodies have been suggested to associate with **more severe disease and/or interstitial lung disease**."

- **SLE、SjD**：Ro52 與 Ro60 盛行率**差不多**
- **IIM、SSc、MCTD**：**Ro52 > Ro60**
- Ro52 陽性普遍被認為跟**較嚴重疾病 / ILD** 相關

**2. Neonatal lupus / Congenital heart block (CHB)**

- 母親帶有 **anti-Ro (Ro52 和/或 Ro60)、anti-La** 抗體，經胎盤傳遞至胎兒，攻擊胎兒心臟傳導系統，導致 **third-degree AV block**，是 neonatal lupus 最嚴重且不可逆的表現。
- 機轉上，**anti-Ro52** 被認為與胎兒心臟 Cav1.2 calcium channel 及 5-HT4 receptor 有交叉反應，被視為造成 CHB 較關鍵的抗體，但 **anti-Ro60、anti-La 也都與 CHB 風險相關**，不是只有單一抗體。
- 曾生過 CHB 病兒的母親，下一胎再發生的風險約 **12–20%**，是抗 Ro/La 陽性孕婦產檢需密切胎兒心臟監測的原因。

**3. ANA 陰性但 Ro52/Ro60 陽性的 SLE**

- 部分 SLE（尤其 **subacute cutaneous lupus, SCLE**）病人可以 **ANA 陰性但 anti-Ro60 陽性**。
- 原因是常規 **HEp-2 cell-based IFA** 檢測 ANA 時，Ro60 抗原在細胞固定過程中容易流失或表現量低，導致 IFA 偵測不到，但用**特異性 anti-Ro/SSA ELISA** 卻可測到陽性，造成「ANA(-) 但 anti-Ro(+)」的現象（Kelly Ch055 指出這可能占「ANA 陰性 SLE」超過一半的原因）。
- 臨床意義：**懷疑 SCLE 或 Sjogren 相關疾病時，即使 ANA 陰性也應加做 anti-Ro/La**，不能單靠 ANA 陰性排除診斷。

**4. Ro52 與 ILD、PAH 的關聯**

- **Anti-Ro52** 常與 **anti-synthetase syndrome（尤其合併 anti-Jo-1）** 及 **systemic sclerosis** 並存，並被多篇研究認為是 **ILD 較嚴重、進展較快、預後較差**的預測因子。
- 在 SSc 族群，**anti-Ro52/TRIM21** 被 Kelly 教科書列為與 **PAH** 相關的抗體之一（與 anti-centromere、anti-U3 RNP、anti-Th/To、anti-Ku、anti-U1 RNP 並列）。

### 9. 一位阿嬤右肩急性疼痛，去年有外傷病史，近一年右肩常痠痛、上舉困難。沒有發燒、右肩腫脹、活動受限。X 光顯示關節狹窄與退化、旋轉肌袖（rotator cuff）與二頭肌的肌腱鈣化。超音波抽 12cc 關節液：translucent with blood streaks, poor viscosity, WBC 2500/HPF, no MSU or CPPD crystal。下列診斷關節炎的步驟何者最適合？
- A MR arthrography
- B Arthroscopy with synovial biopsy
- C 關節液細菌培養
- D Alizarin red stain

**答案：A**

這題的臨床情境其實是在描述典型的 **Milwaukee shoulder syndrome（BCP crystal-associated destructive arthropathy / cuff-tear arthropathy）**：老年女性、慢性肩部疼痛與上舉困難（提示 rotator cuff 病灶）、X 光顯示關節退化狹窄合併肌腱鈣化（BCP/hydroxyapatite 沉積）、關節液呈**血樣、poor viscosity、輕度發炎性 WBC（非化膿性）、未見 MSU 或 CPPD 結晶**——這正是 BCP crystal arthropathy 的經典關節液特徵（BCP 結晶在一般偏光顯微鏡下不易看到）。

**解析：**

- **A（對）** 此病人核心問題是**大範圍 rotator cuff tear 合併其導致的退化性關節病變**（cuff tear arthropathy），**MR arthrography** 能提供最精確的 rotator cuff 完整性、肩關節盂唇（labrum）與關節腔結構評估，是釐清「造成此關節破壞的根本原因」最適合的下一步檢查，對後續治療決策（保守 vs 手術）也最關鍵。
- **B（錯）** Arthroscopy with synovial biopsy 屬於較侵入性的檢查，通常保留給懷疑感染、腫瘤浸潤或診斷仍不明確時使用，並非此情境下的首選步驟。
- **C（錯）** 關節液細菌培養用於懷疑**化膿性關節炎**時；此病人無發燒、WBC 僅 2500/HPF（遠低於化膿性關節炎常見的 >50,000/μL），臨床上不支持感染，優先度低。
- **D（錯，但為重要鑑別知識點）** **Alizarin red S stain** 是用來偵測 **BCP（basic calcium phosphate/hydroxyapatite）結晶**的特殊染色，因為 BCP 結晶太小、在一般偏光顯微鏡下無法像 MSU（negative birefringent）、CPPD（weakly positive birefringent）一樣被辨識，需要靠 Alizarin red 染色間接證實。這個病人的關節液型態（bloody, poor viscosity, no MSU/CPPD）高度懷疑 BCP crystal 沉積，Alizarin red 可以**確認診斷（Milwaukee shoulder）**，但題目問的是「診斷關節炎（即找出破壞根源）最適合的步驟」，MR arthrography 對於評估合併的大範圍 rotator cuff tear 及後續治療規劃更為關鍵，故仍以 A 為優先。

**Milwaukee shoulder syndrome 速記：**

| 特徵 | 內容 |
|---|---|
| 好發族群 | 老年女性 |
| 致病結晶 | BCP (hydroxyapatite) |
| 關節液特徵 | 血樣、poor viscosity、WBC 常 <2000–5000/μL（非化膿性） |
| 合併病灶 | 大範圍 rotator cuff tear、glenohumeral joint 退化 |
| 確認結晶方式 | Alizarin red S stain（一般偏光顯微鏡看不到 BCP） |
| 影像評估首選 | MRI / MR arthrography（評估 cuff tear 範圍） |

### 11. 下列眼睛併發症和藥物史的關係，何者錯誤？
- A Hydroxychloroquine 可能會造成 retinal maculopathy
- B Adalimumab 可能會造成 uveitis
- C Dupilumab 可能會造成 conjunctivitis
- D Cevimeline 可能會造成 glaucoma 惡化

**答案：B（此為錯誤敘述）**

**解析：**

- **A（正確敘述）** **Hydroxychloroquine (HCQ)** 長期使用具有劑量與療程相關的視網膜毒性，典型為 **bull's eye maculopathy**（雙眼對稱的環狀視網膜色素上皮病變），是 HCQ 病人需定期眼科篩檢（baseline + 每年）的原因。
- **B（錯誤敘述，本題答案）** **Adalimumab（anti-TNF 單株抗體）不是造成 uveitis 的藥物，反而是治療 uveitis 的藥物之一**（尤其用於 Behçet's disease、JIA-associated uveitis、難治性葡萄膜炎）。臨床上真正與**誘發或惡化 uveitis** 相關的 anti-TNF 藥物是 **Etanercept**（TNF receptor fusion protein，非單株抗體），機轉推測與其藥物結構（非單株抗體、半衰期短、無法有效中和膜結合型 TNF）有關，因此 Etanercept 在有葡萄膜炎病史或高風險（如 axSpA 合併 uveitis）病人中通常**不列為優先選擇**，而是選 Infliximab、Adalimumab。
- **C（正確敘述）** **Dupilumab（anti-IL-4Rα）**常見副作用為 **conjunctivitis（結膜炎）**，在異位性皮膚炎病人使用時發生率相對更高，是臨床上需注意衛教的常見副作用。
- **D（正確敘述）** **Cevimeline**（muscarinic agonist，用於治療 Sjogren's 相關口乾）具擬副交感神經作用，會造成瞳孔收縮，在**隅角閉鎖型青光眼（narrow/angle-closure glaucoma）**病人可能誘發或惡化眼壓上升，臨床使用前須詢問青光眼病史並小心評估。

**速記：Anti-TNF 藥物與 uveitis 的關係**

| 藥物 | 與 uveitis 的關係 |
|---|---|
| Infliximab、Adalimumab（單株抗體） | **治療** uveitis 的有效選擇 |
| Etanercept（receptor fusion protein） | 可能**誘發或無法有效控制** uveitis，較不建議用於有 uveitis 風險的病人 |

### 12. 一位阿公，雙下肢大量水泡。下列病史詢問何者最不相關？
- A 是否有帶狀皰疹病史
- B 是否服用 DPP4 inhibitor
- C 是否服用 allopurinol
- D 是否被海鮮刺傷或有傷口泡過海水

**答案：A（最不相關的病史詢問）**

這是典型「老年人雙下肢大量水泡」要鑑別 **Bullous pemphigoid (BP)** vs 感染性（如 **Vibrio vulnificus**）的臨床情境。

**解析：**

- **A（最不相關，本題答案）** **帶狀皰疹（Herpes zoster）** 典型表現是**單側、沿著皮節（dermatomal）分布**的群聚水泡，通常侷限在單一皮節範圍，**不會表現為雙下肢大範圍、對稱性的水泡**，與此臨床圖像不符，鑑別診斷幫助最小。
- **B（相關）** **DPP4 inhibitor（如 sitagliptin、vildagliptin）是誘發 drug-induced bullous pemphigoid 的重要藥物**，機轉與 DPP4（即 CD26）抑制影響皮膚基底膜的蛋白分解調控有關，是老年人新發 BP 時必問的用藥史。
- **C（相關）** **Allopurinol** 也是常見會誘發 **drug-induced bullous skin eruption（含 bullous pemphigoid、甚至 SJS/TEN 光譜）**的藥物，同樣是重要用藥史。
- **D（相關）** 詢問是否被海鮮刺傷或傷口泡過海水，是為了篩檢 **Vibrio vulnificus 感染**——好發於**肝硬化、免疫低下的中老年人**，典型表現正是**出血性大水泡（hemorrhagic bullae）**，病程進展快、可併發敗血症，是雙下肢大水泡的重要感染性鑑別診斷之一，臨床上非常相關。

**鑑別重點速記：老年人雙下肢大水泡**

| 病因 | 關鍵病史 | 典型特徵 |
|---|---|---|
| Bullous pemphigoid | DPP4i、allopurinol 等藥物史 | 緊繃的張力性水泡（tense bullae），常伴搔癢 |
| Vibrio vulnificus 感染 | 海鮮傷口、泡海水史、肝硬化 | 出血性水泡，進展快、易敗血症 |
| Herpes zoster | 免疫低下、皮節分布疼痛前驅症狀 | **單側、沿皮節分布**，非雙側大範圍表現 |

### 15–19. 影像題（原始題庫無附圖，僅記錄診斷結論，以下整理各診斷關鍵影像特徵作為複習參考）

**15. 甲褶鏡 giant capillary → SSc**

Nailfold capillaroscopy（甲褶微血管鏡）在 SSc 分為三個典型階段（Cutolo classification）：

| 階段 | 特徵 |
|---|---|
| Early | 少量 giant capillary（微血管環擴大 >50μm）、偶見 hemorrhage，微血管密度大致正常 |
| Active | Giant capillary 與 hemorrhage 數量增加，微血管密度中度減少，開始出現輕微 ramified（分支狀）微血管 |
| Late | 明顯微血管消失（avascular area）、大量 ramified/bushy capillary（新生血管代償），微血管排列極度不規則 |

臨床意義：Giant capillary 是 SSc 甲褶鏡最早、最具特異性的表現，也是 2013 ACR/EULAR SSc classification criteria 中「abnormal nailfold capillaries」的主要依據之一。

**16. 男童皮疹 + X-ray soft tissue calcinosis → JDM**

- **Calcinosis cutis** 在 Juvenile dermatomyositis (JDM) 的發生率遠高於成人型 DM（JDM 約 30–70% vs 成人 DM 較低），是 JDM 慢性、延遲治療或反覆發作病人的重要併發症。
- X-ray 可見皮下或肌肉內鈣化，型態包括：表淺斑塊狀（superficial plaques）、結節狀（nodular）、沿筋膜層分布的「exoskeleton」型鈣化、或大範圍腫瘤樣鈣化（tumoral calcinosis）。
- 好發於**壓力承受處**（肘部、膝蓋、臀部），與皮膚潰瘍、慢性發炎控制不佳相關。

**17. CT clavicle 增生 + acne/pustule → SAPHO**

SAPHO = **S**ynovitis, **A**cne, **P**ustulosis, **H**yperostosis, **O**steitis

- 典型侵犯**前胸壁**：胸鎖關節（sternoclavicular joint）、鎖骨（clavicle）、胸骨柄（manubrium）。
- CT 特徵：鎖骨**骨質增生、硬化（hyperostosis/sclerosis）**，可合併 osteitis，鎖骨本身可肥大變形。
- 核醫骨掃描典型呈現 **"bull's head sign"**（雙側胸鎖關節與胸骨柄攝取增加，形似牛頭形狀）。
- 皮膚表現：**palmoplantar pustulosis**、重度囊腫型痤瘡（severe acne）、化膿性汗腺炎（hidradenitis suppurativa）。

**18. X-ray polyarticular erosion + soft tissue swelling → Gout**

| 特徵 | Gout | RA（鑑別對照） |
|---|---|---|
| 侵蝕型態 | **Punched-out erosion**，具**overhanging edge（骨質懸垂緣）**，俗稱 "rat bite" lesion | Marginal erosion，邊緣較不銳利 |
| 關節間隙 | 疾病後期才變窄，**早期通常保留** | 早期即出現關節間隙變窄 |
| 侵犯分布 | 常**不對稱**，可 para-articular | 通常**對稱性** |
| 骨密度 | 關節周圍骨密度**通常正常**（無 periarticular osteopenia） | 常見 periarticular osteopenia |
| 軟組織腫脹 | 常為**偏心性（eccentric）痛風石**，可有 chalky/calcified density | 較均勻的軟組織腫脹 |

**19. Spine X-ray vertebral body collapse + anterior marginal syndesmophyte → AS with compression fracture & pseudoarthrosis**

- AS 慢性脊椎變化：**marginal syndesmophyte**（垂直、細長、橋接相鄰椎體的骨贅）、vertebral body squaring、facet joint ankylosis，長期進展成 **"bamboo spine"**。
- 併發症機轉：脊椎因廣泛 ankylosis 變得**脆弱、僵直**，即使輕微外傷也容易發生**貫穿性骨折（three-column fracture）**，且因脊椎僵直失去緩衝能力，骨折後神經損傷風險高。
- **Andersson lesion（pseudoarthrosis）**：骨折癒合不良或椎間盤/椎體交界處的破壞性病灶，X 光表現類似感染或腫瘤（椎體塌陷、邊緣硬化、局部不穩定），需與 discitis、malignancy 鑑別，但病史與典型 AS 慢性脊椎變化可協助區分。

### 20. Primary Sjogren syndrome 敘述（原始題庫僅記錄主題，非完整敘述句，改以逐項詳解整理實證資料，不判斷單一答案）

**A. HCQ 對 pSS 關節痛（arthralgia）有無統計顯著改善效果**

- 最重要證據來自 **JOQUER trial**（Gottenberg et al., *Ann Rheum Dis* 2014）——法國多中心 RCT，將 pSS 病人隨機分派使用 HCQ 或 placebo 24 週。
- 主要複合終點（dryness、fatigue、pain 三項 VAS 中至少兩項下降 ≥30%）**未達統計顯著差異**。
- 結論：**目前 RCT 等級證據不支持 HCQ 對 pSS 關節痛有統計顯著改善效果**，臨床仍常經驗性使用，但缺乏高品質證據佐證。

**B. HCQ 在口乾（xerostomia/dryness）有無效果**

- 同一試驗中，HCQ 組在 dryness（口乾/眼乾主觀症狀）改善也**未達統計顯著差異**；客觀唾液流量等指標的研究也大多顯示 HCQ **無法顯著改善腺體分泌功能**。
- 結論：**現有證據不支持 HCQ 對改善 pSS 口乾有顯著效果**，HCQ 角色主要在關節外表現（疲勞、皮疹、輕度關節炎），非直接改善 sicca symptom。

**C. Evoxac（cevimeline）與 Salagen（pilocarpine）的副作用**

兩者皆為 muscarinic receptor agonist，副作用源自全身性膽鹼激導效應：

| 副作用類別 | 常見表現 |
|---|---|
| 分泌相關 | **多汗（diaphoresis，最常見）**、流淚增加、流鼻水 |
| 腸胃道 | 噁心、腹瀉、腹部絞痛 |
| 泌尿道 | 頻尿 |
| 心血管 | 心搏過緩（bradycardia） |
| 呼吸道 | 可能誘發支氣管痙攣，氣喘/COPD 病人小心使用 |
| 眼科 | 瞳孔縮小，可能誘發隅角閉鎖型青光眼惡化 |

- **Cevimeline** 對 **M3 receptor** 選擇性較高，理論上心臟（M2 為主）影響較小；**Pilocarpine（Salagen）選擇性較低**，全身性副作用相對明顯。
- 共同禁忌：未控制的氣喘、隅角閉鎖型青光眼、嚴重心血管疾病。

**D. Anti-IL-17 mAb 在 pSS 有無治療角色**

- 與 IL-17 在 PsA、AS 的成功經驗不同，**Secukinumab 治療 pSS 的第二期臨床試驗未達主要療效終點**。
- 結論：**目前無足夠證據支持 anti-IL-17 mAb 在 pSS 具明確治療角色**，尚未納入標準治療選項。

**pSS 藥物治療速記：**

| 藥物 | 對關節痛 | 對口乾/眼乾 | 目前角色 |
|---|---|---|---|
| HCQ | 無統計顯著效果（JOQUER trial） | 無統計顯著效果 | 經驗性使用，證據薄弱 |
| Cevimeline/Pilocarpine | 不適用 | 有效（促進腺體分泌） | 症狀治療標準用藥 |
| Anti-IL-17 mAb | 未證實有效 | 未證實有效 | 尚未建立治療角色，臨床試驗未達終點 |

### 21. Anti-TNF mAb 副作用造成最常見 PsO 是哪種 type？

**答案：Palmoplantar pustular psoriasis（掌蹠膿疱型）**

Anti-TNF-induced（paradoxical）psoriasis 是經典考點：TNF 抑制劑本身也用於治療乾癬，卻可能誘發「反常性乾癬」，機轉推測與 anti-TNF 治療下 **type I interferon (IFN-α)** 路徑相對不受抑制、代償性增強有關（正常 TNF 會抑制 pDC 產生 IFN-α，anti-TNF 解除此抑制）。

**型態分布（依 Collamer & Battafarano 系統性回顧）：**

| 型態 | 大致比例 |
|---|---|
| **Palmoplantar pustulosis** | **約 40–60%，最常見** |
| Plaque-type psoriasis | 約 20–30% |
| Guttate psoriasis | 較少見 |
| 其他（inverse/flexural、erythrodermic） | 少見 |

**考試重點**：一般族群乾癬最常見型態是 plaque type（約 80–90%），但「anti-TNF 誘發的反常性乾癬」型態分布不同，**palmoplantar pustulosis 才是最常見**，是常見的鑑別考點。

**臨床處置**：輕度可局部藥膏、不需停藥；中重度可換用其他 anti-TNF 或換成不同機轉生物製劑（anti-IL-17、anti-IL-23）。

### 23. Conventional DMARDs 敘述，何者錯誤？（原始題庫僅記錄部分考點，完整選項未記錄，以下整理 MTX 與腎功能關係作為參考；MMF、tacrolimus 考點未進一步整理）

**MTX（Methotrexate）與腎功能的關係，主要是雙向的：**

**1. 腎功能不好 → MTX 清除下降 → 全身性毒性風險增加（最重要的方向）**

- MTX 主要**經腎臟排除**（約 80–90% 以原型藥物經腎絲球過濾 + 腎小管主動分泌排出）。
- 腎功能不全時，MTX 清除率下降、血中濃度累積，大幅增加骨髓抑制、口腔黏膜炎、肝毒性、甚至致命性 pancytopenia 或 MTX 相關肺炎的風險。

| eGFR (mL/min) | 建議 |
|---|---|
| ≥60 | 一般劑量 |
| 30–59 | 建議減量，密切監測 |
| <30 | 通常避免使用（多數指引與教科書列為禁忌） |

- **NSAID 交互作用**：NSAID 會競爭性抑制腎小管對 MTX 的主動分泌，在腎功能已經不佳的病人合併使用 NSAID，會進一步降低 MTX 清除、放大毒性風險，是臨床上常見的用藥陷阱（RA 病人常同時使用 NSAID 止痛）。

**2. MTX 本身也可能造成腎毒性（風濕科低劑量使用時較少見）**

- 主要發生在**腫瘤科高劑量 MTX（HDMTX）**：MTX 及代謝物在酸性尿液中溶解度低，易在腎小管內結晶沉澱，造成急性腎損傷，需搭配大量水化 + 尿液鹼化 + leucovorin rescue。
- 風濕科常用低劑量每週一次 MTX（7.5–25 mg/week）直接造成腎毒性較少見，臨床上更重要的是腎功能不佳導致藥物排除下降、進而引發全身性毒性。

**考試重點：MTX 主要經腎排除，腎功能不全時應減量或避免使用；並非 MTX 本身特別容易傷腎，而是腎功能差會讓 MTX 累積中毒。**

### 24. 關於 Conventional DMARD（含 calcineurin inhibitor）的藥物機轉，何者錯誤？

> ⚠️ 原始題庫記錄考點誤植為「CYP3A4、Ketoconazole 是否會造成 AZA 代謝改變」，經確認 **AZA 代謝（xanthine oxidase、TPMT、HGPRT）與 CYP3A4 無關**，實際應為 **Cyclosporine/Tacrolimus 與 CYP3A4** 的交互作用（已依 Kelly's Textbook Ch062 Immunosuppressive Drugs 修正）。

**Cyclosporine、Voclosporin、Tacrolimus 皆為 calcineurin inhibitor，其藥物處置（disposition）高度依賴 CYP3A（腸道與肝臟）以及 P-glycoprotein (Pgp)。**

- **Ketoconazole（azole 類抗黴菌藥，強效 CYP3A4 抑制劑）會抑制 CYP3A4 對 cyclosporine/tacrolimus 的代謝，導致藥物血中濃度上升**，增加毒性風險（尤其**腎毒性**）。
- 依照藥理學原則：**抑制代謝酵素 → 藥物清除下降、血中濃度上升 → 應該「減量」，而不是「增加劑量」**。若選項敘述「Ketoconazole 會使 cyclosporine/tacrolimus 代謝改變，需要增加劑量」，方向是**錯的**——正確處置應是**減量並密切監測藥物濃度、腎功能**。

**Cyclosporine 藥物交互作用速記（Kelly Table 62.5）：**

| 類別 | 藥物 | 對 Cyclosporine 濃度的影響 |
|---|---|---|
| Macrolide 類抗生素 | Erythromycin, clarithromycin（Azithromycin 例外，影響較小） | ↑ 濃度（CYP3A4 抑制） |
| Azole 類抗黴菌藥 | **Ketoconazole**, fluconazole, itraconazole | ↑ 濃度（CYP3A4 抑制） |
| 鈣離子通道阻斷劑 | Diltiazem, verapamil, amlodipine | ↑ 濃度 |
| 其他 | Amiodarone, danazol, allopurinol, colchicine | ↑ 濃度 |
| 肝酵素誘導劑 | Rifampicin, phenytoin, phenobarbitone, nafcillin, St. John's wort | ↓ 濃度 |

**臨床要點：** Ketoconazole 與 cyclosporine/tacrolimus 併用時血中濃度可能大幅上升，需要**減少劑量**並密切監測藥物濃度與腎功能，而非增加劑量；此交互作用機轉臨床上有時甚至被刻意利用（低劑量 ketoconazole 併用降低 cyclosporine 用量、減少藥費），但需嚴格監測。

### 29. 關於 axial SpA 以下何者錯誤？
- A 不適合以類固醇治療
- B （未記錄）
- C 可使用 BASFI 評估疾病活性
- D 宜每年評估 mSASS

> ⚠️ 原始題庫此題未標記答案，選項 B 也缺失。以下為討論後判斷，非 100% 確定原題意圖。

**答案：C（此為最明確的錯誤敘述）**

**解析：**

- **A（正確敘述）** axial SpA **不建議以全身性類固醇治療**（ASAS-EULAR 建議 NSAID 為第一線），僅在**周邊關節炎或薦髂關節局部注射**時可考慮 steroid，全身性使用不適合。
- **C（錯誤敘述，本題答案）** **BASFI（Bath Ankylosing Spondylitis Functional Index）評估的是「功能（function）」，不是「疾病活性（activity）」**（Kelly's Textbook Ch076 明確將 BASFI 歸類在 Function domain）。評估 axSpA 疾病活性的工具是 **BASDAI**（純主觀症狀）或 **ASDAS**（結合主觀症狀 + CRP/ESR，目前 ASAS 建議優先使用）。「用 BASFI 評估疾病活性」是定義層次的錯誤。
- **D（爭議點，但較非「絕對錯誤」）** **mSASSS** 反映的脊椎結構破壞進展很慢，Kelly's Textbook 指出其 **"requires 2 years to demonstrate a difference"**，故 ASAS-EULAR 建議脊椎 X 光追蹤間隔約 **2 年一次**，而非每年；每年評估臨床意義有限且增加不必要輻射暴露，方向上並非最佳做法，但屬於「頻率建議」層次，不像 C 是明確的定義錯誤。

### 30. 中年男性有 PsA 及抽菸史，以下何者為適合的治療？
- A TNFi
- B IL-17i
- C IL-23i
- D JAKi

**答案：B（IL-17i）**

這題用刪去法思考：

- **D（刪去）** **JAK inhibitor 在抽菸病人是明確警訊**。Kelly's Textbook（Ch065, Janus Kinase Inhibitors）：EMA PRAC 建議將 JAK inhibitor 使用限制在「65 歲以上、**現在或曾經抽菸者**、有其他心血管風險因子、有其他癌症風險因子」的病人中，僅在 TNFi 治療失敗或無其他合適替代方案時才考慮使用（延續 tofacitinib ORAL Surveillance trial 發現的 VTE、MACE、malignancy 風險增加）。

- **B（對，本題答案）與 C** IL-17i、IL-23i 皆無明確證據顯示抽菸會降低療效或增加安全疑慮，原始題庫記錄答案為 B。

### 32. 關於狼瘡性腎炎，以下何者正確？
- A 若每日 proteinuria 達 0.5g 則可進行腎切片檢查
- B 尿檢不一定有 microhematuria 或 cast
- C Lupus nephritis class IV 有超過 50% 的 glomeruli 受影響
- D Creatinine 是可靠的 marker

> ⚠️ 原始題庫題幹寫「以下何者正確」、標記答案為 B，但查證後 A、B、C 皆為正確敘述，僅 D 錯誤，題幹與答案標記很可能是抄錄錯誤（應為「以下何者錯誤」）。

**答案：D（若題幹應為「何者錯誤」）**

**逐一驗證（依 Kelly's Textbook Ch081, Clinical Features of SLE）：**

- **A（對）** Kelly 引用 EULAR/ERA-EDTA 更新指引：SLE 病人若有腎臟侵犯證據（glomerular hematuria 和/或 cellular cast、**proteinuria >0.5 g/24hr**，或不明原因 GFR 下降）即建議進行腎切片，與選項 A 的 0.5g 門檻完全吻合。

### 34. 中年女性 SLE 患者於死後解剖發現心臟有贅生物，以下何者是較可能的發生原因？
- A 二尖瓣產生紊流
- B 血中 norepinephrine 和 epinephrine 濃度過高
- C APS 相關抗體
- D Hypocomplementemia

**答案：C（Libman-Sacks endocarditis）**

**解析：**

- **C（對）** **Libman-Sacks endocarditis** 是 SLE 特有的非感染性（sterile）疣狀心內膜炎，好發於二尖瓣，贅生物組成為纖維蛋白-血小板血栓合併免疫複合體沉積與單核球浸潤。與 **APS 相關抗體（lupus anticoagulant、anticardiolipin、anti-β2GPI）高度相關**——這些抗磷脂抗體造成促凝血狀態與免疫複合體在瓣膜表面沉積，是形成贅生物最主要的致病機轉。
- **A（錯）** 二尖瓣紊流是瓣膜病變後的結果，而非造成贅生物形成的原因，因果方向相反。
- **B（錯）** Catecholamine 濃度與心臟瓣膜贅生物形成沒有已知的直接病理關聯。
- **D（錯）** Hypocomplementemia 反映 SLE 整體疾病活性，但並非造成瓣膜贅生物的特異性機轉。

**Libman-Sacks endocarditis 速記：**

| 特徵 | 內容 |
|---|---|
| 好發瓣膜 | 二尖瓣（mitral）> 主動脈瓣 |
| 贅生物性質 | Sterile、fibrin-platelet thrombi + immune complex + 單核球浸潤 |
| 最相關抗體 | Antiphospholipid antibodies（LA、aCL、anti-β2GPI） |
| 臨床意義 | 多數無症狀，但可造成瓣膜逆流、栓塞（中風風險）、易併發感染性心內膜炎 |

### 35. 40 歲女性 SLE 長年使用類固醇 10–40 mg/d，一個月內 progressive dyspnea，檢查發現心音 P2、雙側下肢水腫，後來 sudden death，下列哪個檢查結果最可能是導致猝死原因？

- B Interstitial lung disease
- C UPCR 20.x
- D Anti-RNP 抗體陽性

**答案：A（PAH 導致 sudden death）**

**解析：**

### 40. 各種 IIM 其 muscle biopsy 特徵

**答案：Dermatomyositis 應是 CD4 cell 為主，而非 CD8**

**完整對照表：**

| 疾病 | 浸潤位置 | 主要免疫細胞 | 特徵性病理 |
|---|---|---|---|
| **Dermatomyositis (DM)** | Perimysial / perivascular | **CD4+ T cell、B cell** | Perifascicular atrophy（束周萎縮，最具特異性）、微血管補體（MAC）沉積、微血管密度下降、內皮細胞 tubuloreticular inclusions（type I IFN signature） |

| **Inclusion Body Myositis (IBM)** | Endomysial（與 PM 類似） | **CD8+ T cell** | 合併退化性特徵：rimmed vacuoles、Congo red 陽性 amyloid 沉積、電顯下 15–21 nm tubulofilamentous inclusions、常合併粒線體病變（ragged red fiber、COX-deficient fiber） |

- DM = 4P：Perimysial、Perifascicular atrophy、Plasmacytoid DC/IFN signature、CD4
- PM = 8E：CD8、Endomysial、Each fiber（逐一侵犯非壞死肌纖維）
- IBM = PM + 退化（rimmed vacuole、amyloid、粒線體病變）
- Antisynthetase：perifascicular necrosis（壞死，非萎縮）——與 DM 對比記憶

### 42. 以下關於肌炎自體抗體 Anti-MDA5 antibody 的敘述，何者不正確？
- A 臨床常有典型肌肉無力的症狀
- B 臨床常有皮膚潰瘍（cutaneous ulcerations）與掌面紅斑（palmar erythema）的症狀
- C 亞洲族群有此抗體者與 rapidly progressive ILD (RP-ILD) 有關
- D 血中 ferritin 高，預後差

### 44. 63 歲女性，2 年前雙手伸側有 linear erythema，手指關節疼痛，沒有肌肉無力。Skin biopsy：interface dermatitis，DIF negative。使用 low dose steroid、azathioprine、plaquenil 後穩定控制。抽血 ANA:160X，ENA screening negative，anti-MDA5+++，HRCT 和肺功能檢查正常。下列關於此病患敘述，何者不正確？

- B Anti-MDA5 dermatomyositis 病患一定會有 rapid progressive ILD 且預後差

**答案：B（此為錯誤敘述）**

**解析：**

- **B（錯，本題答案）** 選項用了「一定會」這種絕對化措辭。Anti-MDA5 DM 病患合併 RP-ILD 的比例雖偏高（尤其亞洲族群），但並非「一定」會發生——這位病人本身就是反例：anti-MDA5+++、病程兩年，但 HRCT 和肺功能檢查都正常，證明 anti-MDA5 陽性不等於必然發生 RP-ILD 或預後不良，只是風險較高、需密切追蹤。
- **A（對）** 病人沒有肌肉無力症狀，符合 anti-MDA5 相關 DM 常表現為 amyopathic dermatomyositis (CADM) 的典型特徵。
- **C（對）** Anti-MDA5 antibody titer 與疾病活性、治療反應具相關性，可作為病程監測與治療反應評估的參考指標。
- **D（對）** MDA5 本身是 cytosolic pattern recognition receptor，屬於 RIG-I-like receptor (RLR) 家族，負責偵測胞質內病毒 double-stranded RNA，啟動 type I interferon 為主的抗病毒先天免疫反應。

**考試技巧提醒：看到「一定」、「都會」、「完全不會」這類絕對化字眼的選項，要特別提高警覺，通常是錯誤選項的常見寫法。**

### 45. 有關 Sjogren's labial salivary gland 切片，何者為非？
- A 大多為 CD8+ T cells 和 B cells
- B 大多為 CD4+ T cells 和 B cells
- C 少數為 Plasma cells
- D 少數為 Natural killer cells

**答案：A（此為錯誤敘述）**

**解析：**

Sjögren's syndrome 的 labial salivary gland biopsy 典型病理為 focal lymphocytic sialadenitis，浸潤細胞組成：

- **A（錯，本題答案）** 主要浸潤細胞不是 CD8+ T cell，而是 CD4+ T cell。
- **B（對）** 浸潤細胞大多為 CD4+ T cells 和 B cells，反映 Th cell 協助 B cell 活化、局部生發中心樣結構（ectopic germinal center）形成的免疫病理機轉。
- **C（對）** 少數為 plasma cells，尤其病程較久或發炎較嚴重的腺體中可見。
- **D（對）** 少數為 NK cells，並非主要浸潤細胞族群。

**Sjögren's labial salivary gland biopsy 速記：**

| 細胞類型 | 比例 |
|---|---|
| CD4+ T cell | 主要族群 |
| B cell | 主要族群（可形成 ectopic germinal center） |
| Plasma cell | 少數 |
| NK cell | 少數 |
| CD8+ T cell | 非主要族群（這題的錯誤選項刻意混淆） |
