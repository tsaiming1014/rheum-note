# Obinutuzumab in SLE 兩大 Phase 3 試驗：REGENCY (LN) 與 ALLEGORY (非腎臟SLE)

> REGENCY：Furie RA, Rovin BH, Garg JP, et al. N Engl J Med. 2025;392:1471-83. DOI: 10.1056/NEJMoa2410965. NCT04221477.
>
> ALLEGORY：Furie RA, Dall'Era M, Vital EM, et al. N Engl J Med. 2026 (Epub March 6, 2026). DOI: 10.1056/NEJMoa2516150. NCT04963296.
>
> 兩試驗皆由F. Hoffmann–La Roche贊助；REGENCY收案active class III/IV(±V) LN病人，ALLEGORY收案active SLE但**排除**proliferative/membranous LN病人——兩者互補，共同建立obinutuzumab於SLE全疾病光譜（腎臟+肺腎外）的療效證據。

## 藥物背景（兩試驗共通）

Obinutuzumab 為 glycoengineered **type II anti-CD20單株抗體**，已核准用於CLL、FL，及（REGENCY後）active LN。

**Type I vs Type II anti-CD20機轉差異：**

| | Type I（如rituximab） | Type II（obinutuzumab） |
|---|---|---|
| 主要效應機轉 | Complement-dependent cytotoxicity (CDC) + antibody-dependent cell-mediated cytotoxicity (ADCC) | 幾乎無CDC，主要走**ADCC**、antibody-dependent cellular phagocytosis (ADCP)、更強的**直接細胞死亡** |
| 結合模式 | 多抗體同時接上CD20，造成antigen modulation（下調/內化），降低效果 | Antigen modulation少，FcγRIIIa結合增強 |
| B cell depletion效果 | 較差；且早期rituximab於SLE/LN試驗未證實臨床效益 | 較佳；非人靈長類與人類研究皆顯示可深度清除**組織內**（非僅周邊血）B細胞 |

早期rituximab於SLE（EXPLORER trial）與LN（LUNAR trial）的RCT皆未達到主要終點顯著差異，但post hoc分析顯示**B細胞清除深度與臨床反應相關**——此為obinutuzumab（更強效清除）的立論基礎。CD19-CAR T細胞療法在難治型SLE觀察到的深度B細胞清除與remission，也支持此機轉假說。

| | **REGENCY**（LN） | **ALLEGORY**（非腎臟SLE） |
|---|---|---|

| 收案期間 | 2020/7–2023/3 | 2021/7–2024/9 |
| 隨機分派人數 | 271人（obi 135、placebo 136） | 303人（obi 151、placebo 152） |

| 給藥時程 | 1000mg：Day1、Wk2、24、26、**52**（±Wk50額外劑量，探索性） | 1000mg：Day1、Wk2、24、**26**（無Wk52劑量） |

## 療效結果比較

**兩試驗Primary endpoint皆達統計顯著：**

| | REGENCY：CRR (Wk76) | ALLEGORY：SRI-4 (Wk52) |
|---|---|---|
| Obinutuzumab | **46.4%** (38.0–54.9) | **76.7%** (69.8–83.5) |
| Placebo | **33.1%** (25.2–41.0) | **53.5%** (45.3–61.6) |
| Adjusted difference (95% CI) | 13.4 pts (2.0–24.8) | 23.1 pts (12.5–33.6) |
| P value | 0.02 | <0.001 |

（ALLEGORY效果差距明顯大於REGENCY，可能與endpoint性質不同有關：SRI-4為較易達成的複合活性指標，CRR則是嚴格的腎臟結構性緩解定義）

**REGENCY Key secondary endpoints：**

| Endpoint | Obinutuzumab | Placebo | Adjusted difference (95% CI) | P |
|---|---|---|---|---|
| CRR + prednisone≤7.5mg/day（Wk64-76維持） | 42.7% | 30.9% | 11.9 pts (0.6–23.2) | 0.04 |
| UPC<0.8（Wk76，無intercurrent event） | 55.5% | 41.9% | 13.7 pts (2.0–25.4) | 0.02 |
| eGFR變化量 | +2.31 mL/min/1.73m² | −1.54 mL/min/1.73m² | 3.84 (−1.83–9.51) | 未達顯著 |
| 死亡或腎臟相關事件（Wk76內） | 18.9% | 35.6% | −16.8 pts (−27.4– −6.2) | — |
| 整體腎臟反應（CRR或PRR，Wk50） | 59.1% | 50.7% | 8.4 pts (−3.4–20.1) | 未達顯著 |
| FACIT-F疲勞分數變化 | +1.8 | +3.1 | −1.4 (−3.9–1.2) | 未達顯著，兩組相近 |

Intercurrent events解釋placebo組CRR較低：**treatment failure** obi組3.7% vs placebo組17.6%；**rescue therapy** obi組5.9% vs placebo組17.6%。

Subgroup分析：高疾病活性族群（UPCR>3、低補體、高anti-dsDNA、Class IV、合併Class V）obinutuzumab效果差距更大，與NOBILITY trial一致。

| Endpoint | Obinutuzumab | Placebo | Adjusted difference/HR (95% CI) | P |
|---|---|---|---|---|

| GC降至≤7.5mg/day並維持（Wk40-52，baseline≥10mg/day族群） | 80.0% | 54.1% | 30.2 pts (15.3–45.1) | <0.001 |

## 安全性比較

| | REGENCY (N=136 vs 132) | ALLEGORY (N=151 vs 151) |
|---|---|---|
| 任何不良事件 | 92.6% vs 88.6% | 88.7% vs 81.5% |
| **嚴重不良事件 (SAE)** | **32.4% vs 18.2%** | **15.9% vs 11.9%** |
| Grade≥3不良事件 | 32.4% vs 16.7% | 16.6% vs 13.9% |
| 死亡 | 2.2%(3) vs 0.8%(1) | 0.7%(1) vs 2.0%(3)＊placebo組較多 |
| 感染（任何） | 72.1% vs 61.4% | 68.2% vs 54.3% |
| 感染屬SAE | 16.9% vs 7.6% | 8.6% vs 4.6% |
| Infusion-related reaction | 15.4% vs 11.4% | 11.9% vs 3.3% |
| Drug-related neutropenia | 12.5% vs 3.8% | 4.6%(7人) vs 2.0%(3人) |
| HBV reactivation / PML | 0 / 0 | 0 / 0 |

- **REGENCY的SAE差距明顯大於ALLEGORY**（32.4% vs 18.2%，差14.2個百分點；ALLEGORY僅差4個百分點），主因COVID-19相關事件——REGENCY收案期橫跨疫情初期（宣布後4個月即開始，疫苗尚未普及），排除COVID-19相關事件後obi組嚴重感染由16.9%降至11.0%（但仍高於placebo的7.6%，故非唯一原因）
- 兩試驗死亡人數方向相反：REGENCY是obinutuzumab組較多死亡（2人COVID肺炎+1人腎病症候群 vs placebo 1人COVID）；ALLEGORY則是placebo組較多（肺泡出血、心肌炎+敗血症、SLE flare各1人 vs obi組1人軟組織感染+肺炎）——皆為個位數事件，解讀需謹慎
- 兩試驗皆**未發現新型態或非預期的安全訊號**

## 臨床意義

- 兩試驗共同建立obinutuzumab作為SLE（含腎臟與肺腎外表現）B細胞標靶治療的角色，機轉上互補印證「更深度B細胞清除→更佳臨床反應」的假說
- **REGENCY已正式改變LN治療guideline**：2025 EULAR LN guideline建議4已納入MPAA+obinutuzumab為初始治療選項之一（詳見 [SLE_Lupus_Nephritis_治療.md](SLE_Lupus_Nephritis_治療.md)）；ACR LN guideline定稿時間early於REGENCY發表，僅列入Discussion，未正式收錄
- **ALLEGORY尚未反映在任一2025年版guideline中**（發表時間晚於ACR SLE guideline與EULAR SLE guideline定稿），是下一版guideline更新最可能新增的證據
- REGENCY重複腎切片顯示腎臟組織內B細胞近乎歸零，支持obinutuzumab「組織層級深度清除」機轉；ALLEGORY未收集組織切片，此點僅能類推

## 共同限制與討論重點

- 兩試驗皆排除重度活動性中樞神經系統SLE病人（REGENCY另排除eGFR<30/ESKD；ALLEGORY另排除proliferative/membranous LN），限制結果外推性
- 追蹤時間皆有限（REGENCY 76週、ALLEGORY 52週），**長期療效與安全性（尤其是否能延緩ESKD、降低長期flare率）仍待更長期資料**
- 兩試驗皆由藥廠（Roche）設計並贊助，惟聲明sponsor未限制發表結果
- REGENCY次要終點中，eGFR變化量、Wk50整體腎臟反應、FACIT-F疲勞分數**皆未達統計顯著**（僅CRR相關的兩項顯著）；ALLEGORY的DORIS/LLDAS則屬未校正type I error的次要分析，不可取代正式假設檢定
- REGENCY收案期橫跨COVID-19疫情初期，可能放大部分安全性數據的組間差距，解讀時須納入時空背景考量
