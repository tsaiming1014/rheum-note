## 風濕專科（風專）口試

SLE 在風專口試中固定為一個獨立考站（「風專口試關卡」第四關：SLE, SjD，見 [風專口試關卡.md](../考試準備/風專歷屆考題/風專口試關卡.md)；2023–2025 常與 APS、SjD 合併同站），幾乎每年必考，核心重複考點為**分類標準（1997/2012/2019）**、**SLEDAI-2K/BILAG 活性評估**、**Lupus Nephritis induction/maintenance 治療**、**致病機轉（NETosis、TLR7/9、BAFF、IL-2/Treg）**。

### 2019（口試 4：SLE – Clinical and Basic）

**陳得源醫師**

- **SLEDAI-2K 裡面計分 8 分的項目有哪些？**

| 項目 | 分數 |
|------|------|
| Seizure | 8 |
| Psychosis | 8 |
| Organic brain syndrome | 8 |
| Visual disturbance | 8 |
| Cranial nerve disorder | 8 |
| Lupus headache | 8 |
| CVA | 8 |
| Vasculitis | 8 |

- **BILAG 計分裡面，是計算回推多久時間的疾病活性？**
  **4 週**（過去 4 週的疾病表現，屬於 physician's global assessment 型的器官別評分系統）

- **SLE 分類標準：ACR 1997 vs SLICC 2012 的不同**

| 項目 | ACR 1997 | SLICC 2012 |
|------|---------|-----------|
| 皮膚 | Malar rash、Discoid rash、Photosensitivity | ACLE、SCLE、CCLE、非瘢痕性 Alopecia |
| 血球 | Lymphopenia < 1,500/μL | Lymphopenia < 1,000/μL |
| 血清學 | 含 syphilis false positive（VDRL） | 改為低補體（C3/C4/CH50）、Direct Coombs test（無溶血時也計） |
| 診斷方式 | 11 條中符合 ≥4 條 = SLE，無需分類 | ≥4 條（需含 ≥1 臨床 + ≥1 免疫學）**或**切片證實 LN + ANA/anti-dsDNA 陽性，即可診斷 |

**謝祖怡醫師**

- **NET 最近也被認為跟 SLE 有關，原理是？**
  SLE 患者清除 NET/chromatin 的能力下降（DNase I 活性不足或有抑制性抗體）→ NET 中的 dsDNA、RNA 持續暴露 → 活化漿細胞樣樹突細胞（pDC）的 TLR7/9 → 大量分泌 Type I IFN → 驅動自體免疫反應惡化，形成惡性循環。

- **TLR 當中，跟 SLE 比較有關的是哪幾個？**
  **TLR7**（辨識 ssRNA，與 anti-Sm/RNP 抗體產生相關）與 **TLR9**（辨識 CpG DNA，與 anti-dsDNA 抗體產生相關）。

- **SLE 若以 RTX 治療無效，以 belimumab 治療有效，原理可能是？**
  RTX（anti-CD20）主要清除表現 CD20 的 mature/memory B cells，但無法清除 CD20 陰性的 plasmablast/plasma cell 及 pre-B cells。**Belimumab**（anti-BAFF）則抑制 BAFF 訊號，影響的是 B cell 分化過程中不同階段的存活（如 transitional B cell 到 naive mature B cell 的過渡、marginal zone B cell），可能清除 RTX 治療後殘存、依賴 BAFF 存活的自體反應性 B cell subset，兩者機轉互補。

- **最近 SLE 的 low-dose IL-2 治療獲得初步成果，原理是？**
  SLE 患者體內存在相對的 **IL-2 缺乏**，導致 **Treg 恆定失衡**（IL-2 是 Treg 存活與功能維持的關鍵細胞激素）。Low-dose IL-2 治療選擇性地補充 Treg 所需的 IL-2（Treg 對低劑量 IL-2 的敏感度高於 effector T cell，因其組成性表現高親和力 IL-2Rα/CD25），恢復 Treg 族群 → 增強對效應 T 細胞（尤其是 **Th17**）的抑制 → 減少組織發炎，且因劑量低不致造成全身性免疫抑制。

- **Treg 是抑制 T cell 的哪個 lineage 而對 SLE 產生療效？**
  **Th17**（Treg/Th17 軸失衡被認為是 SLE 慢性發炎的重要機轉之一）。

### 2020（口試 4：SLE）

**呂聆英主任**

- **Cutaneous LE 中哪些是 LE-Specific，哪些是 LE Non-Specific？**

| LE-Specific | LE Non-Specific |
|------------|----------------|
| ACLE（acute cutaneous LE）：蝴蝶斑 | Alopecia（非瘢痕性） |
| SCLE（subacute cutaneous LE） | Livedo reticularis |
| CCLE（chronic cutaneous LE）：discoid LE、lupus panniculitis | Raynaud's phenomenon |
| | Leukocytoclastic vasculitis |
| | Photosensitivity（單純光敏感不算 LE-specific 皮疹） |

- **ACLE、SCLE、CCLE 圖片判讀**
  - **ACLE**：蝴蝶形紅疹，越過鼻梁、對稱分布於兩頰，通常不留疤
  - **SCLE**：環狀（annular）或丘疹鱗屑性（papulosquamous）皮疹，好發於光照曝露部位（上胸、上背、手臂伸側），與 **anti-Ro/SSA** 高度相關
  - **CCLE（discoid LE）**：硬幣狀（discoid）紅疹，中央萎縮、色素脫失、瘢痕形成、毛囊角化栓（follicular plugging），好發頭皮（可造成瘢痕性禿髮）、耳朵、臉頰

- **CCLE 什麼時候一定要當 SLE 來檢查？**
  - **Disseminated/generalized DLE**（病灶超過頸部以上及頸部以下同時存在）
  - 合併全身性症狀（發燒、關節炎、腎炎等其他器官侵犯）
  - 實驗室異常（血球低下、ANA 高效價陽性等）
  （單純侷限型 discoid LE 進展為 SLE 的機率較低，約 <5–10%）

- **治療的選項和先後順序**
  - 局部：防曬（UV 防護）→ 外用 corticosteroid → 外用 calcineurin inhibitor（tacrolimus，尤其臉部）
  - 全身：**HCQ**（第一線）→ 加上 Quinacrine 或 MTX（refractory）→ Belimumab、Dapsone、Thalidomide（更頑固病灶，thalidomide 需注意致畸胎性與周邊神經病變）

**另一位老師**

- **LN induction therapy**（詳見 2021 口試段落）

- **1997 vs 2012 vs 2019 SLE Criteria 差別**

| 版本 | 重點 |
|------|------|
| 1997 ACR | 11 條，符合 ≥4 條 = 確診；無加權計分 |
| 2012 SLICC | 11 項臨床 + 6 項免疫學；切片證實 LN 可單獨作為診斷依據；較 1997 更敏感 |
| **2019 EULAR/ACR** | **加權計分（總分 ≥10 分）**；**ANA ≥1:80 為必要 entry criterion**；每個 domain 只取最高分項目計分；較 SLICC 更特異 |

- **2019 Criteria 各項分數（重要）**

| 類別 | 項目 | 分數 |
|------|------|------|
| 憲法症狀 | 發燒 | 2 |
| 血液 | 白血球減少 | 3 |
| | 血小板減少 | 4 |
| | Autoimmune hemolysis | 4 |
| 神經精神 | 譫妄 | 2；癲癇 | 5；精神病 | 3 |
| 皮膚黏膜 | 非瘢痕性脫髮 | 2；口腔潰瘍 | 2 |
| | SCLE 或 discoid LE（CCLE） | 4；ACLE | 6 |
| 漿膜炎 | 胸膜炎或心包積液 | 5；急性心包炎 | 6 |
| 骨骼肌肉 | 關節炎（≥2 joints） | 6 |
| 腎臟 | Proteinuria > 0.5 g/24h | 4；LN class II/V | 8；LN class III/IV | 10 |
| 免疫學 | Anti-dsDNA 或 Anti-Sm | 6 |
| | aPL（LA/aCL/anti-β2GP1 任一項） | 2 |
| | 低補體（C3 或 C4 其中一項低） | 3；C3 與 C4 皆低 | 4 |
| | ANA 陽性（entry criterion，非計分但必要） | — |

> 判讀重點：需先滿足 ANA ≥1:80 entry criterion，再取每個 domain 中分數最高的一項加總，總分 **≥10 分**即可分類為 SLE。

### 2021（SLE 站）

**翁孟玉醫師**（Lupus Nephritis 深入考題）

- **如何懷疑有 LN？** 蛋白尿、血尿（active urinary sediment）、水腫、腎功能惡化，配合 SLE 病史

- **LN 的 induction 治療與 Cyclophosphamide protocol（NIH vs Euro-Lupus）**

| | NIH Protocol | Euro-Lupus Protocol |
|-|-------------|---------------------|
| 劑量與頻率 | 0.5–1.0 g/m² IV，每月一次，共 6 次 | 500 mg IV，每 2 週一次，共 6 次（固定總劑量約 3g） |
| 療效 | 相當 | 相當（原始族群為輕中度 LN 之高加索人） |
| 毒性（感染、性腺毒性） | 較高 | 較低 |
| 適用族群 | Severe LN | 一般至中度 LN，現況也常用於較嚴重病人 |

- **MMF 跟 CYC 做 induction 有什麼差別？**
  兩者在多數 RCT（如 ALMS）中療效相當，MMF 對亞裔族群療效可能更佳、性腺毒性較低，較常作為育齡女性首選；CYC 對嚴重（如 crescentic）LN 仍有其角色。

- **LN 的治療目標**：Proteinuria 降至 <0.5–0.8 g/day，GFR 維持穩定不惡化

- **LN 能否停藥？** 一般建議維持治療至少 3–5 年以上，部分病人可能需終身低劑量維持（依復發風險個別化）

- **AZA 在 LN maintenance 的角色**：常用劑量 2 mg/kg/day，作為 MMF 之外的另一個維持期選擇（尤其計畫懷孕者）

- **LN 的 poor prognosis factor**：診斷時高 Cr（腎功能不佳）、低 C3/C4、高 anti-dsDNA titer、病理上有 fibrous crescents（慢性化病灶）、治療後腎功能恢復緩慢

- **Renal gallium scan 臨床使用時機和判讀**：可用於輔助鑑別腎臟發炎（active nephritis）與慢性纖維化，臨床應用有限，非常規檢查

- **補充：LN class IV 和 class V 的病理發現**
  - **Class IV（diffuse lupus nephritis）**：≥50% 絲球體受侵犯，瀰漫性 endocapillary 或 mesangiocapillary 增生，可有 wire-loop lesion、subendothelial immune deposit、crescent formation
  - **Class V（membranous lupus nephritis）**：瀰漫性基底膜增厚，**subepithelial immune deposit**（spike formation），可與 class III/IV 合併存在（mixed LN）

**賴振宏醫師**

- **SLE 的機轉、etiology**：遺傳（HLA、補體缺乏、X染色體相關基因）+ 環境誘發因子（UV、感染、藥物、荷爾蒙）造成免疫耐受性喪失
- **dsDNA/IC complex 在疾病扮演的角色**：anti-dsDNA 與 dsDNA 形成 immune complex，沉積於腎絲球基底膜等組織 → 活化補體、引發局部發炎，為 LN 的核心致病機轉之一
- **Molecular mimicry 這個機轉如何證明**：透過抗原序列比對（如 EBV EBNA-1 與 Sm/Ro 抗原有相似 epitope），並以動物模型或病人抗體 cross-reactivity 實驗證實特定病原體抗原可誘發針對自身抗原的交叉反應性免疫反應

### 2022（4. SLE）

**陳明翰醫師**

- **SLE 合併 HLH（Hemophagocytic Lymphohistiocytosis）題組**
- **HLH 的治療**：
  - 高劑量類固醇（含 pulse therapy）
  - Cyclosporin
  - Etoposide（依 HLH-94/HLH-2004 protocol）
  - 針對潛在 SLE：Rituximab（B cell depletion，尤其懷疑 SLE 誘發的續發性 HLH）

**第二個老師**

- SLE 病人有蛋白尿，請自行講 7 分鐘關於 **Lupus Nephritis（LN）** 的診斷與治療（含 **Cyclosporin 作用機轉**：抑制 calcineurin → 減少 IL-2 轉錄 → 抑制 T 細胞活化，於 LN 中亦有穩定足細胞（podocyte）cytoskeleton、減少蛋白尿的直接作用）

**其他考站提及 SLE（非獨立考站，藥物學延伸提問）**

- 口試 2（藥物學，劉峰誠）：
  - **TULIP-1 vs TULIP-2**（anti-IFN Anifrolumab trial）：為何一個成功一個失敗？TULIP-1 以 **SRI-4** 為主要評估工具（未達統計顯著）；TULIP-2 改以 **BICLA** 為主要評估工具（成功），顯示疾病活性評估工具的選擇會影響臨床試驗結果判讀
  - **Rituximab（LUNAR trial，陰性）vs Obinutuzumab**：Obinutuzumab 為第二代 anti-CD20，**ADCC（antibody-dependent cell-mediated cytotoxicity）效果更強**，於 NOBILITY/REGENCY trial 對 LN 顯示療效（詳見 [SLE_Obinutuzumab_REGENCY_ALLEGORY.md](SLE_Obinutuzumab_REGENCY_ALLEGORY.md)）
  - SLE 併發 PAH 病人的 CXR 與 CT 判讀（central pulmonary artery dilatation）

### 2023（SLE / APS 合併站）

**陳明翰醫師**

情境：年輕女性高燒、hypocomplementemia、dsDNA(+)、aPL(+)、D-dimer 上升，CT 發現肺栓塞（PE），試問可能診斷及後續處置？

1. **為何診斷是 SLE？簡述 2019 Criteria**（見 2020 口試段落之加權計分表）
2. **為何診斷是 APS？簡述 2023 ACR/EULAR APS Criteria，與 Revised Sapporo（2006）criteria 相比有何不同？**
   2023 criteria 引入**加權計分制**（分臨床與實驗室兩大 domain，各取最高分加總），並新增**風險分層**概念（區分 aPL 效價高低對應不同分數），較 Revised Sapporo 的二元（有/無）判定更精細，也更強調需先符合「至少一次臨床事件 + 中高效價 aPL」的 entry criterion。

**APS 治療（依情境）**

| 情境 | 治療 |
|------|------|
| aPL 陽性，無血栓 | Hydroxychloroquine ± low-dose aspirin |
| 只有 pregnancy loss（obstetric APS） | Low-dose aspirin + LMWH |
| 首次靜脈栓塞 | Warfarin（INR 2–3） |
| 首次動脈血栓 | Warfarin（INR 2–3 或更高 2.5–3.5） |
| Catastrophic APS（CAPS） | Anticoagulation + 高劑量 steroid + IVIG/plasmapheresis |

**陳政宏醫師**

1. **補體在免疫系統中的功能，與哪些免疫疾病相關？什麼狀況會 hyper/hypocomplementemia？**
   - 低補體：SLE flare（消耗性）、cryoglobulinemic vasculitis、MPGN、先天性補體缺乏（C1q/C2/C4 缺乏與 SLE-like 疾病相關）
   - 高補體：急性期反應（發炎、感染時 C3 為 acute phase reactant 可上升）
2. **目前有哪些針對補體的藥物？** Eculizumab/Ravulizumab（C5 抑制劑）、Avacopan（C5a receptor antagonist）、Sutimlimab（C1s 抑制劑）等，目前多用於 AAV、aHUS、PNH，SLE 相關臨床試驗持續進行中
3. **SLE 病人高燒住院，該如何 workup？** 需鑑別 infection vs disease flare：完整 septic workup（血液/尿液培養、影像）+ 疾病活性指標（anti-dsDNA、補體）+ procalcitonin/ferritin 等輔助鑑別
4. **如果在嚴重感染時同時 flare up，有哪些治療可以選擇？** 感染需積極抗生素治療，同時視器官侵犯嚴重度給予**最低有效劑量**免疫抑制（如中劑量類固醇），避免過度免疫抑制惡化感染
5. **這種狀況下補體會升高還降低？** 感染本身（急性期反應）可能使補體上升，但若同時有 SLE flare 消耗補體，則需視兩者相對強弱而定，臨床上補體不升反降時應提高懷疑 flare 的可能性
6. **SLE severe flare-up 時有哪些治療可做？** Pulse steroid（IV methylprednisolone）為主，頑固或危及生命之情況可考慮 **plasmapheresis**（如 catastrophic APS、TTP-like 表現、嚴重瀰漫性肺出血）

### 2024（第四站：陳明翰、呂聆音）

**Part 1**

情境：25 歲女性，最近兩週雙手及膝蓋關節痛，雙頰起紅疹（malar rash），曬太陽之後紅疹變嚴重，會胸悶、咳嗽。
- ANA 1:320（AC-1，homogeneous pattern）
- Urine protein 0.8 g（24hr）
- dsDNA positive
- C3/C4 low
- Antiphospholipid antibodies positive

問題：

1. **你還要安排什麼檢查？** 完整 SLE workup（CBC 看血球低下、anti-Sm、補體全套、腎功能、尿沉渣鏡檢看 active sediment、胸部影像評估 pleuritis/serositis、若腎功能異常需考慮腎臟切片以分類 LN class）
2. **ACR EULAR 2019 criteria 要超過多少分可以分類？** **≥10 分**（且需先符合 ANA ≥1:80 entry criterion）
3. **怎麼幫病人算 criteria？** 依本題資訊：Malar rash（ACLE，6 分）+ 關節炎（6 分）+ Proteinuria >0.5g/24h（4 分）+ anti-dsDNA（6 分）+ aPL 陽性（2 分）+ 低 C3/C4（4 分，若兩者皆低）→ 遠超過 10 分閾值，符合 SLE 分類
4. **跟舊的 criteria 比較？**（見 2020 口試段落三版比較表）
5. **怎麼治療？** HCQ 為基礎用藥，依器官侵犯程度加上 NSAIDs（關節炎）、中低劑量類固醇、若有明顯皮膚/關節活性可加 MTX 或 belimumab
6. **如果有 lupus nephritis 怎麼治療？** 依切片分類選擇 induction（MMF 或 CYC + 高劑量/pulse steroid），並視情況加上 belimumab 或 voclosporin（詳見 [SLE_Lupus_Nephritis_治療.md](SLE_Lupus_Nephritis_治療.md)、[SLE_Lupus_Nephritis_三大試驗比較.md](SLE_Lupus_Nephritis_三大試驗比較.md)）

**Part 2**（問 SLE 疾病活性與損傷評估）

- **Disease activity index**：SLEDAI-2K、BILAG（見 2019 口試段落）
- **Flare 怎麼判斷？什麼是 minor flare？什麼是 major flare？**
  - Minor flare：疾病活性些微上升，通常不需大幅調整治療（如 SELENA-SLEDAI flare index 定義的輕度變化）
  - Major flare：出現新的重要器官侵犯（如新發 LN、CNS lupus）或需大幅升級治療（如加用 pulse steroid、新增免疫抑制劑）
- **Improvement 怎麼判斷？** 常用複合式療效指標如 **SRI（SLE Responder Index）**、**BICLA（BILAG-based Composite Lupus Assessment）**，需同時符合疾病活性下降且無新發器官侵犯、無需 rescue therapy
- **損傷指數（SLE damage index，SLICC/ACR Damage Index, SDI）**：評估**不可逆**的器官損傷（不論病因是疾病本身或治療副作用），涵蓋眼睛、神經精神、腎臟、心肺、周邊血管、腸胃、肌肉骨骼、皮膚、性腺、惡性腫瘤等 12 個系統，與活性指標（SLEDAI/BILAG）互補使用

### 2025（第四關：SLE, APS, SjS）

**陳德源醫師**

- **情境 1**：33 歲女性已知 SLE 病史，新發生電流般的頭痛（thunderclap-like headache），從神經科轉診至風濕科，考官給一張手腳皮膚的圖片，似乎是 **livedoid lesions**。
  - 問會想到哪些可能性？→ SLE 神經精神侵犯（NPSLE）合併次發性 **APS**（livedo reticularis/racemosa 為 APS 典型皮膚表現）；需鑑別 CNS vasculitis、腦靜脈竇栓塞（CVST）、RCVS（可逆性腦血管收縮症候群，典型表現即 thunderclap headache）、缺血性中風/TIA
  - 若懷疑 APS，有哪些項目要驗？→ Lupus anticoagulant（LA）、anticardiolipin（aCL, IgG/IgM）、anti-β2-glycoprotein I（IgG/IgM），需間隔 ≥12 週重複驗兩次確認為持續陽性
  - 頭痛最可能的原因是那些？→ 依據影像檢查（brain MRI/MRA/MRV）鑑別缺血性中風（APS 相關動脈血栓）、CVST（靜脈血栓）、NPSLE 本身（lupus headache）

- **情境 2**：新診斷 SLE 的 50 歲女性，有長時間的手部關節疼痛與晨僵，考官給一張雙手外觀的照片與手部 X 光片，看起來有某種 deformity。
  - 會想到什麼？→ **Jaccoud's arthropathy**（SLE 特有的可復位性關節變形，因關節囊與韌帶鬆弛所致，非侵蝕性，X 光通常無骨侵蝕）；需與 RA overlap（rhupus）鑑別
  - 若要鑑別診斷，需要做哪些檢查？→ ACPA/RF（區分是否合併 RA/rhupus）、手部 X 光確認**無侵蝕性變化**（支持 Jaccoud's 而非 RA）、關節超音波評估滑膜炎程度

**謝松洲醫師**

- APS 病人，治療上依你現在的經驗，會用哪些藥物？針對 anticoagulant，個別病人有哪些需要取捨的點？
  - 依血栓類型（靜脈/動脈）、是否為 triple positive（LA+aCL+anti-β2GP1 三項皆陽性，血栓復發風險最高）、是否為 catastrophic APS 決定抗凝強度；**triple positive 病人不建議使用 DOAC**（TRAPS trial 顯示 rivaroxaban 動脈栓塞及出血風險皆高於 warfarin），仍以 warfarin 為主流選擇

## 考試速記重點（跨年度重複考點）

- **SLE 分類標準三版比較（1997 ACR → 2012 SLICC → 2019 EULAR/ACR）**：2019、2020、2024 皆考，2024 更直接考「怎麼幫病人算 criteria」的實際計分練習，務必熟記各 domain 加權分數與 ANA ≥1:80 entry criterion、總分 ≥10 分閾值，詳見 [SLE_分類標準.md](SLE_分類標準.md)。
- **SLEDAI-2K / BILAG 活性評估**：2019、2024 皆考，SLEDAI-2K 8 分項目（神經精神+CVA+vasculitis）為固定考點；BILAG 回推時間為 4 週；2024 進一步考 flare 定義（minor/major）與 improvement 判定（SRI、BICLA）、SLE damage index（SDI），詳見 [SLE_活性評估與remission.md](SLE_活性評估與remission.md)。
- **Lupus Nephritis induction/maintenance 治療**：2021、2022、2024 皆考，核心為 NIH vs Euro-Lupus CYC protocol 比較、MMF vs CYC、LN maintenance（AZA/MMF）、LN poor prognosis factor、LN class IV vs V 病理特徵，為**最高頻**考點，詳見 [SLE_Lupus_Nephritis_治療.md](SLE_Lupus_Nephritis_治療.md)、[SLE_Lupus_Nephritis_病理特徵.md](SLE_Lupus_Nephritis_病理特徵.md)。
- **SLE 致病機轉**：NETosis/TLR7-9（2019）、dsDNA-immune complex/molecular mimicry（2021）、BAFF 各階段作用與 Belimumab 機轉（2019）、Low-dose IL-2/Treg-Th17（2019）反覆出現，詳見 [SLE_致病機轉.md](SLE_致病機轉.md)。
- **Cutaneous LE 分型（LE-specific vs non-specific；ACLE/SCLE/CCLE）**：2020 考圖片判讀，2024 情境題以 malar rash 帶入分類標準計分，詳見 [SLE_光敏感性_UV機轉.md](SLE_光敏感性_UV機轉.md)（光敏感相關機轉）。
- **SLE 常與 APS 合併同一考站**（2023、2025 固定），需同時準備 APS 分類標準（Revised Sapporo vs 2023 ACR/EULAR）、APS 治療依情境分層（無血栓/obstetric/靜脈/動脈/CAPS）、triple positive 病人 DOAC 禁忌（TRAPS trial）。
- **SLE 合併特殊血液/免疫併發症**：HLH（2022）、severe flare 需 plasmapheresis 的情境（2023）、感染 vs flare 的鑑別（2023）為進階延伸考點。
- **新型生物製劑試驗設計**：Anifrolumab TULIP-1/TULIP-2（療效評估工具 SRI vs BICLA 影響試驗結果）、Rituximab LUNAR（陰性）vs Obinutuzumab（ADCC 更強，NOBILITY/REGENCY 陽性）——2022 藥物學延伸提問，詳見 [SLE_Obinutuzumab_REGENCY_ALLEGORY.md](SLE_Obinutuzumab_REGENCY_ALLEGORY.md)、[SLE_健保給付_Belimumab_Anifrolumab.md](SLE_健保給付_Belimumab_Anifrolumab.md)。
- **SLE 特有的非侵蝕性關節病變**：Jaccoud's arthropathy（2025 新考點），需與 rhupus（SLE-RA overlap）鑑別，X 光無侵蝕為關鍵鑑別點。
