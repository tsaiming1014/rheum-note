# Lupus Nephritis (LN) 治療總整理

> 來源：Kelly's Textbook of Rheumatology, Ch.82 Treatment of Systemic Lupus Erythematosus
>
> 病理特徵請見另一篇筆記 [SLE_Lupus_Nephritis_病理特徵.md](SLE_Lupus_Nephritis_病理特徵.md)；一般（非腎臟）SLE治療請見 [SLE_治療.md](SLE_治療.md)

## 治療原則

傳統策略分兩期：**誘導期（initial/induction）**目標為顯著改善疾病活性（甚至達 remission），之後轉為 **維持期（maintenance）** 目標為鞏固療效、預防復發。

- MMF 與 IV CYC（皆併用 GC）在誘導治療被視為 **同等有效**
- 維持治療建議 MMF 或 AZA（通常延續誘導期用 MMF 或 CYC 後對應轉換）
- **belimumab 與 voclosporin 核准後**，此傳統序貫模式受到挑戰——部分（或全部）病人可能可從一開始就採用合併治療（upfront combination therapy），例如：
  - Multitarget therapy：voclosporin/TAC + MMF
  - belimumab + MMF 或 CYC
- 目前仍有爭議；可依腎臟病理及臨床/檢驗特徵做風險分層，找出預後較差、可能受益於較積極初始治療的病人

## LN 嚴重度分類（Table 82.4）

**增生性腎炎 (Proliferative Nephritis)**

輕度 (Mild)：

- Class III nephritis 無嚴重組織學特徵（crescents、fibrinoid necrosis）
- Chronicity index ≤3
- 腎功能正常
- 非腎病症候群範圍蛋白尿

中重度 (Moderately severe)：

- 上述輕度疾病但初始誘導治療後部分/無反應，或延遲緩解（>12個月）
- 或 focal proliferative nephritis 伴不良組織學特徵，或 reproducible Cr 上升≥30%
- 或 Class IV nephritis 無不良組織學特徵

重度 (Severe)：

- 中重度定義但6–12個月治療未緩解
- 或增生性疾病伴腎功能受損 + fibrinoid necrosis 或 crescents 侵犯>25%腎絲球
- 或混合型膜性+增生性腎炎
- 或增生性腎炎伴高 chronicity（chronicity index>4）單獨，或合併高 activity（chronicity index>3且activity index>10）
- 或急速進行性腎絲球腎炎（2–3個月內 Cr 倍增）

**膜性腎病變 (Membranous Nephropathy)**

- 輕度：非腎病症候群範圍蛋白尿，腎功能正常
- 中度：腎病症候群範圍蛋白尿，表現時腎功能正常
- 重度：腎病症候群範圍蛋白尿，表現時腎功能已受損（Cr上升≥30%）

## Class I / II LN 治療

- 建議 RAAS blockade（ACEi/ARB）
- GC（prednisone 0.5–1 mg/kg/day×4–6週後減量）：適用於蛋白尿>1g/day、活動性尿沉渣、組織學顯示 podocytopathy 或有肺腎外疾病活性者；連續3天 IV MP pulse 可加速緩解並使用較低 GC 劑量（0.5mg/kg/day）
- 可考慮免疫抑制劑（如 AZA 1–2mg/kg/day）以降低累積 GC 劑量

## Class III 及 IV（±V）LN 治療

### 誘導治療 (Initial Treatment)

- Pulse IV MP（500–1000mg×1–3天）後接口服 prednisone 0.5mg/kg/day；若有明顯肺腎外疾病活性可用較高起始劑量

**免疫抑制治療選擇：**

- **低劑量 IV CYC**（500mg × 6次，每2週一次）：白人病人中重度疾病（Euro-Lupus regimen）
- **MMF**（3g/day，或等效劑量 eMPA）：中重度疾病；重度疾病作為 second-line；**黑人及西班牙裔病人優先考慮**
- **高劑量 IV CYC**（0.75–1 g/m² × 7次每月一次）：重度疾病
- **Belimumab + MMF 或 IV CYC**：高組織學活性及/或合併肺腎外疾病活性病人
- **Voclosporin（或TAC）+ MMF**：baseline 有腎病症候群範圍蛋白尿病人

### 維持治療 (Subsequent Treatment)

誘導治療後有改善者（蛋白尿降低、GFR 穩定或上升）可轉入維持治療：

- GC 逐漸減量至5–7.5mg/day
- **免疫抑制治療**：
  - MMF（2g/day）：若誘導期用 MMF，或重度 LN 優先選擇
  - AZA（2mg/kg/day）：若誘導期用 IV CYC，或有懷孕考量者優先選擇
  - Belimumab + MMF：若誘導期已用
  - Voclosporin（或TAC）+ MMF：若誘導期已用（voclosporin 治療期間長短目前未知）
- **維持治療期間至少3年，最好5年**；**過早（renal response後18–24個月內）減量或停用免疫抑制治療與 flare 風險增加相關**

## Class V LN 治療

- 建議 RAAS blockade
- 蛋白尿>1g/day（尤其腎病症候群範圍）、GFR 下降者考慮免疫抑制治療

### 誘導治療

- 口服 prednisone 0.3–0.5mg/kg/day；重度可考慮起始 IV MP pulse（250–1000mg×1–3天）

**免疫抑制治療選擇：**

- MMF（3g/day，或等效 eMPA）：中重度或重度疾病
- CNI（CsA、TAC、voclosporin）：輕度或中重度疾病
- 高劑量 IV CYC（0.75–1g/m²×7次每月）：中重度或重度疾病

### 維持治療

改善者轉入維持期：GC 減量至5–7.5mg/day

- MMF（2g/day）：若誘導期用 MMF；中重度或重度疾病優先
- CNI（CsA、TAC、voclosporin）：輕度或中重度疾病；需審慎評估高血壓、腎毒性、代謝副作用風險

## 治療反應目標與難治型疾病判定

- **6個月早期反應**（Cr 正常化 + 蛋白尿降低≥50%或<1g/day）為長期腎臟預後良好的預測因子
- 初始3–4個月未見腎功能及蛋白尿改善，或6–12個月治療後未反應 → 應考慮 **換藥/強化治療**
- Microscopic hematuria 或非腎病症候群範圍蛋白尿可能數月不消退，**complete renal response**（蛋白尿<0.5g/day，GFR 正常或接近正常±10%）平均需1.5–2年才達成
- **未完成至少2年治療前，不應僅因未達 complete renal response 而停藥或換藥**，除非有明確疾病惡化證據（Cr reproducible 上升及/或蛋白尿增加）

## 腎臟復發（Renal Flare）處理

- 30–50%中重度 PLN 病人在達到部分或完全緩解後會復發
- **Nephritic flare**：活動性尿沉渣 + Cr reproducible 上升(≥30%)，可能影響腎臟預後
- **Proteinuric flare**：腎功能無明顯變化，預後較好
- 進展至 ESKD 的風險因子：復發時 Cr>2mg/dL（明顯腎功能喪失）、部分反應、切片高 chronicity 及 activity index
- **應考慮重複腎切片**，評估是否有組織學分類轉換(class switch)或進展性 chronicity

**復發治療選項：**

1. MMF 與 CYC 互換
2. CNI（單獨或加在 MMF 之上）
3. 加用 belimumab（若 baseline 未用）
4. RTX
5. **重度 nephritic flare**：積極細胞毒性治療——monthly IV CYC pulse（若之前未用過）併用 IV MP，為作者偏好方案

## 腎臟保護治療 (Nephroprotective Therapy)

除免疫抑制治療外，保存腎功能、延緩腎元喪失的策略同樣重要：

- **限鹽**
- **RAAS blockade（ACEi/ARB）**：所有 LN 病人建議使用，兼具降蛋白尿及降血壓效果
- **SGLT-2 抑制劑 (SGLT2i)**：新興關注領域，跨多種疾病展現腎臟及心臟保護效果
  - LN 腎臟切片轉錄體分析顯示 SGLT-2表現增加（主要在 tubulointerstitial space）
  - 小型 case series：empagliflozin 於穩定免疫抑制治療下的 LN 病人顯著降低蛋白尿
  - 但一項 phase I/II 探索性試驗（38位 SLE 病人，17位有 LN）未顯示蛋白尿改善
  - **目前證據尚不足以普遍推薦**，潛在候選對象：GFR<60mL/min 或蛋白尿≥1+（dipstick）（albuminuria>30mg/24h 或 UACR≥30mg/g）

## 慢性腎臟病與末期腎病 (CKD/ESKD)

### 流行病學與風險因子

- Meta 分析顯示 LN 相關 ESKD 風險在1970s-1990s間下降（15年風險從>30%降至22%），之後 plateau，近年反而 **上升**
- **Class IV LN 進展至 ESKD 風險最高**
- 美國資料：LN-ESKD 全因死亡率20年間下降（100 patient-years 死亡率從1995-99年11.1降至2010-14年6.7），感染及心血管事件仍為主要死因
- ESKD 臨床預測因子：baseline GFR 降低、高血壓、糖尿病、**持續孤立性 C3 低下**、未達腎臟緩解；組織學上 fibrinoid necrosis、fibrous crescents、interstitial fibrosis with tubular atrophy 也與風險增加相關
- 急速腎功能惡化病人：IV MP + IV CYC（0.4–0.5g/m²）可於透析前8–10小時給藥（讓藥物可被移除），透析期間可持續

### 透析

- SLE 透析病人5年存活率約80–90%，與非 SLE 透析病人相當
- **血液透析可能優於腹膜透析**（尤其仍在使用免疫抑制治療者），因腹膜透析感染併發症（主要是腹膜炎）較多（但腹膜透析在 SLE 整體仍屬安全）
- 考慮停止細胞毒性治療的情境：Cr 持續上升至≥5mg/dL 伴不活動尿沉渣、腎切片僅顯示 scarring 及萎縮、或腎臟萎縮
- 透析超過2年才接受腎臟移植可能對存活有負面影響；但 **至少3個月透析** 可能讓部分病人恢復足夠腎功能一段時間

### 腎臟移植

- 是 ESKD 病人的可行選項，移植腎及病人存活率與其他族群相當（但種族背景可能影響長期腎存活）
- **建議考慮 preemptive transplantation**（透析前移植），與較佳移植及病人預後相關
- 無前瞻性研究比較移植後不同免疫抑制方案；**CNI 通常用於誘導期（6–12個月）預防急性排斥**，維持期應盡量減少使用，改用 MMF、AZA
- Surveillance biopsy 顯示移植腎中 LN 亞臨床復發（多為輕度 class I/II）不罕見，但很少造成臨床顯著問題
- 復發風險因子：黑人種族、女性、活體捐贈移植
- **APS** 與移植後腎臟血栓及較差移植預後相關，需抗凝治療
