## 傳統臨床分型（依外觀/分布型態）

皮膚科傳統上依**臨床型態（morphology）**將乾癬分為以下幾種，Kelly Ch78 也用同一套 phenotype 描述：

| 分型 | 特徵 | 圖片 | 備註 |
|---|---|---|---|
| **斑塊型乾癬**（Plaque psoriasis / psoriasis vulgaris）| **最常見型態**（約 80–90%）；界線清楚的紅色斑塊，覆銀白色鱗屑，好發於**伸側**（膝、肘）、軀幹、頭皮 | ![Plaque](../../images/PsO%20plaque.jpg) | 教科書稱為「典型/古典」乾癬，NHI 給付條件中的「慢性中重度乾癬」即以此型為主 |
| **點滴型乾癬**（Guttate psoriasis）| 全身散布**小顆滴狀（<1cm）**紅色鱗屑丘疹，好發於**兒童/年輕人**，軀幹、四肢近端多 | ![Guttate](../../images/PsO%20Guttate.jpg) | 與**A族鏈球菌（streptococcal）感染**（尤其咽喉炎）後誘發密切相關，是少數有明確誘發因子的型態 |
| **反轉型／屈側型乾癬**（Inverse / flexural psoriasis）| 侵犯**皮膚皺褶處**：腋下、鼠蹊部、乳房下、臍周、生殖器 | ![Inverse](../../images/PsO%20inverse.jpg) | 因摩擦、潮濕，通常**鱗屑不明顯**、外觀較光滑紅斑，易與 candidiasis、intertrigo 混淆 |
| **紅皮症型乾癬**（Erythrodermic psoriasis）| **全身瀰漫性**紅斑脫屑，**體表侵犯範圍廣**（傳統定義多以 >75–90% BSA）| ![Erythrodermic](../../images/PsO%20erythrodermic.jpg) | 屬於**皮膚科急症**之一，可合併發燒、電解質不平衡、蛋白質流失、體溫調節失能；誘發因子包括**突然停用全身性類固醇**、光療過度、感染 |
| **局部膿疱型乾癬**（Palmoplantar pustulosis）| 侷限於**手掌、腳掌**的無菌性膿疱，反覆發作 | ![Palmoplantar](../../images/PsO%20palmoplantar.jpg) | 對應健保的「頑固性掌蹠性乾癬」給付路徑 |
| **全身型膿疱型乾癬**（Generalized Pustular Psoriasis, GPP，von Zumbusch type）| 全身廣泛紅斑上散布無菌性膿疱，常合併發燒、白血球增多 | ![GPP](../../images/PsO%20GPP.jpg) | 屬**皮膚科急症**；近年發現與 **IL36RN 基因突變**（IL-36 receptor antagonist 缺失）相關，是唯一有明確單基因致病機轉的乾癬亞型 |
| **指甲乾癬**（Nail psoriasis）| pitting、onycholysis、oil drop sign、subungual hyperkeratosis | ![Nail](../../images/PsO%20nail.jpg) | 不算獨立「型」，但是**臨床上與 PsA 關聯最強**的表現（NAPSI 評分對象），機轉為 DIP 附著點的 **subclinical enthesitis** 波及甲基質 |
| **頭皮乾癬**（Scalp psoriasis）| 頭皮界線清楚的紅斑脫屑斑塊 | ![Scalp](../../images/PsO%20scalp.jpg) | 好發部位之一，也是 PEST/PASE 問卷中 screen PsA 的重點部位 |

**分型之間的關係：**

- 這些型態**不是互斥**——同一病人可以在不同時期出現不同型態（例如斑塊型病人在停用類固醇後轉為紅皮症型）。
- 依**病程/急慢性**可再簡化分兩大類：
  - **慢性型**：plaque、guttate、inverse、nail、scalp——病程緩慢，多為慢性病灶。
  - **急症型**：erythrodermic、generalized pustular (GPP)——**皆屬皮膚科急症**，需立即處置，也是唯一在健保給付條件中走「急性發作」給付邏輯（4 週制）而非「慢性 PASI≥10」邏輯的兩種型態。
