# PsO — 乾癬皮膚病：分型與治療

> 來源：Kelly's Textbook of Rheumatology Ch78（傳統臨床分型）；全民健康保險藥物給付項目及支付標準 8.2.4.6 / 8.2.4.6.2 / 8.2.16（`健保給付條件202606更新/chap8_1150423.md`）。
> 性質：PsO（皮膚乾癬，非關節炎）臨床分型、健保生物製劑/小分子給付條件、apremilast/deucravacitinib 與生物製劑之比較。

---

## 一、傳統臨床分型（依外觀/分布型態）

皮膚科傳統上依**臨床型態（morphology）**將乾癬分為以下幾種，Kelly Ch78 也用同一套 phenotype 描述：

| 分型 | 特徵 | 圖片 | 備註 |
|---|---|---|---|
| **斑塊型乾癬**（Plaque psoriasis / psoriasis vulgaris）| **最常見型態**（約 80–90%）；界線清楚的紅色斑塊，覆銀白色鱗屑，好發於**伸側**（膝、肘）、軀幹、頭皮 | ![Plaque](../../images/PsO%20plaque.jpg) | 教科書稱為「典型/古典」乾癬，NHI 給付條件中的「慢性中重度乾癬」即以此型為主 |
| **點滴型乾癬**（Guttate psoriasis）| 全身散布**小顆滴狀（<1cm）**紅色鱗屑丘疹，好發於**兒童/年輕人**，軀幹、四肢近端多 | ![Guttate](../../images/PsO%20Guttate.jpg) | 與**A族鏈球菌（streptococcal）感染**（尤其咽喉炎）後誘發密切相關，是少數有明確誘發因子的型態 |
| **反轉型／屈側型乾癬**（Inverse / flexural psoriasis）| 侵犯**皮膚皺褶處**：腋下、鼠蹊部、乳房下、臍周、生殖器 | ![Inverse](../../images/PsO%20inverse.jpg) | 因摩擦、潮濕，通常**鱗屑不明顯**、外觀較光滑紅斑，易與 candidiasis、intertrigo 混淆 |
| **紅皮症型乾癬**（Erythrodermic psoriasis）| **全身瀰漫性**紅斑脫屑，**體表侵犯範圍廣**（傳統定義多以 >75–90% BSA）| ![Erythrodermic](../../images/PsO%20erythrodermic.jpg) | 屬於**皮膚科急症**之一，可合併發燒、電解質不平衡、蛋白質流失、體溫調節失能；誘發因子包括**突然停用全身性類固醇**、光療過度、感染 |
| **局部膿疱型乾癬**（Palmoplantar pustulosis）| 侷限於**手掌、腳掌**的無菌性膿疱，反覆發作 | ![Palmoplantar](../../images/PsO%20palmoplantar.jpg) | 對應健保的「頑固性掌蹠性乾癬」給付路徑 |
| **全身型膿疱型乾癬**（Generalized Pustular Psoriasis, GPP，von Zumbusch type）| 全身廣泛紅斑上散布無菌性膿疱，常合併發燒、白血球增多 | ![GPP](../../images/PsO%20GPP.jpg) | 屬**皮膚科急症**；近年發現與 **IL36RN 基因突變**（IL-36 receptor antagonist 缺失）相關，是唯一有明確單基因致病機轉的乾癬亞型 |
| **指甲乾癬**（Nail psoriasis）| pitting、onycholysis、oil drop sign、subungual hyperkeratosis | ![Nail](../../images/PsO%20nail.jpg) | 不算獨立「型」，但是**臨床上與 PsA 關聯最強**的表現（NAPSI 評分對象），機轉為 DIP 附著點的 **subclinical enthesitis** 波及甲基質 |
| **頭皮乾癬**（Scalp psoriasis）| 頭皮界線清楚的紅斑脫屑斑塊 | ![Scalp](../../images/PsO%20scalp.jpg) | 好發部位之一，也是 PEST/PASE 問卷中 screen PsA 的重點部位 |

**分型之間的關係：**

- 這些型態**不是互斥**——同一病人可以在不同時期出現不同型態（例如斑塊型病人在停用類固醇後轉為紅皮症型）。
- 依**病程/急慢性**可再簡化分兩大類：
  - **慢性型**：plaque、guttate、inverse、nail、scalp——病程緩慢，多為慢性病灶。
  - **急症型**：erythrodermic、generalized pustular (GPP)——**皆屬皮膚科急症**，需立即處置，也是唯一在健保給付條件中走「急性發作」給付邏輯（4 週制）而非「慢性 PASI≥10」邏輯的兩種型態。

## 二、健保分型與生物製劑給付條件

### (一) PsO 臨床分型與健保對應類別

健保給付條件將乾癬依**臨床型態**分為四大類，各自對應不同的給付路徑：

| 臨床分型 | 健保定義門檻 | 對應給付路徑 |
|---|---|---|
| **慢性中重度斑塊型乾癬**（chronic plaque psoriasis）| 病灶持續 **≥6 個月**，**PASI ≥10** | 生物製劑（8.2.4.6.1）或 apremilast/deucravacitinib（8.2.16） |
| **頑固性掌蹠性乾癬**（recalcitrant palmoplantar psoriasis）| 非膿疱性掌蹠廣泛角化，嚴重影響行走/日常作息 | 同上（生物製劑），需附前後左右四張以上照片 |
| **慢性紅皮症乾癬**（chronic erythrodermic psoriasis）| 範圍 **≥75% 體表面積**，病史 >1 年，**cyclosporin 足量（5 mg/kg/d）治療 ≥6 個月**後未滿 3 個月復發至 PASI>10 或體表 >30% | 可**不經照光**，只需 MTX + acitretin 治療無效後直接申請生物製劑 |
| **全身型急性膿疱性乾癬**（Generalized Pustular Psoriasis, GPP）| 伴膿疱之紅腫部位 **>10% 體表** + 系統性症狀（發燒、白血球增多）| 急性期專用給付路徑（8.2.4.6 (2)、8.2.4.6.2），與慢性型完全不同申請邏輯 |

> PASI 無法測量之膿疱型乾癬，以**體表面積 ≥10%** 取代 PASI≥10 作為門檻。

### (二) 慢性中重度乾癬 → 生物製劑給付條件（8.2.4.6.1）

**先行治療（生物製劑前必須先失敗或無法耐受）**：

- 足量照光治療：PUVA 或 nb-UVB 每週 ≥2 次，或寬頻 UVB+焦油每週 ≥3 次
- **加上**以下至少兩種系統性藥物治療無效或無法耐受：**MTX（週劑量需達 15mg）、acitretin（0.3–1 mg/kg/d）、cyclosporin（2.5–5 mg/kg/d）、apremilast、deucravacitinib**
- 治療需至少 3 個月（育齡女性可不經 acitretin）
- 「治療無效」定義：**PASI 或體表面積改善 <50%**

**可用藥物與劑量／療效評估時間點（皆需達 PASI25 才可繼續，部分藥物門檻不同）**：

| 藥物 | 起始劑量 | 療效評估時間點與門檻 |
|---|---|---|
| Etanercept | 50mg biw×3個月 → 25mg biw | 12週，PASI25 |
| Adalimumab | 80mg → 40mg qow | 12週，PASI25 |
| Ustekinumab | 45mg（0,4週）→ q12w（>100kg 或反應不完全可用90mg）| 16週，PASI25 |
| Secukinumab | 300mg（0-4週）→ q4w（≤60kg 用150mg）| 12週，PASI25 |
| Ixekizumab | 160mg（0週）→ 80mg（2,4,6,8,10,12週）→ q4w | 12週，PASI25 |
| Guselkumab | 100mg（0,4週）→ q8w | 12週，PASI25 |
| Brodalumab | 210mg（0,1,2週）→ q2w | 12週，PASI25 |
| Risankizumab | 150mg（0,4週）→ q12w | **16週，PASI75**（門檻較高）|
| Certolizumab | 400mg（0,2,4週）→ 200mg q2w | 懷孕/哺乳期可優先使用（唯一孕期不需停藥者）|
| Bimekizumab | 320mg（0,4,8,12,16週）→ q8w | 16週，PASI25 |

**續用規則**：

- 每 6 個月需再申請一次，續用門檻為**與初次治療前相比達 PASI50**（risankizumab 為 **PASI75**）
- **暫緩續用（減量/停藥）**：治療 2 年後若 **PASI≤10** 應暫緩續用，除非曾兩次暫緩後復發（停藥 6 個月內 PASI>10 或 50% 復發）
- **平行轉換**：PASI<10 但仍有 PASI>1、體表>3% 或病灶在外露部位（頭皮、臉、指甲、手部）影響生活品質者，續用申請時可平行轉換另一種生物製劑

**排除使用情形**：懷孕/哺乳（certolizumab 除外）、活動性感染、未完整治療的結核病（潛伏結核需治療滿 4 週）、人工關節合併敗血症史、惡性腫瘤或癌前病變、免疫功能不全。

### (三) 全身型急性膿疱性乾癬（GPP）→ 專用給付路徑

**① 一般生物製劑（8.2.4.6 (2)）**

- 條件：**18 歲以上**、伴膿疱紅腫部位 **>10% 體表** + 發燒/白血球增多等系統性症狀
- 給藥模式：每次申請以 **4 週**為原則，供當次/下次發作使用；可依病情延長至 **8 週**；下次申請需間隔 **≥12 週**

**② Spesolimab（8.2.4.6.2，專屬 GPP 急性發作用藥）**

- **限皮膚科或風濕免疫科專科醫師**使用
- 需**確診具 IL36RN 突變**的 GPP，且符合：
  - 中重度 GPP（**GPPGA 總分 ≥3** 且 **GPPGA 膿疱項目分數 ≥2**）
  - 伴膿疱紅腫部位 **>10% 體表**
- 劑量：單次 **900mg**；若 1 週後急性發作仍持續（GPPGA 總分≥2 且膿疱評分≥2），可再追加一劑 900mg

### (四) Apremilast／Deucravacitinib（口服小分子，8.2.16）

- 適應症：**中重度斑塊型乾癬**，對傳統全身性治療（照光 + MTX 或 cyclosporine 至少一種）**反應不佳、無法耐受或有禁忌症**的成人
- **不得與生物製劑、tofacitinib、cyclosporine 併用**
- 常作為生物製劑前的**先行/替代治療**選項，尤其**肝腎功能不佳者**（照光+MTX無效後可用）

## 三、Apremilast/Deucravacitinib vs 生物製劑：健保給付條件比較

| 項目 | 生物製劑（8.2.4.6.1） | Apremilast / Deucravacitinib（8.2.16）|
|---|---|---|
| **適用分型** | **斑塊型、頑固掌蹠型、紅皮症型皆可**（另有 GPP 專屬路徑） | **僅限中重度斑塊型乾癬**，條文中未涵蓋掌蹠型、紅皮症型、GPP |
| **先行治療門檻** | 足量照光 **+ 至少兩種**系統性藥物（MTX、acitretin、cyclosporin、apremilast、deucravacitinib）治療無效或無法耐受 | 足量照光 **+ MTX 或 cyclosporine 至少一種**治療無效或無法耐受（門檻較低，只需一種）|
| **與彼此的關係** | 生物製劑先行治療的「系統性藥物」選項**包含 apremilast、deucravacitinib**——即用過這兩者無效，可以算作生物製劑條件的一種先行治療 | Apremilast/deucravacitinib **不得與生物製劑、tofacitinib、cyclosporine併用** |
| **禁忌症/不適用定義** | 僅列 MTX、acitretin 各自的「無法使用」定義（肝功能異常、切片異常、B/C肝、腎功能異常等）| 除肝腎功能不佳外，**多列了皮膚科特有考量**：光敏感疾病不適合照光、多發性非原位皮膚上皮癌不適合照光、**頭皮侵犯>50%照光無效或無法耐受**也算禁忌 |
| **療效評估時間點與門檻** | 有明確時程：多數藥物 **12週評估PASI25**（ustekinumab/bimekizumab 16週、risankizumab 16週且需PASI75）| **條文未列出**類似 PASI25/75 的評估時間點與門檻，僅說明需事前審查核准 |
| **續用規則** | 每6個月續用需達 **PASI50**（risankizumab為PASI75）；治療**2年後PASI≤10需暫緩續用**；有**平行轉換**機制 | 條文未列出對應的續用門檻、2年暫緩續用、平行轉換規則 |
| **肝腎功能不佳者的通融** | 有明確定義（Child-Pugh、肝切片分期、B/C肝、AST/ALT、CCr/eGFR等），但仍需先MTX/acitretin/cyclosporin無效路徑 | **肝腎功能不佳者可略過「傳統全身性治療反應不佳」的完整門檻**，只需經照光、MTX治療無效即可申請（因無法用 cyclosporine）|
| **給藥型式** | 多為**注射劑**，各藥物有詳細起始劑量表（如 secukinumab 300mg×5週後改q4w）| **口服固定劑量**（無需劑量調整表）|
| **排除使用情形** | 明列：懷孕/哺乳（certolizumab除外）、活動性感染、未完整治療結核病、人工關節+敗血症史、惡性腫瘤/癌前病變、免疫功能不全 | 條文僅寫「參照藥物仿單」，未在 NHI 條文中逐項列出 |

**重點結論：**

1. **適應症範圍較窄**：apremilast/deucravacitinib 目前健保條文**只涵蓋中重度斑塊型乾癬**，紅皮症型、頑固掌蹠型、GPP 都沒有把它們列為給付適應症（生物製劑則四種型態都有對應路徑）。
2. **先行治療門檻較低**：生物製劑要求「照光 + 兩種系統性藥物失敗」，apremilast/deucravacitinib **只需一種**（MTX 或 cyclosporine 其一）即可，某種程度上定位為**生物製劑之前的中間選項**。
3. **互斥使用**：兩者**不能併用**，且 apremilast/deucravacitinib 用藥失敗後可以「升階」滿足生物製劑先行治療條件之一。
4. **管控強度較低**：生物製劑有非常詳細的**療效評估時間點/門檻、續用規則、暫緩續用（2年PASI≤10）、平行轉換**等一整套管控機制，apremilast/deucravacitinib 條文相對簡略，沒有這些規則（可能因為口服藥物成本與風險管控考量不同）。

## 四、考試速記重點

- **傳統分型 ↔ 健保分型對照**：慢性斑塊型/掌蹠型 → 走「照光+2種系統性藥物治療無效」路徑；**紅皮症型** → 走「cyclosporin治療無效後直接申請」路徑（可跳過照光）；**GPP** → 走**急性發作**專用路徑（4週制，與慢性型完全不同邏輯）。
- **PASI≥10** 是慢性型的核心量化門檻；GPP 用**體表面積>10%**取代（因膿疱型不適用 PASI）。
- **療效評估時間點多為 12 週（PASI25）**，例外：**ustekinumab/bimekizumab 16週**、**risankizumab 16週且門檻為 PASI75**。
- **Certolizumab 是唯一孕期/哺乳期不需停藥、甚至可優先申請的生物製劑**。
- **Spesolimab 專屬 IL36RN 突變的 GPP**，是唯一需要基因檢測佐證的乾癬生物製劑。
- **Apremilast/deucravacitinib 只涵蓋斑塊型、先行治療門檻較低、但沒有生物製劑那套詳細的療效評估/續用/暫緩續用規則**。
- 與 [PsA_分類標準.md](PsA_分類標準.md) 中 CASPAR criteria 對照：PsO 病灶（現有）在 CASPAR 給 2 分，是唯一給 2 分的項目。
