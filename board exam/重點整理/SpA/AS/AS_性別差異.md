# AS/axSpA 男女性別差異整理

## 資料來源

1. Kelly's Textbook of Rheumatology, Ch76 Axial Spondyloarthritis, "Sex Distribution" 專節。
2. Wright GC, Kaine J, Deodhar A. Understanding differences between men and women with axial spondyloarthritis. *Semin Arthritis Rheum*. 2020;50:687-694. [DOI 10.1016/j.semarthrit.2020.05.005](https://doi.org/10.1016/j.semarthrit.2020.05.005)

## 總表

| 分類 | 項目 | 男性 | 女性 |
|---|---|---|---|
| **流行病學** | AS（有影像學薦髂關節炎）盛行率比 | 較高，M:F 約 **2:1～3:1**（早期研究曾達10:1） | 較低 |
| | nr-axSpA 盛行率 | 兩性相近 | 兩性相近，部分研究更高 |
| | 發病年齡 | 較早 | 較晚（亞洲族群差異最明顯） |
| **免疫機轉／基因／賀爾蒙** | 周邊血 IL-17A、Th17 細胞 | **較高** | 較低 |
| | TNF-α、IL-18 | **較高** | 較低 |
| | IL-6 | 較低 | **顯著較高** |
| | 雌激素 | — | 動物模型顯示可能抑制 TNF-α，具保護作用（人類證據不一致） |
| **影像學結構進展** | 脊椎影像學進展（mSASSS）、新生 syndesmophyte | **較快、較多** | 較慢、較少 |
| | 薦髂關節影像學變化、MRI 發炎病灶 | **較常見** | 較少見 |
| | 進展部位 | 好發**腰椎** | 好發**頸椎**（常規工具較少評估，易被低估） |
| | 胸廓擴張度／occiput-to-wall距離 | 下降較明顯 | 相對較輕 |
| | Bamboo spine（融合型晚期病灶） | 較常見（舊研究） | 較少見 |
| | 影像進展危險因子 | 男性本身（OR 1.90）、吸菸、高CRP | 高 BASMI、追蹤期間使用 bisphosphonate |
| **臨床疾病活性與功能**（★與影像嚴重度方向相反） | BASDAI、ASDAS-CRP、patient global score | 較低 | **較高** |
| | 壓痛關節數、Maastricht enthesitis score | 較低 | **較高** |
| | 同等影像損傷下的功能障礙（BASFI） | 較輕 | **較重** |
| | 整體疾病負擔（症狀、附著點炎、工作生產力影響） | 較輕（脊椎活動度較差） | **較重**（但脊椎活動度較佳） |
| **關節外表現與周邊症狀** | 典型發炎性下背痛（IBP）為首發症狀 | **較常見** | 較少 |
| | 周邊／關節外症狀整體（廣泛性疼痛、骨盆痛、足跟痛、附著點炎、指趾炎、IBD、乾癬） | 較少見、較輕 | **較常見、較重**（廣泛性疼痛使診斷延遲時間增加一倍以上） |
| | 急性前葡萄膜炎（AAU） | **較常見** | 較少見 |
| | 葡萄膜炎（uveitis，整體不分型） | 頻率相近 | 頻率相近 |
| **共病** | 纖維肌痛症 | 少見（0～9.3%） | **明顯較常見**（10.5%～54.5%） |
| | 焦慮、憂鬱 | 較少 | **較常見**（憂鬱 25.7% vs 12.1%） |
| | 神經病變性疼痛 | 較少 | 較常見 |
| | 曾被誤診為精神身心症／纖維肌痛 | 較少（23.0% / 6.6%） | **較常見**（40.8% / 20.7%），延誤 AS 診斷 |
| **診斷延遲** | 平均診斷延遲（meta-analysis） | **6.5 年** | **8.8 年**（P=0.01） |
| | 延遲主因 | 症狀典型（IBP），易辨識 | 症狀不典型，常被誤診為 IBS、纖維肌痛、機械性下背痛 |
| **治療反應（TNFi）** | Etanercept 12週後各項改善 | **較佳** | 較差 |
| | TNFi 藥物存活期 | 較長（44.9個月），換藥率較低 | 較短（33.4個月），換藥率較高 |
| | nr-axSpA 對 TNFi 的 ASAS40 反應率 | 與 AS 相近（38% vs 45%） | **明顯較差**（nr-axSpA 17% vs AS 42%） |
| **懷孕相關**（女性特有） | 疾病活性 | — | 第二孕期 BASDAI 高於產後6週（3.97 vs 3.46） |
| | 妊娠結果 | — | 妊娠併發症、早產、小於妊娠週數胎兒風險較高 |

## 核心結論

男性以**結構性影像損傷**較重為主；女性則是**主觀疾病活性、功能障礙、生活品質、共病負擔、診斷延遲、TNFi治療反應**全面較差——打破「AS是男性疾病、女性病情較輕」的傳統迷思。
